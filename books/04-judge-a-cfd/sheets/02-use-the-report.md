# Use the report

One report, one decision. Write the decision before you read the colors.

Purpose, copied from the report. If it is missing, write "purpose not stated." Do not invent a kinder sentence.

Decision this report is allowed, one only: design comparison / built hall / operating cause / change after a unit stops

The other three: not this report

Scene, four lines: whose heat, which units are on, how the aisles are contained, setpoints in the model. If these disagree with the input list, two reports are in one file. Stop.

IT block, separate: Y / N

Air-unit block, separate: Y / N

Each plot names its plane: Y / N. If N, set the plot aside. It is not evidence.

Comparison written before the run: quantity, limit, document edition. The color bar is not the limit.

Result: held / did not hold / not compared

Liquid-test sheet from the third book: attached / not attached / this report does not prove the liquid side

Recommendation: rerun with the changed input / not rerun. Not rerun is not a conclusion.
