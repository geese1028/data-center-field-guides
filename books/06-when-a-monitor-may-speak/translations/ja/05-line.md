# 5. 閾値線・滞留時間（Dwell）・チャタリング防止

## テレメトリの完全性と「沈黙（SILENT）」の原則

データセンターの監視制御システム（BMS / EPMS / SCADA / DCIM）において、**ヒステリシス（不感帯幅 $H = T_{\text{trip}} - T_{\text{clear}}$）およびオン・オフ遅延時間（$\tau_{\text{on}}, \tau_{\text{off}}$）の数学的設計**は誤報や見逃しによる重大障害を防ぐ最前線の防벽である。画面上のトレンド線や緑色のステータスアイコンは物理現象そのものではなく、通信経路と変換ロジックを経由した「主張」に過ぎない。

![5. 閾値線・滞留時間（Dwell）・チャタリング防止](../figures/fig-02-threshold-deadband-and-dwell-filter.png)

$$V(t) \ge T_{\text{high}}$$

すべての監視ポイントは、センサノイズ標準偏差 $\sigma_n$ に対する $H \ge 4\sigma_n$ の確保によるアラームチャタリング（Flapping）の完全抑止を厳格に満たさなければならない。値（$V$）、同期済みUTCタイムスタンプ（$t_{\text{UTC}}$）、物理ハードウェアURI（$\text{URI}_{\text{source}}$）、および品質ビットマスク（$Q$）の4要素のうち1つでも欠落・破損・陳腐化（Stale）している場合、そのポイントは即座に**沈黙（SILENT）**しなければならない。

> *「出所が証明できないポイント、時刻が同期されていないポイント、あるいは品質フラグが GOOD でないポイントは、オペレータを呼んではならず、制御ループを動かしてはならず、インシデントを閉じてはならない。」*

## 信号品質・ヒステリシス・トポロジー抑制の定量基準

現場のセンサーから上位データベースに至るパイプラインでは、スケーリング係数はただ1箇所でのみ適用し、常にADCの生カウント値（Raw Integer Counts）を並行保存する。また、アラームチャタリング（Flapping）やアラーム洪水（Alarm Flood）を防ぐため、以下の数学的パラメータをMaster Point Sheetで強制する。

$$V(t) \le T_{\text{high}} - \Delta_{\text{deadband}}$$

| 監視ガバナンス項目 | 数学的・物理的定義 | 合格基準（許容エンベロープ） | 強制隔離・拒絶トリガー |
| :--- | :--- | :--- | :--- |
| **ポイント4要素タプル** | $P = \{V, t_{\text{UTC}}, \text{URI}_{\text{source}}, Q\}$ | 物理端子台までのP&IDタグ完全一致 | 未マップ孤児ポイントまたは `Q != GOOD` |
| **時刻同期精度（SOE / テレメトリ）** | IEEE 1588 PTP / Stratum-1 NTP | 保護継電器 $\le 1\,\text{ms}$、熱水理 $\le 100\,\text{ms}$ | DB到着時刻によるソース発生時刻の上書き |
| **陳腐化（Stale）判定時間** | $t_{\text{now}} - t_{\text{last\_good}} > 3 T_{\text{poll}}$ | ゼロ次ホールド解除・即座に `0x01 STALE` 遷移 | 通信断中に前回正常値を緑色で表示し続ける設定 |
| **ヒステリシスと滞留時間** | $H = T_{\text{trip}} - T_{\text{clear}} \ge 4\sigma_n$ | デバウンス時間 $\tau_{\text{on}}, \tau_{\text{off}}$ の明示設定 | 単発ノイズでの誤発報（$\lambda_{\text{alarm}} > 6\,\text{h}^{-1}$） |

さらに、冷却塔や熱交換器などの物理プラントにAI/MLモデルや合成スコアを適用する場合、熱力学の単調性制約（$\partial T_{\text{leave}} / \partial N_{\text{fan}} \le 0$）および直列系の最小値論理（$S_{\text{plant}} = \min_k s_k$）をハードウェアPLC層で強制し、単発のスパイクノイズと真の物理的異常遷移を峻別するデバウンスフィルタの設計を徹底せよ。

## 現場ループ受入試験（SAT）と日常監査プロトコル

監視システムの受入は、会議室でのデモ画面ではなく、現場の物理端子台における実信号注入と断線テストによってのみ成立する。

$$\text{Trigger Condition}: \quad \forall t \in [t_0, \, t_0 + t_{\text{dwell}}], \quad V(t) \ge T_{\text{high}}$$

1. **物理ループ検証**: センサー端での4–20 mA断線（$< 3.6\,\text{mA}$）および短絡（$> 21.0\,\text{mA}$）を発生させ、3ポーリング周期以内にコンソール上で `BAD / FAULT` が表示されることを確認する。
2. **親子トポロジーと保守シェルビング**: 上流遮断器トリップ時に下流の派生アラートが親イベントへ集約されること、および保守ウィンドウの抑制タイマーが失効時刻に自動解除されることを検証する。
3. **翌朝の精算レビュー**: 毎朝のシフト交代時に、過去24時間のStaleポイント、Shelvedポイント、およびForcedオーバーライドを全件監査し、放置された盲点をゼロにする。

$$\text{If } N_{\text{transitions}} \ge N_{\text{flap\_max}} \quad \text{within rolling window } W_{\text{flap}}, \quad \text{engage FLAPPING\_LATCH}$$

## 記録すべき決定事項

- 対象ポイント群の監査焦点（ヒステリシス（不感帯幅 $H = T_{\text{trip}} - T_{\text{clear}}$）およびオン・オフ遅延時間（$\tau_{\text{on}}, \tau_{\text{off}}$）の数学的設計）とハードウェアURI・P&IDタグの台帳登録。
- 定量基準（センサノイズ標準偏差 $\sigma_n$ に対する $H \ge 4\sigma_n$ の確保によるアラームチャタリング（Flapping）の完全抑止）に基づく時刻同期・スケーリング・品質ビットマスクの実機検証。
- ヒステリシス幅 $H \ge 4\sigma_n$、滞留時間 $\tau_{\text{dwell}}$、および親子トポロジー抑制ルールの設定記録。
- 禁止事項（単発のスパイクノイズと真の物理的異常遷移を峻別するデバウンスフィルタの設計）の遵守確認とMaster Point Sheetへの署名。
