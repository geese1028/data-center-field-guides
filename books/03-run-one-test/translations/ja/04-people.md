# 4. 人員配置とガバナンスの環

明確に指定された個人の役割分担を欠いた液冷検証は、瞬く間に無秩序な集団討論へと堕落する。一般的な作業要領書は網羅的なRACIマトリクス（実行責任、説明責任、相談先、報告先）を要求する。しかし、稼働中または稼働直前のデータホールという極めて緊迫した環境において、その構造は3つの明確な商業主体と5つの具体的な技術機能へと純化されなければならない。

**3者によるガバナンストライアングル**

| 施設所有者 （顧客／ハイパースケーラー運用） | 実施に立ち会い、逸脱を承認し、最終証明書ティアに署名する。 自ら工具を操作することはない。 |
| :--- | :--- |
| 検証責任主体（CxA） （独立試験機関） | Cx計画とスクリプトを作成し、校正を管理し、手順を指揮し、 データを記録し、是正項目を監査する。自らの欠陥を自ら閉じない。 |
| 施工事業者 （元請／機械／電気工事） | 竣工図を提供し、ブレーカーやバルブを操作し、許可のもとで パンチリストの物理的修復を実施する。 |

## 3つの商業的当事者

これら3者の境界は厳格に執行されなければならない。
- **施設所有者**: 最終的な商業的権限を保持する。重要な運用手順に立ち会い、レベル4およびレベル5の完了証明書に署名する。所有者の代表者がアイル（通路）に立ちながら現場スクリプトを書いたり、バルブのハンドルを回したりしてはならない。
- **検証責任主体**: コミッショニング計画書および試験スクリプトを作成し、実施シーケンスを指揮し、すべての測定に立ち会う。マスタ是正項目リストを管理し、独立した二次検査を経ることなく自らのパンチリスト項目に承認印を押すことは決してない。
- **施工事業者**: 承認図書および竣工図面を提供し、ブレーカーに通電し、手動隔離バルブを操作し、パンチリストで特定された欠陥を物理的に修復する。

単一のエンジニアリング企業が施工とコミッショニングの双方を請け負う場合、その利益相反はコミッショニング計画書の1ページ目に公式に文書化されなければならない。施工者と検証立会人が同一の組織系統に属している場合、互いに直属関係にない別個の人員が各タスクを実施・立会しない限り、プロジェクトガバナンスは本質的に損なわれる。

## 5つの技術的役割

現場の試験チーム内では、5つの明確な技術機能に人員を割り当てなければならない。これらは機能的な責任範囲を表すものであり、必ずしも5名の独立した人員を要求するわけではない。小規模な試験では、1名の熟練技術者が複数の分野を兼任することもある。しかし、いかなる個人も、自らが物理的に実施した運用作業の唯一の立会人を務めることは許されない。

**5つの技術的役割機能**

| 1. 試験責任者 （Test Lead） | 承認された試験ウィンドウを管轄し、主張を執行し、手順タイミングを指揮し、 連絡を統括し、熱負荷を投入する唯一の権限を保持する。 |
| :--- | :--- |
| 2. 電気主任技術者 （Electrical PE） | LOTO（施錠・標識）を指揮し、メガー絶縁および接地試験を実施し、相回転を確認し、 上流PDUのトリップ曲線を監視し、赤外線熱画像スキャンを実施する。 |
| 3. 機械主任技術者 （Mechanical PE） | 二次側流体ループを管理し、耐圧保持およびエア抜きを監督し、CDUポンプ曲線を 監査し、クイック継手のシール健全性を追跡する。 |
| 4. 計装制御技術者 （Controls PE） | BMSテレメトリと校正済み現場計器を照合し、Modbus/BACnetレジスタを検証し、 ハードウェア警報障害を注入してトリップロジックを検証する。 |
| 5. 試験技術員 （Test Tech） | 負荷装置の物理的接続を管理し、計器校正ログを確認し、すべての測定値を マスタシートにインクで記録し、アーカイブを維持する。 |

### 1. 試験責任者（Test Lead）
承認された試験ウィンドウを管轄し、施設運用チームと調整し、手順の移行を指揮し、承認されたスクリプト改定番号に試験が厳格に準拠していることを担保する。試験責任者は自ら計器を手にしてはならない。その注意力はシステムの安定性、手順遵守、および全体的な安全性に集中されなければならない。

### 2. 電気主任技術者（Electrical Engineer）
ロックアウト／タグアウト（LOTO）プロトコルを指揮し、静的なメガー絶縁抵抗試験を実施し、回転計で相順を検証し、上流ブレーカー設定を監査し、すべての高電流バスバー、ケーブル、接触器に対して熱画像診断を実施する。相回転は安全上極めて重要な電気パラメータである。相順が反転していると、キャンドモータ構造の二次側ポンプが逆回転し、激しいキャビテーション、揚程の未発生、および急速なスラスト軸受の破壊を引き起こす。

### 3. 機械主任技術者（Mechanical Engineer）
流体経路を監督する：二次側配管、ホースの敷設、クイック継手カップリング、エア抜き、および冷却液の化学組成。耐圧試験記録を確認し、膨張タンクの窒素封入圧力を監視し、基準ポンプ特性曲線の測定を監督する。

### 4. 計装制御技術者（Controls Engineer）
中央監視システム（BMS）およびCDUのタッチパネル（HMI）の表示値を、校正された現場標準計器と突き合わせて照合する。レジスタアドレスを確認し、センサーオフセット校正を検証し、模擬警報試験（二次側低流量、高温、液漏れ検知など）を統括する。単に別の画面の値をそのまま表示しているだけのBMS画面は、有効な制御検証とは認められない。

### 5. 試験技術員（Test Technician）
梱包明細書と物理機器を照合し、計器の校正証明書を監視し、現場記録シートを管理する。1名の技術員が校正済み計器で測定を行い、もう1名の技術員が即座にその数値をインクで記録する。記録シートを紛失した場合、機械プラントがいかに完璧に動作していたとしても、その日の試験は無効となる。

## 熱投入の指揮権限と全員一致の非常停止権限

動的試験中における権限の配分は、2つの絶対的な規則に従う：

1. **単一の指揮権限**: 熱負荷の投入を指示できるのは、現場で指名された**唯一の個人**——試験責任者（Test Lead）に限られる。その氏名は、最初のブレーカーを投入する前にシート3にインクで記録される。所有者、施工業者、または見学中のベンダーからの口頭の提案によって負荷ステップを開始することは許されない。
2. **全員一致の非常停止権限**: 非常停止（E-Stop）を発令する権限は、**データホール内にいるすべての人員**に帰属する。この権限は絶対的かつ譲歩不能であり、試験責任者の事前承認を必要としない。技術員がクイック継手からの漏れを発見した場合、電気見習いが異臭を感じた場合、あるいは見学者が過渡挙動に不安を覚えた場合、直ちに停止を叫ぶことができる。議論の余地なく、システムは即座に停止される。

**指揮権限と停止権限のガバナンス**

| 熱負荷の投入を指揮できる者 | 非常停止を発令できる者 |
| :--- | :--- |
| • 現場で指名された厳格に「1名」の個人。 | • 室内にいる「すべての人員」。 |
| • 最初のステップの前にシート3にインクで記録。 | • 合意形成や事前承認は一切不要。 |
| • 前提ゲートがすべて署名済みであることを確認。 | • すべての工期日程およびプロジェクト費用に優先。 |
| • 承認されたスクリプト手順の範囲内でのみ操作。 | • 組織の指揮命令系統を完全に超越。 |

## キックオフ会議のガバナンス

これらの責任範囲は、現場動員の前に開催されるコミッショニング・キックオフ会議において公式に確立される。試験の実施または立会いを認可されたすべての人員の出席が義務付けられる。

キックオフ会議は、以下の5つの譲歩不能な成果を達成しなければならない：
1. すべての機能的役割が、24時間連絡可能な連絡先とともに指名された個人に割り当てられること。
2. 具体的な試験スクリプトの文書番号および承認されたリビジョン番号が凍結されること。
3. 「実施承認済み（Approved for Execution）」文書ステータスの定義が公式に確立されること。「草案（Draft）」、「審査中（Under Review）」、または「参考情報（Informational）」ステータスのスクリプトを現場で実行することは法的に禁止される。
4. 明確な読み書きアクセス権限を備えたマスタ是正項目ログのリポジトリが確立されること。
5. 電力供給遮断担当、防災設備技術者、および機械系漏洩封じ込め担当を含む、緊急エスカレーション系統が確認されること。

## 試験開始前に記録すべき決定事項

- 兼任の有無を明記した、参加する3つの法人組織の特定。
- 5つの技術的役割に割り当てられた個人の氏名、連絡先電話番号、および技術者資格証番号。
- 熱負荷の投入を指示することが認可された、指名された単一の個人。
- 現場のすべての人員が無条件の非常停止権限を保持していることの再確認。
- 現場での試験実施を認可する正式なスクリプト承認ステータス。
