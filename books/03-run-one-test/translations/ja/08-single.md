# 8. 一度に1つのシステム

熱負荷のもとで複数の相互接続されたシステムを同時に動かす動的検証は、後に行われる統合段階の作業である。本段階は、隣接するすべてのシステムを静止させた状態で、単一の機器をスタンドアロンの試験スクリプトで定義された厳密な動作ロジックに従って個別に検証することに特化する。

グローバルなコミッショニング体系において、これは**レベル4機能性能試験（FPT: Functional Performance Testing）**に該当する。数メガワット規模の熱ストレスに晒す前に、個々の機器の自律保護、制御バルブの調整ループ、および物理的な警報機能を検証する。機器がデータホール内に物理的に設置されているからといって、単一システムの試験をレベル5統合システム試験に混入させることは重大な文書管理上の誤りである。

## 自律的冷却液分配装置（CDU）の検証

冷却液分配装置（CDU）は、施設側一次冷却水系統（FWS）とラック側二次技術冷却系統（TCS）を物理的に分離する極めて重要な水力学的インターフェースである。負荷装置によって熱負荷が投入される前に、CDUはスクリプト04およびスクリプト05に基づいて自律的な流体循環制御能力を証明しなければならない。

### 1. ポンプ起動、インバータ（VFD）変速制御、およびソフトスタート
一次側施設ループを隔離した状態で、CDUの二次側ポンプに通電する。制御された起動および停止サイクルを実施する：
- インバータ（VFD）が、設定された加速曲線（通常10〜15秒）に沿ってキャンド遠心ポンプを滑らかに増速させ、電流スパイクや水力サージを発生させないことを確認する。
- 手動周波数オーバーライドの検証：VFDを常用運転範囲（30.0 Hz 〜 50.0/60.0 Hz）にわたって手動操作し、モータ電流、力率、および軸受振動シグネチャを記録する。
- **冷態ポンプ特性曲線と流体密度シフトの把握**: 冷態単体試験における水力学的基準測定において、二次側熱媒体（PG25：プロピレングリコール25%水溶液）の密度特性を厳密に考慮しなければならない。冷態 20.0°C におけるPG25の密度は ρ = 1030 kg/m³ であるのに対し、温態運転時（45.0°C）には ρ = 1018 kg/m³ へと低下する。この流体密度および粘度のシフトは、ポンプの所要軸動力、発生差圧、および質量流量の換算に直接影響を与えるため、冷態単体FPTの段階で基準揚程・流量特性を正確にプロットしておかなければならない。

### 2. N+1二次側ポンプの自動切替（オートフェイルオーバー）
最新の高密度CDUは、N+1二次側ポンプ構成（例：定格容量100%のポンプ2台、P-1A主機およびP-1B待機機）を採用している。自動切替ロジックは、物理的なトリップシミュレーションによって検証されなければならない：
- ループを設計流量で運転し、ポンプP-1Aを100%定格速度で運転する。
- P-1Aインバータの制御電源ブレーカーを開放するか、またはデジタル障害入力をトリガーして電気的トリップを模擬する。
- **受入判定基準**:
 - ローカルCDUコントローラが故障を検知し、重大警報を記録し、≤ 500 ms 以内に待機ポンプP-1Bへ起動指令を発行すること。
 - 待機ポンプP-1Bが全速まで加速し、≤ 1.5 秒 以内に二次側差圧を復帰させること。
 - ポンプP-1Aの吐出側逆止弁（チェックバルブ）が激しいウォーターハンマーを伴わずに確実に着座すること（水撃圧ピークは ± 50 kPa 以内）。
 - 二次側ループ差圧が最小キャビテーション限界圧（100 kPa）を下回らず、負荷装置への連続通流を維持して誤った熱停止を誘発しないこと。

### 3. 電動温度制御調整弁（TCV）の追従性
一次側ループの温度制御弁（TCV-101、通常は電動アクチュエータ付き比例制御2方弁または3方弁）は、プレート熱交換器（PHE-101）を通過する施設一次側冷水流量を調整し、二次側供給温度を維持する：
- 0–10V DCまたは4–20 mAの校正信号発生器を用いて、アクチュエータを全ストローク範囲にわたって駆動する。
- メーカー承認図面と照合して、全開および全閉動作時間（通常 τ ≤ 30 秒）を検証する。
- 制御電源喪失時のフェイルセーフ位置を検証する：施設の設計意図に従い、TCV-101が機械的スプリングによって全開（一次側100%通水）するか、あるいは直前位置を保持することを確認する。
- 弁座漏洩の健全性確認：弁全閉指令時、一次側流量がゼロに低下することを確認する（漏洩等級ANSI/FCI 70-2 クラスIV以上）。

### 4. 二次側差圧バイパス弁（BPV）
二次側往水・還水ヘッダー間に設置された差圧調整バイパス弁（BPV-201）を点検する。下流のマニホールド調整弁が絞られた際、BPVが滑らかに開動作してポンプ揚程を一定に保ち、インペラの締切運転を防止することを確認する。

## 中央監視（BMS）テレメトリと現場計器のポイント・ツー・ポイント照合

中央監視システム（BMS）画面やCDUのローカル操作パネル（HMI）に表示されている数値が物理的現実を反映していると決して思い込んではならない。プロジェクト主張で定義されたすべてのテレメトリ監視点は、校正された現場標準計器と突き合わせて物理的な照合を受けなければならない：

**ポイント・ツー・ポイント・テレメトリ校正監査**

| テレメトリ測定点 | BMS／HMI表示値 | 現場校正標準計器 | 許容偏差帯 | 監査判定 |
| :--- | :--- | :--- | :--- | :--- |
| 二次側往水温度 | 40.12 °C | 40.08 °C (PT100) | +/- 0.30 K | 合格 (PASS) |
| 二次側還水温度 | 50.25 °C | 50.15 °C (PT100) | +/- 0.30 K | 合格 (PASS) |
| 二次側流量 | 115.4 m³/h | 116.1 m³/h (超音波) | +/- 2.0% | 合格 (PASS) |
| 二次側供給圧力 | 285.0 kPa | 282.5 kPa (圧力計) | +/- 10.0 kPa | 合格 (PASS) |
| 二次側還水圧力 | 115.0 kPa | 118.0 kPa (圧力計) | +/- 10.0 kPa | 合格 (PASS) |
| 膨張タンク液位 | 68.0 % | 67.5 % (覗き窓) | +/- 3.0 % | 合格 (PASS) |

不一致が許容値を超える場合、センサーオフセットを再校正するか、センサー自体を交換しなければならない。ドリフトしたセンサーに合わせて受入許容帯を都合よく広げてはならない。

## 物理的ハードウェアによる警報注入試験

警報は、物理的なハードウェアへの直接注入によって検証されなければならない。設定ファイル内のソフトウェア設定値を変更したり、エンジニアリング端末でビットを反転させたりして警報を模擬することは断じて認められない。ソフトウェアシミュレーションは、ソフトウェアが変数を読み取れることを証明するだけであり、物理センサー、現場配線、およびリレー回路が現実の環境で動作することを何ら証明しない。

スクリプト06に従って物理警報試験を実施する：
- **二次側低流量警報**: 二次側往水ヘッダーの手動隔離弁を徐々に絞り、電磁流量計が低流量トリップ閾値を下回るまで流量を低下させる。CDUコントローラが現場の警報ブザーを鳴らし、赤色回転灯を点灯させ、上位BMSへ緊急Modbus/BACnet警報を発信し、負荷装置のインターロックリレーを遮断することを確認する。
- **膨張タンク低液位警報**: 膨張タンクの磁気フロートスイッチのテストレバーを手動で押し下げ、最低液位遮断状態にする。CDUがオペレータに警告を発し、電気ヒータをロックアウトし、自動補給水ポンプへ起動指令を発行することを確認する。
- **二次側液漏れ検知警報**: CDU配管接続部の下部トレイおよびマニホールドトレイに沿って配置された外部液漏れ検知ロープに、5 mLの脱塩水を滴下する。液漏れ検知器が < 2.0 秒 以内に作動し、正確な漏洩位置距離を表示し、上位BMSへ自己保持型の重大警報を送信することを確認する。

**警報に対する3つの監査判定結果**

| 1. 合格（PASS） | センサー部で警報を物理的に注入；現場警報器が作動；BMSが正確な時刻と記述で イベントを記録；インターロックが正常に遮断動作を完了。 |
| :--- | :--- |
| 2. 不合格（FAIL） | 警報を注入したがセンサーが未検知；応答遅延が許容値超過；インターロックリレーが 遮断に失敗；直ちにマスタ是正項目リストへ記録。 |
| 3. 実演不能（NOT DEMONSTRATED） | 機器側に警報を発するための物理センサー、配線、またはソフトウェアレジスタが 欠落。シート2に「実演不能」と明記。「合格」と記録することは厳禁。 |

施工時にハードウェアが省略されたために特定の警報を実演できない場合、シート2の該当行には **実演不能（NOT DEMONSTRATED）** と記録しなければならない。「ベンダーがロジックは入っていると約束したから」という理由で未検証の警報を「合格」と記録することは、重大な職務倫理違反である。

## レベル4前提条件ゲート

レベル4機能性能試験は、すべての単体システムスクリプトが完全に実行され署名されたときに終了する。不合格となった警報注入、未校正のセンサー、またはハンチングを起こす制御バルブは、複数システムの熱試験へ進む前に正式に解消され、再試験されなければならない。

## 試験開始前に記録すべき決定事項

- CDUポンプのソフトスタートおよびVFD周波数追従ログ。
- 立会されたN+1二次側ポンプ自動切替の過渡記録（切替遅延 ≤ 1.5 s）。
- すべての重要監視点にわたるポイント・ツー・ポイント・テレメトリ校正ログ。
- 合格、不合格、および実演不能の全項目を注記した物理警報注入ログ。
- レベル5を開放する前に、すべてのレベル4前提条件が署名・完了していることの確認。
