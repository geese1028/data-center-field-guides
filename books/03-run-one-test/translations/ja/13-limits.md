# 13. 本プロジェクトが所掌しないもの

本書は、液冷工学のあらゆる領域を網羅した百科事典へと無制限に拡大解釈しようとする者たちによって、必ずや誤用される運命にある。ここで、プロフェッショナルとしての明確な境界線を引いておかなければならない。

コミッショニング検証プロジェクトは、その境界が極めて鋭敏に定義されているときにのみ、法的および工学的な権威を維持できる。検証スコープを現場で場当たり的に隣接する工学領域へと拡大することは、欠陥のある試験、責任の希釈、そして深刻な契約紛争を生み出すだけである。

```

| 明示的な否定的スコープ境界（非所掌範囲） |
+------------------------------------+---------------------------------------------------------------+
| 本プロジェクトが検証するもの | 本プロジェクトが所掌せず、所掌できないもの |
+------------------------------------+---------------------------------------------------------------+
| • 模擬熱負荷の熱移動・熱交換性能 | • 第1巻の範囲: 負荷装置の設計・研究開発・製造品質保証 |
| • 二次側ポンプ特性曲線のベースライ | • 第2巻の範囲: テレメトリ数学、異常検知アルゴリズム |
```

## 個別の境界線

### 1. 負荷装置自体の設計は所掌しない（第1巻）
本検証は、現場に搬入された液冷負荷装置が、第1巻の工学規律のもとですでに完全な工場受入試験、筐体絶縁検証、および流量ベンチ測定を完了していることを前提としている。内部のろう付け接合部から漏洩していたりサイリスタ制御が不安定であったりする未検証の試作機として負荷装置が現場に届いた場合、コミッショニング責任者はその接続を拒否しなければならない。現場のコミッショニングキャンペーンを、即席の機材R&D実験室に変質させてはならない。

### 2. テレメトリの統計的解釈は所掌しない（第2巻）
本検証が記録するのは、未加工の物理測定値と立会タイムスタンプである。速報（フラッシュレポート）のアルゴリズム的精算、変化点解析（FLOC／Focus）、およびデータ整合性の統計的検証は、第2巻の工学領域に属する。BMSモニタ上の穏やかに見える熱曲線は、未加工データファイルが厳格な分散確認および品質ビットマスク監査を通過するまで、合格とは認められない。逆に、顧客の役員が見学しているからといって、現場試験チームがその場で甘い独自の受入基準を捏造してはならない。

### 3. 施設全体の設備設計（MEP設計）は所掌しない
検証チームの任務は、承認された設計基準書（BOD）と実在の物理プラントを照合・検証することである。施設の中央熱源チラープラントの容量不足によって二次側供給温度が維持できなかったり、二次側ヘッダー管径の不足によって摩擦損失が過大であったりした場合、その不合格は施工逸脱または設計欠陥である。検証チームは物理的な性能をインクで冷徹に記録するのみであり、現場で配管を再設計したり、施工が「十分に近い」などと慰めの言辞を弄してはならない。

### 4. 流体化学および冶金工学は所掌しない（第8巻）
検証チームは、試験の前提条件として基本的な流体パラメータ（屈折計によるグリコール濃度 ± 0.5%、濁度、および初期pH）を監査する。しかし、銅製コールドプレートとアルミニウム製マニホールドの間の長期的電食（ガルバニック腐食）速度や、殺菌剤の分解曲線を認証するものではない。それらの長期的な化学的検証は、第8巻の規律に属する。

### 5. 半導体計算インフラは所掌しない
液冷負荷装置は、アクセラレータ計算ラック（NVL72級フットプリントなど）の全体的な電気消費と水力学的圧力損失を模擬する。半導体マイクロプロセッサ、光トランシーバ、またはNVLinkネットワークファブリックを含んでいるわけではない。120 kWの熱ステップで安定して稼働した負荷装置は、冷却ループが120 kWの熱を抜去できることを証明したにすぎない。本番の計算ラックが正常にブートするか、大規模ニューラルネットワークを学習できるか、あるいはシリコンのサーマルスロットリングを回避できるかを証明したわけではない。

### 6. 次のデータホールは所掌しない
本書で確立された手順ワークフロー——12の成果物の順序、6段階の階層構造、5つの機能的役割、および7枚のマスタシート——は、あらゆるミッションクリティカル施設に普遍的に適用可能である。しかし、具体的な数値パラメータ（正確なkWステップ、保持時間、流量許容差、および最高運転温度）は、現に有効な特定の契約図書に固有のものである。あるデータホールの数値を独自の工学的分析なしに別の施設へコピー＆ペーストすることは、本フィールドガイドを無検証の模倣作業へと堕落させる行為である。
