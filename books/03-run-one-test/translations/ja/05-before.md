# 5. ウィンドウ前の数週間

データホールにおける通熱試験ウィンドウは、通常わずか数日間にすぎない。コミッショニングプロジェクトの本質は、その数日間を取り巻く激動の準備の1ヶ月間にある。熟練のコミッショニングエンジニアは、この準備の1ヶ月をプロジェクトの決定的な段階と位置づけ、通熱ウィンドウはその規律ある成果を確認する立会検証にすぎないと捉える。

事前の周到な現場調査を行うことなく見知らぬホールへ負荷装置を搬入した試験チームは、通熱ウィンドウの前半を、不足している変換アダプタの特定、上流PDUブレーカーのトリップ原因究明、あるいは未確認の床耐荷重をめぐる議論に浪費することになる。

**動員前のマイルストーンタイムライン**

| T - 4 週間 | 現場アクセスおよび構造調査：搬入経路、荷物用エレベータ容量、床積載荷重（kN/m²）、 電気タップボックス、およびマニホールド接続口の監査。 |
| :--- | :--- |
| T - 3 週間 | 校正および計装監査：電力計、超音波流量計、PT100浸漬プローブ、熱画像カメラの ISO/IEC 17025校正証明書を確認・検証。 |
| T - 2 週間 | 緊急時対応およびMOP承認：化学薬品漏洩封じ込め、非常停止手順、および所有者・ 施設運用部門による通電・作業許可証の署名締結。 |
| T - 1 週間 | 現場受入準備およびブランクシート：スクリプト改定の凍結、マスタシートの印刷、 試験機材の現場配置、二次側ループの洗浄および静的耐圧試験完了。 |

## 装置台数と予備機戦略

主張の一文が正式に署名されるまで、機材のレンタル発注を確定してはならない。汎用的なテンプレートから負荷装置の台数を算出すると、誤ったトポロジーを発注するリスクを冒す。認定された主張から直接、必要機材数を計算すること：
- **液冷熱負荷容量**: 二次側マニホールドで模擬される総kW数（例：1.2 MWの列に対して120 kWの負荷装置10台）。
- **空気側排熱**: 主張がホワイトスペースの熱的安定性を含んでいる場合、コールドプレートから漏れた15%〜20%の対流空気負荷を、専用ファン付き負荷装置コイルまたは補助エアヒータで処理できるようにすること。
- **N+1コールドスペア戦略**: 常に1台の追加負荷装置、予備の高圧ホース、および予備のクイック継手を現場に手配しておくこと。輸送中の制御基板故障や衝撃損傷は物流の現実である。検証済みの予備機を現場に常備しておくことが、数百万ドル規模の試験ウィンドウの遅延を防ぐ。

## 現場アクセスおよび構造事前調査

現場調査は重要な工学ゲートであり、非公式な散歩ではない。以下の4つの必須事項を検証しなければならない：

1. **搬入経路と開口寸法**: 搬入口からデータホールまでのルートを機材が物理的に通過できるか。荷物用エレベータのドア開口寸法、エレベータの積載重量制限、廊下の旋回半径、およびスロープの勾配を実測する。重量のある負荷装置のキャスターを、未完成のフロアタイルの継ぎ目や保護されていないフリーアクセスフロアの上に転がす必要がないことを確認する。
2. **床の構造積載荷重**: 負荷装置、冷却液で満たされたマニホールド、および作業員の合計重量が、床の設計積載荷重（重設備データホールでは通常 12.0 kN/m² 〜 15.0 kN/m²）を超過しないことを確認する。構造設計者の捺印図面と照合し、フリーアクセスフロアの支持脚（ペデスタル）、ストリンガーのボルト締結、および耐震ブレースを検査する。
3. **電気インフラの受電タップ**: 試験対象の列に給電する配電ユニット（PDU）または架空バスダクトのタップボックスを検査する。ブレーカーのフレームサイズ、引外しトリップ設定（電子式LSIGパラメータ）、相ピン配列、およびレセプタクルの形状を確認する。段階的な負荷投入時に上流の受電設備ブレーカーがトリップするのを防ぐため、負荷装置の突入電流および定格全負荷電流を上流の保護協調曲線と比較・照合する。
4. **水力インターフェース**: 二次側の往水・還水マニホールドの接続口を物理的に点検する。配管径、隔離バルブの型番、およびクイック継手（ダンフォス・ハンセンFD83シリーズやISO 16028フラットフェイス継手など）の形状を記録する。継手に互換性があると思い込んではならない。オスメスの嵌合、ネジピッチ、およびOリングのエラストマー適合性（水／グリコールループにはEPDMを使用し、高温グリコール系に標準のBuna-N／ニトリルゴムを決して使用してはならない）を検証する。

アクセス不能なエリア、未検証のバルブ、または未文書化の回路ブレーカーを記録した調査報告書を正式に発行しなければならない。未文書化の物理インターフェースは、機器が倉庫を出発する前に正式な動員前逸脱事項として解消されなければならない。

## 計測器トレーサビリティと校正基準

すべての検証測定は、現場計測器の校正の健全性に法的に依存している。未校正の計器で記録された測定値は、単なる未検証の個人的意見にすぎない。

試験キャンペーン中に使用されるすべての現場計測器は、試験ウィンドウの全期間を通じて有効な、追跡可能な校正証明書（ISO/IEC 17025認定）を保持していなければならない：

**最低限要求される計測器精度基準**

| 計測器分類 | 要求精度基準 | 必須現場配備仕様 |
| :--- | :--- | :--- |
| 電力品質アナライザ 超音波流量計 浸漬型温度プローブ 微差圧伝送器 赤外線サーモグラフィ | クラス0.2（0.2% FS） クラス0.5（±0.5%） 4線式 PT100 1/3 DIN ±0.1% フルスケール NETD < 40 mK; ±1 K | 校正済み三相有効電力＆高調波（THD）アナライザ。 2チャンネル伝搬時間差クランプオン式；10D/5D直管. ±0.05 K校正；高熱伝導ペースト塗布。 校正済みピエゾ抵抗式トランスミッタ。 校正済み焦点面アレイ（最小384x288解像度）。 |

プロジェクト期間中に計測器の校正有効期限が切れた場合、直ちに供用を中止し、校正済みのバックアップ計器と交換しなければならない。期限切れの証明書は、その瞬間以降に記録されたすべてのデータを法的に無効化する。

## 緊急時対応計画（EAP）と現場許可証

最初の機械的接続を行う前に、緊急時対応計画（EAP: Emergency Action Plan）を全当事者で審査し、署名を取り交わさなければならない。計画は以下の4つの具体的なシナリオに対する対応手順を明記しなければならない：
1. **二次側冷却液の漏洩／流出**: 即座のポンプ隔離、真空回収、流出防止ソックスの配置、および環境対策報告。
2. **電気フラッシュ／絶縁破壊**: 上流PDUの即時非常トリップ、アークフラッシュ境界の退避管理、および救護エスカレーション。
3. **制御不能な熱暴走**: 負荷装置の即時遮断シーケンス、CDUバイパスバルブの強制全開、および施設側冷水の最大流量指令。
4. **人命安全・防災警報（VESDA／ガス消火連動）**: 避難経路の確保、人員の点呼確認、および自動EPO回路との連動確認。

工具を動員する前に、必要なすべての作業許可証を取得しなければならない：
- **通電許可証（Energization Permit）**: ブレーカーを投入し、仮設負荷に通電するための認可。
- **火気使用許可証（Hot Work Permit）**: 溶接、はんだ付け、または過度な熱応力試験が予定されている場合に必須。
- **機械配管作業許可証（Mechanical Fluid Permit）**: 施設側液冷ループに接続し、エア抜きを行い、流体を循環させるための認可。

## 事前印刷マスタシートと日次シフト報告

現場に到着する前に、すべての白紙マスタ記録シート（第16章）を設計・印刷しておくこと。各シートには、スクリプトステップ番号、計測器ID、および予想される数値許容帯が明記され、現場での物理測定値を記入するための空白セルが用意されていなければならない。試験開始後に記録シートを作成すると、パラメータの記入漏れや都合の良いデータ抽出が確実に発生する。

キックオフ会議で日次シフト報告プロトコルを確立すること。すべての運用シフトは、以下の内容を記載した正式な日次シフト報告（Daily Shift Note）で締めくくられる：
- 実施された正確な試験スクリプト改定番号。
- 周囲環境条件および施設ベースライン状態。
- 達成された主要な運用マイルストーン。
- 根本原因評価を含む、計画外の停止または安全中断の記録。
- 新規に記録されたパンチリスト項目、および再試験による完了項目。
- 翌シフトの確定工程および予定試験スクリプト。

上流の施設トラブルや機械的故障によりその日の試験が中断された場合でも、「スクリプトの実行件数：0件；［具体的な理由］により試験中断」と記載した日次シフト報告を必ず発行しなければならない。シフト報告の欠落は監査上の重大な空白を生み、動員解除後に修復することはできない。

## 試験開始前に記録すべき決定事項

- 主張に照らして妥当性が確認された、負荷装置の容量およびコールドスペアの配分。
- 床積載荷重および電気容量の検証を含む、署名済みの現場調査報告書。
- 製造番号、証明書ID、および有効期限を含む計測器校正台帳。
- 署名された緊急時対応計画（EAP）およびすべての有効な作業許可証。
- 物理的なマスタ記録シートが現場に印刷・配備されていることの確認。
