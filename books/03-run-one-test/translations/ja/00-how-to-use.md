# 0. 本書の活用法

本書は、本番IT機器が納入される前に、液冷データセンターホールにおいて負荷装置（ロードバンク）試験を実施する技術者のための現場手引きである。負荷装置自体はすでに受入済みであり、テレメトリや速報（フラッシュレポート）の解析手法も習得済みであることを前提とする。読者の目前にある任務は、その負荷装置を高密度ラックの代わりに接続し、制御された熱ステップのもとで施設プラントを計画的に加熱し、第三者監査人、保険会社、またはハイパースケーラーの運用チームが電話での問い合わせなしに検証できる工学的記録を残してホールを退出することである。

本書は建物の総合コミッショニング手引きではない。上位の作業要領書（Method Statement）が、提出すべき契約成果物や法的署名権限を持つ完了証明書を規定する。本書が扱う作業そのものは、液冷ループの検証である。すなわち、開梱と外観検査、絶縁抵抗（メガー）および接地絶縁試験、二次側の化学洗浄と耐圧保持試験、冷態ポンプ特性曲線の基準測定、警報連動ループ、多段階熱ステップ、過渡故障時の乗り切り（ライドスルー）、そして規律ある計画停止である。記載が施設建築の見学案内へと逸れ始めたら、直ちに削ぎ落とさなければならない。現場に残すべきは、工学検証シートである。

**3つの独立したコミッショニングゲート**

| スクリプト草案 事前承認された許容値、 計測器校正ID、 譲歩不能な停止条件 | 現場での実施 1名が計測し、 1名がインクで記録する。 未承認のオーバーライドは皆無 | 監査済み受入パック 7枚の完了済みシート、 トレンドログ、生時系列データ、 署名済みパンチリスト登録簿 |
| :--- | :--- | :--- |

明日現場の作業に入るのであれば、第16章を開き、マスタシートを印刷してホールへ持ち込むこと。誰かにレベル1またはレベル4の完了証明書への署名を求められる前に、第2章および第3章を熟読しなければならない。これらの章は、現場の目視点検記録が工場受入試験のファイルに誤って紛れ込むのを防ぎ、2つの異なるコミッショニング番号体系の混同によってプロジェクトの監査適合性が破綻するのを阻止する。

試験期間が終了したとき、インクで完全に記入された、または書面で適用除外と明記された7枚の完了シートを引き渡さなければならない。空欄のセルは、それ自体が自動的な作業停止事由となる。前回の現場から転記された数値は、単位を付与した捏造記録にほかならない。負荷率、保持時間（ドウェル時間）、および水力限界値は、承認された試験スクリプトまたは有効な工学仕様書から直接引用しなければならない。本書がそれらを独断で捏造することはない。

## 複製が許可されるもの

第16章のシートをプロジェクトファイルに複製し、耐水紙に印刷して現場の床で記入することは完全に許可される。しかし、本書の記述を現場の作業要領書へ貼り付け、それをデータホールの必須運用規則と称してはならない。ホールには独自の運用許可証、独自の電気フラッシュ境界、そして独自の配管計装図（P&ID）が存在する。これらのシートは、それらの許可証やスクリプトが何を網羅すべきかを定義するものであり、主任技術者（Engineer of Record）を代替するものではない。

すべての試験手順において、現場には必ず2名が立ち会わなければならない。1名が校正済み計測器で測定し、もう1名がインクで記録する。熱負荷の投入を指示する権限を持つ者は、最初のブレーカーを投入する前にシートに記入された単一の氏名に限られる。一方、非常停止を発令する権限は、室内にいるすべての作業者に例外なく帰属する。

## 最初のステップの前に記録すべき決定事項

- 本負荷装置試験が証明するよう委託された、境界を定義する厳密な一文。
- 物理的な試験対象機器：抽象的なホール全体ではなく、どの冷却液分配装置（CDU）、どのマニホールド幹線、どのラック位置であるか。
- 7枚のシートのうち、本試験で実施するもの、および書面署名により適用除外と定められたもの。
- 熱負荷の投入を指示することが許可された、指名された単一の指揮権限者。
- 非常停止機構の物理的位置、および二次側の電源遮断経路。
