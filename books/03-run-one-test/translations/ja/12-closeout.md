# 12. 完了引渡しとハンドオーバー

通熱試験の成功は、施設の引渡し（ハンドオーバー）そのものを意味しない。データホールから負荷装置を搬出することは、単に動的検証作業が終了したことを示すにすぎない。施工段階から本番IT運用への施設の正式な移行は、**レベル6完了引渡し、ハンドオーバー、および運用引継ぎ（Close-Out, Turnover, and Operations Handover）**のもとで執り行われる。

パンチリスト項目が未解決のまま残されている段階で、あるいは最終コミッショニング報告書の監査が完了する前に署名された引渡し証明書は、法的に欠陥を抱えている。レベル6の引渡しとは、施設所有者、元請業者、およびコミッショニング責任主体が、機械、電気、および制御システムが発注者要件書（OPR）を満たし、高密度計算インフラを受け入れるにあたって安全であることを共同で認証する公式なマイルストーンである。

**レベル6引渡し文書の構成アーキテクチャ**

| 01 | エグゼクティブサマリーおよび 検証済み主張声明 | 署名された主張の一文、プロジェクトの最終判定、および実証 された運用熱容量の総括。 |
| :--- | :--- | :--- |
| 02 | スコープ境界および除外表明書 | 未実施レベル、季節的な延期試験、および除外された第三者システ ムを文書化した公式な書面。 |
| 03 | マスタマイルストーン完了証明書 | レベル2、3、4、5の正式に署名された完了証明書。 |
| 04 | 7枚の署名済み現場マスタシート | 完全に実施され、インクで記録され、署名されたシート1〜7。 |
| 05 | 計測器校正台帳 | すべての現場計測器の追跡可能なISO/IEC 17025校正証明書。 |
| 06 | 時系列データリポジトリ | 完全な未加工CSVログ、BMSトレンド出力、暗号化SHA-256。 |
| 07 | 解決済み是正項目登録簿 | カテゴリ1および2の項目が100%完了したことを示すマスタ是正表。 |
| 08 | システムマニュアル補遺 | 実測ポンプ特性曲線、常用運転許容帯、フェイルセーフ設定値。 |
| 09 | 施設運用チーム教育訓練記録 | 施設スタッフによる標準作業手順書（SOP）実地研修の立会署名。 |

## 最終コミッショニング報告書の構成

最終コミッショニング報告書は、液冷インフラの恒久的な工学基準線（ベースライン）となる。数十年後、施設が改修を受けたり障害調査に見舞われたりした際にも、将来のエンジニアリングチームはこの報告書を参照して初期の運転パラメータを確認することになる。

報告書は、以下の9つの標準化されたセクションで編纂されなければならない：

### 1. エグゼクティブサマリーおよび認定された主張
第1章で策定された、編集されていない正確な主張の一文から始まる。検証された総熱容量（例：1.2 MW連続運転）、一次側冷却水の供給条件、二次側流量バランス指標、および試験対象となったすべてのシステムが仕様範囲内で動作したことの公式な認証を、曖昧さのない運用要約として提供する。

### 2. スコープ境界および公式な除外表明書
境界条件の厳格な定義。レベル0の設計審査やレベル1の工場試験が契約から除外されていた場合、所有者が署名した正式なスコープ除外書をここに収録しなければならない。季節要因試験（真夏の最高外気温時におけるチラー熱負荷ストレス試験など）を後日に延期せざるを得ない場合、延期試験プロトコル（Deferred Testing Protocol）および予定実施日を公式に文書化する。

### 3. マスタマイルストーン完了証明書
レベル2（受入QA）、レベル3（PFCおよび初期起動）、レベル4（単体機器FPT）、およびレベル5（統合システムIST）の正式な証明書ページ。各証明書には、コミッショニング責任者、電気主任技術者、機械主任技術者、施工業者役員、および所有者正規代表者のインク署名が揃っていなければならない。

### 4. 7枚の現場マスタ記録シート
すべてのインクによる手書き記入、立会人のイニシャル署名、手順のタイムスタンプ、および現場注記をそのまま残した、完成した物理的現場記録シート（第16章のシート1〜7）の全頁フルカラー・スキャン。

### 5. 校正済み計測器台帳
試験中に配備されたすべてのマルチメータ、電力品質アナライザ、超音波流量計、デジタル温度計、差圧伝送器、および赤外線熱画像カメラを網羅した完全なトレーサビリティ台帳。それらのISO/IEC 17025校正証明書の複製を収録する。

### 6. 未加工時系列データリポジトリ
負荷装置、電力計、およびBMSトレンドログからエクスポートされた、1秒周期の未加工テレメトリデータを含む構造化アーカイブ。試験終了後のデータ改ざんを防止するため、すべての未加工データファイルに対して暗号学的ハッシュ（SHA-256チェックサム）を生成し、報告書の付録にハッシュテーブルを記録する。

### 7. 解決済みマスタ是正項目登録簿
コミッショニング是正項目ログの最終印刷版。すべてのカテゴリ1およびカテゴリ2の欠陥について、初期指摘、施工業者の是正処置、立会再試験データシートの参照番号、および完了署名に至る完全な解決履歴が明記されていなければならない。残存するカテゴリ3の外観上の指摘事項は、承認された30日以内是正計画によって担保されなければならない。

### 8. システムマニュアル運用補遺
コミッショニングデータと日常の施設運用を結ぶ実務的な架け橋。試験データから得られた重要なベースライン特性を抽出・収録する：
- 温態運転ポイントに対する、検証済みの冷態・無熱時ポンプ特性曲線（シート6）。
- 一次側温度制御調整弁（TCV-101）の校正済みPIDループパラメータ。
- 正確な二次側流体保有量（V_total）およびグリコール濃度（屈折計による 25.0% ± 0.5% の検証値）。
- ハードウェアトリップ閾値を定義した緊急インターロック・ロジックマトリクス。

### 9. 施設運用チーム教育訓練の修了署名
現地の施設エンジニアを対象に実施された、正式な運用引継ぎ教育訓練の記録文書。訓練には、非常停止機構の物理的巡回点検、手動バイパス弁の操作手順、二次側冷却液の補給手順、および警報応答ワークフローの実地訓練が含まれなければならない。

## 試験開始前に記録すべき決定事項

- すべての未加工テレメトリデータファイルのSHA-256暗号化チェックサム台帳。
