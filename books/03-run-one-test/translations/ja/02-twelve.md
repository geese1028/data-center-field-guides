# 2. 順を追う12の成果物

専門家によるコミッショニングは、熱エネルギーの投入から始まるのではない。厳格な順序を持つ12の工学成果物の作成から始まる。この階層構造の中で成果物を1つでもスキップすれば、その後に続くすべての署名は、法的に文書化されておらず物理的にも立ち会われていない作業を認証することになる。

12の成果物は責任の連鎖を構成するものであり、単なるプロジェクト管理のカレンダーではない。物理的施工がすでに完了している既存のデータホールでは、一部の成果物はゼロから作成するのではなく、監査して添付すべき既存文書となる。しかし、沈黙によって12の成果物のいずれかを省略することは許されない。

```
+--------------------------------------------------------------------------------------------------+
| 順を追う12のコミッショニング成果物 |
+----+----------------------------------+----------------------------------------------------------+
| 01 | 発注者要件書（OPR） | 監査可能な主張の一文および運用上の境界条件。 |
| 02 | 設計基準書（BOD） | OPRを満たすための設計技術者のロードマップ。 |
| 03 | OPRおよびBODの承認 | スクリプト起草前に取り交わす双方署名済みの基準線。 |
| 04 | 設計審査記録 | 設計監査の公式記録、または署名されたスコープ除外書。 |
| 05 | コミッショニング計画書（Cx Plan）| 範囲、工程、ゲート、プロトコル、およびチームガバナンス。 |
| 06 | 仕様書要求事項の監査 | 契約上の試験条項を追跡するトレーサビリティマトリクス。 |
| 07 | 施工チェックリスト（PFC） | 静的・無通電状態での機能前品質保証・品質管理検証。 |
| 08 | 機能性能試験手順書（FPT） | 事前承認されたステップごとの動的実行スクリプト。 |
| 09 | 検証および立会記録 | 第三者立会による実施ログおよび現場マスタシート。 |
| 10 | 是正項目ログ／パンチリスト登録簿 | 欠陥、責任者、および完了再試験を追跡する登録簿。 |
| 11 | 定期コミッショニング報告書 | 日次シフト報告および週次エグゼクティブサマリー。 |
| 12 | システムマニュアル＆最終Cx報告書 | 実測運用基準線および完全な引渡し引き継ぎパック。 |
+----+----------------------------------+----------------------------------------------------------+
```

## 成果物の詳細解体

### 01. 発注者要件書（OPR: Owner's Project Requirements）
第1章で定義した監査可能な主張そのものである。IT受入に必要な温度、流量、電気密度、および冗長性の指標を明示的に確立する。

### 02. 設計基準書（BOD: Basis of Design）
機械・電気・衛生設備（MEP）の主任技術者が執筆した文書であり、プラント機器、配管径、制御ループ、ポンプがどのようにOPRを達成するかを説明する。後から着任した現場検証業務では、最新の竣工版を入手する。現場試験報告書の中で対抗するBODを勝手に作成してはならない。

### 03. OPRおよびBODの審査・承認
主要利害関係者——施設所有者、元請業者、およびコミッショニング責任主体（CxA）による公式な承認署名である。未承認の要求事項は単なる作業草案にすぎない。未承認の草案に対して実施された試験は、所有者の経営陣が交代した際に拒絶され、多額の再動員費用を招くリスクを孕む。

### 04. 設計審査記録
業界の指針（ASHRAE Technical Committee 9.9やOpen Compute Project規格など）に照らして水力および電気系統図を監査した文書化記録。契約が施設完成後に開始される場合、この成果物は過去の設計審査の文書化された確認であるか、あるいは設計監査が業務スコープから除外されていることを所有者が署名した明確な書面声明のいずれかでなければならない。完了ファイル目録に空白として放置してはならない。

### 05. コミッショニング計画書（Cx Plan）
マスタ統括文書である。試験境界、リソース配分、立会プロトコル、連絡連絡網、およびゲート規則を定義する。ガントチャートはコミッショニング計画ではない。ガントチャートは時間軸の可視化にすぎない。Cx計画書は、技術的なゲート、停止基準、および文書管理体系を明確に規定する。

### 06. 契約図書におけるコミッショニング要求事項
機械および電気の契約仕様書（空調のCSI Division 23、電気のDivision 26など）に組み込まれた試験条項の監査。既存の施設において締結済みの契約を変更することはできない。具体的にどの試験条項に準拠して検証を行っているか、また過去の文書欠落によりどの条項が履行不能であるかを示すマトリクスを編纂する。

### 07. 施工チェックリスト（機能前チェックリスト - PFC: Pre-Functional Checklists）
プラントが完全に無通電の状態で記入される物理的・静的な確認シート。機器タグ、物理的芯出し・アライメント、開梱状態、電気ラグのトルク締付マーク、配管の耐圧保持、およびシステムフラッシングを検証する。印刷されたチェックリストを持たずに実施される現場巡回は、単なる散歩にすぎない。

### 08. 機能性能試験手順書（FPT: Functional Test Procedures）
すべての動的シーケンスを管理する、承認済みのステップごとの試験スクリプト。各手順書は、初期条件、正確なステップ指示、計測器の等級、予想される数値許容帯、および具体的な停止限界を文書化しなければならない。試験当日の朝に現場で起草されたスクリプトは容認できない草案である。その「期待される結果」は、必然的に機械プラントがたまたま示した挙動を後追いでなぞるだけになる。

### 09. 検証および立会記録
承認されたスクリプトの物理的実施記録。立会いと実施は法的に分離された義務である。制御バルブやブレーカーハンドルを操作している技術者が、その項目を受入判定する唯一の立会人を兼任することはできない。単一の個人が双方の役割を担うと、無意識のバイアスによってデータが損なわれる。

### 10. 是正項目ログ／パンチリスト登録簿
すべての欠陥、逸脱、漏洩、センサー誤差、および制御ハンチングを記録する網羅的なトラッカー。各項目には、日付、スクリプトステップ、重大度ティア、担当施工業者、必要な是正処置、および再試験受入基準を文書化しなければならない。口頭の会話やチャットのスレッドだけで言及された欠陥は、法的に存在しない。

### 11. 定期コミッショニング報告書
各作業枠の終了時に提出される日次シフト報告、および経営陣へ配布される週次総括報告。試験が中断された日を含め、報告フォーマットはキックオフ会議で合意されていなければならない。日次報告のない空白の一日は、プロジェクト管理の破綻を意味する。

### 12. システムマニュアルおよび最終コミッショニング報告書
包括的な引渡しアーカイブ。署名されたすべてのマスタシート、校正済み計測器証明書、未加工時系列データファイル、BMSトレンドログ、解決済みパンチリスト、および施設技術者が検証済み境界内でプラントを運用するために必要な運転指針が含まれる。

現地の施工業者の習慣に合わせるために、これら12の成果物の番号を付け替えたり統合したりしてはならない。特定の成果物が契約上除外されている場合、コミッショニング計画書にその除外を明記し、最終報告書でそれを再確認しなければならない。プロフェッショナルとしての適合性は、境界を文書化することによってのみ維持され、沈黙によって保たれることは決してない。

## 試験開始前に記録すべき決定事項

- 12の成果物の分類：自ら作成するもの、過去の作業から添付するもの、または書面署名により除外するもの。
- 承認された文書採番規則およびリビジョン管理方針。
- マスタ是正項目ログのホスティングリポジトリおよびアクセス権限。
- 日次シフト報告の配布リストおよび提出期限時刻。
