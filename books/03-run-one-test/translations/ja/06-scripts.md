# 6. 通熱前のスクリプト

いかなる動的コミッショニング試験も、記憶や口頭の指示に基づいて実施してはならない。事前承認されたステップごとの試験スクリプトなしで実施された試験は、単なる非公式な機器の実演にすぎない。工学的な完了証明書の根拠となることは法的に不可能である。

試験チームが作成したものの、発注者主任技術者が正式に審査・署名していないスクリプトは、単なる社内作業文書にすぎない。そこにはいかなる契約的権限も存在しない。未承認の草案に対して試験を実行することは、機器の故障や事故が発生した際に、試験チームを商業紛争や法的責任の危険に完全に晒すことになる。

**コミッショニング文書の階層構造**

| 1. 法規および業界規格 | ASHRAE 0-2019, ASHRAE 90.4, NFPA 70, IEC 60364, BSRIA BG 29. |
| :--- | :--- |
| 2. 契約仕様書および設計基準（BOD） | CSI Div 23 & 26, 発注者要件書（OPR）, 竣工配管計装図（P&ID）. |
| 3. コミッショニング計画書（Cx Plan） | ガバナンス規則、レベルゲート、立会プロトコル、総合工程表。 |
| 4. 機能性能試験手順書（FPT） | 厳密な数値許容帯を備えた、事前承認済みの手順スクリプト。 |
| 5. 現場マスタシート（インク記録） | インクで署名された現場記録、未加工時系列センサーデータファイル |

## 監査可能な試験スクリプトの構造解剖

すべての機能性能試験（FPT）および統合システム試験（IST）スクリプトは、監査に耐えうる一貫した工学的セクションで構成されなければならない：

1. **試験範囲と境界**: 試験対象となる具体的な機械・電気機器、および隣接する稼働中設備とそれらを物理的に隔てる厳密な境界。
2. **準拠基準図書**: 準拠する配管計装図（P&ID）改定番号、単線結線図（SLD）、および機器承認図書の直接引用。すべての許容差は、特定の契約条項またはメーカー基準を引用しなければならない。出典のない受入許容値は、単なる根拠のない私見にすぎない。
3. **計測機器および校正計画**: 手順の実施に必要な具体的な計器の分類、シリアル番号、および校正証明書ID。
4. **前提条件確認ゲート**: 先行レベルのすべての要求事項（開梱検査、無通電メガー試験、耐圧保持試験など）が完全に署名・完了していることの書面確認。
5. **安全管理および環境境界**: 必須の個人用保護具（PPE）、アークフラッシュ境界の定義、流出封じ込めの配備、および検証済みの非常停止経路。
6. **ステップごとの実施シーケンス**: すべての手動操作、観察すべき物理的フィードバック、予想される数値許容帯、測定値の記入セル、および立会人のイニシャル署名欄を詳細に規定した順序表。
7. **明示的な停止条件**: 違反した場合に試験の即時中断を義務付ける明確な運用限界（二次側冷却水温度が 45.0°C を超えた場合、二次側圧力が 100 kPa 未満に低下した場合、供給電源の相電圧不平衡率が 2.0% を超えた場合など）。

## 現場におけるスクリプト改定の凍結

コミッショニング・キックオフ会議において、現場でのスクリプト実行を許可するために必要な正式承認ステータスが確立される。データホール内での実行が許可されるのは、**「実施承認済み（APPROVED FOR EXECUTION - REV [X]）」**という正式なスタンプが押印されたスクリプトのみである。

試験中に機械プラントが承認スクリプトで予期していなかった予期せぬ挙動を示した場合、現場で鉛筆書きによってスクリプトを書き換えることは厳格に禁止される。統制されていない現場修正（レッドライン）を許せば、試験手順はプラントがたまたま示した挙動に合わせて都合よく後退してしまう。

手順の変更が必要となった場合：
- 試験責任者が試験を一時停止する。
- 逸脱内容、工学的正当化理由、および修正手順を明記した正式な工学変更通知書（ECN: Engineering Change Notice）を起草する。
- ECNには、試験責任者、施工責任者、および発注者主任技術者が署名する。
- スクリプトのリビジョン番号を繰り上げ（例：Rev 1.0 から Rev 1.1）、再発行する。

所有者がECNを拒否した場合、試験は元のスクリプトに従って再開され、プラントが元の期待結果を満たせなかった事実はマスタ是正項目リストに記録される。

## 高密度液冷ホールに必須の試験スクリプト一式

完全な検証キャンペーンには、独立した個別のスクリプトからなる網羅的なスイートが必要となる。複数の運用検証を単一の包括的手順にまとめようとすると、重要な安全点検や性能確認が不可避的に見落とされる扱いづらい文書になってしまう。

検証キャンペーンには、以下の9つの専用試験スクリプトが必要である：

### フェーズ1：静的前準備チェックリスト（レベル2／レベル3）
- **スクリプト01：物理的開梱、アライメントおよび外観品質保証**: 負荷装置フレームの構造健全性、ホースの配管経路、継手シールの健全性、および耐震固定の確認。
- **スクリプト02：無通電電気メガー試験および相回転検証**: 絶縁抵抗試験（1000V DC印加で ≥ 100 MΩ）、接地導通試験（≤ 0.1 Ω）、および正相時計回り（A-B-C）の相順確認。
- **スクリプト03：二次側ループ洗浄、耐圧保持およびエア抜き**: 化学フラッシング流速確認（BSRIA BG 29/2020に準拠して ≥ 1.5 m/s）、耐圧保持試験（最高許容使用圧力の1.5倍で2時間保持、圧力低下ゼロ）、および自動脱気。

### フェーズ2：単系統機能性能試験（レベル4 FPT）
- **スクリプト04：自律的CDU起動、流量および圧力基準測定**: キャンドポンプのインバータ（VFD）ランプ曲線、手動差圧設定値追従、および冷態システム抵抗の検証。
- **スクリプト05：CDU N+1ポンプ切替および自律制御**: 主ポンプインバータの物理的トリップ遮断、< 1.5 s 以内の待機ポンプ自動起動、およびループのキャビテーションゼロの検証。
- **スクリプト06：警報注入およびポイント・ツー・ポイント・テレメトリ**: 模擬障害（二次側低流量、膨張タンク低液位、液漏れ検知帯の水濡れ）の物理的注入、およびローカル計器とBMSテレメトリの相互照合。

### フェーズ3：統合システム試験（レベル5 IST）
- **スクリプト07：冷態・無熱基準ポンプ特性曲線**: 自動VFD制御を無効・ロックした状態での、手動絞り弁4点における揚程対流量プロファイル測定。
- **スクリプト08：多段階熱ステップおよび過負荷保持（熱梯子）**: 段階的通熱（定格設計負荷の25%、50%、75%、100%、および110%過負荷マージン）、各段最低45分間の保持、および4時間の全負荷連続浸漬。
- **スクリプト09：動的過渡故障および非常停止**: 2N一次受電電源遮断、施設側一次冷却水喪失の乗り切り、および秩序ある制御下での de-energization 停止シーケンス。

## 「1スクリプト、1署名」の原則

スイート内の各スクリプトは、専用の承認署名ブロックを備えた独立した契約図書として成立していなければならない。成功した冷態ポンプ曲線と失敗した熱過負荷ステップを単一の複合署名に統合することは、根本的に曖昧な記録を生み出す。

各スクリプトは、明確な判定結果を出力しなければならない：**合格（PASS）**、**不合格（FAIL）**、または**未実施（NOT EXECUTED）**。スクリプト内のいかなる未解決の不合格も、直ちにマスタ是正項目リストのエントリを生成する。

## 試験開始前に記録すべき決定事項

- 凍結された改定番号と承認スタンプを備えた、全9つの試験スクリプトの網羅的一覧。
- すべての数値許容差および受入許容帯の根拠となる契約図書番号。
- 現場での手順改定を処理するための正式な工学変更通知書（ECN）プロセス。
- 草案ステータスのスクリプトが一切存在しないことの確認。
