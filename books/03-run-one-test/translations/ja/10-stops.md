# 10. 停止、そして退出の順序

データホールにおける非常停止（E-Stop）は、緊急時マニュアルに記載された推奨事項などではない。機器を迅速かつ安全に電源遮断するために配線された物理的安全回路である。

第1巻で確立したように、負荷装置内部の安全停止機能は自律的に動作し、上位監視ネットワークが喪失しても機能し続ける。本巻が規定するのは、現場において誰がその停止を発令する権限を持ち、誰がそれを無効化（オーバーライド）することを許されるかという統治規則である。

運用規則は絶対である：**一度発令された非常停止をオーバーライドすることは、いかなる者にも許されない。** 技術員、見習い、あるいは見学者が漏洩の疑い、電気的異常、または身の安全への懸念から停止を叫んだ場合、試験はその瞬間に終了する。「待て、あと30秒だけ熱曲線を観察させてくれ」と応じる試験責任者は、重大な安全規則違反を犯したことになる。その秒から先、そのセッションは工学試験であることをやめ、公式な事故調査へと移行する。

## スクリプト09：動的過渡故障検証

スクリプト09に基づく統合試験は、データホールの冷却インフラが、壊滅的な施設障害に見舞われた際にも計算機ハードウェアを損傷させることなく生き延びられる（乗り切れる）ことを検証する。これらの試験は実世界の故障モードを模擬し、得られた過渡復帰曲線をシート4に記録する：

### 1. 二次側ポンプトリップおよび自動切替
システムが100%全熱負荷（1.2 MW）で運転している状態で、稼働中の二次側ポンプ（ポンプP-1A）を物理的にトリップさせる：
- **受入基準**: 待機ポンプ（ポンプP-1B）が差圧低下を検知し、自動起動して、≤ 1.5 秒 以内に定格ループ流量を復帰させること。
- 逆止弁の着座に伴うピーク水撃圧サージは ± 50 kPa 以内であること。
- 二次側ループ差圧が最小キャビテーション限界圧（100 kPa）を下回らないこと。

### 2. 2N受電系統のA系統電源喪失／ATS切替
CDUが2系統受電（2N受電構成）で運転している状態で、主電源Feeder Aの回路ブレーカーをトリップさせる：
- **受入基準**: 静的切替スイッチ（STS）または自動切替スイッチ（ATS）が、≤ 16 ミリ秒（商用周波数の1サイクル以内）でFeeder Bへと受電を切り替えること。
- CDUの24V DC制御電源母線が電圧を維持し、PLCの動作停止（ドロップアウト）電圧を下回らないこと。
- CDUコントローラが**絶対に再起動（リブート）しないこと**。受電バス切替時のコントローラ再起動は、レベル5試験の即時不合格を意味する。
- 二次側ポンプのインバータ（VFD）が無瞬断で切替を乗り切るか、あるいは < 3.0 秒 以内に全速運転周波数へ復帰すること。

### 3. 一次側施設冷却水遮断（FWS喪失・熱慣性乗り切り）
二次側ループが100%熱負荷で運転している状態で、一次側冷水供給隔離弁を急速に全閉にし、施設側一次冷却水の完全喪失を模擬する：
- この試験は、二次側回路の**水力学的熱慣性（バッファ時間）**を測定する。
- 一次側熱交換がゼロに脱落すると、負荷装置から注入される熱エネルギーは、二次側流体質量の顕熱容量によってのみ吸収される：

$$\frac{dT_{\text{supply}}}{dt} = \frac{P_{\text{load}}}{M_{\text{fluid}} \cdot c_p}$$

- **受入基準**:
 - 二次側供給温度が定格 40.0°C から高温警報閾値 45.0°C へ上昇するまでに要する時間（バッファ時間）は、最低でも **40秒以上**（t_buffer ≥ 40 s）であること。
 - 45.0°C に到達した時点で、CDUは自動的に高温警報を発信し、段階的熱負荷遮断（ロードシェディング）を開始すること。
 - 温度が非常重大限界値 **50.0°C** に達した場合、非常インターロック回路がすべての負荷装置電源接触器を即座に遮断し、沸騰やメカニカルシールの熱破壊に至る前に熱入力を完全停止すること。

### 4. 中央監視（BMS）通信ケーブル切断
ループが全熱負荷で運転している状態で、CDUのPLCと中央BMSを結ぶModbus-TCPおよびBACnetのLANケーブルを物理的に引き抜く：
- **受入基準**: CDUのローカルコントローラが混乱なく自律単独運転を継続すること。二次側ポンプ速度および調整弁開度が、ローカルPID設定値追従のもとで安定を維持すること。外部通信の途絶によってCDUがハンチングを起こしたり、開度を見失って全開暴走したりしてはならない。

## 制御された計画停止（シート5）

数メガワット規模の熱負荷試験からの撤収（動員解除）には、試験開始時と同等の規律が求められる。電源遮断および停止手順は、後戻りできない厳格な順序に従って実行されなければならない。

**必須の計画停止実施シーケンス**

| 手順 | 操作指令 | 安全工学的根拠 |
| :--- | :--- | :--- |
| 01 | 熱負荷を 0 kW へ遮断 | すべてのヒータ接触器／SCRを遮断。1.2 MWの熱負荷が投入されている 状態で、流体の循環を決して停止させてはならない！ |
| 02 | 負荷装置ブレーカーの開放 | すべての主給電回路をロックアウト・タグアウト（LOTO）。 校正済み検電器を用いて無電圧であることを確認。 |
| 03 | 10分間の流体冷却循環 | エレメントの残留熱を除去し局所沸騰を防ぐため、ヒータ遮断後も 二次側ポンプの循環を最低10分間継続する。 |
| 04 | CDU二次側ポンプの停止 | 二次側流体温度が30.0°C以下に安全に低下した後にのみポンプを電源 オフ。差圧が0 kPaに低下したことを確認する。 |
| 05 | ホースの隔離および取り外し | マニホールド隔離弁を閉じ、残留静圧をドレンパンへ逃がした上で、 クイック継手を外す。 |

> **手順逆転に関する極めて重大な警告**: 手順1と手順4を決して逆転させてはならない！メガワット規模の電熱ヒータが通電している状態で流体の循環を停止させると、加熱流路内に停滞した流体は数秒以内に瞬時に水蒸気へとフラッシュ沸騰する。結果として生じる急激な気化膨張は爆発的な圧力サージを生み出し、ホースのかしめ部を吹き飛ばし、センサーダイアフラムを破壊し、アイル内の作業員に壊滅的な熱湯・蒸気被災をもたらす。シート5は、各ステップが厳格な時系列順序でチェックされることを要求する。順序が逆転したチェックは、そのシート全体を即座に無効とする。

## データの安全性と即時の二重バックアップ

ケーブルや計測器を輸送箱に梱包する前に、すべての試験データを安全にバックアップしなければならない：
- 負荷装置、電力品質アナライザ、および超音波流量計から、未加工の高周波数CSVログをすべてエクスポートする。
- CDUのローカルPLCおよび施設中央BMSから、1秒周期のトレンドログをすべてエクスポートする。
- 高解像度の赤外線熱画像データ、および現場マスタシートのデジタル写真をすべてアーカイブする。

物理的に分離された2つの独立した記録媒体上にバックアップを作成すること（例：1つは安全な現場作業端末、もう1つは暗号化された外付けドライブ）。輸送箱に詰められたストレージドライブは、アクセス可能なバックアップではない。輸送中にその箱が紛失または遅延した場合、コミッショニングを認証することは不可能となり、数週間に及ぶ試験全体をやり直さなければならなくなる。

## 動員解除と現場復旧

動員解除は、機材の棚卸し監査をもって完了する：
- すべてのクイック継手、可撓性ホース、変換アダプタ、およびブランキングキャップを、シート1に記録された開梱時数量と照合して点検する。
- マニホールドのすべての往水・還水ポートに、耐圧定格を持つ防塵保護キャップを装着する。
- データホールの床タイル、ケーブルトレイ、および壁面を点検し、輸送傷、液滴の付着、または残留ゴミがないことを確認する。
- 施設のすべての恒久バルブ、電気ブレーカー、およびBMS制御ループを、通常の運用基準構成へと復帰させる。

最終日の日次シフト報告には、試験が完了したこと、データアーカイブの物理的保管場所、および残存するパンチリスト是正項目を要約する。その報告書の中で施設が「合格した」と独断で宣言してはならない。最終的な認証は、正式なコミッショニング報告書が監査され承認された後にのみ行われる。

## 試験開始前に記録すべき決定事項

- 物理停止回路が瞬時に熱を遮断することを確認した、立会済み非常停止試験。
- シート4に記録された動的過渡試験ログ（ポンプトリップ、2N受電喪失、一次冷水遮断、BMS切断）。
- 厳格な時系列順序に従って実行された、シート5の署名済み停止手順ログ。
- 二重データバックアップの物理的保管場所および暗号化チェックサム（SHA-256）。
- 継手の紛失や仮設配管の放置が皆無であることを確認した、完了時の撤収点検リスト。
