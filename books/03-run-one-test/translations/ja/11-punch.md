# 11. 是正項目リスト（パンチリスト）

公式のコミッショニング是正項目ログ（Issues Log / Punch List）に記録されていない施工欠陥や性能異常は、法的に存在しない。この不作為は、撤収を急ぐ施工業者にとっては都合が良いかもしれないが、本番IT機器が届いた後にホールを運用しなければならない施設運用チームにとっては、受け入れがたい運用災害の種となる。

マスタ是正項目リストは、最初の二次側冷却液漏洩が発見された後ではなく、コミッショニング・キックオフ会議の場において確立される。記録されるすべての項目は、外部の監査人が即座に理解できる明確な記述を備えていなければならない：具体的な機器タグ、準拠P&ID図面番号、不合格となったスクリプトのステップ番号、故障モード、担当施工業者、必要な是正処置、および完了と認めるために必要な具体的再試験基準である。「CDUの不具合」といった曖昧な記述は断じて認められない。

## 段階インターロックと免除（ウェイバー）プロトコル

データセンターコミッショニングを律する根本原則は、**未解決のカテゴリ1欠陥が残存している限り、いかなるプロジェクトもマイルストーンの境界を越えて進行してはならない**ということである。

パンチリストは、施工業者がこの規則の骨抜きを求めて交渉を試みやすい場である。「一次側逆止弁から逆流時にわずかな漏れがあることは分かっているが、今日のところは100%通熱試験を進めさせてほしい。弁の修理は撤収時に行うから」という施工業者の嘆願は却下されなければならない。逆止弁が損なわれた状態で高負荷熱試験を開始すると、逆流によるポンプキャビテーション、激しい水力ショック、およびポンプモータの致命的な焼損を引き起こす。

施設所有者が、動かせない事業上の納期を満たすためにカテゴリ2の運用逸脱を抱えたまま進行することを決断する場合、その決定は署名された正式な**逸脱免除書（Deviation Waiver）**によって文書化されなければならない。免除書には以下を明記しなければならない：
1. 正確な技術的不備の内容、および準拠仕様書の条項。
2. 運用リスク評価および潜在的な故障モード。
3. 試験期間中に現場へ配備される具体的な代替安全管理策。
4. 是正および立会再試験の完了に向けた契約上の誓約と日程。

口頭の合意や非公式なチャットメッセージは完全に無効である。書面のない免除は、将来運用障害に不意打ちされることを合意したにすぎない。

## 是正修復と再試験のガバナンス

パンチリストの解消作業中における責任の分担は、厳格に維持されなければならない：
- **専門施工業者**: 正式な作業許可証のもとで、物理的な修理を実施する。
- **検証責任主体（CxA）**: 修理を監査し、物理的施工を点検し、再試験スクリプトを指揮し、新しいデータを記録する。検証チームが自ら機械や電気の修復作業を行ってはならない。自ら手を下すことは独立した監査の立場を破壊する。
- **施設所有者**: 再試験に立ち会い、完了記録に副署する。

パンチリストの項目は、施工業者が「技術員が弁パラメータを調整した」という電子メールを提出するだけでは完了（クローズ）できない。項目を閉じるためには、元のスクリプトが要求したのと同等の工学的証拠——パラメータが仕様を満たしていることを実証する、完全に実施され立ち会われた再試験データシートが必須となる。

## 再試験スコープと商業的境界

立会再試験は、技術者の工数、施設の商用電力、および仮設機材のレンタル費用という現実のコストを発生させる。再試験が基本業務スコープに含まれるのか、それとも正式な追加変更指示（Change Order）を必要とするのかについて、コミッショニング計画書の中で事前に明確にしておかなければならない。

この商業的境界を早期に確立しておくことで、施工業者の施工不良によって複雑な試験をやり直さなければならない際の紛争を防止できる。しかし、商業的交渉によって技術基準が妥協されてはならない。正式なスクリプト改定を経ずに行われた未承認の再試験は、有効な検証ではなく、記録のない機器運転にすぎない。

## 動員解除後の机上解析による欠陥発見

一部の欠陥は、動員解除後に現場作業端末で高周波数テレメトリログや電力計のCSVデータを詳細解析して初めて顕在化する。

エンタルピー熱バランス計算によって最終加熱時間の閉合比が 92.0% に低下していたことが判明した場合や、周波数解析によって低振幅のVFDハンチングが検出された場合、その知見は解析による発見日を明記してマスタ是正項目リストに正式に記録されなければならない。

試験責任者は以下を慎重に識別しなければならない：
- **データ取得上の欠陥**: NTPクロックの非同期、CSVフォーマットの破損、または未校正の変流器など。
- **物理プラントの欠陥**: ポンプベルトの滑り、熱交換器プレートの目詰まり・スケール付着、またはサイリスタモジュールの故障など。

データ取得エラーと物理プラントの欠陥を混同すると、正常な機器の調査に施工業者のリソースを浪費させることになる。逆に、物理プラントの欠陥を単なるテレメトリのバグとして片付けると、欠陥を抱えた冷却設備がそのまま本番IT運用へと引き渡されることになる。

## 完了（クローズアウト）の成立要件

実施されたコミッショニングレベル全般にわたって記録されたすべてのカテゴリ1およびカテゴリ2の欠陥が完全に解決され、立会再試験によって検証されたとき、コミッショニング責任主体はクローズアウトを認証することができる。最終完了会議において口頭で「すべて解決した」と合意することには何の法的効力もない。完了したマスタ是正項目ログを印刷し、3者全員がインクで審査・署名しなければならない。

## 試験開始前に記録すべき決定事項

- マスタ是正項目ログの保管場所、ホスティングセキュリティ、および管理ソフトウェア。
- 欠陥の記録、修理の実施、再試験の立会い、および項目の完了承認を行う権限を持つ指名された個人。
- 必須のリスク評価および緩和策を含む、正式な逸脱免除書のテンプレート。
- 再試験費用および日程配分を規定する商業的合意。
- レベル6引渡しの前に、すべての項目が解決済みであることを確認した、印刷・署名されたマスタ是正項目ログ。
