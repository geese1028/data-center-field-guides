# 15. どのシートを手に取るべきか

第16章は、7枚のマスタ工学記録シートを提供する。これらを耐水紙に印刷し、専用の現場バインダーにまとめ、データホールの現場へ携行すること。

試験終了後に未加工の現場データを破棄し、これらのグリッド（記録枠）を大まかな説明文へと要約してはならない。検証パッケージを審査する監査人は、アイル（通路）に立ちながら記録された、生々しいインクの筆跡、タイムスタンプ、立会人のイニシャル署名、および計測器の製造番号を確認することを要求する。

## 現場実施の鉄則

1. **現場には必ず2名**: 1名のエンジニアが校正された計測器を操作し、もう1名のエンジニアが測定値を即座にインクで記録する。画面の数値を記憶しておき、5分後に書き留めようとしてはならない。
2. **すべてのセルは義務である**: 空欄のセルは自動的な作業停止を意味する。パラメータが特定の試験スコープに含まれない場合、**「N/A（主張Rev [X] に基づき対象外）」**と明記し、イニシャルを署名すること。決してセルを空白のまま放置してはならない。
3. **熱ステップごとにシート3を複写して使用する**: シート3は単一の用紙ではない。複数枚印刷すること。熱梯子の各段（25%、50%、75%、100%、および110%）ごとに、独立した完全なシート3を1部ずつ実行する。複数の負荷ステップのデータを1枚のシートに混在させてはならない。
4. **未加工テレメトリのチェックサムを添付する**: 各シートのヘッダーに、対応する高周波数未加工CSVログのファイル名およびSHA-256暗号化チェックサムを直接記録する。
5. **過去に遡った改ざんの禁止**: 記入ミスがあった場合は、誤った箇所に1本の横線を引き、その脇に正しい数値を記入し、イニシャルを付記する。修正液を使用したり、文字を黒く塗りつぶしたりしてはならない。

## 物理的バインダーの編纂

7枚のシートに対応する7つの専用タブに現場バインダーを仕分ける。各タブの冒頭には、承認された試験スクリプトの改定版と、その段階で必要とされる計測器の校正証明書を綴じ込む。

試験が完了したとき、この物理バインダーはフルカラーでスキャンされ、レベル6最終コミッショニング報告書の恒久的な中核を形成する。
