# 3. 2つの番号体系

本章の目的は、正確に実施された現場試験報告書が、監査ファイルの中で虚偽記載・書類偽造として弾かれるのを防ぐことにある。

グローバルなミッションクリティカル・データセンターのコミッショニングにおいて、文書管理は7段階の標準完了証明書ティアを中心に構成される。同時に、現地の機械工事業者は往々にして慣用的な「3段階（ステージ）」の語彙を用いて意思疎通を図る。これら2つの語彙が無思慮に混同された瞬間、プロジェクトの監査適合性は破綻する。

## グローバル標準：レベル0からレベル6

現代のコミッショニング体系（ASHRAE Guideline 0-2019、ASHRAE Guideline 1.1、およびAABC Commissioning Groupに準拠）は、7つの正式な完了証明書を定義している：

- **レベル0：設計および計画（Design and Planning）**。OPR、BOD、および工学仕様書の監査。設計意図とコミッショニング要求事項が完全に統合されていることを証明する。
- **レベル1：工場受入試験（FAT: Factory Acceptance Testing）**。製造工場（CDUベンダー、チラー工場、負荷装置製造所）における立会試験。工場環境下において圧力容器、ポンプ特性曲線、および制御ロジックを検証する。
- **レベル2：コンポーネント納入・受入および静的QA（Component Delivery, Receipt, and Static QA）**。開梱、物理的外観検査、耐震アンカー固定の検証、トルク締付検査、および無通電での電気絶縁抵抗検査。
- **レベル3：機能前チェック（PFC）およびシステム起動（Pre-Functional Checks and System Start-Up）**。配管の化学洗浄、耐圧保持試験、真空脱気、冷却液充填、機器への初回通電、およびメーカーによる初期起動。
- **レベル4：機能性能試験（FPT: Functional Performance Testing）**。個別に隔離された単体機器の動的試験。自律的なCDUポンプ連動シーケンス、調整弁の応答、ローカルVFD制御ループ、および計測器のポイント・ツー・ポイント・テレメトリを実証する。
- **レベル5：統合システム試験（IST: Integrated System Testing）**。全熱負荷を模擬した状態での複数システム連動動的検証。ラック列レベルのマニホールド流量バランス、多段階熱ステップ、2N電源喪失時の自動切替、一次側冷却水遮断時の温度上昇乗り切り（ライドスルー）、および非常停止カスケードを検証する。
- **レベル6：完了引渡し、ハンドオーバー、および運用引継ぎ（Close-Out, Turnover, and Operations Handover）**。全パンチリスト是正項目の解消、最終システムマニュアルの提出、施設運用チームへの教育訓練、および稼働中施設エンジニアリングチームへの正式引継ぎ。

## 現地の現場方言：3つのステージ

改修プロジェクトや、負荷装置検証のために専門チームが後から動員された完成済みホールにおいて、施工業者は慣用的な「3ステージ」の略称を頻繁に用いる：
- **ステージ1：静的受入（無通電）**。物理的据付、ケーブル点検、ホース接続、および耐圧保持。
- **ステージ2：単一システムの機能確認**。個々のCDUの起動、ポンプ回転、およびローカル警報。
- **ステージ3：統合熱性能実証**。負荷装置への通電、段階的通熱ステップ、および施設電源遮断の模擬。

ステージの順序自体は論理的に正しい。静的検査に合格していない機器に通電してはならず、ポンプの機能が実証されていないループに熱負荷を投入してはならない。危険は、その「番号の付け方」に潜んでいる。

## コンプライアンスの罠

施工業者は、プロジェクトフォルダ内でステージ1の静的巡回点検を「レベル1試験」とラベル付けすることが多々ある。監査人や顧客のコンプライアンス担当官がプロジェクトバインダーを審査する際、「レベル1：工場受入試験」と記されたタブを開き、そこに挟まれているのが二次側ホースの開梱とマニホールドへのクランプ固定を確認したクリップボードのチェックリストであるのを発見する。

現場の巡回点検記録を工場受入試験のバインダーに綴じることは、文書偽造に該当する。現場チェックリストのすべてのチェックボックスが真面目な物理的作業を表していたとしても、レベル1は工場の試験ベンチデータ、工場校正シート、および製造元立会人の署名を要求するため、その証明書は法的に無効となる。

この監査違反を防ぐため、コミッショニング計画書の1ページ目には明確な対照マトリクスを掲載しなければならない：

```
+----------------------------------------------------------------------------------------------------+
| コミッショニング段階換算マトリクス |
+--------------------------+----------------------------+--------------------------------------------+
| グローバル証明書ティア | 現地施工業者の通称用語 | 必須の検証境界 |
+--------------------------+----------------------------+--------------------------------------------+
| レベル0: 設計監査 | 除外／添付 | OPRおよびBODの承認署名、設計審査免除書。 |
| レベル1: 工場試験（FAT） | FATベンダー文書 | 証拠として添付される工場試験記録。 |
| レベル2: 現地受入QA | 第1段階（静的パートA） | シート1: 開梱、メガー、相回転確認。 |
| レベル3: 機能前＆起動 | 第1段階（静的パートB） | シート1: 洗浄、耐圧保持、注水・エア抜き。 |
| レベル4: 機能性能（FPT） | 第2段階（単体システム） | シート2、シート6、シート7: CDUおよび警報。 |
| レベル5: 統合システム(IST)| 第3段階（通熱ウィンドウ） | シート3、シート4: 熱梯子および2N電源遮断。 |
| レベル6: 引渡し引継ぎ | 完了ハンドオーバー | シート5、パンチリスト解消、Cx引渡パック。 |
+--------------------------+----------------------------+--------------------------------------------+
```

## 必須の関門（ゲート）とインターロック規則

コミッショニングガバナンスの中核原則は、先行ティアに未解決の欠陥が存在する限り、いかなるプロジェクトもレベルの境界を越えて進行してはならないということである：

1. **静的検証の前提ゲート**: レベル3の機能前チェックリストが未署名のままである場合、レベル4の機能性能試験を開始することはできない。検証およびフラッシングが完了していない二次側ループにCDUポンプを運転させることは、金属切削粉や施工ゴミをプレート熱交換器やクイック継手バルブに直接循環させるリスクを冒す。
2. **通熱検証の前提ゲート**: レベル4の単体機器安全トリップやポンプ切替ルーチンが不合格である場合、レベル5の統合システム試験を開始することはできない。N+1ポンプ切替が未検証のシステムにメガワット級の熱エネルギーを注入することは、ポンプがトリップした際に制御不能な熱暴走を引き起こすことを保証する。
3. **「通熱中に直す」という罠**: 施工業者が「今日のところは通熱試験を進めさせてほしい。ポンプ切替の問題は明日直すから」と懇願した場合、コミッショニング責任者は直ちに停止命令を発令しなければならない。熱エネルギーは機械的・電気的欠陥を修復しない。高リスク環境下でそれらを致命的に拡大させるだけである。

所有者が切迫した工期を守るために未解決の欠陥を免除することを選択する場合、その免除は発注者主任技術者がインクで署名した正式な書面による「逸脱免除書」として文書化されなければならない。免除書には、現場に配備された代替安全管理措置を明示しなければならない。非公式な口頭合意は完全に無効である。

## 試験開始前に記録すべき決定事項

- 現地ステージ用語と、正式なレベル0〜6証明書バインダーとの対応付け。
- 本検証スコープが発行を認可されている具体的な証明書レベル。
- 正式なスコープ除外書が添付され、スコープから除外された証明書レベル。
- レベル2/3、レベル4、およびレベル5の間の移行を管理する、譲歩不能な前提ゲート。
- 公式な逸脱免除書を発行する権限を持つ、指名された単一の権限者。
