# 15. 어느 시트를 손에 쥘 것인가

제16장은 7종의 엔지니어링 마스터 기록 시트를 제공한다. 이를 방수 용지에 인쇄하여 전용 현장 바인더에 편철한 뒤 데이터 전산실 바닥으로 들고 나가라.

시험이 끝난 후 원시 현장 데이터를 내던져 버리고, 이 격자형 서식들을 고수준의 서술형 문단으로 요약하려 하지 마라. 검증 패키지를 실사하는 감사관은 통로에 서서 교정된 계측기로 직접 측정하고, 잉크로 눌러 쓴 타임스탬프와 입회자 이니셜, 그리고 계측기 일련번호가 고스란히 담긴 실물 기록을 원한다.

## 현장 바닥에서의 기록 실행 규칙

1. **공구 앞에는 2인 1조**: 한 명의 엔지니어가 교정된 계측기를 조작하고, 다른 한 명의 엔지니어가 측정값을 즉시 잉크로 기록한다. 디스플레이를 눈으로 보고 기억했다가 5분 뒤에 적으려는 짓은 절대 하지 마라.
2. **모든 칸은 법적 의무**: 빈칸은 자동 작업 정지 사유이다. 특정 파라미터가 이번 시험 범위에 포함되지 않는다면 **"N/A (주장 Rev [X]에 따라 제외됨)"**이라고 명기하고 이니셜을 날인해라. 결코 셀을 빈칸으로 비워두지 마라.
3. **열부하 단계마다 Sheet 3을 사본으로 실행**: Sheet 3은 단 한 장의 서식이 아니다. 여러 부를 인쇄해라. 열부하 사다리의 각 단계(25%, 50%, 75%, 100%, 110%)마다 별도의 완전한 Sheet 3을 독립적으로 작성해라. 여러 부하 단계의 데이터를 한 장의 시트에 뒤섞지 마라.
4. **원시 텔레메트리 체크섬 명기**: 각 시트의 헤더에 해당 시험 구간에 대응하는 고주파 원시 CSV 로그의 파일명과 SHA-256 체크섬을 직접 기록해라.
5. **소급 수정 절대 금지**: 만약 숫자를 잘못 적었다면, 오류 위에 단 한 줄의 수평 취소선을 긋고 그 옆에 올바른 수치를 기재한 뒤 이니셜을 서명해라. 수정액(화이트)을 사용하거나 현장 기록을 덧칠해 뭉개서는 안 된다.

## 실물 현장 바인더 편철 구조

현장 실물 바인더를 7종의 시트에 대응하는 7개의 전용 탭 섹션으로 구성해라. 각 탭의 앞머리에는 해당 단계에 필요한 승인된 시험 스크립트 개정판과 계측기 교정 성적서를 먼저 철해 두어라.

시험이 종료되면 이 실물 바인더는 풀컬러로 고해상도 스캔되어 Level 6 최종 커미셔닝 보고서의 영구적인 핵심 증빙을 구성하게 된다.
