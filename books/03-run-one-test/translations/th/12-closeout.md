# 12. การปิดงานและการส่งมอบ

การทดสอบความร้อนที่ประสบความสำเร็จไม่ได้หมายถึงการส่งมอบอาคาร การถอนโหลดแบงก์ (load bank) ออกจากโถงศูนย์ข้อมูลเป็นเพียงสัญญาณว่าการทวนสอบแบบพลวัตได้สิ้นสุดลงแล้ว การเปลี่ยนผ่านสถานะของอาคารอย่างเป็นทางการจากระยะก่อสร้างเข้าสู่การปฏิบัติการ IT จริงจะเกิดขึ้นภายใต้ **ระดับ 6 การปิดงาน การส่งมอบ และการส่งมอบงานสู่การปฏิบัติการ (Level 6 Close-Out, Turnover, and Operations Handover)**

ใบรับรองการส่งมอบที่ลงนามในขณะที่รายการแก้ไข (พันช์ลิสต์) ยังไม่ได้รับการแก้ไข หรือลงนามก่อนที่รายงานคอมมิชชันนิงฉบับสมบูรณ์จะได้รับการตรวจสอบ ถือเป็นเอกสารที่มีข้อบกพร่องตามกฎหมาย การส่งมอบระดับ 6 คือหมุดหมายอย่างเป็นทางการที่เจ้าของอาคาร ผู้รับเหมาหลัก และหน่วยงานคอมมิชชันนิงร่วมกันรับรองว่าระบบกลศาสตร์ ไฟฟ้า และระบบควบคุมเป็นไปตามข้อกำหนดโครงการของเจ้าของ (OPR) และมีความปลอดภัยในการรองรับโครงสร้างพื้นฐานการประมวลผลความหนาแน่นสูง

**สถาปัตยกรรมเอกสารการส่งมอบระดับ 6**

| 01 | บทสรุปผู้บริหารและประโยค ข้อกล่าวอ้างที่ทวนสอบแล้ว | ประโยคข้อกล่าวอ้างที่มีลายมือชื่อรับรอง, ผลการตัดสินสุดท้าย, และสรุปสมรรถนะทางความร้อนที่พิสูจน์ได้ |
| :--- | :--- | :--- |
| 02 | ขอบเขตงานและหนังสือแจ้ง การยกเว้น | หนังสือขอบเขตงานอย่างเป็นทางการที่ระบุระดับที่ไม่ได้ดำเนินการ, การทดสอบตามฤดูกาลที่เลื่อนออกไป, และระบบภายนอกที่ไม่รวม |
| 03 | ใบรับรองหมุดหมายหลัก | ใบรับรองความสมบูรณ์ที่ลงนามอย่างเป็นทางการสำหรับระดับ 2, 3, 4 และระดับ 5 |
| 04 | แผ่นบันทึกหลักทั้งเจ็ดที่ลงนาม | แผ่นที่ 1 ถึงแผ่นที่ 7 ที่กรอกข้อมูลสมบูรณ์ด้วยหมึกและลงนาม |
| 05 | ทะเบียนการสอบเทียบเครื่องมือวัด | ใบรับรองการสอบเทียบ ISO 17025 ที่ตรวจสอบย้อนกลับได้ครบทุกชิ้น |
| 06 | แหล่งจัดเก็บข้อมูลอนุกรมเวลาดิบ | บันทึก CSV ดิบสมบูรณ์, บันทึกแนวโน้ม BMS, ค่าแฮชเข้ารหัส SHA |
| 07 | ทะเบียนบันทึกประเด็นที่แก้ไขแล้ว | ทะเบียนพันช์ลิสต์หลักที่แสดงว่ารายการประเภท 1 และ 2 ปิด 100% |
| 08 | ส่วนเสริมคู่มือการปฏิบัติการ | เส้นโค้งปั๊มจากการทดสอบจริง, ช่วงการทำงาน, เซ็ตพอยต์ปลอดภัย |
| 09 | บันทึกการฝึกอบรมทีมปฏิบัติการ | การลงนามรับรองการเดินตรวจและฝึกอบรมขั้นตอน SOP ของเจ้าหน้าที่ |

## โครงสร้างของรายงานคอมมิชชันนิงฉบับสมบูรณ์

รายงานคอมมิชชันนิงฉบับสมบูรณ์ (Final Commissioning Report) คือฐานอ้างอิงทางวิศวกรรมถาวรของโครงสร้างพื้นฐานการหล่อเย็นด้วยของเหลว ในอีกหลายสิบปีข้างหน้า เมื่ออาคารต้องผ่านการปรับปรุงระบบหรือการสืบสวนหาสาเหตุความล้มเหลว ทีมวิศวกรจะย้อนกลับมาดูรายงานฉบับนี้เพื่อตรวจสอบพารามิเตอร์การทำงานเริ่มต้น

รายงานจะต้องได้รับการรวบรวมขึ้นโดยมีเก้าหมวดหมู่มาตรฐาน:

### 1. บทสรุปผู้บริหารและข้อกล่าวอ้างที่ได้รับการรับรอง
เปิดเรื่องด้วยประโยคข้อกล่าวอ้างที่แน่นอนโดยไม่มีการดัดแปลงแก้ไขตามที่กำหนดไว้ในบทที่ 1 รายงานจะให้สรุปผลการปฏิบัติการที่ชัดเจน: กำลังความร้อนรวมที่ทวนสอบได้ (เช่น 1.2 MW ต่อเนื่อง) สภาวะการจ่ายน้ำหล่อเย็นปฐมภูมิ ตัวชี้วัดสมดุลการไหลทุติยภูมิ และการรับรองอย่างเป็นทางการว่าระบบทั้งหมดที่ทดสอบทำงานอยู่ภายในเกณฑ์ข้อกำหนด

### 2. ขอบเขตงานและหนังสือยกเว้นอย่างเป็นทางการ
การกำหนดขอบเขตที่เข้มงวด หากการตรวจสอบการออกแบบระดับ 0 หรือการทดสอบที่โรงงานระดับ 1 ถูกยกเว้นออกจากสัญญา หนังสือยกเว้นขอบเขตงานอย่างเป็นทางการที่ลงนามโดยเจ้าของโครงการจะต้องถูกบรรจุไว้ที่นี่ หากการทดสอบตามฤดูกาล (เช่น การทดสอบความเค้นของชิลเลอร์ที่อุณหภูมิภายนอกสูงสุดในฤดูร้อน) จำเป็นต้องเลื่อนออกไป โปรโตคอลการทดสอบที่เลื่อนออกไปและกำหนดเวลาการทดสอบจะต้องได้รับการบันทึกไว้อย่างเป็นทางการ

### 3. ใบรับรองความสมบูรณ์ของหมุดหมายหลัก
หน้าใบรับรองอย่างเป็นทางการสำหรับระดับ 2 (การตรวจรับมอบ QA), ระดับ 3 (การตรวจสอบก่อนเริ่มทำงาน PFC และการสตาร์ตระบบ), ระดับ 4 (การทดสอบสมรรถนะการทำงานของระบบเดี่ยว FPT) และระดับ 5 (การทดสอบระบบบูรณาการ IST) แต่ละใบรับรองต้องมีลายมือชื่อด้วยหมึกของหัวหน้าทีมคอมมิชชันนิง วิศวกรวิชาชีพไฟฟ้า วิศวกรวิชาชีพกลศาสตร์ ผู้บริหารฝ่ายผู้รับเหมา และตัวแทนผู้มีอำนาจของเจ้าของโครงการ

### 4. แผ่นบันทึกภาคสนามหลักทั้งเจ็ดฉบับ
แผ่นบันทึกข้อมูลภาคสนามทางกายภาพที่กรอกข้อมูลสมบูรณ์แล้ว (แผ่นที่ 1 ถึงแผ่นที่ 7 จากบทที่ 16) สแกนเป็นภาพสีเต็มรูปแบบเพื่อแสดงลายมือที่เขียนด้วยหมึก อักษรย่อของพยาน เวลาที่บันทึกแต่ละขั้นตอน และบันทึกหมายเหตุหน้างาน

### 5. ทะเบียนเครื่องมือวัดที่ผ่านการสอบเทียบ
บันทึกการตรวจสอบย้อนกลับที่สมบูรณ์ซึ่งระบุมัลติมิเตอร์ เครื่องวิเคราะห์คุณภาพไฟฟ้า อัลตราโซนิกโฟลว์มิเตอร์ ดิจิทัลเทอร์โมมิเตอร์ ทรานสมิตเตอร์วัดแรงดันแตกต่าง และกล้องถ่ายภาพความร้อนอินฟราเรดทุกตัวที่นำมาใช้งานในการทดสอบ พร้อมแนบสำเนาใบรับรองการสอบเทียบตามมาตรฐาน ISO/IEC 17025

### 6. แหล่งจัดเก็บข้อมูลอนุกรมเวลาดิบ
แฟ้มจัดเก็บที่มีโครงสร้างซึ่งบรรจุข้อมูลการวัดระยะไกลดิบความถี่ 1 วินาทีที่ส่งออกจากโหลดแบงก์ เพาเวอร์มิเตอร์ และบันทึกแนวโน้มของ BMS เพื่อป้องกันการแก้ไขดัดแปลงข้อมูลหลังการทดสอบ ให้สร้างค่าแฮชทางวิทยาการเข้ารหัสลับ (SHA-256 checksum) สำหรับไฟล์ข้อมูลดิบทุกไฟล์ และบันทึกตารางค่าแฮชลงในภาคผนวกของรายงาน

### 7. ทะเบียนบันทึกประเด็นหลักที่ได้รับการแก้ไขแล้ว
สำเนาที่พิมพ์ออกมาฉบับสมบูรณ์ของทะเบียนบันทึกประเด็นคอมมิชชันนิง ข้อบกพร่องประเภทที่ 1 และประเภทที่ 2 ทุกรายการจะต้องแสดงประวัติการแก้ไขที่สมบูรณ์: ข้อค้นพบเริ่มต้น การแก้ไขของผู้รับเหมา การอ้างอิงแผ่นข้อมูลการทดสอบซ้ำที่มีพยานรับรอง และลายมือชื่อปิดรายการ รายการเพื่อความสวยงามประเภทที่ 3 ที่ยังเปิดอยู่จะต้องมีแผนการปิดงานภายใน 30 วันที่ได้รับอนุมัติกำกับไว้

### 8. ส่วนเสริมคู่มือการปฏิบัติการของระบบ
สะพานเชื่อมโยงระหว่างข้อมูลคอมมิชชันนิงกับการปฏิบัติการประจำวันของอาคาร ส่วนนี้จะสกัดคุณลักษณะฐานอ้างอิงที่สำคัญออกมาจากข้อมูลการทดสอบ:
- เส้นโค้งปั๊มสภาวะเย็นเทียบกับจุดทำงานในสภาวะร้อนที่ผ่านการทวนสอบแล้ว (แผ่นที่ 6)
- พารามิเตอร์ลูป PID ที่สอบเทียบแล้วสำหรับวาล์วปรับสัดส่วนปฐมภูมิ (TCV-101)
- ปริมาตรสารหล่อเย็นทุติยภูมิรวมที่แน่นอน (V_total) และความเข้มข้นของไกลคอล (ทวนสอบด้วยรีแฟรกโตมิเตอร์ที่ 25.0% ± 0.5%)
- เมทริกซ์ตรรกะอินเทอร์ล็อกฉุกเฉิน ซึ่งระบุเกณฑ์การทริปของฮาร์ดแวร์

### 9. การลงนามรับรองการฝึกอบรมทีมปฏิบัติการ
เอกสารการส่งมอบการฝึกอบรมการปฏิบัติการอย่างเป็นทางการที่ดำเนินการร่วมกับวิศวกรประจำอาคาร การฝึกอบรมต้องครอบคลุมการเดินตรวจกลไกการหยุดฉุกเฉินทางกายภาพ การใช้งานวาล์วบายพาสแบบแมนนวล ขั้นตอนการเติมสารหล่อเย็นทุติยภูมิ และขั้นตอนการรับทราบและจัดการสัญญาณเตือน

## ข้อความระบุขอบเขตในหน้าสุดท้าย

หน้าสุดท้ายของรายงานจะต้องปกป้องทั้งฝ่ายทดสอบและเจ้าของโครงการโดยระบุไว้อย่างชัดเจนว่าการทวนสอบนี้ไม่ครอบคลุมสิ่งใดบ้าง:

| **ข้อความระบุขอบเขตอย่างเป็นทางการ** |
| :--- |
| "การทวนสอบนี้เป็นการรับรองสมรรถนะของโครงสร้างพื้นฐานการหล่อเย็นด้วยของเหลวภายใต้สภาวะภาระ |
| จำลองทางไฟฟ้าและความร้อนตามที่ได้บันทึกไว้อย่างชัดเจนในเอกสารนี้เท่านั้น การทวนสอบนี้ไม่ได้รับรอง |
| ความน่าเชื่อถือในการปฏิบัติงาน ปริมาณงานประมวลผล หรือความสอดคล้องตามการรับประกันของฮาร์ดแวร์ IT |
| สำหรับการใช้งานจริง ระบบที่ระบุว่าถูกยกเว้นหรือไม่ได้สาธิตยังคงอยู่นอกเหนือขอบเขตของการรับรองนี้ |
| สมรรถนะที่ผ่านการทวนสอบทั้งหมดขึ้นอยู่กับเงื่อนไขว่าอาคารจะต้องทำงานอยู่ภายในขอบเขตด้านสิ่งแวดล้อม |
| ไฟฟ้า และชลศาสตร์ที่กำหนดไว้ในรายงานฉบับนี้เท่านั้น" |

## การตัดสินใจที่ต้องบันทึกก่อนเริ่มการทดสอบ

- เทมเพลตรายงานฉบับสมบูรณ์และรูปแบบการจัดเก็บแฟ้มเอกสาร
- การยืนยันว่าข้อบกพร่องในพันช์ลิสต์ประเภทที่ 1 และ 2 ปิดลงครบ 100%
- ทะเบียนค่าแฮชตรวจสอบความถูกต้อง SHA-256 สำหรับไฟล์ข้อมูลการวัดระยะไกลดิบทั้งหมด
- ใบรับรองการส่งมอบระดับ 6 อย่างเป็นทางการ ซึ่งลงนามโดยผู้มีส่วนได้ส่วนเสียหลักทุกฝ่าย
- ทะเบียนการฝึกอบรมฝ่ายปฏิบัติการอาคารและส่วนเสริมคู่มือระบบที่มีลายมือชื่อรับรอง
