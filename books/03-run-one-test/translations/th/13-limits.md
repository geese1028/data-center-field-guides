# 13. สิ่งที่โครงการนี้ไม่ได้เป็นเจ้าของ

หนังสือเล่มนี้ย่อมจะถูกนำไปใช้อย่างผิดวัตถุประสงค์โดยผู้ที่พยายามขยายเนื้อหาให้กลายเป็นสารานุกรมที่ครอบคลุมงานวิศวกรรมการหล่อเย็นด้วยของเหลวทั้งหมดอย่างหลีกเลี่ยงไม่ได้ จงกำหนดขอบเขตทางวิชาชีพที่ชัดเจนไว้ที่นี่

โครงการทวนสอบคอมมิชชันนิง (commissioning) จะรักษาอำนาจหน้าที่ทางกฎหมายและวิศวกรรมไว้ได้ก็ต่อเมื่อขอบเขตของโครงการได้รับการนิยามไว้อย่างเฉียบคมเท่านั้น การขยายขอบเขตการทวนสอบข้ามไปยังสาขาวิชาชีพวิศวกรรมข้างเคียงอย่างกะทันหันจะนำไปสู่การทดสอบที่บกพร่อง ความรับผิดชอบที่เจือจาง และข้อพิพาทตามสัญญาที่รุนแรง

**ขอบเขตเชิงปฏิเสธที่ชัดเจน**

| สิ่งที่โครงการนี้ทำการทวนสอบ | สิ่งที่โครงการนี้ไม่สามารถและไม่ได้เป็นเจ้าของ |
| :--- | :--- |
| • การถ่ายโอนความร้อนจำลอง | • ขอบเขตเล่ม 01: การออกแบบโหลดแบงก์ R&D และ QA การผลิต |
| • เส้นโค้งฐานอ้างอิงปั๊มทุติยภูมิ | • ขอบเขตเล่ม 02: คณิตศาสตร์การวัดระยะไกล อัลกอริทึมตรวจจับจุดผิด |
| • การทนทานต่อการสลับไฟฟ้าแบบ 2N | • การออกแบบอาคาร: วิศวกรรมสถาปัตยกรรม โครงสร้าง และ MEP |
| • สมดุลการไหลแมนิโฟลด์หลายแร็ค | • สมรรถนะของซิลิคอน: การประมวลผล GPU บัสหน่วยความจำ ภาระงาน AI |
| • ลูปความปลอดภัยอัตโนมัติของ CDU | • โลหะวิทยาและเคมี: การกัดกร่อนของน้ำ สารกำจัดจุลชีพ (เล่ม 08) |
| • การทริปสัญญาณเตือนฮาร์ดแวร์จริง | • โถงศูนย์ข้อมูลถัดไป: กฎหมายอาคารสากลที่อนุมานต่อยอดไปเอง |

## ขอบเขตเฉพาะด้าน

### 1. ไม่ได้เป็นเจ้าของการออกแบบโหลดแบงก์ (ขอบเขตเล่ม 01)
การทวนสอบนี้ตั้งอยู่บนข้อสมมติฐานว่าโหลดแบงก์ (load bank) ที่นำมาใช้งานหน้างานได้ผ่านการทดสอบรับมอบที่โรงงาน การทวนสอบความเป็นฉนวนของโครงตู้ และการทดสอบคุณลักษณะบนแท่นทดสอบการไหลตามระเบียบวินัยของเล่มที่ 01 มาเรียบร้อยแล้ว หากโหลดแบงก์ส่งมอบมายังหน้างานในสภาพของเครื่องต้นแบบที่ยังไม่ได้ทวนสอบ ซึ่งมีรอยเชื่อมประสานภายในรั่วซึม หรือมีชุดควบคุม SCR ที่ไม่เสถียร หัวหน้าทีมคอมมิชชันนิงจะต้องปฏิเสธการเชื่อมต่ออุปกรณ์ดังกล่าว ห้ามเปลี่ยนโครงการคอมมิชชันนิงหน้างานให้กลายเป็นห้องปฏิบัติการวิจัยและพัฒนาอุปกรณ์เฉพาะกิจโดยเด็ดขาด

### 2. ไม่ได้เป็นเจ้าของการแปลผลการวัดระยะไกล (ขอบเขตเล่ม 02)
การทวนสอบนี้ทำหน้าที่บันทึกการวัดค่าทางกายภาพดิบและเวลาที่ร่วมเป็นพยาน การกระทบยอดทางอัลกอริทึมของรายงานด่วน การวิเคราะห์จุดเปลี่ยนพฤติกรรม (FLOC/Focus) และการตรวจสอบความถูกต้องทางสถิติของข้อมูล เป็นระเบียบวินัยของเล่มที่ 02 เส้นโค้งความร้อนที่ดูเหมือนจะนิ่งบนจอมอนิเตอร์ BMS ไม่ถือว่าผ่านจนกว่าไฟล์ข้อมูลดิบจะผ่านการตรวจสอบความแปรปรวนและบิตมาสก์คุณภาพข้อมูล ในทางกลับกัน ทีมทดสอบภาคสนามจะต้องไม่แต่งเกณฑ์การยอมรับที่ผ่อนปรนขึ้นมาเองหน้างานเพียงเพราะมีผู้บริหารของลูกค้ามายืนดูการทดสอบ

### 3. ไม่ได้เป็นเจ้าของการออกแบบระบบ MEP ของอาคาร
ทีมทวนสอบมีหน้าที่ตรวจสอบระบบวิศวกรรมอาคารทางกายภาพเทียบกับเกณฑ์พื้นฐานการออกแบบ (BOD) ที่ได้รับอนุมัติ หากระบบอาคารไม่สามารถรักษาอุณหภูมิจ่ายของลูปทุติยภูมิได้เนื่องจากโรงชิลเลอร์ส่วนกลางมีขนาดเล็กเกินไป หรือเนื่องจากขนาดเส้นผ่านศูนย์กลางท่อเมนทุติยภูมิทำให้เกิดการสูญเสียแรงดันจากแรงเสียดทานมากเกินไป ความล้มเหลวนั้นถือเป็นความเบี่ยงเบนในการติดตั้งหรือความบกพร่องในการออกแบบ ทีมทวนสอบมีหน้าที่บันทึกสมรรถนะทางกายภาพที่เกิดขึ้นด้วยหมึก พวกเขาไม่ได้มีหน้าที่มาออกแบบระบบท่อของอาคารใหม่หน้างาน หรือออกคำพูดปลอบใจว่าการติดตั้งนั้น "ใกล้เคียงพอใช้ได้"

### 4. ไม่ได้เป็นเจ้าของเคมีของเหลวและโลหะวิทยา (ขอบเขตเล่ม 08)
ทีมทวนสอบทำหน้าที่ตรวจสอบพารามิเตอร์ของเหลวพื้นฐาน (ความเข้มข้นของไกลคอลด้วยรีแฟรกโตมิเตอร์ ± 0.5% ความขุ่น และค่า pH เริ่มต้น) เพื่อเป็นเงื่อนไขเบื้องต้นสำหรับการทดสอบ พวกเขาไม่ได้รับรองความเข้ากันได้ทางโลหะวิทยาระยะยาว อัตราการกัดกร่อนจากโลหะต่างชนิด (galvanic corrosion) ระหว่างแผ่นระบายความร้อนทองแดงกับแมนิโฟลด์อะลูมิเนียม หรือเส้นโค้งการเสื่อมสภาพของสารกำจัดจุลชีพ การทวนสอบทางเคมีระยะยาวเหล่านั้นเป็นระเบียบวินัยของเล่มที่ 08

### 5. ไม่ได้เป็นเจ้าของโครงสร้างพื้นฐานการประมวลผลของซิลิคอน
โหลดแบงก์หล่อเย็นด้วยของเหลวทำหน้าที่จำลองการกระจายพลังงานไฟฟ้าและความดันตกคร่อมทางชลศาสตร์ของแร็คประมวลผลเร่งความเร็ว (เช่น สถาปัตยกรรมระดับ NVL72) เท่านั้น ภายในไม่มีไมโครโปรเซสเซอร์ซิลิคอน ทรานซีฟเวอร์แสง หรือโครงข่ายเครือข่าย NVLink โหลดแบงก์ที่ทำงานได้อย่างเสถียรภายใต้ขั้นความร้อน 120 kW ได้พิสูจน์เพียงว่าลูปหล่อเย็นสามารถดึงความร้อน 120 kW ออกไปได้ แต่ไม่ได้พิสูจน์ว่าแร็คเซิร์ฟเวอร์จริงจะสามารถบูตระบบ ฝึกสอนโครงข่ายประสาทเทียมขนาดใหญ่ หรือหลีกเลี่ยงการลดความเร็วของชิปเนื่องจากความร้อน (thermal throttling) ได้

### 6. ไม่ได้เป็นเจ้าของโถงศูนย์ข้อมูลถัดไป
ขั้นตอนการทำงานที่กำหนดขึ้นในหนังสือเล่มนี้—ลำดับของผลิตภัณฑ์ทั้งสิบสอง ลำดับชั้นหกระดับ หน้าที่ปฏิบัติการทั้งห้า และแผ่นบันทึกหลักทั้งเจ็ด—สามารถนำไปประยุกต์ใช้ได้ในระดับสากลกับอาคารที่มีภารกิจวิกฤตทุกแห่ง อย่างไรก็ตาม พารามิเตอร์ทางตัวเลขที่เฉพาะเจาะจง (เช่น ขั้นกำลังไฟฟ้า kW ที่แน่นอน ระยะเวลาคงที่ เกณฑ์ความคลาดเคลื่อนของการไหล และอุณหภูมิการทำงานสูงสุด) เป็นค่าเฉพาะของสัญญาแต่ละฉบับที่มีผลบังคับใช้ การคัดลอกค่าตัวเลขจากโถงนี้ไปใส่ในอาคารอื่นโดยไม่มีการวิเคราะห์ทางวิศวกรรมอย่างอิสระ จะทำให้คู่มือภาคสนามเล่มนี้กลายเป็นการคัดลอกและวางที่ปราศจากการทวนสอบ

## การตัดสินใจที่ต้องบันทึกก่อนเริ่มการทดสอบ

- การอ้างอิงใบรับรองการตรวจรับมอบที่โรงงานของโหลดแบงก์ (เล่ม 01) หรือหนังสือปฏิเสธการเชื่อมต่ออย่างเป็นทางการ
- ขั้นตอนการตรวจสอบข้อมูลที่เป็นทางการที่นำมาจากเล่ม 02
- รายการสาขาวิชาวิศวกรรมที่ได้รับการยกเว้นอย่างชัดเจน โดยบันทึกไว้บนแผ่นข้อกล่าวอ้างและยืนยันซ้ำในรายงานฉบับสมบูรณ์
