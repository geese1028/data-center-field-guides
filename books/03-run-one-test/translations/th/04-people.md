# 4. บุคลากรและวงแหวนการกำกับดูแล

การทวนสอบการหล่อเย็นด้วยของเหลว (liquid cooling) ที่ดำเนินการโดยไม่มีการกำหนดบทบาทหน้าที่ของแต่ละบุคคลอย่างชัดเจน จะกลายสภาพเป็นการถกเถียงกลุ่มที่ไร้ทิศทางอย่างรวดเร็ว ข้อกำหนดขั้นตอนการทำงานทั่วไปมักเรียกร้องให้มีเมทริกซ์ RACI (Responsible, Accountable, Consulted, Informed) อย่างละเอียด แต่ในสภาพแวดล้อมที่มีเดิมพันสูงของโถงศูนย์ข้อมูลที่กำลังทำงานจริงหรือใกล้จะเริ่มทำงาน โครงสร้างดังกล่าวจะต้องถูกกลั่นกรองให้เหลือเพียงนิติบุคคลเชิงพาณิชย์สามฝ่ายและหน้าที่ทางวิศวกรรมเฉพาะด้านห้าหน้าที่

```
+----------------------------------------------------------------------------------------------------+
| สามเหลี่ยมการกำกับดูแลสามฝ่าย |
+------------------------------------+---------------------------------------------------------------+
| เจ้าของอาคาร / ผู้ว่าจ้าง | ร่วมเป็นพยานการทดสอบ อนุมัติการสละสิทธิ์ความเบี่ยงเบน และลงนาม |
| (Client / Hyperscaler Ops) | ใบรับรองระดับสุดท้าย ไม่เป็นผู้ลงมือจับเครื่องมือ |
+------------------------------------+---------------------------------------------------------------+
| หน่วยงานทวนสอบ (CxA) | จัดทำ Cx Plan และสคริปต์ จัดการสอบเทียบ ควบคุมขั้นตอน บันทึก |
| (Independent Testing Agency) | ข้อมูล และตรวจพันช์ลิสต์ ไม่เคยปิดข้อบกพร่องของตนเอง |
+------------------------------------+---------------------------------------------------------------+
| ผู้รับเหมาก่อสร้างและติดตั้ง | จัดหาแบบ as-built สับเบรกเกอร์และเปิดปิดวาล์ว ดำเนินการแก้ไข |
| (General / Mechanical / Electrical)| ข้อบกพร่องในพันช์ลิสต์ตามใบอนุญาต |
+------------------------------------+---------------------------------------------------------------+
```

## นิติบุคคลเชิงพาณิชย์สามฝ่าย

เส้นแบ่งระหว่างทั้งสามฝ่ายนี้จะต้องได้รับการบังคับใช้อย่างเคร่งครัด
- **เจ้าของอาคาร (Facility Owner)**: เป็นผู้ถือครองอำนาจเด็ดขาดในเชิงพาณิชย์ ทำหน้าที่ร่วมเป็นพยานในขั้นตอนการปฏิบัติการที่สำคัญ และลงนามในใบรับรองความสมบูรณ์ระดับ 4 และระดับ 5 ตัวแทนของเจ้าของโครงการต้องไม่มายืนเขียนสคริปต์ภาคสนามอยู่ที่ทางเดินในโถง และต้องไม่ไปจับคันโยกวาล์ว
- **หน่วยงานทวนสอบ (Verification Party / CxA)**: จัดทำแผนงานคอมมิชชันนิงและสคริปต์การทดสอบ ควบคุมลำดับการทดสอบ และร่วมเป็นพยานในทุกการวัดค่า พวกเขาเป็นผู้ดูแลทะเบียนรายการแก้ไขหลัก (Master Punch List) และจะไม่ลงนามปิดรายการแก้ไขของตนเองโดยปราศจากการตรวจสอบอิสระรอบที่สอง
- **ผู้รับเหมาก่อสร้าง (Constructor)**: จัดเตรียมเอกสารอนุมัติวัสดุอุปกรณ์และแบบก่อสร้างจริง (as-built) ทำการสับจ่ายกระแสไฟฟ้าที่เบรกเกอร์ หมุนเปิดปิดวาล์วตัดตอน และลงมือแก้ไขข้อบกพร่องทางกายภาพที่ระบุไว้ในรายการแก้ไข

หากบริษัทวิศวกรรมแห่งเดียวได้รับการว่าจ้างให้ทำงานทั้งสองด้าน คือทั้งก่อสร้างและทำคอมมิชชันนิง ความขัดแย้งทางผลประโยชน์ (conflict of interest) ดังกล่าวจะต้องได้รับการบันทึกเป็นลายลักษณ์อักษรไว้ในหน้าแรกของแผนงานคอมมิชชันนิง เมื่อผู้ติดตั้งและพยานผู้ทวนสอบสังกัดอยู่ในสายการบังคับบัญชาเดียวกัน การกำกับดูแลโครงการจะบกพร่องทันที เว้นแต่ว่าจะมีการแยกบุคลากรที่ปฏิบัติงานและเป็นพยานออกจากกันอย่างเด็ดขาดโดยไม่รายงานตรงต่อกัน

## หน้าที่ปฏิบัติการห้าด้าน

ภายในทีมทดสอบที่หน้างาน จะต้องมีผู้รับผิดชอบหน้าที่ทางเทคนิคห้าด้านที่แตกต่างกัน หน้าที่เหล่านี้แสดงถึงความรับผิดชอบเชิงฟังก์ชันมากกว่าการบังคับว่าต้องมีห้าคนแยกจากกัน ในการทดสอบขนาดเล็ก วิศวกรที่มีประสบการณ์หนึ่งคนอาจรับผิดชอบได้หลายสาขา อย่างไรก็ตาม ห้ามมิให้บุคคลใดทำหน้าที่เป็นพยานเพียงคนเดียวสำหรับงานปฏิบัติการที่ตนเองเป็นผู้ลงมือทำทางกายภาพ

```
+--------------------------------------------------------------------------------------------------+
| หน้าที่ทางเทคนิคห้าด้าน |
+-------------------+------------------------------------------------------------------------------+
| 1. หัวหน้าการทดสอบ| รับผิดชอบหน้าต่างทดสอบที่ได้รับอนุมัติ บังคับใช้ข้อกล่าวอ้าง ควบคุมเวลา |
| (Test Lead) | แต่ละขั้นตอน จัดการการสื่อสาร และเป็นผู้มีอำนาจเดี่ยวในการสั่งเริ่มจ่ายความร้อน|
+-------------------+------------------------------------------------------------------------------+
| 2. วิศวกรไฟฟ้า | ควบคุมระบบตัดแยกและแขวนป้าย (LOTO) ทดสอบความเป็นฉนวน (Megger) และระบบกราวด์, |
| (Electrical PE)| ทวนสอบลำดับเฟส ตรวจสอบเส้นโค้งตัดวงจรของ PDU และสแกนภาพถ่ายความร้อน (IR) |
+-------------------+------------------------------------------------------------------------------+
| 3. วิศวกรกลศาสตร์ | บริหารจัดการลูปของเหลวทุติยภูมิ ดูแลการคงแรงดันไฮโดรสแตติกและการไล่อากาศ, |
| (Mechanical PE)| ตรวจสอบเส้นโค้งปั๊ม CDU และติดตามความสมบูรณ์ของซีลหัวต่อสวมเร็ว |
+-------------------+------------------------------------------------------------------------------+
| 4. วิศวกรระบบควบคุม| ตรวจสอบเปรียบเทียบค่า BMS กับเครื่องมือวัดภาคสนามที่สอบเทียบแล้ว, ทวนสอบรีจิสเตอร์|
| (Controls PE) | Modbus/BACnet และจำลองสัญญาณเตือนฮาร์ดแวร์เพื่อทวนสอบตรรกะการทริป |
+-------------------+------------------------------------------------------------------------------+
| 5. ช่างเทคนิคทดสอบ| ดูแลการเชื่อมต่อโหลดแบงก์ ตรวจสอบบันทึกการสอบเทียบเครื่องมือ บันทึกค่าที่วัดได้|
| (Test Tech) | ทั้งหมดด้วยหมึกลงบนแผ่นบันทึกหลัก และดูแลการจัดเก็บแฟ้มข้อมูล |
+-------------------+------------------------------------------------------------------------------+
```

### 1. หัวหน้าการทดสอบ (The Test Lead)
เป็นเจ้าของหน้าต่างการทดสอบที่ได้รับอนุมัติ ประสานงานกับฝ่ายปฏิบัติการอาคาร สั่งการเปลี่ยนผ่านแต่ละขั้นตอน และดูแลให้การทดสอบดำเนินไปตามฉบับแก้ไขของสคริปต์ที่ได้รับอนุมัติอย่างเคร่งครัด หัวหน้าการทดสอบต้องไม่ถือเครื่องมือวัดไว้ในมือ สมาธิของเขาต้องมุ่งเน้นไปที่เสถียรภาพของระบบ การปฏิบัติตามโปรโตคอล และความปลอดภัยโดยรวม

### 2. วิศวกรไฟฟ้า (The Electrical Engineer)
สั่งการและควบคุมโปรโตคอลตัดแยกพลังงานและแขวนป้ายเตือน (LOTO) ดำเนินการทดสอบความต้านทานของฉนวน (Megger) ในสภาวะสถิต ทวนสอบลำดับเฟสด้วยมิเตอร์วัดการหมุนของเฟส ตรวจสอบการตั้งค่าเบรกเกอร์ต้นทาง และสแกนภาพถ่ายความร้อนบนบัสบาร์ สายเคเบิล และคอนแทกเตอร์ที่มีกระแสไฟฟ้าสูง การหมุนของเฟสเป็นพารามิเตอร์ทางไฟฟ้าที่มีความสำคัญต่อความปลอดภัยขั้นวิกฤต ลำดับเฟสที่กลับทิศสามารถทำให้ปั๊มทุติยภูมิแบบแคนด์ (canned pump) หมุนย้อนทาง ส่งผลให้เกิดการเกิดโพรงไอ (cavitation) รุนแรง ไม่สามารถสร้างแรงดันได้ และทำลายแบริ่งรับแรงตามแนวแกน (thrust bearing) พังเสียหายภายในเวลาไม่กี่นาที

### 3. วิศวกรกลศาสตร์ (The Mechanical Engineer)
ดูแลเส้นทางของเหลว: ท่อทุติยภูมิ การจัดวางสายยาง หัวต่อสวมเร็ว การไล่อากาศ และองค์ประกอบทางเคมีของสารหล่อเย็น พวกเขาต้องตรวจสอบบันทึกการทดสอบคงแรงดันไฮโดรสแตติก ติดตามระดับการอัดก๊าซไนโตรเจนล่วงหน้าของถังขยายตัว (expansion tank) และควบคุมการหาเส้นโค้งปั๊มฐานอ้างอิง

### 4. วิศวกรระบบควบคุม (The Controls Engineer)
ตรวจสอบเปรียบเทียบระบบจัดการอาคาร (BMS) และหน้าจอสัมผัส (HMI) ของ CDU เทียบกับเครื่องมือวัดอ้างอิงภาคสนามที่ผ่านการสอบเทียบ พวกเขายืนยันแอดเดรสของรีจิสเตอร์ ตรวจสอบการสอบเทียบออฟเซ็ตของเซ็นเซอร์ และจัดเตรียมการทดสอบสัญญาณเตือนจำลอง (เช่น อัตราการไหลต่ำ อุณหภูมิสูง และการตรวจจับของเหลวรั่วไหล) หน้าจอ BMS ที่เพียงแค่แสดงผลลอกเลียนแบบหน้าจออื่นไม่ถือว่าเป็นการทวนสอบระบบควบคุมที่ยอมรับได้

### 5. ช่างเทคนิคทดสอบ (The Test Technician)
ทวนสอบอุปกรณ์จริงเทียบกับรายการบรรจุหีบห่อ ตรวจสอบใบรับรองการสอบเทียบของเครื่องมือ และดูแลแผ่นบันทึกข้อมูลภาคสนาม ช่างเทคนิคคนหนึ่งทำการวัดค่าด้วยเครื่องมือที่สอบเทียบแล้ว ขณะที่ช่างเทคนิคอีกคนหนึ่งบันทึกค่าที่อ่านได้ลงในกระดาษด้วยหมึกทันที แผ่นบันทึกที่สูญหายจะทำให้ผลการทดสอบในวันนั้นตกเป็นโมฆะ ไม่ว่าระบบกลศาสตร์จะทำงานได้ยอดเยี่ยมเพียงใดก็ตาม

## อำนาจสั่งจ่ายความร้อน เทียบกับ อำนาจสั่งหยุดฉุกเฉินสากล

การกระจายอำนาจระหว่างการทดสอบแบบพลวัตอยู่ภายใต้กฎเหล็กสองข้อ:

1. **อำนาจสั่งการเดี่ยว (Singular Command Authority)**: การสั่งจ่ายภาระความร้อนสามารถกระทำได้โดย **บุคคลเพียงคนเดียว** เท่านั้น นั่นคือ หัวหน้าการทดสอบ (Test Lead) ที่ได้รับการแต่งตั้ง ชื่อของบุคคลผู้นี้จะถูกเขียนด้วยหมึกลงบนแผ่นบันทึกที่ 3 ก่อนที่จะมีการสับเบรกเกอร์ตัวแรก ไม่อนุญาตให้เริ่มขั้นภาระความร้อนใดๆ จากคำแนะนำด้วยวาจาของเจ้าของโครงการ ผู้รับเหมา หรือผู้สังเกตการณ์จากผู้ผลิต
2. **อำนาจสั่งหยุดฉุกเฉินสากล (Universal Stop Authority)**: การสั่งหยุดฉุกเฉินสามารถกระทำได้โดย **ทุกคนที่อยู่ในโถงศูนย์ข้อมูล** อำนาจนี้เด็ดขาด ไม่สามารถต่อรองได้ และไม่ต้องการการอนุมัติล่วงหน้าจากหัวหน้าการทดสอบ หากช่างเทคนิคสังเกตเห็นรอยรั่วที่หัวต่อสวมเร็ว เด็กฝึกงานไฟฟ้าได้กลิ่นผิดปกติ หรือผู้สังเกตการณ์รู้สึกไม่มั่นใจในสภาวะการทำงานชั่วขณะ ทุกคนสามารถสั่งหยุดได้ทันที ระบบจะถูกปิดลงในเสี้ยววินาทีโดยไม่มีการโต้เถียง

```
+----------------------------------------------------------------------------------------------------+
| การกำกับดูแลคำสั่งและความปลอดภัย |
+--------------------------------------------------+-------------------------------------------------+
| ผู้มีอำนาจสั่งจ่ายความร้อน | ผู้มีอำนาจสั่งหยุดฉุกเฉิน |
+--------------------------------------------------+-------------------------------------------------+
| • มีเพียงบุคคลเดียวที่ระบุชื่อไว้หน้างาน | • ทุกคนที่อยู่ในห้อง |
| • เขียนด้วยหมึกลงบนแผ่นที่ 3 ก่อนเริ่มขั้นตอนแรก | • ไม่ต้องการมติเอกฉันท์หรือการอนุมัติล่วงหน้า |
| • ต้องยืนยันว่าเกตเงื่อนไขเบื้องต้นลงนามครบถ้วน | • มีอำนาจเหนือกว่ากำหนดการและค่าใช้จ่ายโครงการ |
| • ปฏิบัติการอย่างเคร่งครัดตามขั้นตอนในสคริปต์ | • อยู่เหนือผังโครงสร้างองค์กรอย่างสมบูรณ์ |
+--------------------------------------------------+-------------------------------------------------+
```

## การกำกับดูแลในการประชุมเปิดโครงการ (Kickoff Meeting)

ความรับผิดชอบเหล่านี้จะต้องได้รับการลงนามรับรองอย่างเป็นทางการระหว่างการประชุมเปิดโครงการคอมมิชชันนิง ซึ่งจัดขึ้นก่อนการระดมพลเข้าสู่พื้นที่ การเข้าร่วมประชุมเป็นข้อบังคับสำหรับทุกคนที่มีอำนาจในการปฏิบัติการหรือร่วมเป็นพยาน

การประชุมเปิดโครงการจะต้องบรรลุผลลัพธ์ห้าประการที่ไม่สามารถละเว้นได้:
1. กำหนดบทบาทหน้าที่ทุกด้านให้แก่บุคคลที่มีชื่อระบุชัดเจน พร้อมข้อมูลติดต่อตลอด 24 ชั่วโมง
2. ตรึงหมายเลขเอกสารสคริปต์การทดสอบและฉบับแก้ไขที่ได้รับอนุมัติให้หยุดนิ่ง (freeze)
3. กำหนดนิยามของสถานะเอกสาร "อนุมัติสำหรับการปฏิบัติงานจริง (Approved for Execution)" ไว้อย่างเป็นทางการ สคริปต์ที่อยู่ในสถานะ "ฉบับร่าง (Draft)", "อยู่ระหว่างการทบทวน (Under Review)" หรือ "เพื่อทราบ (Informational)" ถือเป็นเอกสารที่ต้องห้ามนำมาใช้ทดสอบหน้างานโดยเด็ดขาดตามกฎหมาย
4. จัดตั้งแหล่งจัดเก็บทะเบียนบันทึกประเด็นหลัก (Issues Log) พร้อมสิทธิ์การอ่าน/เขียนที่ปลอดภัย
5. ทวนสอบสายการบังคับบัญชาและแจ้งเหตุฉุกเฉิน ซึ่งรวมถึงผู้รับผิดชอบการตัดระบบสาธารณูปโภค วิศวกรระบบแจ้งเหตุเพลิงไหม้ และผู้รับผิดชอบการกักกันสารเคมีรั่วไหล

## การตัดสินใจที่ต้องบันทึกก่อนเริ่มการทดสอบ

- นิติบุคคลสามฝ่ายที่เข้าร่วม พร้อมบันทึกหากมีการแต่งตั้งบทบาททับซ้อน
- รายชื่อ เบอร์โทรศัพท์ติดต่อ และใบอนุญาตประกอบวิชาชีพของแต่ละบุคคลในหน้าที่ทั้งห้า
- บุคคลผู้ได้รับมอบหมายเพียงคนเดียวที่มีอำนาจสั่งจ่ายภาระความร้อน
- การยืนยันซ้ำว่าทุกคนในสถานที่ปฏิบัติงานมีอำนาจสั่งหยุดฉุกเฉินโดยไม่มีอุปสรรคขัดขวาง
- สถานะการอนุมัติสคริปต์ที่เป็นทางการซึ่งอนุญาตให้เริ่มการทดสอบที่หน้างาน
