# 11. รายการแก้ไข (พันช์ลิสต์)

ข้อบกพร่องจากการติดตั้งหรือความล้มเหลวของสมรรถนะที่ไม่ได้ถูกบันทึกไว้ในทะเบียนบันทึกประเด็นคอมมิชชันนิงอย่างเป็นทางการ (Official Commissioning Issues Log) ถือว่าไม่มีตัวตนอยู่จริงตามกฎหมาย แม้ว่าการละเว้นนี้อาจสะดวกสำหรับผู้รับเหมาที่เร่งรีบจะถอนกำลัง แต่กลับสร้างอันตรายในการปฏิบัติการที่ไม่อาจยอมรับได้แก่ทีมปฏิบัติการของอาคารซึ่งต้องเป็นผู้ดูแลโถงศูนย์ข้อมูลเมื่ออุปกรณ์ IT จริงมาถึง

ทะเบียนรายการแก้ไขหลัก (Master Punch List) จะต้องได้รับการจัดตั้งขึ้นระหว่างการประชุมเปิดโครงการคอมมิชชันนิง ไม่ใช่รอจนกระทั่งพบการรั่วไหลของสารหล่อเย็นทุติยภูมิจุดแรก ทุกรายการที่บันทึกจะต้องมีคำอธิบายที่ชัดเจนซึ่งผู้ตรวจสอบภายนอกสามารถเข้าใจได้: รหัสป้ายอุปกรณ์เฉพาะ การอ้างอิงแบบ P&ID ที่เกี่ยวข้อง หมายเลขขั้นตอนในสคริปต์ที่ล้มเหลว รูปแบบความล้มเหลว ผู้รับเหมาที่ได้รับมอบหมาย การดำเนินการแก้ไขที่จำเป็น และเกณฑ์การยอมรับในการทดสอบซ้ำเพื่อปิดรายการ การบันทึกอย่างคลุมเครือ เช่น "ปัญหา CDU" ถือเป็นสิ่งที่ยอมรับไม่ได้โดยสิ้นเชิง

## สามระดับความรุนแรงของข้อบกพร่อง

ทุกข้อค้นพบที่ถูกบันทึกลงในทะเบียนประเด็นจะต้องได้รับการจำแนกออกเป็นหนึ่งในสามระดับความรุนแรงมาตรฐาน:

```

+------------+-------------------------------+-------------------------------------------------------+

+------------+-------------------------------+-------------------------------------------------------+
| ประเภทที่ 1| ความปลอดภัยวิกฤต / ตัวขัดขวาง | คำสั่งหยุดเด็ดขาด (HARD STOP) ห้ามก้าวข้ามไปสู่ระดับ |
| (Category 1| รั่วไหล > 0 หยด/นาที; ลำดับ | ถัดไป การจ่ายไฟทดสอบความร้อนระดับ 5 ถือเป็นข้อห้าม |
| | เฟสกลับทิศ; E-Stop ล้มเหลว; | ตามกฎหมายตราบใดที่ยังมีรายการประเภทที่ 1 เปิดค้างอยู่ |

| | เซ็นเซอร์เพี้ยน; วาล์วแกว่งตัว| และต้องทำการทดสอบซ้ำภาคบังคับ |

| (Category 3| ลูกศรท่อกลับทิศ; สีรางถลอก; | ใบรับรองหมุดหมาย ทวนสอบผ่านหลักฐานภาพถ่ายภายใน 30 วัน |
```

## อินเทอร์ล็อกของขั้นตอนและโปรโตคอลการสละสิทธิ์

กฎพื้นฐานที่ควบคุมการทำคอมมิชชันนิงศูนย์ข้อมูลคือ **ไม่มีโครงการใดสามารถก้าวข้ามเส้นแบ่งหมุดหมายได้ตราบใดที่ยังมีข้อบกพร่องประเภทที่ 1 (Category 1) ตกค้างอยู่โดยยังไม่ได้รับการแก้ไข**

รายการแก้ไขมักเป็นจุดที่ผู้รับเหมาพยายามเจรจาต่อรองเพื่อเลี่ยงกฎนี้ คำขอร้องของผู้รับเหมาที่กล่าวว่า "เราเข้าใจว่าเช็ควาล์วปฐมภูมิมีน้ำรั่วซึมเล็กน้อยเมื่อเกิดการไหลย้อนกลับ แต่ขอให้เราเดินหน้าทดสอบความร้อน 100% ไปก่อน แล้วเราจะมาซ่อมวาล์วให้ตอนถอนกำลัง" จะต้องได้รับการปฏิเสธอย่างสิ้นเชิง การเริ่มทดสอบความร้อนภาระสูงด้วยเช็ควาล์วที่ชำรุดเสี่ยงต่อการเกิดโพรงไอของปั๊มจากการไหลย้อนกลับ การกระแทกทางชลศาสตร์ที่รุนแรง และมอเตอร์ปั๊มไหม้เสียหายอย่างสิ้นเชิง

หากเจ้าของโครงการตัดสินใจที่จะเดินหน้าต่อไปแม้ว่าจะมีข้อเบี่ยงเบนการทำงานประเภทที่ 2 (Category 2) เปิดค้างอยู่ เพื่อให้ทันกำหนดเวลาส่งมอบทางธุรกิจที่เลื่อนไม่ได้ การตัดสินใจนั้นจะต้องจัดทำเป็น **หนังสือสละสิทธิ์ความเบี่ยงเบน (Deviation Waiver)** ที่ลงนามอย่างเป็นทางการ ซึ่งต้องระบุ:
1. ข้อบกพร่องทางเทคนิคที่แน่นอนและข้อกำหนดสัญญาที่เกี่ยวข้อง
2. การประเมินความเสี่ยงในการปฏิบัติการและรูปแบบความล้มเหลวที่อาจเกิดขึ้น
3. มาตรการควบคุมความปลอดภัยชดเชยเฉพาะที่นำมาใช้ระหว่างหน้าต่างการทดสอบ
4. ข้อผูกพันตามสัญญาและกำหนดเวลาสำหรับการแก้ไขและการทดสอบซ้ำโดยมีพยานร่วมสังเกตการณ์

ข้อตกลงด้วยวาจาหรือข้อความสั้นๆ ทางแอปพลิเคชันถือเป็นโมฆะโดยสิ้นเชิง การสละสิทธิ์ที่ไม่มีการบันทึกเป็นลายลักษณ์อักษรเป็นเพียงการตกลงที่จะยอมรับการประหลาดใจจากความล้มเหลวในการปฏิบัติการเท่านั้น

## การกำกับดูแลการแก้ไขและการทดสอบซ้ำ

การแบ่งแยกหน้าที่ความรับผิดชอบระหว่างการแก้ไขรายการพันช์ลิสต์จะต้องได้รับการรักษาไว้อย่างเข้มงวด:
- **ผู้รับเหมางานก่อสร้างและติดตั้ง**: ลงมือซ่อมแซมทางกายภาพภายใต้ใบอนุญาตทำงานที่เป็นทางการของสถานที่
- **หน่วยงานทวนสอบ (CxA)**: ตรวจสอบการซ่อมแซม ตรวจสอบงานทางกายภาพ ควบคุมสคริปต์การทดสอบซ้ำ และบันทึกข้อมูลใหม่ ทีมทวนสอบจะต้องไม่ลงมือซ่อมแซมระบบกลศาสตร์หรือไฟฟ้าด้วยตนเองเป็นอันขาด เนื่องจากการกระทำดังกล่าวจะทำลายจุดยืนการตรวจสอบที่เป็นอิสระของพวกเขา
- **เจ้าของอาคาร**: ร่วมเป็นพยานในการทดสอบซ้ำและลงนามรับรองการปิดรายการ

รายการแก้ไขไม่สามารถปิดลงได้เพียงเพราะผู้รับเหมาส่งอีเมลแจ้งว่า "ช่างเทคนิคได้ทำการปรับตั้งพารามิเตอร์ของวาล์วแล้ว" การปิดรายการต้องการหลักฐานทางวิศวกรรมในระดับเดียวกันกับที่สคริปต์เดิมเรียกร้อง นั่นคือ แผ่นข้อมูลการทดสอบซ้ำที่มีการปฏิบัติการครบถ้วนและมีพยานรับรอง ซึ่งพิสูจน์ว่าพารามิเตอร์ดังกล่าวเป็นไปตามข้อกำหนดแล้ว

## ขอบเขตการทดสอบซ้ำและขอบเขตเชิงพาณิชย์

การทดสอบซ้ำที่มีพยานรับรองย่อมก่อให้เกิดค่าใช้จ่ายจริงในส่วนของชั่วโมงการทำงานของวิศวกร พลังงานไฟฟ้าของอาคาร และค่าเช่าอุปกรณ์ชั่วคราว แผนงานคอมมิชชันนิงจะต้องระบุไว้ล่วงหน้าอย่างชัดเจนว่าการทดสอบซ้ำครอบคลุมอยู่ในขอบเขตสัญญาเดิมหรือต้องมีการออกเอกสารสั่งเปลี่ยนแปลงงาน (Change Order) เพิ่มเติม

การกำหนดขอบเขตเชิงพาณิชย์นี้ไว้ตั้งแต่เนิ่นๆ จะช่วยป้องกันข้อพิพาทเมื่อต้องทำซ้ำการทดสอบที่ซับซ้อนอันเนื่องมาจากการติดตั้งที่บกพร่องของผู้รับเหมา อย่างไรก็ตาม การเจรจาเชิงพาณิชย์จะต้องไม่ประนีประนอมกับมาตรฐานทางเทคนิค: การทดสอบซ้ำที่ไม่ได้รับอนุมัติซึ่งดำเนินการโดยไม่มีสคริปต์ฉบับแก้ไขอย่างเป็นทางการ ไม่ถือว่าเป็นการทวนสอบที่ถูกต้อง แต่เป็นเพียงการเดินเครื่องอุปกรณ์โดยไม่มีการบันทึกข้อมูลเท่านั้น

## ข้อบกพร่องที่ตรวจพบบนโต๊ะทำงานหลังการถอนกำลัง

ข้อบกพร่องบางประการจะปรากฏให้เห็นหลังจากถอนกำลังออกจากพื้นที่แล้วเท่านั้น เมื่อไฟล์บันทึกการวัดระยะไกลความถี่สูงและไฟล์ CSV ของมิเตอร์วัดกำลังไฟฟ้าได้รับการวิเคราะห์อย่างละเอียดบนเวิร์กสเตชันทางวิศวกรรม

หากการคำนวณสมดุลความร้อนเอนทัลปีเผยให้เห็นว่าอัตราการปิดสมดุลลดลงเหลือ 92.0% ในชั่วโมงความร้อนสุดท้าย หรือหากการวิเคราะห์ความถี่ตรวจพบอาการแกว่งตัวของ VFD แอมพลิจูดต่ำ ข้อค้นพบนั้นจะต้องได้รับการบันทึกอย่างเป็นทางการลงในทะเบียนประเด็นหลัก พร้อมระบุวันที่ตรวจพบในขั้นตอนการประมวลผลข้อมูล

หัวหน้าการทดสอบจะต้องแยกแยะความแตกต่างอย่างรอบคอบระหว่าง:
- **ข้อบกพร่องในการได้มาซึ่งข้อมูล (Data Acquisition Defect)**: เช่น นาฬิกา NTP ไม่ตรงกัน รูปแบบไฟล์ CSV เสียหาย หรือทรานสดิวเซอร์กระแสไฟฟ้าไม่ได้สอบเทียบ
- **ความล้มเหลวของระบบกายภาพ (Physical Plant Failure)**: เช่น สายพานปั๊มลื่นไถล ตะกรันเกาะบนแผ่นแลกเปลี่ยนความร้อน หรือโมดูลไทริสเตอร์เริ่มเสื่อมสภาพ

การสับสนระหว่างข้อผิดพลาดในการรับข้อมูลกับข้อบกพร่องทางกายภาพของระบบ จะทำให้ผู้รับเหมาต้องเสียทรัพยากรไปกับการตรวจสอบอุปกรณ์ที่ปกติ ในทางกลับกัน การระบุว่าความล้มเหลวทางกายภาพของระบบเป็นเพียงความผิดพลาดของระบบวัดระยะไกล จะทำให้ระบบหล่อเย็นที่ชำรุดถูกส่งมอบต่อไปยังการใช้งาน IT จริง

## ข้อกำหนดในการปิดงาน (Closeout Requirement)

เมื่อข้อบกพร่องประเภทที่ 1 และประเภทที่ 2 ทั้งหมดที่ถูกบันทึกไว้ในทุกระดับการทำคอมมิชชันนิงได้รับการแก้ไขอย่างสมบูรณ์และผ่านการทวนสอบด้วยการทดสอบซ้ำที่มีพยานรับรองแล้ว หน่วยงานคอมมิชชันนิงจึงจะสามารถรับรองการปิดงานได้ ข้อตกลงด้วยวาจาในที่ประชุมปิดงานครั้งสุดท้ายว่า "ทุกอย่างเรียบร้อยแล้ว" ไม่มีน้ำหนักตามกฎหมาย ทะเบียนรายการแก้ไขหลักฉบับสมบูรณ์จะต้องได้รับการพิมพ์ออกมา ตรวจสอบ และลงนามด้วยหมึกโดยผู้มีส่วนเกี่ยวข้องทั้งสามฝ่าย

## การตัดสินใจที่ต้องบันทึกก่อนเริ่มการทดสอบ

- แหล่งจัดเก็บ ความปลอดภัยของระบบ และแพลตฟอร์มซอฟต์แวร์สำหรับทะเบียนบันทึกประเด็นหลัก
- รายชื่อบุคคลที่ได้รับมอบหมายให้บันทึกข้อบกพร่อง ดำเนินการซ่อมแซม ร่วมเป็นพยานการทดสอบซ้ำ และลงนามปิดรายการ
- แบบฟอร์มหนังสือสละสิทธิ์ความเบี่ยงเบนที่เป็นทางการ รวมถึงการประเมินความเสี่ยงและแผนบรรเทาผลกระทบภาคบังคับ
- ข้อตกลงเชิงพาณิชย์ที่ควบคุมค่าใช้จ่ายในการทดสอบซ้ำและการจัดสรรเวลาในกำหนดการ
- ทะเบียนรายการแก้ไขหลักที่พิมพ์ออกมาและลงนามครบถ้วน โดยยืนยันว่าทุกรายการได้รับการปิดเรียบร้อยแล้วก่อนการส่งมอบระดับ 6
