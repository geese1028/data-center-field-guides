# 6. สคริปต์ก่อนความร้อน

ห้ามดำเนินการทดสอบคอมมิชชันนิง (commissioning) แบบพลวัตจากความจำหรือคำสั่งด้วยวาจาโดยเด็ดขาด การทดสอบที่ดำเนินการโดยไม่มีสคริปต์การทดสอบแบบทีละขั้นตอนที่ผ่านการอนุมัติล่วงหน้าเป็นเพียงการสาธิตการทำงานของอุปกรณ์อย่างไม่เป็นทางการ และไม่สามารถนำมาใช้สนับสนุนใบรับรองความสมบูรณ์ทางวิศวกรรมได้

สคริปต์ที่ทีมทดสอบร่างขึ้นมาเองแต่ยังไม่ได้รับการทบทวนและลงนามอย่างเป็นทางการจากวิศวกรโครงการของเจ้าของ (Owner PE) เป็นเพียงเอกสารการทำงานภายในเท่านั้น ซึ่งไม่มีผลผูกพันตามสัญญา การดำเนินการทดสอบเทียบกับร่างที่ไม่ได้รับอนุมัติจะทำให้ทีมทดสอบต้องแบกรับความเสี่ยงต่อข้อพิพาทเชิงพาณิชย์และความรับผิดชอบตามกฎหมายอย่างเต็มที่หากเกิดความเสียหายต่ออุปกรณ์ขึ้น

**ลำดับชั้นของเอกสารคอมมิชชันนิง**

| 1. กฎหมายและมาตรฐาน | ASHRAE 0-2019, ASHRAE 90.4, NFPA 70, IEC 60364, BSRIA BG 29 |
| :--- | :--- |
| 2. ข้อกำหนดสัญญา และ BOD | CSI Div 23 & 26, ข้อกำหนดโครงการของเจ้าของ (OPR), แบบ P&ID |
| 3. แผนงานคอมมิชชันนิง (Cx Plan) | กฎการกำกับดูแล, เกตระดับการทดสอบ, โปรโตคอลพยาน, กำหนดการ |
| 4. ขั้นตอนการทดสอบการทำงาน (FPT) | สคริปต์ทีละขั้นตอนที่อนุมัติแล้ว พร้อมช่วงตัวเลขที่ยอมรับได้ |
| 5. แผ่นบันทึกหลักภาคสนาม (หมึก) | บันทึกหน้างานที่ลงนามด้วยหมึก; ไฟล์เซ็นเซอร์อนุกรมเวลาดิบ |

## โครงสร้างของสคริปต์การทดสอบที่ตรวจสอบได้

ทุกขั้นตอนการทดสอบการทำงาน (FPT) และสคริปต์การทดสอบระบบบูรณาการ (IST) จะต้องได้รับการจัดโครงสร้างตามหมวดหมู่วิศวกรรมที่ตรวจสอบได้และสอดคล้องกัน:

1. **ขอบเขตและแนวเขตการทดสอบ**: ส่วนประกอบทางกลศาสตร์และไฟฟ้าเฉพาะที่อยู่ภายใต้การทดสอบ และแนวเขตทางกายภาพที่แน่นอนที่แยกอุปกรณ์เหล่านี้ออกจากอุปกรณ์ที่กำลังทำงานอยู่ข้างเคียง
2. **เอกสารอ้างอิงที่มีผลบังคับใช้**: การอ้างอิงโดยตรงถึงฉบับแก้ไขของแบบ P&ID, แผนภาพเส้นเดี่ยวทางไฟฟ้า (SLD) และเอกสารส่งอนุมัติอุปกรณ์ เกณฑ์ความคลาดเคลื่อนทุกค่าต้องอ้างอิงข้อกำหนดในสัญญาหรือมาตรฐานผู้ผลิตเฉพาะเจาะจง เกณฑ์การยอมรับที่ไม่มีแหล่งที่มาอ้างอิงถือเป็นเพียงความเห็นที่ไร้การทวนสอบ
3. **กำหนดการเครื่องมือวัดและการสอบเทียบ**: ระดับชั้นของเครื่องมือวัด หมายเลขซีเรียล และรหัสใบรับรองการสอบเทียบที่จำเป็นต้องใช้ในการดำเนินขั้นตอน
4. **เกตการทวนสอบเงื่อนไขเบื้องต้น**: การทวนสอบเป็นลายลักษณ์อักษรว่าข้อกำหนดของระดับก่อนหน้าทั้งหมด (เช่น การเปิดหีบห่อสภาวะสถิต การวัดฉนวนเมกเกอร์ขณะตัดไฟ และการทดสอบคงแรงดันไฮโดรสแตติก) ได้รับการลงนามอนุมัติครบถ้วนแล้ว
5. **การควบคุมความปลอดภัยและขอบเขตสิ่งแวดล้อม**: อุปกรณ์คุ้มครองความปลอดภัยส่วนบุคคล (PPE) ภาคบังคับ การกำหนดแนวเขตอันตรายจากประกายไฟวาบ การจัดเตรียมอุปกรณ์กักกันสารเคมีรั่วไหล และเส้นทางการสั่งหยุดฉุกเฉินที่ผ่านการทวนสอบแล้ว
6. **ลำดับการปฏิบัติการทีละขั้นตอน**: ตารางตามลำดับที่ระบุการกระทำด้วยมือทุกขั้นตอน การตอบสนองทางกายภาพที่แน่นอนที่ต้องสังเกต ช่วงความคลาดเคลื่อนทางตัวเลขที่คาดหวัง และช่องลงนามเฉพาะสำหรับข้อมูลที่วัดได้และอักษรย่อของพยาน
7. **เงื่อนไขการหยุดที่ชัดเจน**: ขีดจำกัดในการปฏิบัติงานที่ชัดเจนซึ่งบังคับให้ต้องหยุดการทดสอบทันทีหากเกิดการละเมิด (เช่น อุณหภูมิสารหล่อเย็นทุติยภูมิสูงเกิน 45.0°C, แรงดันสารหล่อเย็นทุติยภูมิลดลงต่ำกว่า 100 kPa หรือแรงดันไฟฟ้าเฟสไม่สมดุลเกิน 2.0%)

## การตรึงฉบับแก้ไขของสคริปต์ที่หน้างาน

การประชุมเปิดโครงการคอมมิชชันนิงจะกำหนดสถานะการอนุมัติเฉพาะที่จำเป็นก่อนที่สคริปต์จะสามารถนำไปปฏิบัติการที่หน้างานได้ เฉพาะสคริปต์ที่ประทับตราสถานะอย่างเป็นทางการว่า **"อนุมัติสำหรับการปฏิบัติงานจริง - ฉบับแก้ไข [X]" (APPROVED FOR EXECUTION - REV [X])** เท่านั้นที่ได้รับอนุญาตให้นำเข้ามาในโถงศูนย์ข้อมูล

หากในระหว่างการทดสอบ ระบบวิศวกรรมอาคารแสดงพฤติกรรมทางพลวัตที่ไม่คาดคิดซึ่งสคริปต์ที่ได้รับอนุมัติไม่ได้คาดการณ์ไว้ การขีดเขียนแก้ไขสคริปต์ที่หน้างานด้วยดินสอถือเป็นข้อห้ามเด็ดขาด การแก้ไขแบบไม่มีการควบคุมจะทำให้ขั้นตอนการทดสอบถูกดัดแปลงตามสิ่งที่ระบบกลศาสตร์บังเอิญทำได้ไปโดยปริยาย

เมื่อมีความจำเป็นต้องแก้ไขขั้นตอนการทำงาน:
- หัวหน้าการทดสอบสั่งหยุดการทดสอบชั่วคราว
- จัดทำเอกสารแจ้งการเปลี่ยนแปลงทางวิศวกรรม (Engineering Change Notice - ECN) อย่างเป็นทางการเพื่อระบุความเบี่ยงเบน เหตุผลสนับสนุนทางเทคนิค และขั้นตอนที่ปรับปรุงใหม่
- เอกสาร ECN ต้องได้รับการลงนามโดยหัวหน้าการทดสอบ หัวหน้าฝ่ายผู้รับเหมา และวิศวกรโครงการของเจ้าของ
- ปรับเพิ่มหมายเลขฉบับแก้ไขของสคริปต์ (เช่น จาก Rev 1.0 เป็น Rev 1.1) และออกเอกสารใหม่

หากเจ้าของโครงการปฏิเสธ ECN การทดสอบจะต้องดำเนินต่อไปตามสคริปต์เดิม และความล้มเหลวของระบบที่ไม่สามารถทำได้ตามผลลัพธ์ที่คาดหวังเดิมจะถูกบันทึกลงในทะเบียนรายการแก้ไขหลัก (Master Punch List)

## ชุดสคริปต์ภาคบังคับสำหรับโถงของเหลวความหนาแน่นสูง

การทวนสอบที่สมบูรณ์ต้องการชุดสคริปต์ที่ครอบคลุม แยกเฉพาะและเป็นอิสระต่อกัน การพยายามรวมการทวนสอบการปฏิบัติการหลายระบบเข้าไว้ในขั้นตอนระดับสูงขั้นตอนเดียวจะทำให้เกิดเอกสารที่เทอะทะและละเลยการตรวจสอบความปลอดภัยและสมรรถนะที่สำคัญไปในที่สุด

โครงการทวนสอบต้องการสคริปต์การทดสอบเฉพาะเก้าฉบับ:

### ระยะที่ 1: รายการตรวจสอบสภาวะสถิตก่อนเริ่มเดินเครื่อง (ระดับ 2 / ระดับ 3)
- **สคริปต์ 01: การเปิดหีบห่อ การจัดแนว และการประกันคุณภาพทางสายตา**: การทวนสอบความสมบูรณ์ของโครงสร้างโหลดแบงก์ เส้นทางการเดินสายยาง ซีลของข้อต่อ และการยึดเหนี่ยวต้านแผ่นดินไหว
- **สคริปต์ 02: การทดสอบเมกเกอร์ฉนวนไฟฟ้าและลำดับเฟสขณะตัดไฟ**: การทดสอบความต้านทานของฉนวน (≥ 100 MΩ ที่แรงดัน 1000V DC) ความต่อเนื่องของระบบกราวด์ (≤ 0.1 Ω) และการยืนยันลำดับเฟสตามเข็มนาฬิกา A-B-C
- **สคริปต์ 03: การล้างชะล้างลูปทุติยภูมิ การคงแรงดันไฮโดรสแตติก และการไล่อากาศ**: การทวนสอบความเร็วชะล้างด้วยสารเคมี (≥ 1.5 m/s ตาม BSRIA BG 29/2020) การทดสอบคงแรงดันไฮโดรสแตติก (1.5× ของแรงดันใช้งาน เป็นเวลา 2 ชั่วโมงโดยไม่มีแรงดันตก) และการไล่อากาศด้วยสุญญากาศอัตโนมัติ

### ระยะที่ 2: การทดสอบสมรรถนะการทำงานของระบบเดี่ยว (ระดับ 4 FPT)
- **สคริปต์ 04: การสตาร์ต CDU อัตโนมัติ เส้นโค้งฐานอ้างอิงอัตราการไหลและแรงดัน**: การทวนสอบโปรไฟล์การเร่งความเร็วของ VFD ของปั๊มแบบแคนด์ การติดตามค่าเซ็ตพอยต์แรงดันแตกต่างแบบแมนนวล และความต้านทานของระบบในสภาวะเย็น
- **สคริปต์ 05: การสลับปั๊ม CDU แบบ N+1 และการควบคุมอัตโนมัติ**: การจำลองทริปทางกายภาพที่ VFD ของปั๊มหลัก; ทวนสอบการสตาร์ตอัตโนมัติของปั๊มสแตนด์บายภายในเวลา < 1.5 s โดยไม่มีการเกิดโพรงไอในลูป
- **สคริปต์ 06: การจำลองสัญญาณเตือนและการวัดค่าทางไกลแบบจุดต่อจุด**: การจำลองความผิดพร่องทางกายภาพ (อัตราการไหลทุติยภูมิต่ำ ระดับของเหลวถังขยายตัวต่ำ การเปียกของสายตรวจจับการรั่วไหล) และการตรวจสอบเปรียบเทียบค่า BMS กับเครื่องมือวัดในพื้นที่

### ระยะที่ 3: การทดสอบระบบบูรณาการ (ระดับ 5 IST)
- **สคริปต์ 07: เส้นโค้งปั๊มฐานอ้างอิงสภาวะเย็นแบบไม่มีความร้อน**: การสร้างโปรไฟล์เฮดชลศาสตร์เทียบกับอัตราการไหลผ่านจุดหรี่วาล์วแบบแมนนวล 4 จุด โดยล็อกการปรับความเร็วรอบอัตโนมัติของ VFD ไว้
- **สคริปต์ 08: บันไดภาระความร้อนหลายระดับและการแช่คงที่ที่ภาระเกินพิกัด**: การทดสอบความร้อนแบบเป็นขั้น (25%, 50%, 75%, 100% ของพิกัดการออกแบบ และ 110% สำหรับพิกัดเกิน) โดยคงที่ขั้นละไม่น้อยกว่า 45 นาที และแช่คงที่ที่โหลด 100% เป็นเวลา 4 ชั่วโมง
- **สคริปต์ 09: สภาวะความล้มเหลวชั่วครู่แบบพลวัตและการดับระบบฉุกเฉิน**: การตัดแหล่งจ่ายไฟฟ้าหลัก 2N การรับมือเมื่อน้ำเย็นของอาคารหยุดจ่าย และลำดับขั้นตอนการดับระบบเพื่อตัดพลังงานอย่างปลอดภัย

## หลักการ "หนึ่งสคริปต์ หนึ่งลายเซ็น"

ทุกสคริปต์ในชุดเอกสารนี้ถือเป็นเอกสารสัญญาที่เป็นอิสระต่อกันโดยมีช่องลงนามเฉพาะ การนำเส้นโค้งปั๊มสภาวะเย็นที่ผ่านการทดสอบมารวมกับขั้นตอนความร้อนเกินพิกัดที่ล้มเหลวไว้ในการลงนามเพียงจุดเดียว จะสร้างเอกสารที่มีความคลุมเครือในระดับพื้นฐาน

แต่ละสคริปต์จะต้องให้ผลการตัดสินที่ชัดเจน: **ผ่าน (PASS)**, **ไม่ผ่าน (FAIL)** หรือ **ไม่ได้ดำเนินการ (NOT EXECUTED)** ความล้มเหลวใดๆ ที่ยังไม่ได้รับการแก้ไขภายในสคริปต์จะต้องถูกสร้างเป็นรายการในทะเบียนรายการแก้ไขหลัก (Issues Log) ทันที

## การตัดสินใจที่ต้องบันทึกก่อนเริ่มการทดสอบ
