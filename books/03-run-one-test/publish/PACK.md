## Description

A load-bank test is not finished because the afternoon was hot. This field guide tells you how to connect an accepted load bank in place of the rack, run the approved scripts, and leave with sheets a stranger can audit.

Seven sheets: before connect, alarms, one heat step, failures, shutdown, the no-heat pump curve if the script asks for it, and CDU logic. A blank cell is a stop.
