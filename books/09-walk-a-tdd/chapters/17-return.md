# 17. The return visit

A first opinion is about the days you were there. Financing often assumes the plant stays as described. That assumption needs a return, or it needs to be labeled as a one-time look. Do not let the first report become a standing certificate because nobody scheduled the second walk.

The return is not a new due diligence with a new scope slipped in. It checks whether the sentences you signed are still true. The sample rule is written again, before you arrive, against the asset list as it is now, not against the list from the first visit. Equipment added or removed is a change. A change that was not in the opinion is a finding, even if the new equipment is fine. You were not asked to bless a different plant.

Identity is rechecked on a sample, not by faith that serials do not move. A list that matched once can be edited. Running state is rechecked. A machine that was running and is now dark is not "still accepted." Write dark. Spares are rechecked against the rule, not against your memory of a shelf. Procedures are resampled only if they claim to have changed, or if the person who could say the stop has changed. A new person who cannot say the stop is a finding about issuance, not about personality.

Do not grow the sample in the aisle because you have more time. A larger sample is a new rule, written, and the sentence says so. Do not shrink it and keep the old sentence. The first report's "identity checked" does not cover this visit. Each visit has its own sheet.

If the engagement names a periodic inspection, the period is theirs. This book does not set one. A missed return is not a confirmation that nothing changed. It is a lapse. Write the lapse. Do not backfill it with a call in which they say the hall is fine.

## Decisions to record

- First opinion labeled one-time, or a return dated.
- Asset list compared to the list the first opinion used. Adds and removes written.
- This visit's sample rule, separate from the last visit.
- A missed return written as a lapse, not as continued acceptance.
