# 2. 決して越えてはならない一線

## 技術デューデリジェンス（TDD）現地監査の基本規律

データセンターのM&A買収、プロジェクトファイナンス融資、または大規模AIクラスター向けのホール一括リース契約において、**決して越えてはならない一線**は数億ドル規模の投資判断を物理的現実へ繋ぎ止める唯一の防波堤である。売主の投資目論見書（CIM）に記載された「Tier III 相当」「50 MW 2N冗長」「PUE 1.25」といった文言は営業上の主張であり、工学的事実ではない。

$$\text{Scope}_{\text{TDD}} = \{\text{CapEx}, \text{OpEx}_{\text{tech}}, \text{Availability}, \text{Permits}_{\text{tech}}\}$$

TDD監査人の責務は、稼働中の設備に一切手を触れず（Hands-Off Rule）、単線結線図（SLD）、配管計装図（P&ID）、現地銘板、保護継電器設定、および過去24ヶ月のSLAインシデント台帳を照合して、**売主の主張文を物理的事実に基づく正確な条件文へ書き換えること**にある。

> *「どれほど美しいロビーや緑色のダッシュボードがあっても、冷却塔の共通ヘッダに単一障害点があれば、あるいは99.6%設計外気温でチラーが30%ディレーティングされるなら、その施設は売主が主張する容量を持っていない。」*

## 実効容量（Derated Capacity）・冗長性・CAPEX負債の定量監査マトリクス

現地踏査では、銘板合計値（Nameplate Sum）ではなく、最悪設計外気条件（ASHRAE 0.4% 乾球・湿球温度）、2N系統の45%負荷上限則、および非常用発電機の連続定格（COP/PRP）を適用した**正味サバイバル容量（$P_{\text{IT, firm}}$）**を算定する。

| TDD 監査領域 | 現地検証ドキュメント & 物理計測 | 合格基準（健全資産） | レッドフラグ（価格調整 / 先行条件 CP トリガー） |
| :--- | :--- | :--- | :--- |
| **受配電・発電機実効容量** | 受電契約MVA、発電機ISO 8528定格、UPS $N-1$ 負荷率 | $P_{\text{IT, firm}}$ が契約販売kWを 100% カバー | 2N片系45%超、または発電機燃料 $< 48\,\text{h}$ |
| **冷却プラント熱ディレーティング** | 極暑日チラー能力曲線、CDU $\Delta T_{\text{PHE}}$、単一ヘッダ有無 | 設計外気温かつ $N-1$ で SLA 温度維持 | 共通配管SPOF、または外気高温時の容量不足 |
| **設備寿命（EOSL）と更新CAPEX** | 製造年銘板、稼働時間、バッテリーインピーダンス、冷媒種別 | 向こう5年間の更新CAPEX積立が計画済 | EOSL到来機器の放置、またはVRLA膨張・絶縁劣化 |
| **運用実績・ファイバー多様性** | 過去24ヶ月障害ログ、入退館バッジ履歴、MMR引込ルート | 重大SLA違反ゼロ・完全2ルート異経路 | 単一トレンチ（Single Trench）交差、または要員不足 |

資料間に矛盾（SLDと現地遮断器枠電流の不一致など）が見つかった場合、決してそれを丸めてはならない。決して越えてはならない一線をVisit Sheetに証拠写真および図面リビジョンと共に記録せよ。

## 現地ウォークスルー手順と法務・財務への引き継ぎプロトコル

限られた現地滞在時間（1日〜2日）で最大の検出力を発揮するため、以下の3フェーズで調査を完遂する。

1. **事前データルーム解剖（Pre-Flight RFI）**: 出発前にSLD・P&IDの単一障害点候補を赤枠でマーキングし、過去2年間のP1/P2インシデント報告書と保護継電器協調計算書の提出を要求する。
2. **物理トレースと深夜当直者インタビュー**: 受電端からラックPDU・二次CDUまで物理配管とケーブルトレイを目視追跡し、当直エンジニアに「どのバルブが固着しているか」「どのアラームが常時鳴っているか」を直接聴取する。
3. **レッドフラグ速報とSPA契約条項への変換**: 発見された各欠陥に対し、即時必要な是正費用（Immediate Deficit CAPEX）と5年更新費用を算定し、売買契約（SPA）の先行条件（CP）または価格控除項目として法務チームへ引き渡す。

## 記録すべき決定事項

- 監査対象項目（決して越えてはならない一線）における売主主張と現地物理状態の照合記録。
- 設計外気温ディレーティングおよび $N-1$ 単一故障を反映した正味IT容量（$P_{\text{IT, firm}}$）の確認。
- 単一障害点（SPOF）、EOSL更新CAPEX、および未解決パンチ項目の定量化。
- 売買契約・融資契約の先行条件（Conditions Precedent）として課す是正措置とVisit Sheetへの署名。
