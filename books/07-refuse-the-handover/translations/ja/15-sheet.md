# 15. マスター引き渡し拒絶シート（The Refusal Sheet）

## 引き渡しゲートにおける拒絶権の工学的根拠

データセンターの新設または増設プロジェクトにおいて、建設・コミッショニング段階から商用運用段階への引き渡し（Handover）は、リスクと法的責任が恒久的に移転する不可逆の境界線である。本章が扱う**全10ゲートの受入監査チェックリスト：As-Built図面、L1〜L5記録、IST波形、水質・腐食、O&M要員、パンチリスト**は、未完成の設備や隠蔽された欠陥を運用チームが背負い込む事態を防ぐための絶対的な防衛規律である。

![15. マスター引き渡し拒絶シート（The Refusal Sheet）](../figures/fig-07-master-refusal-sheet-and-dissent-ledger.png)

$$\forall k \in \{1..12\}: \text{Field}_k \neq \text{Blank} \implies \text{Eligible for Signature}$$

建設請負業者やプロジェクトマネージャーは工期遵守（Schedule Milestone）のために署名を急がせるが、運用責任者が一度引き渡し証書に署名すれば、その瞬間からすべてのSLA違反、単一障害点、および未検証の保護協調ミスは運用部門の責任となる。証跡が1つでも欠けているなら、ペンを置き、引き渡しを正式に**拒絶（REFUSE）**しなければならない。

> *「引き渡しの署名とは、建設業者への感謝状ではない。『この設備が今後10年間、単一故障や保守作業中であっても顧客SLAを100%維持できることを私自身の専門職ライセンスにおいて保証する』という法的宣誓文である。」*

## L1〜L5コミッショニング証跡と受入監査マトリクス

ASHRAE Guideline 0 / Standard 202 および NETA ATS に準拠した5段階のコミッショニング（L1: 工場試験 FAT、L2: 据付・フラッシング、L3: 単体起動試験、L4: 機能性能試験 FPT、L5: 統合システム試験 IST）のすべてにおいて、生の計測波形と校正証明書が揃っていなければならない。

| 受入監査ゲート | 必須エンジニアリング証跡 | 合格基準（許容値） | 即時引き渡し拒絶（Refusal）トリガー |
| :--- | :--- | :--- | :--- |
| **Gate A: 竣工図（As-Built）照合** | 赤ペン修正反映済みのSLD・P&ID・制御論理図 | 現地バルブタグ・遮断器整定値と 100% 一致 | ファイル名だけを変更した設計図の提出 |
| **Gate B: L4/L5 統合負荷試験（IST）** | 100% 実負荷熱平衡（$\ge 8\,\text{h}$）とブラックスタート波形 | 2N片系喪失・電源切替時間 $t_{\text{transfer}} \le 10\,\text{ms}$ | CFD画像や短絡計算ソフトでの実機試験代用 |
| **Gate C: 二次冷却水・配管清浄度** | $50\,\mu\text{m}$ フラッシング・耐圧試験・水質分析票 | 導電率 $< 10\,\mu\text{S/cm}$, PG $25.0\% \pm 1.0\%$, 漏水ゼロ | ストレーナ未点検または腐食クーポン未設置 |
| **Gate D: パンチリスト・運用準備** | 欠陥分類台帳、LOTO実技合格証、予備品在庫 | **Type A（安全・SLA・冗長性）残件 = 0件** | Type A欠陥を「軽微（Minor）」と偽る条件付き署名要求 |

いかなる場合も、隣のデータホールの合格記録やベンダーの口頭保証をもって実機試験の省略（Similarity Waiver）を認めてはならない。全10ゲートの受入監査チェックリスト：As-Built図面、L1〜L5記録、IST波形、水質・腐食、O&M要員、パンチリストを現場の物理検収で100%確認せよ。

## 引き渡し審査会議とRefusal Sheetの運用手順

引き渡し審査会議の72時間前までに全証跡パッケージ（Turnover Dossier）を凍結させ、以下の3ステップで監査を実施する。

1. **ドキュメントと現物のクロスチェック**: データルーム内のPDF試験成績書から無作為に20箇所の遮断器・バルブ・センサーを抽出し、現地の物理設定値およびBMS生カウント値と照合する。
2. **ジャンパー・強制オーバーライドの総点検**: 制御盤内の仮設ジャンパー線、PLCのForcedビット、BMSのShelvedアラームがゼロであることを現地で確認する。
3. **Refusal Sheetの発行**: 不備が確認された項目には直ちに拒絶コードを付与し、是正措置と再試験（Re-test）が完了するまで物理的な鍵とLOTO管理権の受領を拒否する。

## 記録すべき決定事項

- 監査対象ゲート（全10ゲートの受入監査チェックリスト：As-Built図面、L1〜L5記録、IST波形、水質・腐食、O&M要員、パンチリスト）における必須証跡の完全性確認。
- 現地ウォークダウンによる竣工図（As-Built）・保護継電器整定値・バルブタグの100%照合。
- Type Aパンチリスト残件ゼロおよび仮設ジャンパー・ソフトウェア強制ビット皆無の証明。
- 不備発見時の即時引き渡し拒絶（Refusal Sheet署名）と再試験条件の明記。
