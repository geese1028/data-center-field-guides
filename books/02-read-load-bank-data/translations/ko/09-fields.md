영어판을 AI 보조로 번역한 것이다.

# 9. 자동 생성 필드와 인간의 판단

현대의 커미셔닝 플랫폼은 초당 수천 개의 Modbus 및 MQTT 텔레메트리 포인트를 수집하기 위해 자동화된 데이터 수집 스크립트, Python 파이프라인, 클라우드 대시보드를 사용한다. 자동화는 효율적이고 일관되며 수동 계산 피로에 영향을 받지 않는다.

그러나 숫자를 계산하는 자동화 스크립트가 기술적 승인을 부여하는 자동화 스크립트와 혼동되어서는 결코 안 된다.

플래시 보고서는 두 가지 명확한 기입 칸 범주 사이에 타협할 수 없는 경계를 설정한다:
1. **스크립트 기입 칸(Script-Filled Cells)**: 원시 텔레메트리로부터 결정론적으로 계산된 산술 및 통계 수치.
2. **인간 기입 칸(Human-Filled Cells)**: 정성적 판정, 계약상의 적합성 판단, 기술적 인수에 대한 법적 서명.

알고리즘은 전문 기술사(PE) 면허를 소지하지 않으며, 법정에 출석할 수 없고, 데이터 홀 화재에 대해 재정적 또는 운영적 책임을 질 수 없다. 알고리즘은 숫자를 계산하고, 인간이 판정을 내린다.

## 스크립트가 채울 수 있는 항목

자동화 스크립트, 수집 파이프라인, 데이터베이스 집계 쿼리는 결정론적 수학 연산에 이상적으로 적합하다. 스크립트는 인간의 개입 없이 다음 필드를 채울 수 있으며, 마땅히 채워야 한다:

- **타임스탬프 및 샘플 수**: 밀리초 단위까지의 정확한 시작 및 종료 시각, 초 단위의 유지(dwell) 지속 시간, 채널당 수신된 유효 원시 1초 샘플의 총개수.
- **통계 요약**: 정의된 시간 구간에 걸친 산술평균(μ), 최솟값($\min$), 최댓값($\max$), 표본 표준편차(σ), 표본 분산(σ²).
- **도출된 물리량 계산**: 질량 유량(ṁ), 벌크 유체 밀도(ρ), 비열용량(C_p), 액체 엔탈피 흡수량(Q_liquid), 동반 공기 현열량(Q_air).
- **다중 캐비닛 지표**: 병렬 캐비닛 전반의 그룹 평균, 그룹 표준편차, 변동계수(CV).
- **엔탈피 폐합비(Closure Ratio)**: 유효 전력과 총 열역학적 열 방출량 사이의 정확한 백분율 폐합비(P_elec 대 Q_liquid + Q_air).
- **알고리즘 이상 징후 플래그**: 분산 제로 평탄선(σ² ≤ 1.0 × 10^{-4}), 통신 결측 공백, 범위를 벗어난 센서 판독값, Focus, FLOC 또는 CPOP에 의해 트리거된 변화점 후보 시각을 나타내는 자동 경보.

컴퓨터는 포켓 계산기를 든 인간보다 훨씬 빠르고 월등히 높은 정밀도로 산술 연산을 수행한다. 산술 연산은 스크립트에 맡겨라.

## 스크립트의 작성이 엄격히 금지된 항목

어떠한 경우에도 자동화 스크립트, 대시보드 매크로 또는 AI 모델이 다음 단어를 생성해서는 안 된다:
- **합격 (PASS)**
- **불합격 (FAIL)**
- **미실행 (NOT RUN)**
- **면제 / 웨이버 (WAIVED)**

어떤 행을 평가하여 계산된 온도가 상한 기준 46.0°C에 대해 45.1°C임을 확인한 후 PDF에 자동으로 "합격(PASS)"이라는 단어를 날인하는 자동화 스크립트는 자신의 권한을 월권한 것이다.

### 자동 "합격"이 위험한 이유
알고리즘이 알 수 없는 것들을 생각해보라:
- 알고리즘은 45.1°C를 보고하는 RTD가 활성 유동 스트림이 아닌 차가운 데드레그 스터브에 실수로 설치되었는지 알지 못한다.
- 알고리즘은 캐비닛 뒤에서 임시 바이패스 호스가 꺾여 있는지, 혹은 유지 시간 동안 기록되지 않은 수동 밸브 조작이 수행되었는지 알지 못한다.
- 알고리즘은 발주처가 당일 아침 시험 기준 엔벨로프를 46.0°C에서 44.0°C로 낮추라는 긴급 구두 공지를 내렸는지 알지 못한다.

"PASS"를 작성하는 자동화 스크립트는 엔지니어링 팀에 허위의 안전감을 심어준다. 운전자들은 "소프트웨어가 적합성을 처리하고 있다"고 가정하고 실제 배관을 살펴보지 않고, 펌프 캐비테이션 소리에 귀 기울이지 않으며, 계측기 교정 태그 확인을 중단하게 된다.

본 현장 가이드에서 플래시 보고서 템플릿의 판정 기입 칸은 처음부터 빈칸으로 생성된다. 이 칸들은 잉크 펜을 든 인간의 손이나 인증된 디지털 암호화 서명에 의해서만 채워질 수 있다.

## 인간의 불법 오버라이드 범죄

그 반대의 고장 모드 역시 똑같이 유해하다. 스크립트가 계산한 불합격 수학적 기입 칸을 보고 인간이 무단으로 "합격(PASS)"으로 덮어쓰는 행위가 이에 해당한다.

스크립트가 유량 CV를 최대 허용 임계값인 **5.0%**를 초과하는 **7.2%**로 올바르게 계산했다면, 엔지니어는 해당 칸 옆에 "합격(PASS)"을 적고 구두 변명을 덧붙여서는 안 된다: *"유량이 다소 불균일했으나 전반적인 냉각 상태는 양호해 보였음."*

그러한 행위는 엔지니어링 해석이 아니다. 그것은 기록되지 않은 불법적인 면제(waiver)다.

계산된 기입 칸이 기준을 만족하지 못한 경우:
- 해당 행에 대한 인간의 판정은 반드시 **불합격(FAIL)**이어야 한다.
- 프로젝트 팀이 해당 결함이 광범위한 커미셔닝 목표를 훼손하지 않는다고 진정으로 믿는다면, 시트 소유자는 공식적인 **면제(Waiver) 프로토콜**을 발동해야 한다:
 1. 허용 오차를 5.0%에서 7.5%로 명시적으로 확장하도록 설계 기준 사양서를 개정한다.
 2. 새로운 문서 개정 번호(예: Rev 2.5)를 부여한다.
 3. 해당 주장을 알려진 한계 사항으로 공식 재분류한다.
 4. 설비 소유자로부터 서명된 서면 승인을 획득한다.

업데이트된 문서 개정판과 함께 대낮에 투명하게 실행된 면제는 감사 가능한 엔지니어링 결정이다. 스프레드시트의 어둠 속에서 불합격된 칸 위에 사람이 적어 넣은 "PASS"는 시험 기록의 위조에 불과하다.

## 2열 인터페이스의 설계

소프트웨어와 인쇄물 모두에서 이러한 규율을 강제하기 위해, 모든 플래시 보고서 템플릿은 엄격한 **2열 인터페이스(Two-Column Interface)**를 구현해야 한다:

| 좌측 열: 자동 데이터 블록 (스크립트 소유) | 우측 열: 평가 및 판정 (인간 소유) |
| :--- | :--- |
| • 지시 전력: 120.0 kW | • 인용 한계 기준: DOC-SPEC Rev 2.4, 표 2 |
| • 측정 전력: 120.2 kW | • 검증된 피더 평형: 상 불평형률 < 1.0% |
| • 추정 액체 열량: 98.6 kW | • 열역학적 타당성: 확인 완료 |
| • 엔탈피 폐합비: 98.0% | • 하드웨어 물리 검사: 누수 없음 / 소음 정상 |
| • 계산된 유량 CV: 2.95% (σ = 5.21 LPM) | • 일관성 검증: 5.0% 임계값 이내 합격 |
| • 품질 마스크: 0x0007 (유효, σ² > 0) | • **인간 판정**: **합격 (PASS)** [이니셜: E.V., 수석 CxA] |

좌측 열에는 코드가 생성한 수정되지 않은 순수 수치가 포함된다. 우측 열에는 인간의 면밀한 정밀 조사, 수동 검증 점검, 최종 책임 서명이 포함된다.

## 기록해야 할 결정 사항

플래시 보고서의 거버넌스 섹션에 다음 사항을 기록하라:

- 자동 데이터 수집 파이프라인의 소프트웨어 버전, 스크립트 체크섬(SHA-256 해시) 및 리포지토리 브랜치.
- 모든 판정 기입 칸(합격/불합격/미실행)이 지정된 인간 권한자에 의해 수동으로 검토되고 입력되었음을 증명하는 공인 진술서.
- 캠페인 기간 동안 발동된 공식 면제 사항(승인된 문서 개정판 및 소유자 서명 참조 포함).
