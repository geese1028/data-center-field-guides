# 10. ชุดเอกสารรายงานฉบับทางการ

แฟลชรีพอร์ตได้รับการออกแบบมาเพื่อการคัดกรองทางเทคนิคที่รวดเร็วหน้างาน โดยจะให้คำตัดสินห้าบรรทัดในทันทีภายในสองชั่วโมงหลังจากการหยุดการทดสอบโหลดแบงก์ เพื่อให้ผู้จัดการอาคาร ผู้อำนวยการฝ่ายทดสอบและตรวจรับระบบ และหัวหน้าผู้รับเหมาสามารถพิจารณาได้ว่าจะก้าวไปสู่เฟสการตรวจรับถัดไป หรือระงับไซต์งานไว้เพื่อดำเนินการแก้ไขปรับปรุง

อย่างไรก็ตาม แฟลชรีพอร์ตไม่ได้เลือนหายไปเมื่อสิ้นสุดกะการทำงาน แต่จะกลายเป็นแกนกลางถาวรของ **ชุดเอกสารส่งมอบการตรวจสอบยืนยันการทดสอบและตรวจรับระบบฉบับทางการ (Formal Commissioning Verification Handover Package)**—ซึ่งเป็นแฟ้มเอกสารทางกฎหมายและทางเทคนิคที่จะคงอยู่ตลอดอายุการใช้งานของดาต้าเซ็นเตอร์ และถูกจัดเก็บไว้สำหรับผู้รับประกันภัย การตรวจสอบของผู้เช่าระดับไฮเปอร์สเกล และการต่ออายุใบรับรองอาคารประจำปี

ชุดเอกสารทางการที่มีความหนาแปดสิบหน้าซึ่งเต็มไปด้วยโบรชัวร์การตลาดและข้อมูลดิบดัมป์ที่ไม่มีดัชนี จะถูกผู้ตรวจสอบโยนทิ้งไป ในทางกลับกัน ชุดเอกสารที่สั้นเกินไปจนไม่สามารถปกป้องตัวเลขของตนเองได้ ก็จะถูกปฏิเสธเช่นกัน

บทนี้จะนิยามอย่างแน่นอนว่าสิ่งใดต้องเก็บรักษาไว้ในชุดเอกสารส่งมอบฉบับทางการ สิ่งใดต้องตัดทิ้งอย่างเด็ดขาด และจะจัดโครงสร้างคลังจัดเก็บอย่างไรเพื่อให้บุคคลภายนอกสามารถตรวจสอบความสมบูรณ์ของเอกสารได้ในอีกสิบปีข้างหน้า หลังจากที่ทีมงานทดสอบได้ถอนกำลังออกไปแล้ว

## สิ่งที่ต้องเก็บรักษาไว้: ชิ้นงานจำเป็นทั้งเจ็ดประการ

ชุดเอกสารส่งมอบฉบับทางการต้องประกอบด้วยชิ้นงานที่มีหมายเลขกำกับเจ็ดชิ้นงาน หากขาดชิ้นงานใดชิ้นงานหนึ่งในเจ็ดชิ้นนี้ไป ชุดเอกสารจะถือว่าไม่สมบูรณ์:

### ชิ้นงานที่ 1: แฟลชรีพอร์ตสำหรับผู้บริหารแบบหน้าเดียว
แผ่นสรุปอย่างเป็นทางการที่นิยามไว้ในบทที่ 1 และแสดงในภาพที่ 01:
- เมทาดาทาของการรัน (รหัสการรัน, ตำแหน่งอาคาร, วันที่, ฉบับแก้ไขของข้อกำหนดที่อ้างอิง)
- ตารางการผ่านของฉากการทดสอบ 5 รายการ (Pretest, Gradient, Overload, Step Change, Single-Feed Fault) พร้อมค่าที่วัดได้, ระยะเวลาคงสถานะ, และคำตัดสินที่ชัดเจนว่า PASS/FAIL/NOT RUN
- ข้อความตัดสินผลการทดสอบโดยรวม
- ลายมือชื่อหมึกจริงหรือลายมือชื่อดิจิทัลที่มีการเข้ารหัสของทั้ง 4 บทบาทที่กำหนดไว้ (เจ้าของเอกสารข้อกำหนด, ผู้ควบคุมการทำงาน, ผู้บันทึก, บุคคลภายนอกผู้ตรวจสอบอิสระ)

### ชิ้นงานที่ 2: ใบรับรองการเตรียมความพร้อมและค่าฐานอ้างอิง
เอกสารที่พิสูจน์ว่าคลัสเตอร์ทดสอบมีความพร้อมสำหรับการทดสอบก่อนที่จะสั่งการจ่ายความร้อน:
- ประตูการเตรียมความพร้อมทั้งสี่ประการที่ได้รับการตรวจสอบและลงนาม
- บันทึกการรักษาเสถียรภาพขณะเย็นเป็นเวลา 10 นาที รวมถึงค่าเฉลี่ยฐานอ้างอิงหนึ่งนาที
- บันทึกการสอบเทียบอิมพีแดนซ์ทางชลศาสตร์ขณะเย็น ซึ่งระบุตำแหน่งวาล์วปรับสมดุลที่ล็อกไว้และความดันแตกต่างฐานอ้างอิง (ΔP)

### ชิ้นงานที่ 3: แผ่นบันทึกความสอดคล้องระหว่างหลายตู้
การประเมินทางสถิติของความสมดุลของคลัสเตอร์ข้ามตู้โหลดแบงก์ที่ต่อขนานกันทั้งหมด:
- ค่าสัมประสิทธิ์ความแปรผัน (CV) ที่คำนวณได้สำหรับกำลังไฟฟ้าจริง (CV ≤ 1.0%), อัตราการไหลของสารหล่อเย็น (CV ≤ 5.0%), อุณหภูมิที่เพิ่มขึ้น (CV ≤ 3.0%), และความดันแมนิโฟลด์ (CV ≤ 5.0%)
- การตรวจสอบที่รับรองว่าความแปรปรวนไม่เป็นศูนย์ (σ² > 0) ซึ่งพิสูจน์ว่ามีการไหลปั่นป่วนจริงปรากฏอยู่ และไม่มีแชนเนลใดส่งค่าข้อมูลที่แคชไว้/นิ่งสนิทซ้ำ

### ชิ้นงานที่ 4: บล็อกข้อมูลแต่ละขั้นและตารางการปิดสมดุลเอนทัลปี
งบดุลทางอุณหพลศาสตร์ที่สมบูรณ์สำหรับทุกขั้นโหลด (25%, 50%, 75%, 100%, 110%):
- สถิติสรุปสี่ค่า (ต่ำสุด, สูงสุด, ค่าเฉลี่ยเลขคณิต, ส่วนเบี่ยงเบนมาตรฐาน) สำหรับทุกแชนเนลทางไฟฟ้า ทางของเหลว และทางอากาศ
- สมดุลพลังงานทางอุณหพลศาสตร์ตามหลักการมูลฐาน: กำลังไฟฟ้าจริง (P_elec) เปรียบเทียบกับเอนทัลปีของเหลว (Q_liquid = ṁ C_p ΔT) และความร้อนสัมผัสของอากาศร่วม (Q_air)
- อัตราส่วนการปิดสมดุลเอนทัลปีที่ได้รับการรับรอง (≥ 97.0%)

### ชิ้นงานที่ 5: ออสซิลโลแกรมและแผนภูมิอนุกรมเวลา
แผนภูมิคุณภาพเวกเตอร์ความละเอียดสูงที่สร้างขึ้นจากข้อมูลดิบที่ไม่สามารถแก้ไขได้:
- รูปคลื่นกำลังไฟฟ้าและอุณหภูมิที่ซ้อนทับกันสำหรับทุกยูนิตที่ต่อขนานกัน ซึ่งพล็อตบนสเกลที่เปิดเผยการเบี่ยงเบนของแต่ละตู้อย่างตรงไปตรงมา
- กราฟการตอบสนองต่อการเปลี่ยนขั้นตอนแบบฉับพลันที่มีการกำกับคำอธิบาย ซึ่งแสดงรายละเอียดเวลาเข้าสู่สภาวะคงตัวและคลื่นแรงดันพุ่งชั่วขณะทางชลศาสตร์สูงสุด
- ออสซิลโลแกรมสภาวะทรานเชียนต์ของการสูญเสียแหล่งจ่ายเดี่ยวแบบ 2N ซึ่งจับภาพเวลาการตัดวงจรของคอนแทกเตอร์ (< 20 มิลลิวินาที) และเสถียรภาพของบัสควบคุมที่ไร้แรงดันตก

### ชิ้นงานที่ 6: บันทึกการตรวจสอบจุดเปลี่ยนแปลงและความผิดปกติจากขั้นตอนวิธี
บันทึกที่สมบูรณ์ของการตรวจสอบอย่างละเอียดโดยขั้นตอนวิธีอัตโนมัติ:
- เวลาสั่งการตัวเลือกของ Focus และ FLOC แบบออนไลน์ เปรียบเทียบตามลำดับเวลากับบันทึกคำสั่งของผู้ควบคุม
- ส่วนความชันเชิงเส้นทีละช่วงของ CPOP แบบออฟไลน์ ข้ามกล่องการคงสถานะคงที่
- แท็กการจัดประเภทโดยมนุษย์ที่มีการลงนามย่อสำหรับทุกตัวเลือก: *Expected Step (ขั้นที่คาดไว้)*, *Inspect / Split Hold (ตรวจสอบ / แยกช่วงคงสถานะ)*, หรือ *No Impact (ไม่มีผลกระทบ)*

### ชิ้นงานที่ 7: คลังจัดเก็บข้อมูล CSV ดิบที่มีการลงลายมือชื่อเข้ารหัส
ไฟล์ข้อมูลเทเลเมทรีดิบระดับ 1 วินาทีที่สมบูรณ์และไม่ได้ปรับแต่ง ซึ่งส่งออกจากเอดจ์เกตเวย์โดยตรง:
- ทุกแชนเนลเซนเซอร์ที่ทำงานอยู่ได้รับการบันทึกวินาทีละหนึ่งครั้ง พร้อมการประทับเวลาแบบ ISO-8601 UTC
- แนบมาพร้อมกับไฟล์ตรวจสอบความถูกต้องของการเข้ารหัส SHA-256 อย่างเป็นทางการ (เช่น `LB_TEST_2026_H01_RAW.csv.sha256`) ซึ่งสร้างขึ้นทันทีเมื่อปิดไฟล์ เพื่อรับประกันว่าตัวเลขดิบไม่ได้ถูกแก้ไข กรอง หรือปรับแต่งย้อนหลัง

## สิ่งที่ต้องตัดทิ้งอย่างเด็ดขาด

ชุดเอกสารส่งมอบฉบับทางการคือบันทึกการตรวจสอบทางวิศวกรรม ไม่ใช่พอร์ตโฟลิโอโฆษณา รายการต่อไปนี้จะต้องถูกแยกออกอย่างเด็ดขาด:

- **ภาพถ่ายจากสมาร์ตโฟนที่ไม่ได้สอบเทียบ**: อย่าใส่ภาพถ่ายสมาร์ตโฟนที่เบลอจำนวนหลายสิบภาพของหลอดไฟบนแผงควบคุม ใบหน้าของผู้ควบคุม หรือมัดสายไฟ ภาพถ่ายของไฟ LED สีเขียวเป็นเพียงของที่ระลึก ไม่ใช่หลักฐานของความต่อเนื่องทางไฟฟ้าหรือเอนทัลปีของของเหลว (ภาพถ่ายความร้อนความละเอียดสูงที่มีสเกลอุณหภูมิที่สอบเทียบแล้ว ได้รับอนุญาตเฉพาะกรณีที่ใช้เป็นเอกสารสนับสนุนสำหรับการตรวจสอบหางปลาขั้วต่อสายไฟเท่านั้น)
- **โบรชัวร์การตลาดของผู้ขายและภาพเรนเดอร์ 3 มิติ**: อย่าทำให้เอกสารหนาขึ้นด้วยโบรชัวร์การขายที่สวยหรู ภาพแนวคิดที่สร้างจากคอมพิวเตอร์ หรือสไลด์แนะนำบริษัท ชุดเอกสารการตรวจสอบเป็นของเครื่องจักรทางกายภาพบนพื้นที่ปฏิบัติงาน ไม่ใช่โบรชัวร์การขาย
- **ข้อมูลที่เป็นความลับของลูกค้าที่ไม่ได้ปกปิด**: อย่าใส่ข้อมูลระบุตัวตนของผู้เช่าที่เป็นลูกค้า, ชื่อโมเดล AI ที่เป็นกรรมสิทธิ์, รหัสผ่านความปลอดภัยที่ไม่ได้ปิดบัง, หรือที่อยู่ IP เครือข่ายภายในองค์กร รายงานนี้ทำหน้าที่ตรวจสอบประสิทธิภาพทางอุณหพลศาสตร์และทางไฟฟ้า ไม่ได้ทำแผนที่เครือข่ายข้อมูลส่วนตัว
- **ดัมป์บันทึกดิบขนาดหลายกิกะไบต์ที่ไม่ได้จัดทำดัชนี**: อย่าแปะบรรทัดบันทึก JSON ดิบหรือเอาต์พุตเทอร์มินัลดิบที่ไม่ได้จัดรูปแบบหลายล้านบรรทัดลงในภาคผนวกของ PDF จงจัดเก็บคลังข้อมูล CSV ดิบไว้ในที่จัดเก็บดิจิทัลที่ปลอดภัยแยกต่างหาก ระบุแฮช SHA-256 ของไฟล์ และรักษาให้ไฟล์ PDF ของรายงานฉบับทางการมีความสะอาด อ่านง่าย และตรงประเด็น

## โครงสร้างของโฟลเดอร์คลังจัดเก็บ

จัดระเบียบชุดเอกสารส่งมอบดิจิทัลขั้นสุดท้ายให้อยู่ในโครงสร้างไดเรกทอรีโฟลเดอร์ที่เป็นมาตรฐานและสะอาดตา:

```
├── 01_Executive_Flash_Report.pdf # รายงานสรุปหน้าเดียวที่มีการลงนาม
├── 02_Preparation_and_Baseline.pdf # ประตูขณะเย็นและการสอบเทียบทางชลศาสตร์
├── 03_Consistency_and_Uniformity.pdf # การคำนวณ CV และความสมดุลระหว่างหลายตู้
├── 04_Step_Data_Blocks_and_Enthalpy.pdf # ตารางการกระทบยอดทางอุณหพลศาสตร์
├── 05_Time_Series_Charts.pdf # ออสซิลโลแกรมความละเอียดสูงและขั้นตอนพลวัต
├── 06_Changepoint_Audit_Log.pdf # บันทึกตัวเลือกของ Focus / FLOC / CPOP

│ └── LB_RAW_1HZ_TELEMETRY.csv.sha256 # แฮชการเข้ารหัส SHA-256 ที่เปลี่ยนแปลงไม่ได้

 ├── PT100_RTD_Calibration.pdf # แผ่นสอบเทียบ NIST/ISO 17025

```

เมื่อผู้ตรวจสอบหรือตัวแทนตรวจรับระบบได้รับชุดเอกสารนี้ พวกเขาสามารถตรวจสอบยืนยันแฮช SHA-256 ของไฟล์ CSV ดิบได้ภายในห้าวินาที รันการคำนวณรวบรวมข้อมูลซ้ำใน Python และยืนยันตัวเลขทุกตัวบนแฟลชรีพอร์ตสำหรับผู้บริหารได้อย่างเป็นอิสระ

ก่อนที่จะปิดผนึกชุดเอกสารส่งมอบฉบับทางการ จงตรวจสอบและบันทึก:

- ค่าเช็กลำดับความถูกต้อง SHA-256 ที่คำนวณได้ของไฟล์เทเลเมทรี CSV ดิบ พร้อมลงนามโดยผู้บันทึก
- URI ของที่จัดเก็บบันทึกถาวร หรือตำแหน่งของคลังจัดเก็บที่จัดเก็บไฟล์ดิบที่ไม่สามารถแก้ไขได้
- รายการใบรับรองการสอบเทียบเครื่องมือวัดทั้งหมดที่รวมอยู่และวันหมดอายุ
- ลายมือชื่อการยอมรับขั้นสุดท้ายของเจ้าของเอกสารข้อกำหนดและตัวแทนตรวจรับระบบ (CxA) ภายนอก
