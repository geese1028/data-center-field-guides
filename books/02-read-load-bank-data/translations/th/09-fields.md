# 9. ฟิลด์อัตโนมัติและการตัดสินใจของมนุษย์

แพลตฟอร์มการทดสอบและตรวจรับระบบสมัยใหม่ใช้สคริปต์นำเข้าข้อมูลอัตโนมัติ, ไปป์ไลน์ Python, และแดชบอร์ดบนคลาวด์ เพื่อนำเข้าจุดข้อมูลเทเลเมทรี Modbus และ MQTT นับพันจุดต่อวินาที ระบบอัตโนมัติมีประสิทธิภาพ มีความสม่ำเสมอ และไม่มีความเหนื่อยล้าจากการคำนวณด้วยตนเอง

อย่างไรก็ตาม สคริปต์อัตโนมัติที่คำนวณตัวเลขจะต้องไม่ถูกนำไปสับสนกับสคริปต์อัตโนมัติที่ให้การยอมรับทางเทคนิค

แฟลชรีพอร์ตกำหนดขอบเขตที่ไม่อาจโอนอ่อนได้ระหว่างช่องตารางสองประเภทที่แตกต่างกันอย่างสิ้นเชิง:
1. **ช่องตารางที่กรอกโดยสคริปต์ (Script-Filled Cells)**: ปริมาณทางเลขคณิตและทางสถิติที่คำนวณขึ้นอย่างแน่นอนจากข้อมูลเทเลเมทรีดิบ
2. **ช่องตารางที่กรอกโดยมนุษย์ (Human-Filled Cells)**: คำตัดสินเชิงคุณภาพ, การประเมินการปฏิบัติตามสัญญา, และลายมือชื่อทางกฎหมายของการยอมรับทางเทคนิค

ขั้นตอนวิธี (algorithm) ไม่ได้ถือใบอนุญาตประกอบวิชาชีพวิศวกรรม ไม่สามารถไปปรากฏตัวในศาลได้ และไม่สามารถรับผิดชอบทางการเงินหรือทางการปฏิบัติการต่อเหตุเพลิงไหม้ในโถงดาต้าเซ็นเตอร์ได้ ขั้นตอนวิธีทำหน้าที่คำนวณตัวเลข ส่วนมนุษย์เป็นผู้เขียนคำตัดสิน

## สิ่งที่สคริปต์ได้รับอนุญาตให้กรอก

สคริปต์อัตโนมัติ ไปป์ไลน์การนำเข้าข้อมูล และเคิวรีการรวบรวมข้อมูลในฐานข้อมูล เหมาะสมอย่างยิ่งสำหรับคณิตศาสตร์เชิงกำหนด สคริปต์สามารถ—และควร—กรอกฟิลด์ต่อไปนี้โดยไม่ต้องอาศัยการแทรกแซงของมนุษย์:

- **การประทับเวลาและจำนวนตัวอย่าง**: เวลาเริ่มต้นและสิ้นสุดที่แน่นอนระดับมิลลิวินาที, ระยะเวลาคงสถานะเป็นวินาที, และจำนวนรวมของตัวอย่างดิบระดับ 1 วินาทีที่ถูกต้องซึ่งได้รับต่อแชนเนล
- **บทสรุปทางสถิติ**: ค่าเฉลี่ยเลขคณิต (μ), ค่าต่ำสุด ($\min$), ค่าสูงสุด ($\max$), ส่วนเบี่ยงเบนมาตรฐานของกลุ่มตัวอย่าง (σ), และความแปรปรวน (σ²) ข้ามหน้าต่างเวลาที่กำหนด
- **การคำนวณทางกายภาพที่อนุมานได้**: อัตราการไหลเชิงมวล (ṁ), ความหนาแน่นของเนื้อของเหลว (ρ), ความจุความร้อนจำเพาะ (C_p), การดูดซับเอนทัลปีของของเหลว (Q_liquid), และความร้อนสัมผัสของอากาศร่วม (Q_air)
- **ตัวชี้วัดระหว่างหลายตู้**: ค่าเฉลี่ยของกลุ่ม, ส่วนเบี่ยงเบนมาตรฐานของกลุ่ม, และสัมประสิทธิ์ความแปรผัน (CV) ข้ามตู้ที่ต่อขนานกัน
- **อัตราส่วนการปิดสมดุลเอนทัลปี**: เปอร์เซ็นต์การปิดสมดุลที่แน่นอนระหว่างกำลังไฟฟ้าจริงกับการระบายความร้อนทางอุณหพลศาสตร์รวม (P_elec เทียบกับ Q_liquid + Q_air)
- **แฟล็กแจ้งเตือนความผิดปกติจากขั้นตอนวิธี**: การแจ้งเตือนอัตโนมัติที่บ่งชี้ถึงเส้นเรียบนิ่งสนิทที่ไร้ความแปรปรวน (σ² ≤ 1.0 × 10^{-4}), ช่องว่างการสื่อสารที่ขาดหาย, ค่าอ่านเซนเซอร์ที่อยู่นอกย่าน, และเวลาสั่งการที่เป็นตัวเลือกจุดเปลี่ยนแปลงจาก Focus, FLOC, หรือ CPOP

คอมพิวเตอร์ดำเนินการทางเลขคณิตได้รวดเร็วกว่าและมีความแม่นยำสูงกว่ามนุษย์ที่ใช้เครื่องคิดเลขพกพาอย่างเทียบกันไม่ได้ จงปล่อยให้สคริปต์ทำหน้าที่ทางเลขคณิต

## สิ่งที่สคริปต์ต้องห้ามเขียนโดยเด็ดขาด

ห้ามมิให้สคริปต์อัตโนมัติ มาโครของแดชบอร์ด หรือโมเดล AI สร้างคำต่อไปนี้ขึ้นมาไม่ว่าในสถานการณ์ใดก็ตาม:
- **PASS (ผ่าน)**
- **FAIL (ไม่ผ่าน)**
- **NOT RUN (ไม่ได้ทดสอบ)**
- **WAIVED (ได้รับการผ่อนปรน)**

สคริปต์อัตโนมัติที่ประเมินแถวข้อมูล แล้วสังเกตเห็นว่าอุณหภูมิที่คำนวณได้คือ 45.1°C เทียบกับขีดจำกัดบนที่ 46.0°C แล้วประทับคำว่า "PASS" ลงบนไฟล์ PDF โดยอัตโนมัตินั้น ถือว่าได้กระทำเกินขอบเขตอำนาจหน้าที่ของตน

### ทำไมคำว่า "Pass" อัตโนมัติจึงเป็นอันตราย
พิจารณาสิ่งที่ขั้นตอนวิธีไม่สามารถรับรู้ได้:
- ขั้นตอนวิธีไม่ทราบว่า RTD ที่รายงานค่า 45.1°C นั้นบังเอิญถูกติดตั้งไว้ในปลายท่อตันที่ไม่มีการไหล แทนที่จะอยู่ในกระแสไหลหลัก
- ขั้นตอนวิธีไม่ทราบว่าท่ออ่อนบายพาสชั่วคราวเกิดการพับงออยู่หลังตู้ หรือมีการปรับวาล์วด้วยมือโดยไม่ได้บันทึกในระหว่างการคงสถานะ
- ขั้นตอนวิธีไม่ทราบว่าลูกค้าเพิ่งออกประกาศเตือนทางวาจาฉุกเฉินในเช้าวันนั้น เพื่อปรับลดขอบเขตการทดสอบจาก 46.0°C ลงเหลือ 44.0°C

สคริปต์อัตโนมัติที่เขียนคำว่า "PASS" จะกล่อมให้ทีมวิศวกรหลงอยู่ในความรู้สึกปลอดภัยที่ผิดพลาด ผู้ควบคุมจะหยุดมองดูท่อทางกายภาพ หยุดฟังเสียงการเกิดโพรงไอของปั๊ม และหยุดตรวจสอบป้ายการสอบเทียบเครื่องมือวัด โดยทึกทักเอาเองว่า "ซอฟต์แวร์กำลังจัดการเรื่องการปฏิบัติตามข้อกำหนดอยู่"

ในคู่มือภาคสนามเล่มนี้ ช่องตารางคำตัดสินบนเทมเพลตแฟลชรีพอร์ตจะกำเนิดขึ้นมาในสภาพที่ว่างเปล่า ช่องเหล่านี้จะสามารถกรอกได้ด้วยมือของมนุษย์ที่ใช้ปากกาหมึก หรือใช้ลายมือชื่อดิจิทัลที่มีการเข้ารหัสและตรวจสอบสิทธิ์แล้วเท่านั้น

## ความผิดของการแทรกแซงแก้ไขโดยมนุษย์

รูปแบบความล้มเหลวในทางตรงกันข้ามก็มีความเป็นพิษไม่แพ้กัน: มนุษย์ที่สังเกตเห็นช่องตารางทางคณิตศาสตร์ที่ไม่ผ่านซึ่งคำนวณโดยสคริปต์ แล้วเขียนทับคำตัดสินนั้นด้วยคำว่า "PASS" ที่ไม่ได้รับอนุญาต

หากสคริปต์คำนวณได้อย่างถูกต้องว่าค่า CV ของการไหลคือ **7.2%** เทียบกับเกณฑ์สูงสุดที่ **5.0%** วิศวกรไม่สามารถเขียนคำว่า "PASS" ข้างช่องตารางนั้นแล้วใส่ข้อแก้ตัวทางวาจาว่า: *"การไหลไม่สม่ำเสมอเล็กน้อย แต่การระบายความร้อนโดยรวมดูเรียบร้อยดี"*

การกระทำนั้นไม่ใช่การตีความทางวิศวกรรม หากแต่เป็นการผ่อนปรนโดยพลการและไม่ได้รับการบันทึก 

หากช่องตารางที่คำนวณได้เกิดไม่ผ่าน:
- คำตัดสินของมนุษย์สำหรับบรรทัดนั้นจะต้องเป็น **FAIL**
- หากทีมโครงการเชื่ออย่างแท้จริงว่าความล้มเหลวนั้นไม่กระทบต่อเป้าหมายการทดสอบและตรวจรับระบบในภาพรวม เจ้าของเอกสารข้อกำหนดจะต้องใช้ **เกณฑ์วิธีผ่อนปรนอย่างเป็นทางการ (Waiver Protocol)**:
 1. แก้ไขเอกสารข้อกำหนดเกณฑ์การออกแบบเพื่อขยายพิกัดความเผื่ออย่างเปิดเผย จาก 5.0% เป็น 7.5%
 2. กำหนดเครื่องหมายฉบับแก้ไขเอกสารใหม่ (เช่น Rev 2.5)
 3. จัดประเภทข้ออ้างสิทธิ์ใหม่ให้เป็นข้อจำกัดที่ทราบอย่างเป็นทางการ
 4. ขอรับการอนุมัติเป็นลายลักษณ์อักษรพร้อมลงนามจากเจ้าของอาคาร

การผ่อนปรนที่กระทำอย่างเปิดเผยท่ามกลางแสงสว่าง พร้อมฉบับแก้ไขเอกสารที่อัปเดต ถือเป็นการตัดสินใจทางวิศวกรรมที่สามารถตรวจสอบได้ ส่วนคำว่า "PASS" ของมนุษย์ที่เขียนทับช่องตารางที่ไม่ผ่านในเงามืดของสเปรดชีต ถือเป็นการปลอมแปลงบันทึกการทดสอบ

## การออกแบบส่วนต่อประสานแบบสองคอลัมน์

เพื่อบังคับใช้วินัยนี้ทั้งในซอฟต์แวร์และในเอกสารสิ่งพิมพ์ ทุกเทมเพลตของแฟลชรีพอร์ตจะต้องนำ **ส่วนต่อประสานแบบสองคอลัมน์ (Two-Column Interface)** ที่เข้มงวดไปใช้งาน:

| คอลัมน์ซ้าย: บล็อกข้อมูลอัตโนมัติ (สคริปต์เป็นเจ้าของ) | คอลัมน์ขวา: การประเมินและคำตัดสิน (มนุษย์เป็นเจ้าของ) |
| :--- | :--- |
| • กำลังไฟฟ้าที่สั่งการ: 120.0 kW | • การอ้างอิงขีดจำกัด: DOC-SPEC Rev 2.4, Table 2 |
| • กำลังไฟฟ้าที่วัดได้: 120.2 kW | • การตรวจสอบความสมดุลของแหล่งจ่าย: ความไม่สมดุลของเฟส < 1.0% |
| • ความร้อนของเหลวที่อนุมาน: 98.6 kW | • ความสมเหตุสมผลทางอุณหพลศาสตร์: ได้รับการยืนยัน |
| • การปิดสมดุลเอนทัลปี: 98.0% | • การตรวจสอบทางกายภาพของฮาร์ดแวร์: ไม่มีการรั่วไหล / เสียงปกติ |
| • ค่า CV การไหลที่คำนวณได้: 2.95% (σ = 5.21 LPM) | • การตรวจสอบความสอดคล้อง: ผ่านเกณฑ์เกณฑ์ขีดจำกัด 5.0% |
| • บิตมาสก์คุณภาพ: 0x0007 (ถูกต้อง, σ² > 0) | • **คำตัดสินของมนุษย์**: **PASS** [ลายมือชื่อย่อ: E.V., หัวหน้า CxA] |

คอลัมน์ด้านซ้ายประกอบด้วยตัวเลขที่ไม่ได้ปรับแต่งซึ่งสร้างขึ้นโดยโค้ด คอลัมน์ด้านขวาประกอบด้วยการตรวจสอบอย่างละเอียดถี่ถ้วนของมนุษย์, การตรวจสอบยืนยันด้วยตนเอง, และลายมือชื่อสุดท้ายที่รับผิดชอบ

## การตัดสินใจที่ต้องบันทึก

ในส่วนการกำกับดูแลของแฟลชรีพอร์ต จงบันทึก:

- เวอร์ชันของซอฟต์แวร์, เช็กลำดับความถูกต้องของสคริปต์ (แฮช SHA-256), และแบรนช์ของที่เก็บโค้ด (repository branch) ของไปป์ไลน์การรวบรวมข้อมูลอัตโนมัติ
- ข้อความรับรองว่าช่องตารางคำตัดสินทั้งหมด (Pass/Fail/Not Run) ได้รับการสอบทานและกรอกด้วยตนเองโดยผู้มีอำนาจหน้าที่ที่เป็นมนุษย์ที่ได้รับมอบหมาย
- การผ่อนปรนอย่างเป็นทางการใดๆ ที่ถูกนำมาใช้ในระหว่างแคมเปญ โดยอ้างอิงฉบับแก้ไขเอกสารที่ได้รับอนุญาตและลายมือชื่อของเจ้าของอาคาร
