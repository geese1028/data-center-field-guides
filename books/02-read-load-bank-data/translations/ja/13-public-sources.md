# 13. 公開資料と引用の完全性

速報またはコミッショニング文書の記入セルにおいて、確立された公的規格や公表されたエンジニアリングガイドラインを引用することは認められる。しかし、セルそのものを公的規格で代替することは決して許されない。

最新のミッションクリティカルエンジニアリングにおいて、厳格な引用の規律は、技術的厳密さと法的完全性の双方を保護する。業界標準規格を引用することは、自らの検証方法論が、査読を経た反論の余地のないエンジニアリング上の合意に基づいていることを証明する。しかしながら、民間ベンダーのマニュアルから著作権で保護された表をコピーしたり、守秘義務のある顧客の独自回路図を公開レポートに貼り付けたりする行為は、即座に著作権侵害の責任および秘密保持契約（NDA）違反を招く。

本章では、引用、知的財産の境界、および許容される公的エンジニアリング情報源を規定する厳格な規則を定義する。

## 引用が果たし得ること、果たし得ないこと

引用とは、工学的手法、安全定義、または環境分類を裏付ける外部の権威への参照ポインタである。

### 引用が果たし得ること：
- **環境クラスの確立**：ASHRAE TC 9.9への引用は、*「二次側ループ冷媒供給温度は、ASHRAE液冷クラスW4の許容枠（32°C〜45°C）に照らして監査された」*という文言を支えることができる。
- **電気的基本規則の定義**：IEC 60204-1またはNFPA 70への引用は、*「主回路断路器および非常停止インターロックは、IEC 60204-1第9.2節（停止カテゴリ0：機械アクチュエータへの電源を即座に遮断する非制御停止）に準拠して検証された」*という文言を支えることができる。
- **コミッショニング工程用語の基礎づけ**：ASHRAE Guideline 0-2019への引用は、5段階のコミッショニング階層（レベル1工場立会試験からレベル5統合システム試験まで）を支えることができる。
- **アルゴリズム手法の参照**：Romanoら（arXiv:2607.19961）およびFearnheadら（DOI:10.1080/10618600.2018.1512868）への引用は、FocusおよびCPOP変化点アルゴリズムの数学的査読実績を確立する。

### 引用が果たし得ないこと：
- **引用で測定セルを埋めることはできない**：NVIDIA GB200 NVL72の営業用ホワイトペーパーを引用したとしても、試験フロアで現場の還流温度を実測する義務を代替することはできない。観測セルには、校正された物理センサーからの実測値が必要である。
- **引用で未実施の行を免除することはできない**：*「業界慣行に基づき片給電障害試験は省略」*と記載して一般的なコミッショニングハンドブックを引用することは許されない。ハンドブックが契約上義務付けられた試験シナリオを免除することはできない。
- **引用は無断転載であってはならない**：ベンダー独自の特性曲線、顧客の機密フロアプラン、または著作権で保護された規格本文をレポートに複写・貼り付けしてはならない。正式な文書名、発行機関、改定番号、および発行年を明記して引用せよ。

## 認可された公的エンジニアリング参照規格

本フィールドガイドの方法論は、以下の公的かつ非専有的な規格および業界団体に準拠している：

1. **ASHRAE Guideline 0-2019**：*『コミッショニング工程（The Commissioning Process）』*。発注者要求仕様（OPR）、設計基準（BOD）、および検証チェックリストを含む、施設向けの標準化された品質重視のコミッショニングプロセスを定義。
2. **ASHRAE Guideline 1.1-2007**：*『コミッショニング工程における空調衛生設備の技術的要求事項（HVAC&R Technical Requirements for The Commissioning Process）』*。一次および二次流体取り扱いループの機能性能試験プロトコルを規定。
3. **ASHRAE TC 9.9**：*『データ処理環境のための熱ガイドライン（第5版、2021年）（Thermal Guidelines for Data Processing Environments）』*。液冷環境分類（クラスW1〜W5）、および結露防止のための施設周囲露点限界を定義。
4. **IEC 60204-1（第6.0版、2016年）**：*『機械類の安全性 - 機械の電気装置 - 第1部：一般要求事項』*。産業機械の電気的絶縁、過電流保護、非常停止ハードワイヤードループ、および耐電圧試験を規定。
5. **NFPA 70（米国電気工事規程、2023年版）**：第645条（情報技術装置）および第250条（接地およびボンディング）。
6. **Open Compute Project（OCP）液冷ガイドライン**：二次流体ループの清浄度、材料適合性（接液部金属材料）、およびクイックディスコネクト分類を統括するオープンスペック規格——ブレードレベルのブラインドメイト（UQD）と、マニホールド試験用の全流量カップリング（Danfoss FD83など）を明確に区別。
7. **ISA-5.1-2009**：*『計装シンボルと識別表示（Instrumentation Symbols and Identification）』*。液冷ループにおける配管計装図（P&ID）の標準化された図面作成規則を規定。

## ベンダーの提案による責任回避の防御

コミッショニング会議において準備不足の機器サプライヤーが頻繁に用いる戦術は、不合格となった試験セルに対して一般的なホワイトペーパーや学術論文のプレプリントを提示して言い逃れを図ることである。

深刻な流量不足によって負荷装置ラックが15分間の保持に失敗した際、ベンダーが「高度なマイクロチャネルコールドプレートは一時的な沸騰を許容し得る」という公開論文を提出してきた場合、その提出物は直ちに却下せよ。
- そのホワイトペーパーは、管理された条件下での実験室テストを記述した学術文書にすぎない。
- 実施中の試験は、NVL72クラスの量産ラックの代替機として契約された特定の機械に対する受入検証である。
- 速報は、引用された仕様書改定番号に対して、現場の物理的な実機が実際に何を示したかを記録するものである。学術的な可能性を議論する場ではない。

境界線を死守せよ。引用は参考文献欄に留め、記入セルは現場の事実で埋めよ。

## 記録すべき決定事項

速報の適合性および引用セクションにおいて、以下を文書化すること：

- レポート内で引用されたすべての外部規格について、正式名称、発行組織、版数、および改定記号。
- ベンダー固有の非公開文書、顧客機密データ、または著作権で保護された回路図面が文書内に貼り付けられていないことの証明。
- すべての技術的限界値が、その時点で有効な確定プロジェクト仕様書改定記号と照合して評価されたことを確認する署名済み声明文。
