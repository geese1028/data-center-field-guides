# 2. 加熱前の確認

液冷負荷装置の速報（フラッシュレポート）は、必須の「準備ブロック（Preparation Block）」から始まる。このブロックは、最初の1キロワットの熱負荷を通電するはるか前に、合格（Pass）または不合格（Fail）として評価される。準備ゲートでの不合格は、その後の勾配試験において許容可能な軽微な異常へと変わるものではない。それは試験キャンペーンを直ちに中断させるものである。加熱前の準備が不合格であったにもかかわらず熱試験が成功したと主張することは、エンジニアリング上の矛盾である。

高密度液冷において、加熱前フェーズは熱力学体系全体のゼロ基準（ベースライン）を確立する。ベースラインが気泡、未校正のセンサーオフセット、または未検証の電源供給によって汚染されていれば、その後に続くすべてのエネルギー収支計算は根本から損なわれることになる。

## 4つの準備ゲート

電磁接触器に対して加熱指令を発する前に、試験チームは以下の4つの連続する準備ゲートを検証し、イニシャル署名を行わなければならない：

### ゲート1：全ユニットの注水・脱気・エア抜き完了
液冷負荷装置は空気の混入・滞留を決して許容しない。浸漬型加熱容器内において、空気だまりは液体が循環しない局所的な死域（デッドゾーン）を形成する。電力が投入された瞬間、露出したヒーターエレメントのシース表面は急速な空焚き熱暴走を起こし、インコロイ（Incoloy）シースに膨れを生じさせ、内部バッフルシールを焦がし、数秒のうちに高温スナップスイッチを作動（トリップ）させる。

準備ブロックでは、以下の物理的証拠を提示することが義務付けられる：
- 内部加熱容器、50μmのコミッショニング前バイパスループ、マニホールドドロップホース、およびDanfoss FD83クイックディスコネクトカップリングを含む接液回路全体が、指定された熱媒体（例：PG25、25%プロピレングリコール水溶液）で完全に満水状態になっていること。
- すべての高所手動エア抜き弁および自動エアベント（AAV）が開放され、気泡の混入しない連続した液体が排出されるまで脱気され、その後に確実に閉止座着されていること。
- 循環ポンプ全圧運転下において、目視サイトグラスまたは脱気チャンバーにより、泡立ちや微小気泡の巻き込みが皆無（ゼロ）であることが確認されていること。

### ゲート2：エンジニアリング仕様書に対する電源供給の検証
負荷装置に電力を供給する電源系統は、宣言された設計基準に適合していなければならず、見逃されることを期待したような安易な仮設便宜配線であってはならない。
- 負荷装置の主回路遮断器端子において、校正済みデジタルマルチメーターを用いて全相間の線間電圧（V_AB, V_BC, V_CA）を測定・検証する。電圧不平衡率は V_unbalance ≤ 1.0% を満たさなければならない。
- 内部の補助換気ブロワーの逆回転を防止するため、正しい時計回りの相回転（A-B-C）を確認する。
- 接地ループインピーダンスを測定し、NFPA 70（NEC第250条）またはIEC 60364-5-54に厳格に準拠して機器接地導体（EGC）が施設側接地バスにボンディング接続されていることを確認する。
- 施錠可能な主断路スイッチの通電実動作試験を実施し、緊急時にユニットを完全に無電圧化し機械的にロックアウト（LOTO）できることを証明する。

### ゲート3：ユニットの包括的セルフチェック合格
試験クラスタ内のすべての負荷装置ラックは、内蔵自己診断テスト（BIST）シーケンスを実行しなければならない：
- 監視PLCはすべての制御リレーを作動させ、主浸漬ヒーター用電磁接触器が機械的な固着、過度な接点バウンス、またはうなり音（ハム音）なしに円滑に動作することを検証する。
- クラス1ハードワイヤード安全ループを検証する：前面パネルの非常停止（E-stop）キノコ型押しボタンスイッチを押下した際、20ミリ秒未満ですべての接触器制御コイルが開放（遮断）されなければならない。
- 最下部ドリップパン（液受け槽）内の内部漏液検知ロープまたは光学式フロートセンサーをテストし、ハードワイヤードによる即時緊急停止が作動することを確認する。
- すべてのデジタル通信チャネル（Modbus-TCP / MQTT）においてアクティブなアラームフラグがゼロであることを報告し、16ビット品質ビットマスクが健全な状態（`0x0001`〜`0x0007`）に初期化されていること。

### ゲート4：安定した10分間の無負荷ベースライン運転
ゲート1からゲート3までが完了した後、試験クラスタ全体において、すべての加熱エレメントを厳格に通電停止（ゼロワット指令）とした状態で、定格全流量での冷媒循環運転を実施する。

この無負荷運転は、少なくとも**10分間**（または要求仕様書に事前に宣言されたベースライン時間）にわたり連続して維持されなければならない。この保持の目的は、コールドループが水力学的平衡に達するのを待つとともに、データストリームに熱的ノイズが混入する前に、センサーのドリフト、通信途絶、または無応答（デッド）チャネルを露出・検出することにある。

オペレーターが待ちきれずに、部屋を温めるために「ほんの少しだけ熱をかける」（例：5kW）ような行為を行った場合、その期間を準備ベースラインとして使用することはできない。ベースライン中に一部でも加熱を指令することは、ゼロ基準を破壊する。早期に加熱が印加された場合は、直ちに試験を中止し、ヒーターの電源を切り、10分間のタイマーを最初からやり直さなければならない。

## ベースライン中に記録すべき事項

10分間の無負荷安定化運転の最後の1分間において、連続した1分間のベースラインブロックを記録する。このブロックでは以下を取得しなければならない：
- **電気チャネル**：全ラックにおいて有効電力 P_elec が正確に 0.0 kW を示していること（補助ブロワーの寄生電力［通常0.8kW程度］は別行に記録し、ヒーター電力と混同してはならない）。
- **水力チャネル**：冷媒供給温度（T_in）、冷媒還流温度（T_out）、体積流量（Q_v）、供給側静圧（P_in）、および還流側静圧（P_out）。
- **付随空気チャネル**：周囲吸気温度（T_air,in）および排気温度（T_air,out）。

健全な無負荷ベースラインにおいて、加熱コア前後の温度差（ΔT = T_out - T_in）は、配管内部およびCDUポンプインペラ内で機械的ポンプ動力が粘性摩擦熱へと変換されることにより、通常わずかに正の値（おおむね +0.05 K〜+0.15 K 程度）を示す（P_friction = Q_v · ΔP）。この微小なオフセットを文書化しておくことは極めて重要である。これにより、低負荷ステップにおいて監査人がポンプの摩擦熱を電気校正誤差と誤認することを未然に防止できる。

その後の勾配データブロックに登場するすべてのセンサーチャネルは、このベースラインの1分間においてすでに存在し、測定値を読み取り、健全な状態で動作していなければならない。勾配試験の途中でエクスポートデータに突如「出現」したセンサーは、準備段階で検証されていない。そのデータを用いて適合性を証明することはできない。

## 水力抵抗ベースライン：コールドインピーダンス曲線

要求仕様書に実機ラックの水力抵抗曲線（流量と圧力損失の関係を表す k_v または C_v 特性）の模擬要求が含まれている場合、準備フェーズこそがその整合性を校正する場となる。

低温の冷媒（例：35.0°CのPG25）は、45.0°Cの高温冷媒（動粘度 $\nu ≈ 2.15 cSt$）に比べて高い動粘度（$\nu ≈ 2.85 cSt$）を示す。その結果、負荷装置前後のコールドベースラインにおける圧力損失は、高温定常時の圧力損失よりもわずかに高くなる。

無負荷準備運転中において：
1. 定格流量（176.5 LPM）において、マニホールドの供給・還流ポート間の差圧（ΔP = P_in - P_out）を測定する。
2. 負荷装置に調整可能な手動バランス調整弁（校正済みトリプルデューティバランス弁など）が備わっている場合、測定された ΔP が引用された模擬ラックインピーダンス曲線（例：112.0 kPa ± 3.0 kPa）に合致するよう調整ハンドルを調整する。
3. 機械的メモリーストップまたは改ざん防止シールを用いて、バランス弁の開度位置を固定・ロックする。
4. 最終的な弁開度位置、低温流体温度、および測定された ΔP を準備シートに記録する。

この調整は物理的なセットアップ基準値である。実験結果ではない。準備段階で水力抵抗について「PASS」と記すのではなく、セットアップの確定事実として記録する。これにより、その後の120kW熱勾配試験が実行された際、差圧の変化が記録のないバルブの不正操作によるものではなく、温度依存の粘度変化に起因するものであると誠実に帰属させることができる。

## 記録すべき決定事項

最初の負荷ステップへの昇温（ランプアップ）指令を発する前に、速報の準備セクションに以下の事項を記録すること：

- 各ラックのエア抜きおよび脱気完了を確認した技術者のイニシャル署名。
- A系統およびB系統について測定された線間電圧および接地ループ抵抗値。
- 確認されたクラス1非常停止回路のトリップ遮断時間（20ms未満）。
- 10分間の無負荷安定化運転の正確な開始および終了タイムスタンプ。
- ベースライン最終分におけるすべての電気、水力、および空気チャネルの算術平均値。
- 水力バランス調整弁のロック位置および測定されたコールド ΔP。
- 4つの準備ゲートすべてが合格（PASS）を達成したことを証明するシートオーナーの署名。
