# 10. 正式報告パッケージ

速報（フラッシュレポート）は、現場での迅速な技術的トリアージ（優先度判定）を目的として設計されている。負荷装置の試験停止から2時間以内に5行の即時判定を提供し、施設管理者、コミッショニング責任者、および施工統括者が、次のコミッショニングフェーズへ進むべきか、あるいは是正改修のために現場を保留すべきかを直ちに判断できるようにする。

しかしながら、速報は作業シフトの終了とともに消え去るものではない。それは**正式コミッショニング検証引き渡しパッケージ（Formal Commissioning Verification Handover Package）**の恒久的な中核を成す。このパッケージは、データセンターの運用期間全体にわたって保管され、保険会社（アンダーライター）の引受査定、ハイパースケールテナントの監査、および年次の施設再認証に供される法的・技術的公式記録（ドシエ）となる。

80ページにも及ぶ営業用パンフレットや、索引のない生データの無秩序なダンプで水増しされた正式パッケージは、監査人によって一蹴される。逆に、自らの数値を論証できないほど内容が希薄なパッケージもまた却下される。

本章では、正式引き渡しパッケージに何を保持すべきか、何を容赦なく破棄すべきか、そして試験クルーが撤収した10年後であっても第三者がその完全性を検証できるようにアーカイブをどのように構造化すべきかを明確に規定する。

## 保持すべき必須事項：7つの不可欠な成果物

正式引き渡しパッケージには、番号付けされた以下の7つの個別の成果物が含まれていなければならない。これら7つのうち1つでも欠落していれば、パッケージは不完全とみなされる：

### 成果物1：1ページのエグゼクティブ速報（The One-Page Executive Flash Report）
第1章で定義され、図01に示された決定的な総括シート：
- 試験実行メタデータ（Run ID、施設場所、実施日、引用仕様書改定記号）。
- 実測値、保持時間、および明示的なPASS／FAIL／NOT RUN判定を伴う5つのシナリオ合格表（事前試験、勾配、過負荷、ステップ変化、片給電障害）。
- 総合試験判定条項。
- 指定された4つの役割（シートオーナー、オペレーター、レコーダー、ストレンジャー）の直筆インク署名または暗号署名。

### 成果物2：準備およびベースライン証明書（The Preparation and Baseline Certificate）
加熱が指令される前に試験クラスタが試験適格状態にあったことを証明する文書：
- 検証および署名がなされた4つの準備ゲート。
- 1分間のベースライン平均値を含む、コールド状態での10分間安定化ログ。
- ロックされたバランス調整弁の開度位置およびベースライン差圧（ΔP）を記録したコールド水力インピーダンス校正記録。

### 成果物3：複数ラック一貫性シート（The Multi-Cabinet Consistency Sheet）
すべての並列負荷装置にわたるクラスタ平衡度の統計的評価：
- 有効電力（CV ≤ 1.0%）、冷媒流量（CV ≤ 5.0%）、温度上昇（CV ≤ 3.0%）、およびマニホールド差圧（CV ≤ 5.0%）について算出された変動係数（CV）。
- 現場で実際の乱流動が存在し、キャッシュ／フリーズされたデータをエコー出力しているチャネルが皆無であったことを証明する、認証済みの非ゼロ分散チェック（σ² > 0）。

### 成果物4：ステップデータブロックおよびエンタルピークロージャ表（The Step Data Blocks and Enthalpy Closure Tables）
各負荷ステップ（25%、50%、75%、100%、110%）における完全な熱力学貸借対照表：
- すべての電気、液体、および空気チャネルに関する4要約統計量（最小値、最大値、算術平均値、標準偏差）。
- 第一原理熱力学エネルギー収支：有効電力（P_elec）と、液体エンタルピー（Q_liquid = ṁ C_p ΔT）および付随空気顕熱量（Q_air）との比較照合。
- 認証されたエンタルピークロージャ比率（≥ 97.0%）。

### 成果物5：時系列オシログラムおよびグラフ（The Time-Series Oscillograms and Charts）
改ざん不能な生データから生成された、高解像度ベクター品質のグラフ群：
- すべての並列ユニットの電力および温度波形を重畳表示したプロット。個々のラック間の差異を誠実に露出させるスケールで描画されていること。
- 整定時間およびピーク水力圧力パルスを詳細に注記した動的ステップ変化応答プロット。
- 接触器の遮断開放時間（20ms未満）および制御バスの瞬低ゼロ安定性を捕捉した2N片給電喪失過渡オシログラム。

### 成果物6：アルゴリズムによる変化点および異常監査ログ（The Algorithmic Changepoint and Anomaly Audit Log）
アルゴリズムによる自動精密検査の完全なログ：
- オペレーターの指令ログと時系列で照合された、オンラインFocusおよびFLOCによる変化点候補トリガー時刻。
- 定常保持区間ボックスにわたるオフラインCPOP区分線形勾配セグメント。
- すべての候補点に対してイニシャル署名された人間の分類タグ：*予期されたステップ（Expected Step）*、*要点検／保持区間分割（Inspect / Split Hold）*、または*影響なし（No Impact）*。

### 成果物7：暗号署名付き未加工生CSVデータアーカイブ（The Cryptographically Signed Raw CSV Data Archive）
エッジゲートウェイから直接エクスポートされた、完全で無加工の1秒生テレメトリファイル：
- すべてのアクティブなセンサーチャネルが、ISO-8601 UTCタイムスタンプとともに毎秒1回記録されていること。
- ファイルのクローズ直後に生成された正式なSHA-256暗号チェックサムファイル（例：`LB_TEST_2026_H01_RAW.csv.sha256`）を添付し、生データが事後的に修正、フィルタリング、または編集されていないことを担保すること。

## 容赦なく破棄・排除すべき事項

正式引き渡しパッケージはエンジニアリングの監査記録であり、宣伝用ポートフォリオではない。以下の項目は厳格に排除されなければならない：

- **未校正のスマートフォン写真**：点灯した表示灯ランプ、オペレーターの顔写真、またはケーブル束などを撮影した不鮮明なスマートフォン写真を何十枚も添付してはならない。緑色LEDの写真は記念品にすぎず、電気的導通や流体エンタルピーの証拠にはならない（校正された温度スケールを備えた高解像度赤外線サーモグラフィ画像のみ、端子ラグ点検の裏付け文書として添付が認められる）。
- **ベンダーの営業用パンフレットおよび3Dレンダリング**：光沢のある販売用カタログ、コンピュータ生成のコンセプトアート、または企業紹介スライドで文書を水増ししてはならない。監査パッケージはフロアに置かれた物理的な実機のものであり、営業用パンフレットのものではない。
- **マスキングされていない顧客機密データ**：顧客のテナント識別情報、独自AIモデルの名称、マスキングされていないセキュリティアクセスコード、または企業内部IPアドレスを含めてはならない。レポートが検証するのは熱力学的および電気的性能であり、プライベートデータネットワークのマッピングではない。
- **索引のないギガバイト級の生ログダンプ**：何百万行もの未フォーマットの生JSONログや端末出力をPDFの付録に貼り付けてはならない。生CSVアーカイブは安全な独立したデジタルリポジトリに保管し、そのSHA-256ハッシュを引用することで、正式レポートPDFの簡潔さ、可読性、および焦点を維持せよ。

## アーカイブフォルダのディレクトリ構成

最終的なデジタル引き渡しパッケージを、以下のように整理された標準的なフォルダディレクトリ構成にまとめる：

```
├── 01_Executive_Flash_Report.pdf # 署名済み1ページ総括シート
├── 02_Preparation_and_Baseline.pdf # コールドゲートおよび水力校正記録
├── 03_Consistency_and_Uniformity.pdf # CV計算および複数ラック平衡度
├── 04_Step_Data_Blocks_and_Enthalpy.pdf # 熱力学照合表
├── 05_Time_Series_Charts.pdf # 高解像度オシログラムおよび動的ステップ応答
├── 06_Changepoint_Audit_Log.pdf # Focus / FLOC / CPOP変化点候補ログ
├── 07_Raw_Telemetry_Archive/
│ ├── LB_RAW_1HZ_TELEMETRY.csv # 完全な1秒生データファイル
│ └── LB_RAW_1HZ_TELEMETRY.csv.sha256 # 改ざん不能なSHA-256暗号ハッシュ
└── 08_Calibration_Certificates/
 ├── PT100_RTD_Calibration.pdf # NIST/ISO 17025校正証明書
 ├── Vortex_Flow_Meter_Cal.pdf # 工場流量校正証明書
 └── Power_Transducer_Class02.pdf # 電力変換器（クラス0.2）校正タグ
```

監査人やコミッショニング代理人がこのパッケージを受け取った際、生CSVファイルのSHA-256ハッシュを5秒で照合し、Pythonで集約計算を再実行して、エグゼクティブ速報に記載されたすべての数値を独自に再確認・検証することができる。

これこそが、エンジニアリングフィールドガイドの到達水準である。

## 記録すべき決定事項

正式引き渡しパッケージを封印する前に、以下を検証し文書化すること：

- レコーダーが署名した、生CSVテレメトリファイルの算出SHA-256チェックサム。
- 改ざん不能な生ファイルが保存されているアーカイブストレージURIまたはリポジトリの格納場所。
- パッケージに含まれるすべての計器校正証明書の一覧およびその有効期限。
- シートオーナーおよび第三者CxAによる最終受入検収署名。
