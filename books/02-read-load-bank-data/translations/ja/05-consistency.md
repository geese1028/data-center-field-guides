# 5. 一貫性と複数ラック間の均一性

単一のセンサーがもっともらしく良好な数値を報告していたとしても、それが物理的現実から根本的に乖離していることはあり得る。複数の負荷装置が並列に配置され、AIクラスタ全体の列（Row）を模擬する高密度データホールにおいて、ユニットを個別に孤立して評価することは不十分である。

速報では、複数ラック間の一貫性に関する厳格な数学的検証を義務付けている：同一の二次側マニホールド上に配置され、同一の双子であると主張する計器および装置群は、全負荷運転下において真に双子のように振る舞っているか？

本フィールドガイドにおいて、一貫性とは主観的な印象や、並列グラフを目視で眺めるような定性的な評価ではない。それは厳格な数学的指標である**変動係数（Coefficient of Variation、CV）**によって定義される。

$$\text{CV} = \left( \frac{\sigma}{\mu} \right) \times 100\% = \left[ \frac{\sqrt{\frac{1}{N} \sum_{i=1}^N (x_i - \mu)^2}}{\mu} \right] \times 100\%$$

ここで N はクラスタ内の並列負荷装置ラックの台数、μ はグループの算術平均値、σ は標本標準偏差である。

（複数ラックの水力分配系統図、マニホールド圧力勾配、およびバランス状態と流量飢餓状態のクラスタの比較事例については図03を参照）。

## CV指標の適用対象

速報では、各負荷ステップの定常保持時間中において、以下の4つの物理次元にわたってCVを算出する：

### 1. 有効電力消費の均一性（CV ≤ 1.0%）
並列接続されたすべての負荷装置ラックにわたり、消費される有効電力は 1.0% の許容枠内で平衡していなければならない。高級ニッケル・クロム（NiCr 80/20）合金製のヒーター抵抗体は、厳格な抵抗値許容差（コールド時 ± 2.0%、平衡3相デルタ結線全体で ± 1.0% 以内）を有する。
- 4台の並列ラックに120kWを指令した際、3台が120.2kWを消費する一方でラック4が108.5kWしか消費しなかった場合、電力のCVは 4.8% へと急上昇する。
- 1.0%を超える電力CVは、端子ラグの緩み、分岐ヒューズの溶断、SSRの焼損、または未校正の変流器（CT）が存在することを示す。これは直ちに電気的一貫性の行で不合格となる。

### 2. 冷媒体積流量の均一性（CV ≤ 5.0%）
適切にバランス調整された二次側冷却分配配管網において、すべての並列ITラックは全液流量の均等な配分を受けなければならない。
- 合計供給流量が 706 LPM である共通マニホールド上で動作する4台の120kWユニットの場合、ユニットあたりの理想的な分岐流量は 176.5 LPM となる。
- すべてのアクティブなラックにわたる冷媒流量は、**CV ≤ 5.0%** を満たさなければならない。
- 5.0%を超える流量CVは水力学的な偏流（分配不良）を露呈させる——これは通常、分岐ホース長の不揃い、急峻な90°エルボによる屈曲、クイックディスコネクト内蔵逆止弁の不完全な着座、または分岐バランス調整弁の未調整に起因する。

### 3. 還流冷媒温度上昇の均一性（CV ≤ 3.0%）
電力が均一（CV ≤ 1.0%）であり、液流量が均一（CV ≤ 5.0%）であるならば、熱力学の法則により還流冷媒の温度上昇（ΔT = T_out - T_in）もまた均一でなければならない。
- 全ラックにわたり、温度上昇は **CV ≤ 3.0%** を満たさなければならない。
- ラック1からラック3までが ΔT = 10.0 K を示しているのに対し、ラック4が ΔT = 14.5 K を示した場合、ラック4は局所的な熱集中（低流量が原因であることが多い）を起こしている。逆にラック4が ΔT = 2.1 K を示した場合は、内部の加熱コア周辺で流体のショートサーキット（短絡流）が発生している。

### 4. マニホールド差圧の均一性（CV ≤ 5.0%）
各個別ラックの供給・還流ポート間で測定された差圧は、**CV ≤ 5.0%** を満たさなければならない。これにより、すべての筐体が施設側CDUポンプに対して同一の水力インピーダンスを提示していることが検証される。

## 水力学の落とし穴：ダイレクト・リターン方式 vs リバース・リターン方式

一貫性の章では、仮設液冷負荷装置の敷設において最も頻発する配管欠陥である**ダイレクト・リターン（直接還流）マニホールドの流量飢餓（スターベーション）**を暴き出す。

図03に示す通り：
- **ダイレクト・リターン（先入れ・先出し）**マニホールドでは、最初の負荷装置（ラック1）が一次側供給管と一次側還流管の両方に最も近い位置にある。ラック1は最も短い水力回路を通り、最も高い利用可能差圧（ΔP）を享受する。一方、最も離れたユニット（ラック4）は水力学的な末端に位置し、管路摩擦によって供給圧力が減衰し、還流背圧が蓄積している。
- 各分岐ごとのバランス調整弁がない場合、ラック4への供給流量は著しく低下する（例：ラック1の 192.0 LPM に対し、ラック4は 124.0 LPM）。この結果、流量CVは **18.25%** という致命的な値に跳ね上がる！
- この不合格を隠蔽しようとして、経験の浅いチームは「クラスタ平均流量」（168.25 LPM）を算出して試験合格を宣言してしまう。その裏でラック4では流速が激減し、シース表面温度は85°Cのトリップ限界に向かって急上昇しており、CDUポンプは不安定領域で運転されている。
- **リバース・リターン（逆還流、ティヘルマン方式）**配管ループでは、最初に冷媒が供給されたユニットが最後に還流されるため、4本のすべての分岐にわたって総等価管長が等しくなる。この構成により、流量CVは容易に **0.33%** まで低減し、真の水力学的忠実度が保証される。

速報では、流量のCVを算出して1ページ目に印刷することを義務付けている。高いCV値は、本番の計算ハードウェアが配備される前に、ダイレクト・リターンによる流量飢餓の存在を即座に白日の下に晒す。

## 評価ウィンドウの規則

一貫性解析は、15分間の負荷保持時間の最終定常部から抽出された、連続する**5分間の評価ウィンドウ**に対して実施されなければならない。
- ウィンドウ内のデータは **1 Hz**（チャネルあたり毎秒1回のリアルタイム測定値）でサンプリングされなければならない。
- ウィンドウは定常状態に厳格に限定されなければならない。負荷ステップの遷移時やオペレーターによる弁の調整操作期間を跨いではならない。ウィンドウ内に電力変動を含めると分散が人為的に膨張し、正常なラック群であっても計算上不合格となってしまう。
- 負荷ステップが3分間しか保持されなかった場合、CVを算出するための十分な定常データが存在しない。その場合、一貫性行を**未実施（NOT RUN）**と記録するか、適切な保持時間を確保してステップを再実行しなければならない。十分なデータ点数を集めるために、ウィンドウを過渡昇温期間へと過去に引き延ばすことは禁じられる。

## CVが語れないこと：分散ゼロの不正

CVが低いということは、クラスタ内の各機が相互に一致していることを証明するにすぎない。クラスタ全体が仕様を満たして正しいことを証明するものではない。

見かけ上極めて低いCVを生み出してしまう、2つの危険な障害モードを考慮せよ：
1. **一様に仕様外（Uniformly Out of Spec）**：仕様書で要求される下限値 170.0 LPM に対して、4台のラックすべてが均等に 130.0 LPM の流量しか受け取っていない場合。標準偏差はゼロとなり、計算上の流量CVは非の打ちどころのない 0.00% となる。しかし、クラスタ全体が一様に流量不足に陥っているのである！これは一貫性の行には合格するが、事前試験の行では無条件で不合格となる。一様な失敗であっても、失敗であることに変わりはない。
2. **データの陳腐化／フリーズの不正（The Stale / Frozen Data Fraud）**：エッジゲートウェイの通信スレッドがクラッシュした場合、あるいはModbusポーラーが生レジスタを読み取らずにキャッシュされた数値を繰り返しログに書き込んでいる場合、全4台のラックに記録される数値は数学的にフリーズした状態となる。通信が死滅したグループは標準偏差 σ = 0.000 を報告し、算出されるCVは **0.00%** となる！

正確に 0.00% のCVは、エンジニアリング上の完璧さを示すものではない。乱流状態にある流体ループにおいて、それはテレメトリの不正・虚偽を示す物理的証拠である。現実の乱流対流は、常に微細な熱的・圧力的なゆらぎ（ジッター）を発生させる。

したがって、速報において算出されたCVを受理する前に：
- 監視システムは、すべてのチャネルにおいて**標本分散 σ² > 0** であることを検証しなければならない。
- 16ビット品質ビットマスクによって、いずれのチャネルにも「陳腐化／フリーズ（STALE / FROZEN）」ビットがセットされていないことを確認しなければならない。

分散がゼロであるか、品質ビットに異常がある場合、算出されたCVは見せかけの塗装にすぎない。その行を不合格とせよ。

## 記録すべき決定事項

速報の一貫性セクションにおいて、以下の事項を記録すること：

- 有効電力（≤ 1.0%）、液流量（≤ 5.0%）、温度上昇（≤ 3.0%）、および差圧（≤ 5.0%）について事前に宣言されたCV閾値限界。
- 定常状態計算に使用された正確な5分間の時間ウィンドウ（秒単位の開始および終了タイムスタンプ）。
- すべての並列ラックにわたる各パラメータの算術平均値（μ）、標本標準偏差（σ）、および算出されたCV。
- 各チャネルにおいて現場の乱流ゆらぎが存在していたことを確認する、証明済みの非ゼロ分散チェック（σ² > 0）。
- ストレンジャーのイニシャル署名が付された複数ラック間一貫性の合否判定。
