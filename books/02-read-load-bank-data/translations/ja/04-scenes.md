# 4. シナリオの機能

事前試験ゲートで合格（PASS）を達成した後、速報は実際のアクティブな運用シナリオの実行へと進む。シナリオとは、非公式なウォークスルーや、時間管理のなされていない機器の実演、あるいは居合わせた関係者が納得するまで適当に制御ノブを回すようなものではない。

シナリオとは、明確な開始時刻、必須の保持時間（滞留時間）、定義された物理的外乱、および定量的な合否判定基準を備えた、正式かつ時間枠が厳格に区切られた機能性能試験である。各シナリオは、液冷負荷装置および関連する施設側CDU冷却プラントの固有の運用能力をそれぞれ個別に検証する。

標準的な液冷負荷装置の検証は、以下の5つのコアシナリオで構成される：
1. **階段状勾配（Stepped Gradients）**（定常容量および熱線形性）；
2. **過負荷到達（The Overload Visit）**（設計マージンおよび緊急時耐力）；
3. **急激なステップ変化（The Sudden Step Change）**（動的制御応答および水力学的安定性）；
4. **2N片給電喪失ドロップ試験（The 2N Single-Feed Loss Drop Test）**（電気的冗長性およびテレメトリの耐障害性）；
5. **調整弁の権能およびストローク検証（Modulating Valve Authority & Stroke Verification）**（水力トリム制御）。

（2N片給電喪失ドロップ試験の詳細な電気機械および制御オシログラムについては図07を参照）。

## シナリオ1：勾配（階段状容量試験）

勾配シナリオは、負荷装置がその動作範囲全体にわたり、ハンチング、ヒーターエレメントの劣化、または過度な流体バイパスを起こすことなく、個々の負荷プラトー（平坦域）において安定して保持できることを検証する。

標準的な試験は、4つの異なる負荷率に従って進行する：
- **ステップ1（定格容量の25%）**：有効電力 30.0 kW（液冷 24.6 kW、付随空冷 4.8 kW）。
- **ステップ2（定格容量の50%）**：有効電力 60.0 kW（液冷 49.3 kW、付随空冷 9.6 kW）。
- **ステップ3（定格容量の75%）**：有効電力 90.0 kW（液冷 74.0 kW、付随空冷 14.4 kW）。
- **ステップ4（定格容量の100%・全負荷）**：有効電力 120.0 kW（液冷 98.6 kW、付随空冷 19.2 kW）。

### 保持時間クロックの規則
各プラトーにおいて、負荷指令は**少なくとも連続15分間**（または試験契約で宣言された特定の保持間隔）にわたり一定に維持されなければならない。

物理的な液体ループには質量があるため、この15分間のクロックは一切の妥協が許されない。150kgのSUS316ステンレス製容器金属、20リットルの流体、堅牢な内部銅製バスバー、および厚肉の断熱ヘッダーを備えた産業用浸漬負荷装置の熱時定数は、τ ≈ 45 秒 である。
- いかなる負荷ステップにおいても、最初の3〜5分間は**熱的過渡ウィンドウ**に相当し、この間は流体の温度上昇が安定する前に、低温の金属外殻によって熱が活発に吸収される。
- この過渡ウィンドウの最中に熱収支計算を試みると、ヒーターの出力が不足しているという誤った判定を下すことになる。
- 定常状態の評価ウィンドウは、4つの時定数（t ≥ 4τ ≈ 3 分）が経過した後に初めて開始される。15分間の保持時間のうち最後の10分間こそが、真の定常プラトーを表す。

勾配シナリオに合格するためには、4つのステップすべてが正常に保持され、観測された流体温度上昇（ΔT = T_out - T_in）が理論値に対して ± 2.0% 以内で指令電力に線形比例していなければならない。

## シナリオ2：過負荷（制限付き到達）

過負荷シナリオは、加熱エレメント、内部ソリッドステートリレー（SSR）、電磁接触器、配線ハーネス、および配管ガスケットが、定格銘板容量の100%を超える十分な安全マージンを有していることを検証する。

120kW基準ユニットの場合、過負荷ステップでは**定格電力の110%（132.0 kW）**を指令する。
- **到達（ビジット）規則**：過負荷シナリオは、通常正確に**5分間**継続する意図的な**一時到達（ビジット）**として厳格に定義される。恒久的な定格値ではない。
- **なぜ5分で停止するのか**：110%負荷で動作する浸漬加熱エレメントは、15 W/cm² に迫るシースワット密度（表面熱流束）に達する。高流速の冷媒循環下における短時間のコミッショニング確認としては安全であるものの、この高熱流束での長時間の運転は流体中の腐食防止剤（トリルトリアゾールなど）を劣化させ、EPDMガスケットの熱硬化を加速させる。
- **合否判定基準**：過負荷シナリオは、装置が132kWにクリーンに突入し、過熱防止スナップスイッチをトリップさせることなく5分間の保持を維持し、接触器のチャタリングや端子台の発煙を生じさせず、指令に従って定格負荷またはゼロ負荷へクリーンに遮断・復帰した場合に合格となる。
- **定格引き上げの不正（プロモーション詐欺）**：試験クルーが132kWでの運転が順調であったことを見て、当該機を「132kW連続定格の負荷装置」として宣伝したり銘板を貼り替えようとしたりした場合、その主張は即座に拒絶しなければならない。一時的な到達に耐え抜いたからといって、連続定格になるわけではない。

## シナリオ3：ステップ変化（動的制御およびサージ耐性）

ステップ変化シナリオは、大規模な電力急変時におけるシステムの動的応答性を検証する——これは同期されたAI推論バッチの一斉開始や、緊急時のGPUクラスタのスロットリングを模擬するものである。

本シナリオでは瞬間的なステップジャンプを実行する：
1. 負荷装置を25%負荷（30 kW）で安定維持する。
2. 自動監視スクリプトまたは手動オペレーターにより、100%負荷（120 kW）への瞬間的なステップ投入を指令する。
3. ユニットを100%で10分間保持する。
4. 100%から25%への瞬間的なステップ遮断を指令する。

### 評価項目
- **電気的追従性**：電磁接触器またはサイリスタ電力調整器が、1.5 秒 未満で電力ステップを切り替え、安定させなければならない。
- **制御ループの整定時間**：施設側CDUの冷却制御弁（TCV）は、冷媒流量または二次側供給温度を調整し、オーバーシュートを 5.0% 未満に抑えつつ、120秒以内に新たな熱流束を安定化させなければならない。
- **水力学的ウォーターハンマーの抑制**：大型ヒーターステージの遮断や制御弁の絞り動作時、急激な流量変動が音響的圧力脈動を誘発することがある。マニホールド差圧センサーにより、ピーク圧力サージが ΔP_surge ≤ 15.0 kPa を超えないことを検証しなければならない。弁の急激な動作によって激しい配管の振動、サポート金具の衝突音、または50 kPaを超える圧力スパイクが発生した場合、ステップ変化シナリオは直ちに不合格（FAIL）となる。

## シナリオ4：片給電（2N給電喪失ドロップ試験）

高密度AIデータホールにおいて、ラックレベルへの配電は2N（A系統・B系統の二重化経路）または分散冗長構成として設計される。NVL72ラックの代替機として稼働する液冷負荷装置は、この二重化電気トポロジーを忠実に再現しなければならない。

### 試験の実施
負荷装置クラスタが定格容量100%（ラックあたり 120.0 kW、A系統から 60.0 kW、B系統から 60.0 kW を受電）で稼働している状態で：
1. オペレーターが手動でA系統に給電している主電源遮断器をトリップさせる。
2. A系統から給電されているバンク1およびバンク2の接触器制御ロジックが即座に消磁（遮断）されなければならない。
3. 補助接点が**20ミリ秒未満**で回路を開放し、有効負荷の正確に50%（60.0 kW）をクリーンに遮断しなければならない。
4. B系統は、上流側の回路遮断器をトリップさせたり、定格電流の115%を超える突入電流過渡現象を被ることなく、バンク3およびバンク4をシームレスに継続担持しなければならない。
5. **制御バスの瞬低ゼロ要求**：PLC、センサー、およびModbus/MQTT通信ゲートウェイに給電するDC24Vの監視電源バスは、両系統間でダイオードOR結合されていなければならない（図07参照）。A系統の脱落によって生じる電圧瞬低（ブラウンアウト）は**完全にゼロ（リップル < 50 mV）**でなければならない。A系統の喪失によってPLCが再起動したり、ネットワークリンクが切断されたり、センサーの読み取りがフリーズしたりした場合、負荷装置は無条件で片給電試験不合格となる。
6. A系統遮断の検証が完了した後、A系統を復旧させ、ユニットを100%定常状態に復帰させた上で、B系統をトリップさせて同一の試験を繰り返す。両系統とも、脱落側経路としての検証を受けなければならない。

## シナリオ5：調整弁の権能およびストローク検証

負荷装置にラック側の差圧または流量インピーダンスを調整するための内蔵調整弁（TCV）が備わっている場合、その弁の機械的・水力学的権能（バルブオーソリティ）を検証しなければならない。

本試験では、弁動作前の5分間の定常ウィンドウと、弁位置変更後の5分間の定常ウィンドウを比較評価する：
- **ストローク検証**：弁アクチュエータは、指令に応じて機械的な固着、ハンチング、またはモーターの失速を起こすことなく、100%全開から50%絞り位置へと動作しなければならない。
- **水力学的権能**：弁を50%ストロークまで絞った際、激しいキャビテーション異音領域に陥ることなく、分岐差圧（ΔP）に測定可能かつ再現性のある変化を生じさせなければならない。
- 単に「弁が動作した」とだけ記されたレポートは監査不能である。レポートには、指令されたストローク開度率、実測された流量変化（Δ Q_v）、およびそれに伴うマニホールド差圧の変動値を明記しなければならない。

## 記録すべき決定事項

試験キャンペーン中に実施されたすべてのアクティブシナリオについて、速報に以下を記録すること：

- 各勾配プラトーについて、時系列上の正確な開始時刻、安定化時刻、および終了時刻。
- 過負荷到達について事前に宣言された継続時間および電力レベル。
- ステップ変化投入時において測定された整定時間およびピーク水力圧力サージ（ΔP_surge）。
- A系統およびB系統の遮断試験中における接触器の遮断開放時間（20ms未満）、および確認されたDC24V制御バスの瞬低ゼロ継続性。
- 調整トリム弁のストローク試験前後の流量および圧力測定値。
- すべてのシナリオ遷移が試験スケジュールに厳格に従って実行されたことを証明するレコーダーおよびオペレーターの署名。
