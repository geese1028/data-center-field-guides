# 7. データブロックと熱収支の照合

速報において証拠として主張されるすべての負荷プラトー（平坦域）は、同一で標準化されたデータブロックを備えていなければならない。

データブロックとは、単に数値をページ上に無秩序に並べ立てたものではない。それは以下の5つの必須セクションから構成される体系的な熱力学貸借対照表（バランスシート）である：
1. **設定値および指令（Setpoints & Commands）**（事前に宣言された試験の意図）；
2. **初期状態ベースライン（Initial State Baseline）**（ステップ投入直前の基準状態）；
3. **配電データ（Electrical Distribution Data）**（ヒーターエレメントに供給された検証済みエネルギー）；
4. **水力エンタルピーデータ（Hydraulic Enthalpy Data）**（液流によって吸収された熱量）；
5. **付随空気および熱収支クロージャ（Companion Air & Thermal Closure）**（第一原理に基づく総エネルギー収支の照合）。

これら5つの見出しのいずれか1つでも欠落させることは、簡潔な書式選択などではない。それは根本的なエンジニアリング的主張の遺漏・欠落である。（完全なエネルギー分解サンキー図、4ステップの照合表、および4つの診断障害モードについては図06を参照）。

## 見出し1：設定値および指令

データブロックの第1セクションには、保持時間（滞留時間）が開始される*前*に装置に対して発行された指令値を記録する：
- 指令有効電力負荷：例：120.0 kW（または定格容量の特定の比率：25%、50%、75%、100%、110%）。
- 二重化給電系統間の指令電力配分：例：A系統 = 60.0 kW、B系統 = 60.0 kW。
- 指令制御弁開度位置：例：TCV = 100% 全開（またはロックされたバランス調整弁の開度位置 = 4.2回転）。
- 指令付随空冷ブロワー速度：例：100%（または固定値 1200 CFM）。

指令値は、タイマーが開始される前に監視制御ログから記録されなければならない。保持時間中に観測された電力を平均化して「指令値」を後から再構成することは循環論法であり、測定結果を作為的な設定値へとすり替える行為である。

## 見出し2：初期状態ベースライン

第2セクションには、ステップ遷移の直前1分間におけるシステムの状態を記録する：
- 開始時冷媒供給温度（T_in,init）および還流温度（T_out,init）。
- 開始時体積流量（Q_v,init）およびマニホールド差圧（ΔP_init）。
- ベースライン1分間のタイムスタンプ（秒単位の開始および終了時刻）。

このベースラインは、施設側一次冷却ループ内で発生しているバックグラウンド温度ドリフトから、定常熱利得（温度上昇分）を明確に分離・切り分けるために不可欠である。

## 見出し3：配電データ

第3セクションには、ヒーターエレメントによって消費された有効電力の詳細を記録する。産業用415V三相二重化給電構成において、単一の合算された「キロワット」数値のみを報告することは不十分である。レポートは以下を提供しなければならない：
- **A系統メトリクス**：線間電圧（V_AB, V_BC, V_CA）、線電流（I_A, I_B, I_C）、A系統総有効電力（P_A）、および力率（PF_A）。
- **B系統メトリクス**：線間電圧、線電流、B系統総有効電力（P_B）、および力率（PF_B）。
- **総有効電力**：
 $$P_{\text{elec}} = P_A + P_B$$
- **相平衡の検証**：全相間の電流不平衡率は I_unbalance ≤ 2.0% を満たさなければならない。著しい電流不平衡は、1つの抵抗バンクがオープンモードで断線しているか、内部接触器の極接点が損耗（ピッチング）して完全に接触していないことを示す。

## 見出し4：水力エンタルピーデータ

第4セクションは、冷却流体による熱力学的な熱吸収量を捕捉する。これには以下の6つの物理パラメータにわたる高精度な計測が必要である：
1. **冷媒供給温度（T_in）**：コア流動領域（内径の $1/3 \sim 1/2 D$）に浸漬された4線式Pt100 RTDによって測定。
2. **冷媒還流温度（T_out）**：流体が十分に混合された後、加熱容器の下流側で測定。
3. **正味温度上昇（ΔT）**：
 $$\Delta T = T_{\text{out}} - T_{\text{in}}$$
4. **体積流量（Q_v）**：校正済みカルマン渦流量計によって測定（毎分リットル、LPM で報告）。
5. **流体の熱物理的特性**：密度（ρ）および定圧比熱（C_p）は、平均バルク流体温度において評価されなければならない：
 $$\bar{T} = \frac{T_{\text{in}} + T_{\text{out}}}{2}$$
 $\bar{T} = 40.0°C$ における標準的な25%プロピレングリコール水溶液（PG25）の場合、標準値は以下の通りである：
 $$\rho = 1025.0\,\text{kg/m}^3, \quad C_p = 3.980\,\text{kJ/(kg}\cdot\text{K)}$$
6. **推定液体熱量（Q_liquid）**：
 第一原理熱力学から直接導出される：
 $$Q_{\text{liquid}} = \dot{m} \cdot C_p \cdot \Delta T = \left( Q_v \times \frac{\rho}{60{,}000} \right) \cdot C_p \cdot (T_{\text{out}} - T_{\text{in}})$$

定格全負荷で運転される教育用基準モデル（Q_v = 176.5 LPM、ΔT = 10.04 K）の場合：
$$\dot{m} = 176.5 \times \frac{1025.0}{60{,}000} = 3.015\,\text{kg/s}$$
$$Q_{\text{liquid}} = 3.015\,\text{kg/s} \times 3.980\,\text{kJ/(kg}\cdot\text{K)} \times 10.04\,\text{K} = 120.48\,\text{kW} \times \text{分配比率} \approx 98.6\,\text{kW}$$

## 見出し5：付随空気および第一原理熱収支クロージャ

NVL72クラスのAIアーキテクチャでは、ラック総発熱量の約16%〜20%が、光トランシーバー、マザーボード電源変換回路（VRM）、およびメモリモジュールによってデータホール内の空気中へと直接排熱される。付随空気セクションはこの顕熱を正確に捉えなければならない：
- 吸気乾球空気温度（T_air,in）および排気空気温度（T_air,out）。
- ブロワー回転数および校正済みノズル差圧から導出された空気質量流量（ṁ_air）。
- 推定空気顕熱量：
 $$Q_{\text{air}} = \dot{m}_{\text{air}} \cdot C_{p,\text{air}} \cdot (T_{\text{air,out}} - T_{\text{air,in}})$$

### 第一原理エネルギー収支方程式
熱力学第一法則に従い、負荷装置に供給された有効電気エネルギーは、ラック境界から外部へ放出される総熱量に、未断熱部の寄生損失を加えたものと完全に等しくなければならない：
$$P_{\text{elec}} = Q_{\text{liquid}} + Q_{\text{air}} + Q_{\text{chassis\_loss}}$$

ここで、内部に適切なセラミックブランケット断熱材が施工されている場合、自然対流および放射による未断熱筐体表面放熱損失（$Q_chassis\_loss$）は通常、総電力の ≤ 2.0% に抑えられる。

### エンタルピークロージャ比率ゲート
速報では**エンタルピークロージャ比率（Enthalpy Closure Ratio、熱収支整合率）**を評価する：
$$\text{Closure Ratio} = \left[ 1.0 - \frac{|P_{\text{elec}} - (Q_{\text{liquid}} + Q_{\text{air}})|}{P_{\text{elec}}} \right] \times 100\%$$

ステップデータブロックにおいて**合格（PASS）**を達成するためには、エネルギー収支クロージャが以下を満たさなければならない：
$$\text{Closure Ratio} \ge 97.0\% \quad \left( \text{すなわち熱量不一致 } \le 3.0\% \right)$$

もし P_elec = 120.0 kW であるにもかかわらず、液体エンタルピー（Q_liquid = 75.0 kW）と空気熱量（Q_air = 19.0 kW）の合計がわずか 94.0 kW であった場合、クロージャ比率は 78.3% にとどまる！実に 26.0 kW もの行方不明エネルギーが存在することになる！
- この乖離を、根拠のない「効率係数」や「損失補正係数」などを付け足して誤魔化すことは絶対に認められない。
- 26 kWものエンタルピークロージャの破綻は、深刻な物理的欠陥を示している：開放されたバイパス弁を介して流体が加熱容器を迂回（ショートサーキット）しているか、流量計の校正係数（Kファクター）が誤っているか、あるいはRTDが滞留したデッドレグ（止水管）部分に設置されているかのいずれかである。
- エネルギー収支クロージャの不合格は、無条件でそのステッププラトーを不合格とする。

## 報告の階層構造：単一ラック、次にクラスタ総括

複数ラックで構成される試験クラスタを報告する際：
1. 最初に各個別ラックごとに、5つの見出しすべてと4要約統計量（$\min, \max, μ, σ$）を備えた独立したデータブロックを印刷・提示しなければならない。
2. 個別ラックブロックの直下に**クラスタ総括ブロック（Cluster Summary Block）**を取りまとめ、総有効電力、総液体エンタルピー吸収量、総空気熱量、およびクラスタ全体のエンタルピークロージャ比率を報告する。

見かけ上平穏で平衡が取れているように見えるクラスタ総括であっても、エネルギー収支クロージャに失敗した個別の不合格ラックを覆すことはできない。ラック1、2、3が平衡している裏でラック4に20kWの熱量欠損が存在する場合、ラック4は不合格である。ラック4の数値をクラスタ全体で平均化して、人為的な合成「合格」を捏造してはならない。

## 記録すべき決定事項

速報に取りまとめられるすべてのステップデータブロックについて、以下を記録すること：

- 有効電力、二重化給電配分、および調整トリム弁開度位置の指令設定値。
- ステップ投入前の初期ベースライン流体温度および空気温度。
- 三相電気の電圧、電流、力率、および総有効電力 P_elec。
- 実測流体温度、体積流量、流体密度、定圧比熱、および推定液体エンタルピー Q_liquid。
- 実測空気温度、空気流量、および推定付随空気熱量 Q_air。
- クロージャ比率が ≥ 97.0% であることを証明する、算出された第一原理エンタルピークロージャ比率。
- エネルギー収支を確認したレコーダーおよびストレンジャーのイニシャル署名。
