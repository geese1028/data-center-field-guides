# 6. プロット点の生成方法

速報のグラフ上にプロットされた1つのデータ点は、生の測定値そのものではない。また、生の測定値は任意に破棄してよい使い捨てのスクラッチファイルなどではない。

ミッションクリティカルなコミッショニングにおいて、基礎となる生の時系列データを提示できないエンジニアリンググラフは、解析ではなく単なる絵画イラストである。生のデータを破棄して1分ごとの平均値のみを保持した場合、電磁接触器のアーク放電、流量計のキャビテーション気泡（スラグ）、および通信タイムアウトを検出する能力が失われてしまう。逆に、監査人に対して1時間あたり6万点もの未集約な散布データをそのまま提示した場合、目は視覚的ノイズに埋没し、長期的な熱力学的ドリフトを見逃すことになる。

専門的な速報はその双方を保持する：高周波の未加工生サンプルを取得して改ざん不能な時系列データストアにアーカイブし、厳格で監査可能な統計的集約処理を通じて個々のプロット点を構築するのである。

（現場の物理的乱流ゆらぎと、バッファフリーズによる直線フラットライン不正の計量学的比較については図04を参照）。

## 1 Hzでの生データ取得と60秒平均値

本フィールドガイドにおけるすべての主要チャネルの標準取得レートは、**1 Hz（チャネルあたり毎秒1サンプル）**である。
- **なぜ1 Hzが要求されるのか**：1 Hzのサンプリングレートは、ヒーターステージ投入時の急峻な突入電流、片給電遮断試験中の14ミリ秒の接触器遮断開放時間、および急激な弁動作に伴う動的圧力スパイクなど、1分未満の決定的な物理現象を正確に捕捉する。10秒または30秒に1回のサンプリングは過酷なローパスフィルターとして作用し、観測者から危険な過渡現象を覆い隠してしまう。
- **60秒平均値**：速報の時系列グラフ上にプロットされる正式な各点は、**連続する60個の未加工1秒サンプルの算術平均値**を表す：
 $$\mu_t = \frac{1}{60} \sum_{i=1}^{60} x_i$$
 ここで、各点にはその60秒間インターバルの正確な開始時刻のタイムスタンプ（例：`14:22:00.000Z`）が付与される。
- **サンプル欠落規則**：当該の1分間にエッジゲートウェイまたはModbusポーラーの通信が瞬断し、60サンプルではなく52個の有効サンプルしか得られなかった場合、データブロック内でその1分間は**部分的（PARTIAL）**と記録される。「曲線を滑らかに見せる」ために、レポート生成スクリプトが前後の分の平均値をコピーしたり、線形補間を捏造したりすることは、いかなる場合も固く禁じられる。通信途絶を隠蔽した滑らかな曲線は、監査上の虚偽報告である。

## 分散ゲート：陳腐化データ不正の摘発

キャッシュされた単一の浮動小数点数値をそのまま60回複製したものは、60サンプルの平均値ではない。それは60個のタイムスタンプを貼り付けただけの1つの数値にすぎない。

配管径1.5インチ（DN39）を通り 176.5 LPM の流体が流れる乱流状態において、レイノルズ数は容易に Re ≈ 28,000 を超える。この領域の流体流動は極めて激しい乱流である。対流微小渦、境界面の渦放出、およびポンプインペラの翼通過周波数は、絶え間なく微細な熱的・圧力的なゆらぎを生み出している。
- 実際の流体中に置かれた本物の物理的浸漬型RTDは、常に非ゼロの標本分散を示す：
 $$\sigma_t^2 = \frac{1}{60} \sum_{i=1}^{60} (x_i - \mu_t)^2 > 0$$
 通常、健全な1秒周期の温度ストリームは、標準偏差 σ ≈ 0.05 K〜0.20 K（分散 σ² ≈ 0.0025〜0.0400 K²）を示す。
- **不正を示す直線フラットラインの兆候**：エッジゲートウェイの通信スレッドがロックアップした場合、あるいはADCドライバがハングアップしてRAM上の最終レジスタ値を連続してエコー出力し続けた場合、記録される数値は数学的に完全な平坦線（フラットライン）となる。5分間にわたるすべてのサンプルが、最下位ビットに至るまで正確に 45.000000°C を示す。このとき算出される標本分散は以下のようにゼロに崩壊する：
 $$\sigma_t^2 \equiv 0.000000\,\text{K}^2$$

稼働中の液冷ループにおいて、分散が完全にゼロになることは物理的にあり得ない。それは**陳腐化データ不正（Stale Data Fraud）**の決定的な動かぬ証拠（スモーキング・ガン）である。

速報の自動データ取り込みエンジンは、継続的な分散チェックを実行しなければならない：
$$\text{3分間以上連続して } \sigma_t^2 \le 1.0 \times 10^{-4}\,\text{K}^2 \text{ である場合、CHANNEL\_FROZEN\_STALE をフラグ付けする。}$$
このフラグがアサートされた場合、レポートエンジンはその1分間ブロックを拒否し、警報音を発し、適合平均値の算出を拒絶しなければならない。陳腐化したデータの繰り返しは、当該ステッププラトーを自動的に不合格とする。

## すべてのステップにおける4要約値の義務付け

速報用にステップデータブロックを取りまとめる際、単なる算術平均値のみを報告することは固く禁じられる。平均値だけでは、危険な局所的スパイクが容易に隠蔽されてしまうからである。

各ステップデータブロックは、定常保持時間中の各アクティブチャネルについて、**4つの必須統計量**を報告しなければならない：
1. **最小値（$\min$）**：保持時間中に記録された未加工1秒読み取り値の最小値。
2. **最大値（$\max$）**：保持時間中に記録された未加工1秒読み取り値の最大値。
3. **算術平均値（μ）**：すべての有効サンプルにわたる中心基準値。
4. **標本標準偏差（σ）**：物理的乱流および制御安定性の尺度。

### なぜ最大値が不可欠なのか
平均冷媒温度が 45.0°C である120kW負荷ステップを想定せよ。もしポンプが一時的にキャビテーションを起こすか、気泡が10秒間にわたってヒーター容器を通過した場合、局所的な流体温度は回復する前に 68.5°C まで急上昇した可能性がある。
- 900個のデータ点からなる15分間の平均値において、この10秒間の 68.5°C のスパイクは、平均値をわずか 0.26 K しか引き上げない——これは監査人が単なる丸め誤差として見過ごしてしまうオフセットである。
- しかし最大値を報告すれば、ピーク値が即座に白日の下に晒される：$\max = 68.5°C$。これにより、EPDMホースの許容温度限界が超過されたこと、およびキャビテーションが発生したことがエンジニアリングチームに直ちに警告される。

最大値を省略したレポートは、都合の良い平均値の背後に運用の極値を埋没させようとする不正の試みである。すべての行にこれら4つの数値を義務付けよ。

## 分岐および合計合算の数学的規則

複数の並列ラックにわたる流量および電力を合算集約する際、算術演算の規則は物理的な配管および電気トポロジーを厳格に尊重しなければならない：

- **総体積流量**：個々の各分岐渦流量計の合計から厳格に計算されなければならない：
 $$Q_{\text{total}} = \sum_{k=1}^N Q_{\text{branch},k}$$
 メインヘッダーの超音波流量計の測定値と個々の分岐流量計の測定値を二重に合算して、ループが2倍の流体を循環させたと主張してはならない！
- **流量計欠落規則**：ラック3の流量計が故障するか通信途絶した場合、Q_total は不完全となる。速報には*「総流量：不完全（ラック3の計器オフライン）」*と報告しなければならない。自動スクリプトがラック1、2、4の平均値を用いてラック3の流量を推定・補間することは断じて許されない！合計値の中に推定数値を混入させることは、エンジニアリング上のデータ捏造である。
- **総有効電力**：各分岐給電線の個別相電力から計算されなければならない：
 $$P_{\text{total}} = \sum_{k=1}^N \left( P_{A,k} + P_{B,k} \right)$$
 上流側受電変電所の変圧器電力の測定値をそのまま報告して、負荷装置の熱負荷と称してはならない。上流の変圧器電力には、配線ケーブル損失、照明電力、および液冷負荷装置とは無関係な補助チラーポンプ電力などが含まれている。

## 動的ステップ遷移の注記

急激なステップ変化および過負荷シナリオにおいて、時系列グラフには指令が発せられた正確な秒を明示的に注記しなければならない：
- 垂直の赤色破線マーカーによって t_command（指令時刻）を示さなければならない。
- 垂直の青色マーカーによって、流体温度および電力が新たな定常プラトーに達した t_settled（整定時刻）を示さなければならない。
- グラフの注記ラベルには、観測された立ち上がり時間（Δt_rise）およびピーク過渡圧力パルス（ΔP_surge）を明記しなければならない。

注記のないグラフ上のスパイクは、懐疑的な人間からは致命的な障害と解釈され、楽観的な人間からは優れた運用の特徴と解釈されてしまう。主観的な神学論争を防ぐ唯一の手段は、正確にラベル付けされたタイムスタンプである。

## 記録すべき決定事項

速報の計測・計量セクションにおいて、以下の事項を記録すること：

- エッジデータロガーの検証済み 1 Hz サンプリング周波数、および改ざん不能な生CSVアーカイブの保存先。
- 定常保持時間中のすべてのチャネルについて算出された標本分散（σ²）、および σ² > 0 であることの証明。
- 各負荷ステップにおけるすべての監視パラメータに対する4要約値テーブル（最小値、最大値、平均値、標準偏差）。
- 総流量の合算に含まれる分岐流量計の認証済み一覧。
- すべてのステップ指令遷移および遮断器トリップに対する注記付きの正確なタイムスタンプ。
