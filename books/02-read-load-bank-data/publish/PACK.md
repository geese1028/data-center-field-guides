## Description

A load-bank test is not valid because the curve looks calm. This field guide tells you how to turn a run into a flash report a stranger can audit.

The report opens with five lines: pretest, gradient, overload, step change, and single-feed fault. Overall pass requires every line you attempted. Not run is not a pass. The book covers the preparation block, the pretest cells, consistency, how a plotted point is made from raw samples, the data block on every step, and the sentence you are allowed to write.

It also covers the automatic charts, the hop from sensor to Modbus poll to MQTT message, and what an online hit from FLOC or Focus is allowed to mean. A hit is a time. CPOP waits until the file is closed. None of them write pass.

Flow, temperature, and pressure limits stay on your sheet, cited to the document then in force. This book does not paste a datasheet, a register map, or a site record.

Read the first book before this one if the prototype has not been accepted. The next book runs the load-bank test and leaves seven sheets. This one stops at the file.
