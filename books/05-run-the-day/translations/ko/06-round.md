영어판을 AI 보조로 번역한 것이다.

# 6. 교대 순회 점검

텔레메트리 대시보드는 거짓말을 한다. 빌딩 관리 시스템(BMS)의 압력 변환기는 교정 드리프트가 발생할 수 있다. 광전식 연기 감지기는 먼지가 쌓여도 정상 신호를 보낼 수 있다. 측온저항체(RTD) 온도 센서는 상한값으로 튄 채 잘못된 소프트웨어 필터에 의해 고정될 수 있다.

물리적인 교대 순회 점검은 데이터센터의 물리적 현실이 제어실의 수학적 모델과 일치하는지 확인하는 최후의 검증 수단이다.

```
+-----------------------------------------------------------------------------+
| 교대 순회 물리 점검 토폴로지 |
| |
| [STATION 1] 특고압 수배전반실 (35kV/10kV SF6 가스, 스프링, 계전기) |
| | |
| [STATION 2] 변압기실 (권선 온도, 전자기 웅웅 소음, 단자대) |
| | |
| [STATION 3] UPS 및 축전지실 (DC 부동 전압, 셀 온도, 수소 배기) |
| | |
| [STATION 4] 중앙 냉동기 플랜트 (어프로치 온도, 유압, 냉수 펌프 차압) |
| | |
| [STATION 5] 액체 냉각 CDU 스테이션 (0.15-0.90 MPa, 굴절계, 드레인 팬 건조) |
| | |
| [STATION 6] AI 화이트스페이스·NVL72 랙 (열화상 IR, 바닥 차압, FD83 커플링) |
+-----------------------------------------------------------------------------+
```

![Shift Round Inspection Topology](../figures/fig-03-shift-round-inspection-topology.png)

순회 점검을 도는 기술자는 클립보드에 체크나 하는 심부름꾼이 아니다. 순회 중인 기술자는 그 자체로 살아 움직이는 정밀 다중 감각 진단 기기다.

## 다중 감각 점검 규율

운영 중인 데이터센터의 모든 구역은 네 가지 감각 채널을 통해 점검되어야 한다:
1. **시각**: 물방울, 얼룩, 변색, 녹, 볼트 풀림, 커패시터 부풀어 오름, 과열을 나타내는 페인트 들뜸이나 그을림을 살피고, 아날로그 기계식 게이지 바늘과 디지털 원격 수치를 대조한다.
2. **청각**: 펌프 케이싱 내부의 캐비테이션 소음(자갈을 퍼 올리는 듯한 소리), 변압기 철심 이완이나 포화로 인한 웅웅거리는 전자기 소음, 팬 모터 베어링 비명음, 컨테인먼트 도어 틈새의 휘파람 소리를 포착한다.
3. **열감각 (적외선)**: 교정된 휴대용 적외선(IR) 카메라로 모선 접속부, 차단기 단자, 케이블 러그, 기계 베어링을 훑는다. 70°C를 초과하거나 상간 온도차 ΔT > 10 K를 보이는 연결부는 즉시 1등급 중대 결함이다.
4. **후각**: 타는 듯한 전기 절연재 냄새(오존 및 과열된 페놀 수지 냄새), 미세 누출된 프로필렌 글리콜 증기의 달착지근한 냄새, 열화된 납축전지에서 방출되는 황 냄새(계란 썩는 냄새)를 맡는다.

## 6대 핵심 점검 스테이션

OpenViking 운영 표준(`ALZJ-YW-2.6XZ02`: IT 화이트스페이스, `ALZJ-YW-2.6XZ10`: 액체 냉각 인프라)에 따라 순회 점검은 6개 필수 스테이션을 통과한다:

```
+-----------------------------------------------------------------------------+
| 핵심 스테이션 점검 판정 기준 |
| |
| 스테이션 / 설비 표준 운전 매개변수 불합격·결함 판정 기준 |
| ----------------------- ------------------------ ---------------------- |
| 특고압 수배전반 SF6 가스 압력 정상 저압 경보 및 트립 범위 |
| 수전 변압기 권선 온도 < 90°C 온도 >= 110°C (경보) |
| UPS 축전지실 실온 20°C ~ 25°C 온도 > 28°C / 외관 팽창 |
| 냉동기 플랜트 응축기 어프로치 < 1.5K 어프로치 >= 2.5K |
| CDU 2차 냉각 루프 압력 0.15 ~ 0.90 MPa 압력 < 0.12 MPa |
| CDU 글리콜 농도 25.0 wt% PG (±1.0%) PG < 23% 또는 > 27% |
| IT 화이트스페이스 바닥 차압 >= 5.0 Pa 차압 < 2.5 Pa (풍량부족)|
| 액체 냉각 랙 (NVL72) FD83/UQD 커플링 완전건조 육안상 액체 방울 존재 |
+-----------------------------------------------------------------------------+
```

![CDU Shift Inspection Checklist](../figures/fig-05-liquid-cdu-shift-inspection-checklist.png)

### 스테이션 1: 특고압 수배전반실
- 35kV 및 10kV 진공/가스 차단기의 스프링 충전 표시기가 "충전 완료" 상태인지 확인한다.
- 가스절연개폐장치(GIS)의 SF6 가스 압력계가 녹색 정상 범위에 안착해 있는지 점검한다.
- DC 제어 모선 축전지 충전 전압(125 VDC ± 2%)을 확인하고, 비접지 DC 제어 계통에 지락 경보가 전혀 없는지 확인한다.

### 스테이션 2: 변압기실
- 몰드형 변압기의 디지털 권선 온도 표시기를 확인한다(정상 범위: $60°\text{C} \sim 85°\text{C}$, 경보 임계값: 110°C, 자동 트립: 130°C).
- 강제 냉각 팬의 흡입 장애 여부와 베어링 진동을 점검한다.
- 유입식 변압기의 경우 유면계 수위, 실리카겔 흡습 호흡기 색상(진한 파란색이어야 하며, 핑크색은 습기 포화를 의미하므로 즉시 교체 필요), 탱크 용접부의 유류 누유를 확인한다.

### 스테이션 3: UPS 및 축전지실
- 모든 정지형 UPS 모듈의 DC 모선 부동 충전 전압과 충전 전류를 기록한다.
- 축전지실 환경 온도를 점검한다($20°\text{C} \sim 25°\text{C}$를 엄격히 유지. 납축전지는 25°C 이상에서 8 K 상승할 때마다 설계 수명이 50% 단축된다).
- 밸브조절식 납축전지(VRLA)의 외관 배부름, 단자 부식, 전해액 누출을 육안 점검한다. 리튬이온 축전지의 경우 BMS가 셀 간 전압 불평형(> 50 mV)이 없음을 보고하는지 확인한다.
- 수소 배기 팬 흡입구에서 공기 흐름을 손으로 느껴 배기 동작을 확인한다.

### 스테이션 4: 중앙 냉동기 및 펌프실
- 냉동기 운전 로그 확인: 응축기 어프로치 온도가 ≤ 1.5 K인지 확인한다(ΔT_approach = T_cond, leaving - T_tower, entering). 2.5 K를 초과하는 어프로치 온도는 전열관 오염이나 스케일링을 나타내며 화학 세정이 필요하다.
- 압축기 유면, 유압, 유류 회수 온도를 점검한다.
- 냉수 펌프 차압(ΔP)을 확인하고 2차측 인버터(VFD)가 헌팅 없이 부드럽게 변속되는지 확인한다.

### 스테이션 5: 2차 냉각 분배 장치 (CDU)
OpenViking `ALZJ-YW-2.6XZ10`에 따라 CDU는 AI 고밀도 클러스터의 기계적 심장부다:
- **압력 범위**: 1차 시설수(FWS) 공급 압력과 2차 기술냉각수(TCS) 공급 압력이 $0.15 \text{MPa} \sim 0.90 \text{MPa}$ 사이에 엄격히 유지되는지 확인한다. 펌프 차압이 < 1.0 bar인지 확인한다.
- **열교환 성능**: 판형 열교환기 어프로치 온도(ΔT_approach = T_TCS, supply - T_FWS, supply)가 8.0 K를 초과하지 않는지 확인한다. 8.0 K 초과는 플레이트 표면의 이물질 막힘이나 생물학적 오염을 의미한다.
- **유체 화학 특성**: 교정된 광학 굴절계로 2차 냉각수를 측정한다. 프로필렌 글리콜 농도는 정확히 **중량비 25.0%**(± 1.0%)여야 한다(동결 방지 -11.5°C, 동파 방지 -22.0°C). 전도도는 < 10 μ S/ cm, pH는 7.5~9.0 범위를 유지해야 한다.
- **물리적 건전성**: 내부 CDU 드레인 팬과 바닥 프레임에 습기가 없는지 확인한다. 연속 로프형 누수 감지 센서가 완벽히 건조하고 바닥에 밀착 배치되어 있는지 점검한다. 팽창 탱크의 질소 봉입 압력을 확인한다(P_0 = P_fill - 0.2 bar).

### 스테이션 6: AI 화이트스페이스 및 NVL72 랙
OpenViking `ALZJ-YW-2.6XZ02`에 의거:
- **전력 분전**: 원격 전원 패널(RPP)과 PDU를 점검한다. 적외선 카메라로 차단기 및 러그를 훑어 단자 풀림을 감지한다.
- **기류 제어**: 콜드 아일 또는 핫 아일 차폐(컨테인먼트)를 점검한다. 이중바닥 하부 또는 차폐벽 전후의 차압이 ≥ 5.0 Pa를 유지하는지 확인한다. 빈 랙 유닛에 블랭킹 패널이 빈틈없이 장착되어 있는지 점검한다(1U 누락 시 초당 25리터의 냉기가 바이패스되어 국소 핫스팟을 유발한다).
- **액체 냉각 매니폴드 및 커플링**: 랙 수직 분배 매니폴드를 점검한다. 컴퓨팅 트레이 및 NVLink 스위치 트레이에 연결되는 모든 퀵 디스커넥트 커플링(Danfoss FD83 또는 UQD)을 점검한다. 유체 스며듦, 결정화, 물방울 맺힘은 즉각적인 트레이 격리를 요하는 작업 중지 조건이다. 매니폴드 하단 드레인 트레이가 깨끗하고 건조한지 확인한다.

## 방을 나가기 전 즉시 결함 등록 원칙

순회 중 결함을 발견했다면 **그 방을 떠나기 전에** 현장 설비관리시스템(CMMS)이나 물리적 결함 등록부에 기록해야 한다.

개인 스마트폰으로 사진을 찍어 두고 교대 종료 후에 기록하겠다는 생각은 절대 용납되지 않는다:
- 대장에 등록된 결함은 물리적 타임스탬프, 설비 자산 ID, 우선순위 등급, 지정된 담당자를 갖는다.
- 스마트폰 속 사진은 30분 뒤 다른 경보가 울렸을 때 잊혀질 사적 메모에 불과하다.

발견된 결함이 설비 이중화를 훼손하거나 매개변수가 SLA 임계값을 벗어나게 한다면 순회 점검을 즉시 중단하고 무전으로 당직 관리자에게 보고하며 현장에서 즉시 장애 티켓을 발행하라. 점심을 먹으면서 "아까 보니 CDU 펌프에서 물이 새더라"고 뒤늦게 말하는 운전원은 실격이다.

## 기록할 결정

- 시작 및 완료 타임스탬프와 순회 기술자 서명이 포함된 물리 점검 경로 완주 기록.
- 6대 점검 스테이션 모두에서 기록된 구체적 실측 운전 매개변수.
- 2차 냉각 루프에 대해 현장 굴절계로 측정한 글리콜 농도, 전도도, pH 측정값.
- 각 방을 나서기 전에 공식 현장 대장에 등록된 결함 내역 또는 "결함 없음"의 명시적 확인.
