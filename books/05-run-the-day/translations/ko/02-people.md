영어판을 AI 보조로 번역한 것이다.

# 2. 교대근무 인원

데이터센터는 원격 소프트웨어 텔레메트리만으로 돌아가지 않는다. 플랜트 바닥을 직접 걷는 엔지니어들의 역량, 법적 자격증, 물리적 규율로 돌아간다. 마스터키를 쥐고 있는 사람들의 정확한 자격을 모른다면 당신은 플랜트를 통제하고 있지 못한 것이다.

```
+-----------------------------------------------------------------------------+
| 교대 자격 요건 및 작업 권한 매트릭스 |
| |
| 역할 필수 자격증 승인된 작업 범위 |
| ------------------ ---------------------------- ----------------------- |
| 당직 관리자 CDFOM / 설비총괄운영 자격 전체 SLA 관리, 허가 발효 |
| 수석 전기기사 특고압/고압/저압 전기면허 수배전반, 변압기, 전력선 |
| 냉동공조 전문가 공조냉동기계 / 냉매취급자격 냉동기, CDU, 글리콜 관리 |
| 교대 엔지니어 데이터센터 설비운영 자격 순회 점검, 계측, 로그 기록|
| 안전/에스코트 담당 산업안전 / 응급처치 / 심폐 업체 감독, LOTO 입회 |
+-----------------------------------------------------------------------------+
```

## 법적 면허 및 법정 자격 요건

메가와트급 액체 냉각과 수십 메가볼트암페어의 특고압 변전소를 갖춘 고밀도 AI 데이터센터에서 전문 지식이 없는 일반 시설 관리자는 치명적인 위험 요소다. 현장 운영 작업에는 법정 면허가 필수적이다:
- **전기 작업**: 특고압(10kV/35kV 등) 또는 저압(400V/480V) 수배전반의 절체, 차단기 인입/인출(Racking), 활선 근접 시험은 유효한 국가 공인 전기 자격증을 보유한 전기 기술자만이 독점적으로 수행해야 한다.
- **냉각 및 화학 작업**: 터보 냉동기, 산업용 냉각탑, 1차/2차 펌프 스테이션 운영은 압력 냉매 취급 및 산업용 수처리 인증을 보유한 자격 있는 공조냉동 기술자가 담당해야 한다.

OpenViking 운영 지침(`ALZJ-YW-2.6XZ10`)에 따라, 2차 냉각 분배 장치(CDU), 1차 시설수 계통(FWS), 랙 레벨 매니폴드를 다루는 액체 냉각 작업은 살균제, 글리콜 농도 측정, 누출 격리 프로토콜에 대한 정식 교육 이수를 필수로 한다.

교대 인원 중 고압 절체 작업에 필요한 법정 면허가 없는 기술자의 이름은 전기 절체 작업표에 기재될 수 없다. 무자격 외주업체가 배전반 도어를 열고 있는 것이 발견되면 즉시 작업을 중지시켜라.

## 2인 1조 원칙 (Two-Person Rule)

어떠한 중요 전기 절체 작업, 고압 차단기 인출, 1차 냉각 루프의 밸브 격리 작업도 단독으로 수행되어서는 안 된다.

2인 1조 원칙은 다음을 요구한다:
1. **작업 수행자(The Performer)**: 승인된 작업절차서(MOP)를 쥐고 조작 스위치, 차단기 핸들, 격리 밸브를 물리적으로 직접 조작하는 유자격 기술자.
2. **작업 확인자(The Checker)**: 수행자 바로 뒤에 서서 인쇄된 절차서를 쥐고 각 단계를 큰 소리로 복창하며, 장비 명판 태그(예: 차단기 조작 전 명판 `SWG-01-4A`가 작업표와 일치하는지 확인)를 지적 확인하고, 비상정지 대기 상태를 유지하는 동등한 자격을 갖춘 기술자.

확인자의 유일한 임무는 검증과 안전 확보다. 수행자가 잘못된 차단기 핸들로 손을 뻗거나 잘못된 순서로 밸브를 돌리려 할 경우, 확인자는 작업을 즉시 중단시킬 절대적인 권한을 갖는다.

```
+-------------------------------------------------------------------------+
| 2인 1조 원칙 |
| |
| +------------------+ +------------------+ |
| | 작 업 확 인 자 | | 작 업 수 행 자 | |
| | MOP 절차서 소지 | | 스위치에 접촉 | |
| | 절차를 소리내 복창| ----------> | 명판 라벨 지적 | |
| | 태그 ID 일치 확인 | | 조작 동작 실행 | |
| | 즉각 중지 권한 보유| | 상태 보고 | |
| +------------------+ +------------------+ |
+-------------------------------------------------------------------------+
```

## 작업 중지 권한 (Stop Work Authority: SWA)

상급 운영 디렉터부터 견습 케이블 포설공에 이르기까지 시설에 들어오는 모든 개인은 완전하고 무조건적인 작업 중지 권한(SWA)을 갖는다.

다음과 같은 상황에서는 예외 없이 작업 중지 권한이 발동되어야 한다:
- 현장의 물리적 조건이 서면 MOP의 전제 조건과 다를 때.
- 빌딩 관리 시스템(BMS)이나 전력 모니터링 시스템(EPMS)에서 예상치 못한 경보가 울릴 때.
- 전기 장비 근처에서 물방울, 고인 액체, 비정상적인 화학 냄새가 감지될 때.
- 필수 안전 방호벽, 개인 보호구(PPE), 또는 잠금/표지(LOTO) 자물쇠가 누락되거나 훼손되었을 때.
- 작업자가 다음 절차 단계에 대해 혼란이나 의문을 느낄 때.

작업 중지가 발동되면:
1. 장비를 절차서에 정의된 가장 가까운 안정적이고 안전한 상태로 즉시 전환한다.
2. 공구를 내려놓고 더 이상의 밸브나 스위치를 조작하지 않는다.
3. 당직 관리자를 작업 현장으로 호출한다.
4. 불확실성이 완전히 해소되고 허가서에 서면으로 기록된 후에만 작업을 재개한다.

선의로 작업 중지를 발동한 기술자나 계약자에게 불이익을 주거나 질책하거나 추궁해서는 안 된다. 일정 압박 때문에 작업자가 작업 중지 호출을 주저하는 시설은 수십 메가와트 규모의 대정전을 기다리고 있는 시설이다.

## 30분 합동 현장 점검

제어실 책상 뒤에 앉아 커피를 마시며 교대 인수인계를 진행하지 마라. 현장을 확인하지 않는 인수인계는 직무 유기다.

인계 관리자와 인수 관리자는 당일 시트에 서명하기 전에 반드시 시설의 6대 핵심 구역을 30분간 함께 물리적으로 걸으며 합동 점검해야 한다:
1. **특고압 수배전반실**: 35kV/10kV 차단기, 차단기 스프링 충전 표시기, SF6 가스 압력계, DC 제어 전원 배터리 충전기 상태를 점검한다.
2. **변압기실**: 몰드형/유입식 변압기 권선 온도(T < 90°C 유지 확인), 강제 냉각 팬 작동 상태, 비정상적인 전자음 및 고조파 소음을 청취한다.
3. **UPS 및 축전지실**: DC 모선 부동 충전 전압, 개별 셀 온도(T < 25°C), 배터리 단자 부식 및 외관 배부름, 수소 배기 팬의 공기 흐름을 점검한다.
4. **중앙 냉동기 및 펌프실**: 응축기 어프로치 온도(ΔT_approach ≤ 1.5 K), 응축 압력, 인버터(VFD) 주파수, 이상 진동을 확인한다.
5. **CDU 액체 냉각 스테이션**: 1차/2차 계통 압력($0.15 \sim 0.90 \text{MPa}$), 펌프 차압(ΔP < 1.0 bar), 팽창 탱크 수위, 드레인 팬 내부 누수 여부를 점검한다.
6. **AI 화이트스페이스 홀**: 핫 아일과 콜드 아일을 걷고, PDU의 열적 핫스팟, 바닥 차압(ΔP ≥ 5 Pa), 퀵 디스커넥트 커플링(FD83/UQD) 누설 여부를 확인한다.

두 관리자는 반드시 전 경로를 나란히 함께 걸어야 한다. 인계 관리자가 현장 점검 동행을 거부할 경우, 인수 관리자는 모든 설비가 미검증 상태인 것으로 간주하고 인수인계 로그에 거부 사실을 기록하라.

## 기록할 결정

- 당직 인원 전원의 이름, 공인 면허 번호 및 유효 기간.
- 고압 전기 및 중요 유체 작업에서 2인 1조 원칙 준수 확인.
- 교대 중 발생한 작업 중지 권한(SWA) 발동 내역, 원인 및 해결 결과.
- 인계 및 인수 관리자 양측이 서명한 30분 합동 물리적 점검 완료 기록.
