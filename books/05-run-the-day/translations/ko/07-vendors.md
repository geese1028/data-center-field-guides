영어판을 AI 보조로 번역한 것이다.

# 7. 외주업체와 계약자

데이터센터 내부에서 작업하는 외주업체나 설비 제조사 서비스 엔지니어는 당신의 법적 작업허가서 아래에서 움직이는 "한 쌍의 손"이다. 그들은 전기실에 감독 없이 홀로 남겨두어도 되는 자율적인 존재가 아니다.

| **외주업체 통제 게이트웨이** |
| :--- |
| [GATE 1] 입문 전 작업 범위 정의: 대상 장비, 승인된 MOP, 공구 등록 |
| ↓ |
| [GATE 2] 보안 및 안전 브리핑: 출입증 발급, LOTO 검증, PPE 점검 |
| ↓ |
| [GATE 3] 전담 에스코트: 유자격 사내 기술자 상시 동행, 단독 행동 엄금 |
| ↓ |
| [GATE 4] 작업 경계 준수: MOP 절차를 벗어나는 즉시 작업 중지(SWA) 발동 |
| ↓ |
| [GATE 5] 기술적 검수 완료: 물리 점검, 철거 부품 회수, 작업장 정리 정돈 |
| ↓ |
| [GATE 6] 상업적 완료와의 분리: 현장 기술 확인 서명 != 세금계산서 청구 승인 |

방문증에 서명하고 축전지실을 손으로 가리킨 뒤 자기 사무실로 돌아가는 관리자는 설비 통제를 포기한 것이다. 그 외주업체 직원이 480V 모선에 라챗 렌치를 떨어뜨리거나 엉뚱한 밸브를 열어버렸을 때, 발생하는 장애의 책임은 업체가 아니라 관리자에게 있다.

## 입문 전 명확한 작업 범위 정의

외주업체가 보안 게이트를 통과하기 전에 그들의 작업 범위는 서면으로 모호함 없이 정의되어야 한다:
- 만질 수 있도록 허용된 정확한 설비 태그(예: *"터보 냉동기 CH-02 압축기 오일 필터 어셈블리만"*).
- 접촉이 엄격히 금지된 설비(예: *"냉각수 격리 밸브 및 인접한 냉동기 CH-01 제어반은 일체 접촉 금지"*).
- "완료"의 정의: 설비가 수리 완료되었다고 인정하기 위해 검증해야 할 구체적인 물리 시험, 압력 수치, 또는 운전 마일스톤.
- 퇴청 전 제출물: 공장 서비스 보고서, 교정된 공구 계측 로그, 설치된 모든 교체 부품의 일련번호, 원인 분석을 위해 제출해야 할 모든 고장 부품 실물.

*"UPS 시스템 연간 정기 유지보수"*라고만 적힌 외주업체 작업지시서는 재앙으로의 초대장이다. 경계도, 시험 한계도, 운영상 제약도 명시되어 있지 않다. 작업 72시간 전까지 단계별 상세 MOP가 제출되지 않는다면 방문 일정을 취소하라.

## 전담 사내 에스코트 (Site Host)

중요 전기실, 기계실, 또는 서버 홀 내에서 작업하는 모든 외주업체에는 교대 근무조에서 선발된 자격 있는 전담 사내 기술자(에스코트)가 반드시 밀착 동행해야 한다.

사내 에스코트는 외주업체의 육체 노동을 대신해 주는 사람이 아니다. 에스코트의 임무는 다음과 같다:
1. **작업 경계 감시 및 강제**: 외주업체 엔지니어의 행동을 상시 관찰한다. 엔지니어가 인접한 배전반 칸으로 손을 뻗거나 MOP에 없는 밸브를 돌리려 하면 에스코트는 즉각 작업 중지(Stop Work)를 명령한다.
2. **비상 대응**: 아크 플래시, 화학약품 튐, 설비 트립이 발생할 경우 에스코트는 현장 비상대응절차(EOP)를 가동하고, 구급대를 호출하며, 안전 격리를 지휘한다.
3. **동선 통제**: 외주업체가 승인된 물리적 작업 범위 내에 머물도록 통제하며, 운영 중인 서버 통로를 감독 없이 배회하지 못하도록 차단한다.

### "오신 김에 이것도"식 무단 작업 확대의 근절

데이터센터 운영에서 가장 위험한 말은 외주업체 엔지니어가 던지는 다음 한마디다:
> *"패널 커버를 연 김에, 이 지락 계전기 감도 설정도 온 김에 손봐 드릴까요?"*

이 제안에 대한 답은 예외 없이 단호한 **"아니오(No)"**다.

설비가 열려 있는 김에 발견된 유용한 추가 작업은 친절한 호의가 아니다. 사전 검토도 승인도 없는 무단 엔지니어링 변경이다:
- 승인된 MOP가 없다.
- 변경자문위원회(CAB) 위험 평가를 거치지 않았다.
- 계산된 원상복구 계획이 없다.
- 제어실에 비정상 운전 상태로 등록되지 않았다.

작업 중 예상치 못한 결함이나 권장 조정 사항이 발견되었다면 현장 결함 대장에 그 내용을 기록하라. 그 항목은 향후 별도의 작업허가 아래 공식 유지보수 윈도우에서 정식으로 계획, 검토, 실행될 것이다. 가동 중인 시설에서 자발적인 작업 확대를 절대 허용하지 마라.

## 기술적 인수 vs. 상업적 대금 지급 승인의 분리

외주업체의 청구 마감 일정 때문에 기술적 인수를 타협해서는 안 된다.

기술적 인수란 설비가 완전한 운영 성능을 회복했음을 입증하는 엄격한 엔지니어링 검증이다:
- 설비가 실부하 하에서 비정상 진동, 온도 일탈, 유체 누출 없이 정상 운전되는가.
- 설비와 중앙 BMS/EPMS 간의 디지털 통신(Modbus, BACnet, SNMP)이 복구되고 검증되었는가.
- 작업 구역이 청소되고 모든 쓰레기, 케이블 타이 찌꺼기, 전선 피복이 전량 수거되었으며 모든 커버, 보호 덮개, 안전 인터록이 재장착되었는가.
- 교체된 낡고 결함 있는 부품들(소손된 접촉기, 마모된 메커니컬 씰, 열화된 커패시터)에 태그가 부착되고 상자에 담겨 정밀 분석을 위한 격리 창고로 이관되었는가.

외주업체 퇴청 시 당신이 서명하는 서류는 오직 **"현장 수행 작업 확인서"**일 뿐이다.

이는 청구서에 대한 상업적 수락을 의미하지 않으며, 추후 잠재 결함이 드러났을 때 시설 소유자가 하자 보증을 청구할 권리를 포기하는 것도 아니다. 실부하 검증이 완료되기 전에 상업적 완료 확인서 서명을 요구받는다면 시트에 다음과 같이 단서를 적어라: *"육안상 작업 수행 확인 완료. 기능적 기술 인수는 24시간 실부하 연속 운전 후 판정."*

## 기록할 결정

- 사전 승인된 외주업체 작업 범위 및 첨부된 MOP 등록 번호.
- 외주업체에 지정된 전담 교대 사내 에스코트 엔지니어 성명.
- 작업 경계 준수 확인: 서면 MOP로부터의 일탈 없음 확인 또는 작업 중지 명령 기록.
- 현장 물리 점검 및 실부하 운전 검증 후에만 서명된 기술 인수 서명.
- 설치된 부품의 일련번호 및 수거된 불량 부품의 격리 보관 위치.

## 물리적 책임 분계(Demarcation) 및 정량적 교대 감사 프로토콜

교대 운영 관리자는 설비의 물리적 경계(Ring 1: 수전·외곽, Ring 2: 중앙 열원·특고압 변전, Ring 3: 홀 배전·2차 CDU, Ring 4: 고객 랙 내부)에서 책임 분계점(`DEMARC`)을 엄격히 유지하고, 다음의 정량적 감사 기준을 일일 시트(Day Sheet)에 기록해야 한다.

| 교대 감사 영역 | 감시·계측 파라미터 | 정상 운영 엔벨로프 | 즉시 개입·작업 중지(Stop Work) 임계값 |
| :--- | :--- | :--- | :--- |
| **2N 수배전 계통 부하율 상한** | 버스 A / 버스 B 정상 부하율 ($P_{\text{bus}} / P_{\text{rated}}$) | $\le 45.0\%$ (단일 계통 상실 시 $\le 90.0\%$) | $> 45.0\%$ 상태에서 신규 랙 통전 요청 즉시 거부 |
| **2차 냉각 루프(CDU) 수리·화학** | 공급 압력 $P_{\text{sup}}$, 접근 온도 $\Delta T_{\text{PHE}}$, PG 농도 | $0.15\sim 0.90\,\text{MPa}$, $\Delta T_{\text{PHE}} \le 8.0\,\text{K}$, PG $25.0\% \pm 1.0\%$ | 차압 $> 1.0\,\text{bar}$, 전도도 $> 10\,\mu\text{S/cm}$ 또는 커플러 누수 |
| **작업 허가(PTW) 및 제로 에너지 검증** | LOTO 시건, 잔류 전하 방전, 바이패스 밸브 폐쇄 확인 | 100% 현장 호스트 동행·만료 시각 전 완전 복구 | 승인된 MOP 이탈 또는 '겸사겸사 작업' 즉시 중지 |
| **인시던트 시계 및 SLA 통지** | 이벤트 감지($T_0$), EOP 안전 상태 확립, 고객 1차 통지 | P1: $T_0 + 15\,\text{min}$ 이내 물리적 사실만 통지 | 미확인 추측(가설)의 통지문 포함 절대 금지 |
