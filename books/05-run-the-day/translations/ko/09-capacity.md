# 9. 숫자를 지어내지 않는 용량 관리

시설 관리자의 일일 용량 관리 책무는 다음 세 가지 근본적인 질문에 의해 지배된다:
1. 계약상 고객에게 얼마의 용량을 판매했는가?
2. 바로 지금 이 순간, 물리적으로 얼마의 용량이 사용되고 있는가?
3. 가장 큰 단일 부품이 지금 당장 고장 난다면 얼마의 용량이 살아남는가?

## 2N 이중화의 수학: 45% 규칙

데이터센터 관리에서 가장 널리 퍼져 있고 치명적인 신화는 2N 이중화 전력 아키텍처에서 각 전력 경로를 정격 용량의 **50%까지** 안전하게 운전할 수 있다는 믿음이다.

이것은 업계 전반에서 수십 메가와트 규모의 연쇄 셧다운을 불러온 수학적 함정이다:

$$P_{\text{total}} = P_{\text{Bus A}} + P_{\text{Bus B}}$$

정격 2000 kVA의 2N 배전 모선을 생각해보자. 운영 관리자는 A 모선이 1040 kVA(부하율 52%), B 모선이 1020 kVA(부하율 51%)를 담당하고 있는 것을 보고, 두 모선 모두 과부하가 아니므로 안전 마진 내에서 편안하게 가동 중이라고 판단했다.

이때 A 모선에 전원을 공급하는 상류 변압기가 트립되었다.
수 밀리초 만에 A 모선에 연결되어 있던 모든 이중 전원 IT 서버 파워서플라이가 전기 부하를 B 모선으로 완전히 전환시킨다.

B 모선에 가해지는 순간 총 부하는 다음과 같다:

$$P_{\text{Bus B, transient}} = 1040\,\text{kVA} + 1020\,\text{kVA} = 2060\,\text{kVA} \quad (\text{정격 용량의 } 103\%)$$

B 모선은 즉시 과부하 상태에 빠진다. B 모선의 주 차단기는 지속적인 과전류를 감지하고 설정된 한시 트립 곡선에 따라 차단 동작을 수행하여 데이터 홀 전체를 완전한 암전 속으로 몰아넣는다. 완벽한 2N 무중단 내고장성을 갖추도록 설계된 시설이 단 하나의 부품 고장으로 100% 전면 블랙아웃을 겪은 것이다.

이러한 연쇄 트립을 방지하기 위해 모든 2N 전력 배전 경로는 **"45% 부하 규칙"**을 엄격히 준수해야 한다:

$$P_{\text{steady-state}} \le 0.45  \times P_{\text{rated}}$$

45% 규칙 하에서는:
- A 모선 평상시 부하 ≤ 45% (900 kVA).
- B 모선 평상시 부하 ≤ 45% (900 kVA).
- A 모선이 트립되면 살아남은 B 모선이 인수하는 총 부하는 900 + 900 = 1800 kVA (정격의 90%).
- B 모선은 10%의 안전 마진을 유지하며 열동전자 트립 임계값 훨씬 아래에서 안정적으로 가동되어 기술자들이 사태를 안전하게 수습할 여유를 제공한다.

2N 모선의 평상시 부하가 45%를 초과하도록 방치하는 교대 관리자는 시설의 이중화를 파괴하고 정격 밖의 고위험 상태로 시설을 몰아넣고 있는 것이다.

## 2차 냉각 루프의 수력 용량

랙당 최대 132 kW를 소비하는 NVIDIA NVL72 아키텍처와 같은 고밀도 컴퓨팅 랙을 수용하는 액체 냉각 화이트스페이스에서는 수력 용량 관리가 전기 용량 관리만큼이나 필수적이다:

**CDU 수력 용량 상한선**

| 매개변수 설계 정격 한계 운영 이중 | 화 한계 |  |
| :--- | :--- | :--- |
| 총 열 제거 용량 CDU당 1200 | kW <= 1000 kW (PHE 정격의 8 | 3%) |
| 2차측 유량 1440 LPM (24 | LPS) <= 1200 LPM (단일 펌프 | N) |
| 공급 온도 25.0°C ~ 32.0 | °C (W3/W4) <= 30.0°C (최대 | 외기온 시) |
| 펌프 구성 N+1 듀얼 VFD 펌프 | 1대 운전 / 1대 자동 대기 |  |
| 루프 압력 0.15 ~ 0.90 M | Pa 배관 압력 강하 < 1.0 bar |  |

고객으로부터 고밀도 액체 냉각 랙 증설 요청을 받았을 때 당직 관리자는 수력학적 제약 조건을 검증해야 한다:
1. **총 유량 공급 가능 여부**: 콜드 플레이트 내부의 난류 열전달을 유지하는 데 필요한 체적 유량(q_v)을 2차측 펌프가 공급할 수 있는지 확인한다:

$$q_v = \frac{Q}{\rho \cdot c_p \cdot \Delta T}$$

여기서:
- Q는 총 발열량( kW).
- $\rho$ 는 25% 프로필렌 글리콜 수용액의 밀도(30°C에서$1026\,\text{kg/m}^3$ ).
- c_p는 정압 비열(3.92 kJ/( kg· K)).
- ΔT는 랙 매니폴드 전후의 유체 온도차(통상 10.0 K).

2. **수력학적 불평형과 직접 환수 방식의 유량 기아**: 2차 분배 매니폴드에 랙이 추가됨에 따라 배관 마찰 손실(ΔP_f)은 유속(v)의 제곱에 비례하여 증가한다:

$$\Delta P_f = f \cdot \frac{L}{D} \cdot \frac{\rho v^2}{2}$$

매니폴드가 역환수(Tichelmann) 방식이 아닌 직접 환수 방식으로 배관되어 있다면 열의 맨 끝에 부하를 추가할 때 가장 먼 인덱스 랙에서 유량 기아 현상이 발생하여 GPU의 서멀 스로틀링이 즉시 유발된다.

"펌프가 충분히 커 보이니 괜찮다"는 고객의 구두 장담만 믿고 액체 부하 추가를 승인하지 마라. 배관 연결 허가서를 발행하기 전에 검증된 수력 시뮬레이션 및 압력 강하 계산서 제출을 요구하라.

## "일단 켜보자"는 미신의 위험

계산된 용량을 초과하는 추가 서버 랙을 켜겠다고 승인을 요청하는 고객이나 프로젝트 설치팀은 흔히 이렇게 제안한다:
> *"일단 랙을 켜보고 차단기가 버티는지 20분만 미터를 지켜보죠."*

이것은 30톤짜리 트럭을 얼음판 위로 몰고 올라가 얼음 두께를 시험해보자는 것과 다름없는 자살 행위다.

"버티는지 보려고" 전원을 켜는 것은:
- 배전 모선과 변압기에 거대한 돌입 전류와 열적 충격을 가한다.
- 상류 보호계전기를 오작동시켜 인접한 정상 고객들에게 순간 정전을 유발할 위험을 초래한다.
- 엄밀한 엔지니어링 계산을 무모한 도박으로 대체하는 행위다.

요청된 부하 투입이 계약된 배정 용량이나 45% 이중화 상한선 중 어느 하나라도 초과한다면 당직 관리자는 즉시 승인을 거부해야 한다. 전원 투입을 저지하라. 고객은 단 하나의 추가 차단기를 올리기 전에 정식 엔지니어링 기술 검토서를 제출하고 계약 변경에 합의해야 한다.

## 기록할 결정

- 고객 계약 조항 및 랙 번호로 인용된 계약상 판매 용량.
- 45% 이중화 규칙 준수 여부가 검증된 모선별 실측 전력 부하.
- CDU별로 기록된 2차 냉각 루프 유량, 공급 온도, 차압.
- 최악의 단일 부품 고장 후 남는 잔여 용량: 공인 엔지니어링 검토서 확인값, 또는 미확인 기록.
- 안전 운전 용량을 초과하는 전원 투입 요청에 대해 서면 거부한 기록 ("시험 투입" 완전 배제).

## 물리적 책임 분계(Demarcation) 및 정량적 교대 감사 프로토콜

교대 운영 관리자는 설비의 물리적 경계(Ring 1: 수전·외곽, Ring 2: 중앙 열원·특고압 변전, Ring 3: 홀 배전·2차 CDU, Ring 4: 고객 랙 내부)에서 책임 분계점(`DEMARC`)을 엄격히 유지하고, 다음의 정량적 감사 기준을 일일 시트(Day Sheet)에 기록해야 한다.

| 교대 감사 영역 | 감시·계측 파라미터 | 정상 운영 엔벨로프 | 즉시 개입·작업 중지(Stop Work) 임계값 |
| :--- | :--- | :--- | :--- |
| **2N 수배전 계통 부하율 상한** | 버스 A / 버스 B 정상 부하율 ($P_{\text{bus}} / P_{\text{rated}}$) | $\le 45.0\%$ (단일 계통 상실 시 $\le 90.0\%$) | $> 45.0\%$ 상태에서 신규 랙 통전 요청 즉시 거부 |
| **2차 냉각 루프(CDU) 수리·화학** | 공급 압력 $P_{\text{sup}}$, 접근 온도 $\Delta T_{\text{PHE}}$, PG 농도 | $0.15\sim 0.90\,\text{MPa}$, $\Delta T_{\text{PHE}} \le 8.0\,\text{K}$, PG $25.0\% \pm 1.0\%$ | 차압 $> 1.0\,\text{bar}$, 전도도 $> 10\,\mu\text{S/cm}$ 또는 커플러 누수 |
| **작업 허가(PTW) 및 제로 에너지 검증** | LOTO 시건, 잔류 전하 방전, 바이패스 밸브 폐쇄 확인 | 100% 현장 호스트 동행·만료 시각 전 완전 복구 | 승인된 MOP 이탈 또는 '겸사겸사 작업' 즉시 중지 |
| **인시던트 시계 및 SLA 통지** | 이벤트 감지($T_0$), EOP 안전 상태 확립, 고객 1차 통지 | P1: $T_0 + 15\,\text{min}$ 이내 물리적 사실만 통지 | 미확인 추측(가설)의 통지문 포함 절대 금지 |

$$I_{\text{RMS}} = I_1 \sqrt{1 + \text{THD}_I^2}, \qquad \text{THD}_I = \frac{\sqrt{\sum_{h=2}^{\infty} I_h^2}}{I_1}$$

$$K = \sum_{h=1}^{H} \left( \frac{I_h}{I_{\text{RMS}}} \right)^2 \cdot h^2$$
