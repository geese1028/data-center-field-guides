# 1. สิ่งที่ผู้จัดการเป็นเจ้าของในวันนี้

ผู้จัดการที่พยายามเป็นเจ้าของทั้งงานออกแบบ ซอฟต์แวร์แอปพลิเคชันของลูกค้า และการรับประกันจากโรงงานของผู้ผลิตไปพร้อมๆ กัน สุดท้ายแล้วจะไม่ได้เป็นเจ้าของสิ่งใดเลย สิ่งที่คุณเป็นเจ้าของในวันนี้คือสถานะการทำงานของศูนย์ข้อมูล ผู้คนที่ได้รับอนุญาตให้สัมผัสอุปกรณ์ และบันทึกที่ไม่สามารถแก้ไขได้ว่าได้ทำอะไรลงไปบ้าง

ไม่ใช่หน้าที่ของคุณที่จะไปรับผิดชอบว่าฐานข้อมูลแบบกระจายของลูกค้าจะแบ่งส่วนข้อมูลข้ามคลัสเตอร์ได้อย่างถูกต้องหรือไม่ สิ่งที่คุณเป็นเจ้าของคือ แหล่งจ่ายไฟฟ้าคู่ อัตราการไหลของลูปความเย็น และขอบเขตความปลอดภัยทางกายภาพที่คุณขายให้พวกเขานั้น ถูกส่งมอบอย่างเคร่งครัดตามพารามิเตอร์ที่ลงนามไว้ในสัญญาหรือไม่ หากสัญญาไม่ได้ระบุถึงเรื่องใด อย่าได้สร้างคำสัญญาขึ้นมาเองในสมุดบันทึกประจำวัน ผู้อำนวยการฝ่ายเทคนิคของลูกค้าที่กำลังตะโกนผ่านสายประชุมทางไกลไม่ใช่ข้อสัญญาใหม่

คุณไม่ได้เป็นเจ้าของสิทธิ์ในการออกแบบระบบใหม่ การเปลี่ยนแปลงใดๆ ที่ส่งผลกระทบต่อรูปแบบความล้มเหลวของสวิตช์เกียร์ไฟฟ้าหรือลูปหล่อเย็นทุติยภูมิ คืองานวิศวกรรมโครงการลงทุน (CAPEX) ซึ่งต้องผ่านการตรวจสอบจากผู้เชี่ยวชาญ การศึกษาการประสานการทำงานของรีเลย์ป้องกัน และการลงนามอนุมัติจากผู้บริหาร ฝ่ายปฏิบัติการประจำวันอาจเสนอแนะได้ แต่ฝ่ายปฏิบัติการต้องไม่แอบลักไก่ยัดมันเข้าไปในหน้าต่างเวลาบำรุงรักษาแล้วเรียกมันว่า "การปรับจูนการทำงานตามปกติ" หากงานนั้นต้องมีการเขียนแบบเส้นเดี่ยวไฟฟ้า (SLD) หรือแบบท่อและเครื่องมือวัด (P&ID) ใหม่ นั่นไม่ใช่งานบำรุงรักษาของวันนี้ หยุดเครื่องมือเดี๋ยวนี้

คุณไม่ได้เป็นเจ้าของใบประกาศนียบัตรที่ใส่กรอบไว้บนผนังแผนกต้อนรับ ป้ายรับรอง ISO 9001 ใบรับรองการออกแบบระดับ Tier IV จาก Uptime Institute หรือรางวัลความยั่งยืนขององค์กร ไม่ใช่หลักฐานว่ากะการทำงานของวันนี้ดำเนินไปอย่างมีสมรรถนะ หลักฐานที่แท้จริงคือแผ่นงานประจำวัน: รายชื่อช่างปฏิบัติการที่มีคุณสมบัติตรงตามเกณฑ์ ใบอนุญาตทำงานที่ยังมีผล การเดินตรวจจริงทางกายภาพที่ได้รับการบันทึก และอุบัติการณ์ที่คุณปฏิเสธที่จะปกปิด

## ครึ่งชั่วโมงแรก

อ่านสี่สิ่งนี้ก่อนที่คุณจะเปิดแดชบอร์ดเทเลเมทรี ตรวจเช็กอีเมล หรือดื่มกาแฟของคุณ:

1. **ความบกพร่องที่ส่งต่อมาจากกะก่อนหน้า (Impairments)**: เครื่องกำเนิดไฟฟ้าที่ถูกล็อกไม่ให้สตาร์ตอัตโนมัติ โซนดับเพลิงที่ถูกปิดการทำงานบนแผงควบคุม VESDA ยูนิตจ่ายของเหลวหล่อเย็นทุติยภูมิ (CDU) ที่รันด้วยการบายพาสปั๊มเดี่ยว หรือเครื่องสำรองไฟ (UPS) ที่รันอยู่บนระบบสแตติกบายพาส
2. **ใบอนุญาตทำงานที่ยังเปิดอยู่ และเวลาหมดอายุที่แน่นอนในระดับนาที**: ใบอนุญาตทำงาน (PTW) คือการเช่าความเสี่ยงชั่วคราว หากใบอนุญาตหมดอายุเวลา 06:00 น. แต่ผู้รับเหมายังอยู่ในห้องสวิตช์เกียร์แรงดันปานกลาง แสดงว่าศูนย์ข้อมูลกำลังทำงานอยู่ในสภาวะที่ไม่ได้รับอนุญาต
3. **อุบัติการณ์ที่ยังเปิดค้างอยู่ และผู้รับผิดชอบงานแต่ละรายการ**: หากเกิดอุบัติการณ์ขึ้นในเวลากลางคืน จงระบุว่าใครเป็นหัวหน้างานเทคนิคและได้สร้างสภาวะปลอดภัย (Safe State) ใดไว้แล้ว
4. **งานเปลี่ยนแปลงที่มีกำหนดดำเนินการในวันนี้ และใครเป็นผู้ยอมรับความเสี่ยงอย่างเป็นทางการ**: ตรวจสอบว่างานเปลี่ยนแปลงตามตารางทุกงานมีระเบียบวิธีปฏิบัติงาน (MOP) ที่ได้รับอนุมัติพร้อมแผนการย้อนกลับ (Back-out plan) ที่ชัดเจน

| **การตรวจสอบบังคับ 4 ประการก่อนเริ่มกะ** |
| :--- |
| [1] ความบกพร่องที่ยังคงอยู่ → ระบบดับเพลิง, วาล์วบายพาส, UPS N-1 |
| [2] ใบอนุญาตทำงานที่เปิดอยู่→ สถานที่, ขอบเขตงาน, เวลาหมดอายุ |
| [3] อุบัติการณ์ที่ยังค้างอยู่ → ระดับความรุนแรง, สภาวะปลอดภัย, ผู้รับผิดชอบ |
| [4] การเปลี่ยนแปลงวันนี้ → MOP ที่อนุมัติ, ผู้รับความเสี่ยง, แผนถอย |

หากสิ่งใดสิ่งหนึ่งในสี่ข้อนี้ขาดหายไปจากบันทึกส่งมอบกะ แสดงว่าการส่งมอบกะนั้นล้มเหลว อย่ารับวิทยุสื่อสาร อย่าลงนามในสมุดบันทึก ผู้จัดการศูนย์ข้อมูลที่ลงนามรับมอบกะที่ไม่สมบูรณ์จะต้องรับมรดกความรับผิดชอบต่อข้อบกพร่องที่ซ่อนอยู่ทั้งหมด อินเตอร์ล็อกความปลอดภัยที่ถูกปิด และการทริปของอุปกรณ์ที่ไม่ได้บันทึกไว้ตลอดสิบสองชั่วโมงที่ผ่านมา

เมื่อตรวจสอบครบทั้งสี่ข้อแล้ว ให้เดินไปยังสถานที่ทางกายภาพที่งานของวันนี้จะเกิดขึ้นก่อนที่ผู้รับเหมาจะมาถึงประตูด้านหน้า ตรวจสอบแผงสวิตช์บอร์ด วาล์วตัดแยก และช่องทางบริการ หากสภาพทางกายภาพหน้างานทำให้ไม่สามารถตัดแยกอุปกรณ์ได้อย่างปลอดภัยตามขั้นตอนที่เขียนไว้ แสดงว่าเอกสารขั้นตอนนั้นผิด ยกเลิกงานนั้นเสีย อย่าปล่อยให้เกิดเหตุการณ์ที่เปิดตู้ควบคุมไปแล้วจึงพบว่าวาล์วตัดแยกแบบแมนนวลติดตายหรือเบรกเกอร์บายพาสถูกคล้องกุญแจไว้

เขียนประโยคผูกพันเดี่ยวสำหรับวันนี้ก่อนที่ความวุ่นวายในตอนเช้าจะเริ่มต้นขึ้น ในศูนย์ข้อมูลระดับมืออาชีพ ประโยคนั้นถูกตั้งใจให้ฟังดูน่าเบื่อและเรียบง่าย:
> *"โครงสร้างพื้นฐานด้านพลังงานและระบบหล่อเย็นที่สำคัญยังคงอยู่ภายในกรอบ SLA ตามสัญญาอย่างเคร่งครัด งานบำรุงรักษาที่ได้รับอนุญาตทั้งหมดเสร็จสมบูรณ์ภายใต้ MOP ที่ได้รับอนุมัติโดยไม่มีการหยุดชะงักของบริการ และไม่มีความบกพร่องหรือการลดทอนของระบบที่ไม่ได้รับการบันทึกอยู่ภายในสถานที่"*

หากคุณไม่สามารถลงนามในประโยคนั้นได้อย่างตรงไปตรงมาเมื่อสิ้นสุดกะการทำงาน วันนั้นก็คือความล้มเหลวในการปฏิบัติการ แม้ว่าแดชบอร์ดของผู้บริหารจะสว่างเป็นสีเขียวทั้งหมดก็ตาม

## สิ่งที่คุณต้องไม่มอบหมายให้ผู้อื่นทำแทน

คุณอาจมอบหมายให้คนอื่นหมุนวาล์ว ดึงเบรกเกอร์ตัดวงจร 480V ออก (rack out) หรือจดค่าความดันต่างของฟิลเตอร์ดักฝุ่นได้ แต่คุณต้องไม่มอบหมายสิ่งเหล่านี้เด็ดขาด:
- การตัดสินว่าศูนย์ข้อมูลยังคงทำงานอยู่ภายในข้อตกลง SLA ตามสัญญา
- การอนุมัติเปิดหน้าต่างเวลาสำหรับการเปลี่ยนแปลงที่กระทบต่อระบบสำคัญ
- การตัดสินใจส่งหนังสือแจ้งเตือนอุบัติการณ์ไปยังลูกค้า

ความรับผิดชอบทั้งสามประการนี้เป็นของวิศวกรผู้จัดการปฏิบัติการที่มีใบอนุญาตซึ่งกำลังเข้าเวรอยู่ หรือผู้ช่วยที่ได้รับการแต่งตั้งอย่างเป็นทางการเป็นลายลักษณ์อักษรในตารางเข้ากะเท่านั้น กลุ่มแชตของบริษัทไม่ใช่ตัวแทนที่ได้รับการแต่งตั้ง

## การตัดสินใจที่ต้องบันทึก

- มาตรฐานการบริการตามสัญญา โดยระบุชื่อสัญญาและเลขที่ข้อสัญญาอย่างถูกต้อง
- สิ่งที่คุณระบุไว้อย่างชัดเจนว่าจะไม่รับปากลูกค้าในวันนี้
- การตรวจสอบการรับมอบกะ 4 ประการ: ยืนยันว่ามีครบ หรือระบุว่าขาดหายไป
- ประโยคปิดกะที่มีผลผูกพันซึ่งคุณตั้งใจจะลงนามเมื่อสิ้นสุดกะการทำงาน

## เส้นแบ่งขอบเขตความรับผิดชอบทางกายภาพและโปรโตคอลการตรวจสอบกะเชิงปริมาณ

ผู้จัดการกะปฏิบัติการต้องรักษาจุดแบ่งขอบเขตความรับผิดชอบ (`DEMARC`) ทั้ง 4 วงแหวนของศูนย์ข้อมูล (Ring 1: ระบบรับไฟฟ้าและรั้วโครงการ, Ring 2: ห้องเครื่องหลักและหม้อแปลง, Ring 3: ระบบจ่ายในห้องเซิร์ฟเวอร์และ CDU ทุติยภูมิ, Ring 4: ภายในแร็คของลูกค้า) และบันทึกเกณฑ์วัดผลเชิงปริมาณต่อไปนี้ลงในแผ่นงานประจำวัน (Day Sheet):

| หมวดการตรวจสอบกะ | พารามิเตอร์ที่ตรวจวัด | ขอบเขตการทำงานปกติ | เกณฑ์สั่งหยุดงานทันที (Stop Work) / ปฏิเสธ |
| :--- | :--- | :--- | :--- |
| **เพดานโหลดระบบไฟฟ้าสำรอง 2N** | โหลดปกติบนบัส A / บัส B ($P_{\text{bus}} / P_{\text{rated}}$) | $\le 45.0\%$ (เมื่อเสีย 1 ฝั่ง โหลดรวม $\le 90.0\%$) | ปฏิเสธการจ่ายไฟแร็คใหม่ทันทีหากโหลดเกิน $45.0\%$ |
| **ไฮดรอลิกและเคมีของ CDU ทุติยภูมิ** | ความดันจ่าย $P_{\text{sup}}$, อุณหภูมิเข้าใกล้ $\Delta T_{\text{PHE}}$, ความเข้มข้น PG | $0.15\sim 0.90\,\text{MPa}$, $\Delta T_{\text{PHE}} \le 8.0\,\text{K}$, PG $25.0\% \pm 1.0\%$ | ความดันตกคร่อม $> 1.0\,\text{bar}$, ค่าการนำไฟฟ้า $> 10\,\mu\text{S/cm}$ หรือพบหยดน้ำ |
| **ใบอนุญาตทำงาน (PTW) และ LOTO** | การล็อกกุญแจ LOTO, การคายประจุ และวาล์วบายพาส | มีผู้ควบคุมของศูนย์ข้อมูลประกบ 100% และปิดงานก่อนหมดเวลา | หยุดงานทันทีหากทำนอกเหนือขั้นตอน MOP ที่อนุมัติ |
| **นาฬิกาเหตุขัดข้องและการแจ้ง SLA** | เวลาตรวจพบ ($T_0$), การเข้าสู่สภาวะปลอดภัย EOP, การแจ้งลูกค้า | P1: แจ้งข้อเท็จจริงภายใน $\le 15\,\text{นาที}$ | ห้ามใส่ข้อสันนิษฐานหรือการคาดเดาลงในใบแจ้งเหตุฉบับแรก |

$$P_{\text{construction\_valve\_open}} = \text{FORBIDDEN without a signed Operations Switching Permit}$$
