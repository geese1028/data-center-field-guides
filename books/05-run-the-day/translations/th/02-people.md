# 2. บุคลากรในกะการทำงาน

ศูนย์ข้อมูลไม่ได้ทำงานได้ด้วยซอฟต์แวร์เทเลเมทรี แต่มันทำงานได้ด้วยสมรรถนะ ใบอนุญาตตามกฎหมาย และวินัยทางกายภาพของช่างเทคนิคที่เดินอยู่บนพื้นอาคาร หากคุณไม่ทราบคุณสมบัติที่แน่นอนของบุคคลที่ถือกุญแจหลัก คุณก็ไม่ได้เป็นผู้ควบคุมศูนย์ข้อมูลแห่งนี้

| บทบาท ใบอนุญาต/วุฒิ | บัตรที่ต้องมี ขอบเขตงานที่ได้ | รับอนุญาต |

## ข้อกำหนดด้านใบอนุญาตและกฎหมาย

ในศูนย์ข้อมูล AI ความหนาแน่นสูงที่ติดตั้งระบบระบายความร้อนด้วยของเหลวระดับเมกะวัตต์และสถานีไฟฟ้าย่อยระดับหลายสิบเมกะโวลต์แอมแปร์ ช่างเทคนิคทั่วไปที่ไม่มีความเชี่ยวชาญเฉพาะทางถือเป็นความเสี่ยงอย่างร้ายแรง งานปฏิบัติการจำเป็นต้องมีใบรับรองตามกฎหมาย:
- **งานปฏิบัติการทางไฟฟ้า**: การสลับวงจร การดึงเข้า-ออกเบรกเกอร์ หรือการทดสอบในขณะที่มีกระแสไฟฟ้าบนสวิตช์เกียร์แรงดันปานกลาง (10kV/35kV) หรือแรงดันต่ำ (400V/480V) ต้องดำเนินการโดยช่างไฟฟ้าที่มีใบอนุญาตถูกต้องตามกฎหมายเท่านั้น
- **งานระบบหล่อเย็นและสารเคมี**: การควบคุมชิลเลอร์แบบหอยโข่ง หอหล่อเย็นอุตสาหกรรม และสถานีสูบน้ำหลัก/ทุติยภูมิ ต้องใช้ช่างเทคนิคระบบทำความเย็นที่มีใบอนุญาตด้านการจัดการสารทำความเย็นที่มีแรงดันและการบำบัดน้ำในระบบอุตสาหกรรม

ตามแนวทางปฏิบัติการของ OpenViking (`DCFG-SOP-LIQUID-01`) การปฏิบัติการระบบหล่อเย็นด้วยของเหลวที่เกี่ยวข้องกับยูนิตกระจายทุติยภูมิ (CDU) ระบบน้ำของศูนย์ข้อมูลหลัก (FWS) และแมนิโฟลด์ระดับแร็ค จำเป็นต้องผ่านการฝึกอบรมทางเทคนิคที่ผ่านการตรวจสอบเกี่ยวกับการใช้สารกำจัดจุลชีพ การวัดความเข้มข้นของไกลคอล และโปรโตคอลการควบคุมการรั่วไหล

หากช่างเทคนิคในกะไม่มีใบอนุญาตตามกฎหมายสำหรับงานสลับวงจรไฟฟ้าแรงสูง ชื่อของพวกเขาจะต้องไม่ปรากฏในใบสั่งงานสลับวงจรไฟฟ้า หากพบผู้รับเหมาที่ไม่มีใบอนุญาตเปิดประตูแผงสวิตช์บอร์ดอยู่ ให้สั่งหยุดงานทันที

## กฎสองคน (The Two-Person Rule)

ห้ามมิให้ช่างเทคนิคปฏิบัติงานสลับวงจรไฟฟ้าที่สำคัญ การดึงเบรกเกอร์แรงดันสูง หรือการตัดแยกวาล์วบนลูปหล่อเย็นหลักโดยลำพังเป็นอันขาด

กฎสองคนกำหนดให้ต้องมี:
1. **ผู้ปฏิบัติการ (The Performer)**: ช่างเทคนิคที่มีใบอนุญาตซึ่งถือระเบียบวิธีปฏิบัติงาน (MOP) ที่ได้รับอนุมัติ และเป็นผู้สัมผัสสวิตช์ควบคุม ด้ามจับเบรกเกอร์ หรือวาล์วตัดแยกทางกายภาพ
2. **ผู้ตรวจสอบ (The Checker)**: ช่างเทคนิคที่มีคุณสมบัติเท่าเทียมกันซึ่งยืนอยู่ด้านหลังผู้ปฏิบัติการ ถือเอกสารขั้นตอนที่พิมพ์ออกมา อ่านแต่ละขั้นตอนด้วยเสียงดัง ยืนยันป้ายชื่ออุปกรณ์ (เช่น ยืนยันว่าป้ายเบรกเกอร์ `SWG-01-4A` ตรงกับใบสั่งงานก่อนดึงเบรกเกอร์) และพร้อมสำหรับการสั่งหยุดฉุกเฉินตลอดเวลา

หน้าที่เดียวของผู้ตรวจสอบในระหว่างการทำงานคือการตรวจสอบความถูกต้องและความปลอดภัย หากผู้ปฏิบัติการเอื้อมมือไปยังด้ามเบรกเกอร์ผิดตัว หรือหมุนวาล์วผิดลำดับ ผู้ตรวจสอบมีอำนาจเด็ดขาดในการสั่งหยุดการทำงานทันที

| **กฎสองคน** |
| :--- |
| ผู้ตรวจสอบ \| \| ผู้ปฏิบัติการ |
| ถือแผ่นงาน MOP \| \| สัมผัสสวิตช์ |
| อ่านขั้นตอนเสียงดัง\| ------→ \| ชี้ไปที่ป้ายชื่อ |
| ตรวจเช็กป้ายแท็ก\| \| ลงมือปฏิบัติ |
| มีอำนาจสั่งหยุด \| \| รายงานสถานะ |

## อำนาจสั่งหยุดงาน (Stop Work Authority: SWA)

ทุกคนที่ก้าวเข้ามาในศูนย์ข้อมูล—ตั้งแต่วิศวกรผู้อำนวยการฝ่ายปฏิบัติการอาวุโสไปจนถึงช่างฝึกหัดดึงสายไฟ—ล้วนมีอำนาจสั่งหยุดงาน (SWA) อย่างเต็มที่และไม่มีเงื่อนไข

ต้องใช้อำนาจสั่งหยุดงานทันทีเมื่อ:
- สภาพทางกายภาพหน้างานเบี่ยงเบนไปจากสมมติฐานที่เขียนไว้ใน MOP
- มีสัญญาณเตือนภัยที่ไม่คาดคิดดังขึ้นบนระบบ BMS หรือ EPMS
- ตรวจพบหยดน้ำ แอ่งของเหลว หรือกลิ่นสารเคมีที่ผิดปกติใกล้กับอุปกรณ์ไฟฟ้า
- แผงกั้นเพื่อความปลอดภัย อุปกรณ์คุ้มครองความปลอดภัยส่วนบุคคล (PPE) หรือกุญแจ LOTO สูญหายหรือชำรุด
- ผู้ปฏิบัติงานเกิดความสับสนหรือไม่แน่ใจเกี่ยวกับขั้นตอนต่อไป

เมื่อมีการประกาศใช้อำนาจสั่งหยุดงาน:
1. ปรับเปลี่ยนอุปกรณ์ให้อยู่ในสภาวะปลอดภัยและเสถียรที่ใกล้ที่สุดตามที่ระบุไว้ในขั้นตอนทันที
2. วางเครื่องมือลง ห้ามขยับวาล์วหรือสวิตช์ใดๆ เพิ่มเติม
3. เรียกผู้จัดการเวรปฏิบัติการมายังสถานที่ทำงาน
4. เริ่มงานใหม่ได้ต่อเมื่อข้อสงสัยได้รับการแก้ไขและบันทึกเป็นลายลักษณ์อักษรลงในใบอนุญาตแล้วเท่านั้น

ห้ามตำหนิ ลงโทษ หรือตั้งคำถามต่อช่างเทคนิคหรือผู้รับเหมาที่ใช้อำนาจสั่งหยุดงานด้วยเจตนาสุจริต วัฒนธรรมของศูนย์ข้อมูลที่ช่างเทคนิคลังเลที่จะสั่งหยุดงานเพราะแรงกดดันด้านเวลาคือศูนย์ข้อมูลที่กำลังรอคอยหายนะไฟฟ้าดับระดับเมกะวัตต์

## การเดินตรวจร่วม 30 นาที

อย่าส่งมอบกะขณะนั่งอยู่หลังโต๊ะในห้องควบคุม การส่งมอบกะบนโต๊ะกาแฟคือการละทิ้งหน้าที่

ผู้จัดการเวรที่กำลังจะเข้ากะและผู้จัดการเวรที่กำลังจะออกกะต้องเดินตรวจกายภาพร่วมกันเป็นเวลา 30 นาทีใน 6 โซนวิกฤตของศูนย์ข้อมูลก่อนที่จะลงนามในแผ่นงานประจำวัน:
1. **สถานีไฟฟ้าย่อยแรงดันปานกลาง**: ตรวจสอบสวิตช์เกียร์ 35kV/10kV สลักแสดงสถานะการชาร์จสปริงของเบรกเกอร์ เกจวัดความดันก๊าซ SF6 และสถานะเครื่องชาร์จแบตเตอรี่ควบคุม DC
2. **ห้องหม้อแปลง**: ตรวจสอบอุณหภูมิขดลวดหม้อแปลงชนิดแห้ง/น้ำมัน (ตรวจสอบให้แน่ใจว่า T < 90°C) การทำงานของพัดลมระบายความร้อน และฟังเสียงฮาร์มอนิกที่ผิดปกติ
3. **ห้อง UPS และแบตเตอรี่**: ตรวจสอบแรงดันลอยตัว (float voltage) ของบัส DC อุณหภูมิของแต่ละสตริง (T < 25°C) ตรวจสอบการกัดกร่อนหรือการบวมที่ขั้วแบตเตอรี่ และตรวจสอบการไหลของอากาศของพัดลมดูดอากาศไฮโดรเจน
4. **โรงทำความเย็นส่วนกลางและสถานีสูบน้ำ**: ตรวจสอบอุณหภูมิเข้าใกล้ (approach temp) ของคอนเดนเซอร์ (ΔT_approach ≤ 1.5 K) ความดันน้ำมัน ความถี่อินเวอร์เตอร์ (VFD) และการสั่นสะเทือน
5. **สถานีหล่อเย็นด้วยของเหลว CDU**: ตรวจสอบความดันฝั่งปฐมภูมิและทุติยภูมิ (0.15 - 0.90 MPa) ความดันต่างของปั๊ม (ΔP < 1.0 bar) ระดับน้ำในถังขยายตัว และตรวจสอบถาดรองน้ำหยดว่าแห้งสนิท
6. **ห้องไอทีเซิร์ฟเวอร์ AI**: เดินตรวจทางเดินลมร้อนและทางเดินลมเย็น ตรวจสอบตู้ PDU เพื่อหาจุดความร้อนสะสม ตรวจสอบความดันต่างใต้พื้นยก (ΔP ≥ 5 Pa) และตรวจสอบข้อต่อสวมเร็ว (FD83/UQD) ว่ามีรอยซึมหรือไม่

ผู้จัดการทั้งสองต้องเดินเคียงข้างกันตลอดเส้นทาง หากผู้จัดการที่กำลังจะออกกะปฏิเสธที่จะเดินตรวจหน้างาน ผู้จัดการที่เข้ากะต้องถือว่าอุปกรณ์ทั้งหมดอยู่ในสถานะที่ยังไม่ได้รับการตรวจสอบ และบันทึกการปฏิเสธนั้นลงในบันทึกส่งมอบกะ

## การตัดสินใจที่ต้องบันทึก

- รายชื่อบุคลากรประจำกะทุกคน พร้อมหมายเลขใบอนุญาตที่ได้รับการตรวจสอบและวันหมดอายุ
- การยืนยันว่าการปฏิบัติงานไฟฟ้าแรงสูงและของเหลวสำคัญเป็นไปตามกฎสองคน
- การประกาศใช้อำนาจสั่งหยุดงาน (SWA) ใดๆ ในระหว่างกะ พร้อมระบุสาเหตุและการแก้ไข
- บันทึกการเดินตรวจกายภาพร่วม 30 นาทีที่ลงนามโดยทั้งผู้จัดการที่เข้ากะและออกกะ

## เส้นแบ่งขอบเขตความรับผิดชอบทางกายภาพและโปรโตคอลการตรวจสอบกะเชิงปริมาณ

ผู้จัดการกะปฏิบัติการต้องรักษาจุดแบ่งขอบเขตความรับผิดชอบ (`DEMARC`) ทั้ง 4 วงแหวนของศูนย์ข้อมูล (Ring 1: ระบบรับไฟฟ้าและรั้วโครงการ, Ring 2: ห้องเครื่องหลักและหม้อแปลง, Ring 3: ระบบจ่ายในห้องเซิร์ฟเวอร์และ CDU ทุติยภูมิ, Ring 4: ภายในแร็คของลูกค้า) และบันทึกเกณฑ์วัดผลเชิงปริมาณต่อไปนี้ลงในแผ่นงานประจำวัน (Day Sheet):

| หมวดการตรวจสอบกะ | พารามิเตอร์ที่ตรวจวัด | ขอบเขตการทำงานปกติ | เกณฑ์สั่งหยุดงานทันที (Stop Work) / ปฏิเสธ |
| :--- | :--- | :--- | :--- |
| **เพดานโหลดระบบไฟฟ้าสำรอง 2N** | โหลดปกติบนบัส A / บัส B ($P_{\text{bus}} / P_{\text{rated}}$) | $\le 45.0\%$ (เมื่อเสีย 1 ฝั่ง โหลดรวม $\le 90.0\%$) | ปฏิเสธการจ่ายไฟแร็คใหม่ทันทีหากโหลดเกิน $45.0\%$ |
| **ไฮดรอลิกและเคมีของ CDU ทุติยภูมิ** | ความดันจ่าย $P_{\text{sup}}$, อุณหภูมิเข้าใกล้ $\Delta T_{\text{PHE}}$, ความเข้มข้น PG | $0.15\sim 0.90\,\text{MPa}$, $\Delta T_{\text{PHE}} \le 8.0\,\text{K}$, PG $25.0\% \pm 1.0\%$ | ความดันตกคร่อม $> 1.0\,\text{bar}$, ค่าการนำไฟฟ้า $> 10\,\mu\text{S/cm}$ หรือพบหยดน้ำ |
| **ใบอนุญาตทำงาน (PTW) และ LOTO** | การล็อกกุญแจ LOTO, การคายประจุ และวาล์วบายพาส | มีผู้ควบคุมของศูนย์ข้อมูลประกบ 100% และปิดงานก่อนหมดเวลา | หยุดงานทันทีหากทำนอกเหนือขั้นตอน MOP ที่อนุมัติ |
| **นาฬิกาเหตุขัดข้องและการแจ้ง SLA** | เวลาตรวจพบ ($T_0$), การเข้าสู่สภาวะปลอดภัย EOP, การแจ้งลูกค้า | P1: แจ้งข้อเท็จจริงภายใน $\le 15\,\text{นาที}$ | ห้ามใส่ข้อสันนิษฐานหรือการคาดเดาลงในใบแจ้งเหตุฉบับแรก |

$$\text{FTE}_{\text{per\_post}} = \frac{365\,\text{days} \times 24\,\text{h/day}}{\left( 52\,\text{weeks} \times 40\,\text{h/week} \right) - H_{\text{leave}} - H_{\text{training}} - H_{\text{sick}}} = \frac{8,760\,\text{h}}{2,080 - 160 - 80 - 64} \approx 4.93\,\text{FTE}$$
