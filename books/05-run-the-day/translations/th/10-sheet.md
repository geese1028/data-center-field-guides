# 10. แผ่นงานหลักประจำวัน (Master Day Sheet)

แผ่นงานหลักประจำวันคือสมุดบัญชีทางกฎหมาย ทางเทคนิค และการปฏิบัติการที่มีผลผูกพันของกะการทำงานในศูนย์ข้อมูล

```
+-----------------------------------------------------------------------------+
| โครงสร้างแผ่นงานหลักประจำวัน |
| |
| [ส่วนที่ 1] การตรวจสอบส่งมอบก่อนเริ่มกะ (ความบกพร่อง, ใบอนุญาต, เหตุการณ์) |
| | |
| [ส่วนที่ 2] ทะเบียนงานที่อนุญาต & PTW (ขอบเขตงาน, LOTO, เวลาหมดอายุ) |
| | |
| [ส่วนที่ 3] บันทึกการเดินตรวจกายภาพรอบกะ (6 สถานี, การวัดค่าหลายประสาทสัมผัส)|
| | |
| [ส่วนที่ 4] บันทึกลำดับเหตุการณ์ & การยกระดับ (การจัดระดับ, SLA T-15 นาที) |
| | |
| [ส่วนที่ 5] การตรวจสอบความจุ & ความซ้ำซ้อน (กฎไฟฟ้า 45%, ชลศาสตร์ CDU) |
| | |
| [ส่วนที่ 6] ประโยคปิดกะขั้นสุดท้าย (การลงนามเดี่ยวที่ไม่สามารถเปลี่ยนแปลงได้)|
+-----------------------------------------------------------------------------+
```

![Manager Shift Closeout Sheet](../figures/fig-07-manager-shift-closeout-sheet.png)

คัดลอกหัวข้อด้านล่างนี้ลงในซอฟต์แวร์การปฏิบัติการของศูนย์ข้อมูลของคุณหรือสมุดบันทึกการส่งมอบงานที่พิมพ์ออกมา เส้นว่างในแผ่นงานประจำวันคือตัวแทนของส่วนของศูนย์ข้อมูลที่คุณไม่ได้ตรวจสอบ ความเสี่ยงที่คุณไม่ได้จัดการ และเหตุการณ์ไฟฟ้าดับที่คุณจะต้องเป็นผู้รับผิดชอบแต่เพียงผู้เดียว
