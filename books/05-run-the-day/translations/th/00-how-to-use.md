# 0. วิธีใช้หนังสือเล่มนี้

หนังสือเล่มนี้เขียนขึ้นสำหรับผู้ที่ต้องบริหารจัดการวันหนึ่งวันของศูนย์ข้อมูล มันคือเรื่องของกะการทำงาน งานที่ได้รับอนุญาตให้เกิดขึ้น สิ่งที่เกิดข้อผิดพลาด และประโยคที่คุณยังคงสามารถยืนยันได้อย่างถูกต้องตามกฎหมายเมื่อสิ้นสุดวัน

นี่ไม่ใช่หลักสูตรการปฏิบัติการสิ่งอำนวยความสะดวกศูนย์ข้อมูล และไม่ใช่สิ่งทดแทนการเข้าอบรมหลักสูตรดังกล่าว Certified Data Centre Facilities Operations Manager (CDFOM) และ Certified Data Centre Facilities Operations Specialist (CDCS) เป็นชื่อหลักสูตร หนังสือเล่มนี้ไม่ได้นำสไลด์บรรยาย แบบฝึกหัดปรนัย หรือข้อสอบของหลักสูตรเหล่านั้นมาเล่าซ้ำ หากคุณต้องการประกาศนียบัตรเหล่านั้นสำหรับเกณฑ์การคัดเลือกผู้รับเหมาของลูกค้า ให้ไปลงทะเบียนเรียนกับองค์กรที่เป็นเจ้าของหลักสูตรโดยตรง

นี่ไม่ใช่สำเนาของคลังการจัดการบริการ มาตรฐานความปลอดภัย มาตรฐานการออกแบบ หรือระเบียบความปลอดภัยในการทำงาน ITIL, ISO/IEC 20000, ISO 22301, ISO 55001, NFPA 70E และ OSHA 1910 ล้วนมีชื่อและฉบับปรับปรุงอย่างเป็นทางการ จงอ้างอิงถึงเอกสารเหล่านั้น อย่าคัดลอกมาแปะ ผู้จัดการที่คัดลอกข้อความระเบียบองค์กรหนาหกสิบหน้ามาใส่ในแฟ้มงานประจำกะไม่ได้บริหารจัดการศูนย์ข้อมูล เขาเพียงแค่สร้างกำแพงกระดาษขึ้นมาเพื่อหลบซ่อนตัวในยามที่ชิลเลอร์ทริปเท่านั้น

หนังสือเล่มก่อนๆ ในชุดคู่มือภาคสนามนี้หยุดอยู่ที่เครื่องจักร ไฟล์ ข้อมูลการทดสอบ หรือแบบจำลอง:
- เล่ม 01 สร้างโหลดแบงก์แบบของเหลวและติดตั้งเครื่องมือวัดบนท่อแมนิโฟลด์
- เล่ม 02 อ่านรายงานสรุปฉับพลันทางความร้อนและชลศาสตร์
- เล่ม 03 ดำเนินการตรวจสอบการทดสอบระบบทั้ง 7 แผ่นงาน
- เล่ม 04 ตรวจสอบแบบจำลองพลศาสตร์ของไหลเชิงคำนวณ (CFD) เทียบกับการวัดทางกายภาพจริง

หนังสือเล่มนี้เริ่มต้นขึ้นเมื่อวิศวกรผู้ทดสอบระบบได้เก็บกระเป๋าเพลิแกนกลับไปแล้ว โหลดแบงก์ชั่วคราวถูกยกขึ้นรถบรรทุกเรียบร้อยแล้ว เซิร์ฟเวอร์ไอทีทำงานภายใต้โหลดจริง และจะต้องมีใครสักคนถูกตำหนิหากห้องข้อมูลเกิดดับมืดลง

## สิ่งที่คุณสามารถคัดลอกได้

คุณสามารถคัดลอกหัวข้อในแผ่นงานไปใส่ในสมุดบันทึกการปฏิบัติการหรือซอฟต์แวร์การจัดการไซต์ของคุณได้ แต่คุณต้องไม่คัดลอกข้อความจากหนังสือเล่มนี้ไปใส่ในข้อตกลงระดับการให้บริการ (SLA) ของลูกค้าแล้วเรียกมันว่าเป็นกฎเกณฑ์การดำเนินงานของพวกเขา ศูนย์ข้อมูลแต่ละแห่งมีใบอนุญาตปฏิบัติการ กรอบเวลาแจ้งเตือนตามสัญญา และเส้นทางการแจ้งเตือนเหตุฉุกเฉินเฉพาะตัว หนังสือเล่มนี้บอกคุณว่าเอกสารเหล่านั้นต้องบังคับใช้สิ่งใด มันไม่ได้เข้าไปแทนที่เอกสารเหล่านั้น

## การตัดสินใจที่ต้องบันทึก

- ประโยคผูกพันเดี่ยวที่วันนั้นได้รับอนุญาตให้ยืนยันได้
- มาตรฐาน กฎหมาย หรือสัญญาที่คุณจะอ้างอิงด้วยชื่อและฉบับพิมพ์ ไม่ใช่การคัดลอกแปะ
- แผ่นงานประจำวันที่คุณจะลงนามด้วยตนเองก่อนที่จะส่งมอบวิทยุสื่อสารให้แก่กะถัดไป

## เส้นแบ่งขอบเขตความรับผิดชอบทางกายภาพและโปรโตคอลการตรวจสอบกะเชิงปริมาณ

ผู้จัดการกะปฏิบัติการต้องรักษาจุดแบ่งขอบเขตความรับผิดชอบ (`DEMARC`) ทั้ง 4 วงแหวนของศูนย์ข้อมูล (Ring 1: ระบบรับไฟฟ้าและรั้วโครงการ, Ring 2: ห้องเครื่องหลักและหม้อแปลง, Ring 3: ระบบจ่ายในห้องเซิร์ฟเวอร์และ CDU ทุติยภูมิ, Ring 4: ภายในแร็คของลูกค้า) และบันทึกเกณฑ์วัดผลเชิงปริมาณต่อไปนี้ลงในแผ่นงานประจำวัน (Day Sheet):

| หมวดการตรวจสอบกะ | พารามิเตอร์ที่ตรวจวัด | ขอบเขตการทำงานปกติ | เกณฑ์สั่งหยุดงานทันที (Stop Work) / ปฏิเสธ |
| :--- | :--- | :--- | :--- |
| **เพดานโหลดระบบไฟฟ้าสำรอง 2N** | โหลดปกติบนบัส A / บัส B ($P_{\text{bus}} / P_{\text{rated}}$) | $\le 45.0\%$ (เมื่อเสีย 1 ฝั่ง โหลดรวม $\le 90.0\%$) | ปฏิเสธการจ่ายไฟแร็คใหม่ทันทีหากโหลดเกิน $45.0\%$ |
| **ไฮดรอลิกและเคมีของ CDU ทุติยภูมิ** | ความดันจ่าย $P_{\text{sup}}$, อุณหภูมิเข้าใกล้ $\Delta T_{\text{PHE}}$, ความเข้มข้น PG | $0.15\sim 0.90\,\text{MPa}$, $\Delta T_{\text{PHE}} \le 8.0\,\text{K}$, PG $25.0\% \pm 1.0\%$ | ความดันตกคร่อม $> 1.0\,\text{bar}$, ค่าการนำไฟฟ้า $> 10\,\mu\text{S/cm}$ หรือพบหยดน้ำ |
| **ใบอนุญาตทำงาน (PTW) และ LOTO** | การล็อกกุญแจ LOTO, การคายประจุ และวาล์วบายพาส | มีผู้ควบคุมของศูนย์ข้อมูลประกบ 100% และปิดงานก่อนหมดเวลา | หยุดงานทันทีหากทำนอกเหนือขั้นตอน MOP ที่อนุมัติ |
| **นาฬิกาเหตุขัดข้องและการแจ้ง SLA** | เวลาตรวจพบ ($T_0$), การเข้าสู่สภาวะปลอดภัย EOP, การแจ้งลูกค้า | P1: แจ้งข้อเท็จจริงภายใน $\le 15\,\text{นาที}$ | ห้ามใส่ข้อสันนิษฐานหรือการคาดเดาลงในใบแจ้งเหตุฉบับแรก |
