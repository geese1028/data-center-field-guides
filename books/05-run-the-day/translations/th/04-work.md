# 4. งานที่ได้รับอนุญาต

งานใดๆ ที่กระทำขึ้นในศูนย์ข้อมูลที่ใช้งานจริงโดยไม่มีวิธีการที่เป็นลายลักษณ์อักษรและผ่านการตรวจสอบแล้ว ไม่ใช่งานวิศวกรรม แต่มันคือการนำธุรกิจของลูกค้าไปเล่นการพนัน

เอกสารการปฏิบัติการที่แตกต่างกันสี่ฉบับควบคุมทุกการกระทำทางกายภาพในสถานที่ อย่าสับสนหน้าที่ของเอกสารเหล่านี้เป็นอันขาด

## ขั้นตอนปฏิบัติงานมาตรฐาน (SOP)

SOP ควบคุมการปฏิบัติงานประจำที่เป็นกิจวัตรซ้ำๆ ซึ่งโครงสร้างระบบยังคงอยู่ภายในขีดจำกัดการทำงานปกติ:
- การเดินตรวจรอบพื้นที่ทางกายภาพประจำวัน
- การเก็บตัวอย่างน้ำเพื่อตรวจสารเคมีและการทดสอบด้วยรีแฟรคโตมิเตอร์ไกลคอล
- การใช้งานวาล์วบายพาสแบบแมนนวลบนชุดปรับสภาพน้ำกระด้าง
- การตรวจสอบความดันต่างของฟิลเตอร์ตามปกติ

SOP ทุกฉบับต้องมีอยู่เป็นเอกสารที่พิมพ์และเคลือบพลาสติกวางไว้ ณ จุดปฏิบัติงานจริง (เช่น ติดตั้งอยู่ภายในตู้ CDU หรือบนผนังห้องบำบัดน้ำ) SOP ที่มีอยู่เพียงเป็นไฟล์ PDF ที่ซ่อนอยู่ในอินทราเน็ตของบริษัทนั้นไร้ประโยชน์อย่างสิ้นเชิงสำหรับช่างเทคนิคที่กำลังถือขวดเก็บตัวอย่างน้ำ

## ระเบียบวิธีปฏิบัติงาน (MOP)

MOP ควบคุมกิจกรรมที่ไม่ใช่งานประจำตามกำหนดการ ซึ่งมีการสัมผัสกับโครงสร้างพื้นฐานที่สำคัญ มีการเปลี่ยนแปลงความซ้ำซ้อนของอุปกรณ์ หรือนำมาซึ่งความเสี่ยงต่อการหยุดชะงักทางไฟฟ้าหรือทางความร้อน:
- การดึงเข้าหรือดึงออกของแอร์เซอร์กิตเบรกเกอร์ (ACB) 480V
- การตัดแยกแผ่นแลกเปลี่ยนความร้อนปฐมภูมิเพื่อล้างกรด
- การเปลี่ยนแมคคานิคอลซีลของปั๊มลูปทุติยภูมิขนาด 75 kW
- การอัปเดตเฟิร์มแวร์บนคอนโทรลเลอร์ระบบบริหารจัดการอาคาร (BMS) ส่วนกลาง

MOP ทุกฉบับต้องประกอบด้วย 6 ส่วนโครงสร้างที่บังคับ:
1. **ขอบเขตและการระบุอุปกรณ์**: ระบุทรัพย์สินด้วยป้ายแท็กอุปกรณ์ อาคาร ห้อง และพิกัดตำแหน่งอย่างชัดเจน
2. **เงื่อนไขเบื้องต้น**: ตรวจสอบว่าระบบสำรอง (N+1 หรือ 2N) ทำงานได้ 100% พร้อมใช้งานเต็มที่ และไม่มีสัญญาณเตือนภัยใดๆ ก่อนเริ่มงาน
3. **อุปกรณ์คุ้มครองความปลอดภัยส่วนบุคคล (PPE) และเครื่องมือพิเศษที่ต้องใช้**: ชุดป้องกันไฟวาบจากอาร์ก (Arc-flash suits) ประแจทอร์กที่ผ่านการสอบเทียบ เครื่องมือหุ้มฉนวน เกจวัดความดัน และชุดอุปกรณ์ดูดซับสารเคมีหก
4. **ลำดับขั้นตอนการปฏิบัติงาน**: การกระทำที่มีการระบุหมายเลขเรียงตามลำดับ พร้อมช่องทำเครื่องหมายและช่องลงนามสำหรับทั้งผู้ปฏิบัติการและผู้ตรวจสอบในทุกๆ ขั้นตอน
5. **แผนการย้อนกลับโดยละเอียด (Back-Out Plan)**: ลำดับการปฏิบัติการที่คำนวณไว้ล่วงหน้าอย่างแม่นยำเพื่อยกเลิกงานและนำศูนย์ข้อมูลกลับคืนสู่สถานะการทำงานปกติที่มีความเสถียรและมีความซ้ำซ้อน 100% ณ จุดใดๆ ในช่วงเวลาทำงาน
6. **การลงนามและการยอมรับทางเทคนิค**: การยืนยันอย่างเป็นทางการว่าอุปกรณ์ได้รับการฟื้นฟูกลับเข้าสู่การให้บริการ ได้รับการทดสอบภายใต้โหลดจริง และได้ถอดสายจั๊มเปอร์ชั่วคราว กุญแจ LOTO และเครื่องมือทั้งหมดออกแล้ว

MOP ที่ร่างขึ้นหรือแก้ไขบนคลิปบอร์ดขณะยืนอยู่หน้าตู้ไฟฟ้าที่เปิดฝาออกอยู่นั้น ก็คือร่างรายงานอุบัติการณ์ที่รอเวลาเกิดเท่านั้น หากขั้นตอนการปฏิบัติงานไม่สามารถทำได้ตามที่เขียนไว้ ช่างเทคนิคต้องหยุดงาน ถอยกลับไปยังขั้นตอนที่ปลอดภัยล่าสุด และขอความเห็นชอบทางวิศวกรรมใหม่อย่างเป็นทางการ

## ขั้นตอนปฏิบัติการฉุกเฉิน (EOP)

EOP ควบคุมการตอบสนองทันทีภายใต้ความเครียดสูงในระหว่างที่อุปกรณ์เกิดความล้มเหลวหรือเกิดภัยพิบัติ:
- การรั่วไหลที่ไม่สามารถควบคุมได้ของลูปหล่อเย็นทุติยภูมิ (> 50 LPM)
- การสูญเสียไฟฟ้าจากโครงข่ายแรงดันปานกลางของระบบสาธารณูปโภคทั้งหมด
- ความล้มเหลวร้ายแรงของสวิตช์ถ่ายโอนอัตโนมัติ (ATS)
- เพลิงไหม้บัสไฟฟ้าของโรงทำความเย็นที่ต้องกดสวิตช์ปิดระบบไฟฟ้าฉุกเฉิน (EPO)

EOP ได้รับการออกแบบมาเพื่อให้ร่างกายทำตามความจำอัตโนมัติ ต้องมีความยาวไม่เกิน **สองหน้ากระดาษ** EOP ที่มีเนื้อหาบรรยายยาวถึงยี่สิบหน้าคือตำราเรียนวิศวกรรม ไม่ใช่ขั้นตอนปฏิบัติในภาวะฉุกเฉิน

EOP ที่มีประสิทธิภาพจะระบุเพียงสามสิ่ง:
1. **การหยุด (The Stop)**: การกระทำด้วยมือทันทีเพื่อหยุดความเสียหายไม่ให้ลุกลาม (เช่น กดปุ่มวาล์วตัดแยกฉุกเฉิน `EIV-101`, ปลดเบรกเกอร์แบตเตอรี่)
2. **การเรียก (The Call)**: ระบุตำแหน่งหรือหมายเลขโทรศัพท์ที่แน่นอนเพื่อเรียกหน่วยตอบสนองเหตุฉุกเฉิน (เช่น วิทยุสื่อสารผู้จัดการเวรช่อง 1, หน่วยดับเพลิงเทศบาล)
3. **สภาวะปลอดภัยแรก (The First Safe State)**: โหมดการทำงานที่เสถียรและได้รับการตรวจสอบแล้วว่าต้องควบคุมให้คงอยู่ขณะที่ทีมจัดการอุบัติการณ์เข้ามารับช่วงต่อ (เช่น สลับโหลดไอทีที่เหลือไปยังบัส B, เปิดใช้งานปั๊มเติมไกลคอลฉุกเฉิน)

เมื่อควบคุมเข้าสู่สภาวะปลอดภัยแรกได้แล้ว EOP จะสิ้นสุดลง งานตรวจสอบ การกู้คืน หรือการซ่อมแซมต่อจากนั้นทั้งหมดจะเปลี่ยนไปสู่การปฏิบัติงานตามแผนภายใต้ MOP อย่างเป็นทางการ

## ใบอนุญาตทำงาน (Permit to Work: PTW)

ใบอนุญาตทำงานอยู่บนจุดสูงสุดของโครงสร้างระเบียบปฏิบัติ มันคือการอนุมัติทางกฎหมายและการปฏิบัติการที่ออกโดยผู้จัดการเวรปฏิบัติการ เพื่ออนุญาตให้บุคคลที่ระบุชื่อไว้สามารถดำเนินการตาม MOP ที่ได้รับอนุมัติ ภายในพื้นที่ทางกายภาพที่กำหนด และในช่วงเวลาที่แน่นอน

PTW ที่ถูกต้องจะบังคับใช้เงื่อนไขเข้มงวด 4 ประการ:
- **สถานที่**: ห้อง แถวตู้ และตู้ควบคุมที่เฉพาะเจาะจง การทำงานนอกขอบเขตใบอนุญาตถือเป็นการละเมิดความปลอดภัยโดยตรง
- **ช่วงเวลา**: เวลาเริ่มต้นและสิ้นสุดที่แน่นอน ใบอนุญาตที่หมดอายุคือคำสั่งหยุดงานทันที
- **บุคลากร**: บุคคลที่มีรายชื่อตรงกับบันทึกคุณสมบัติที่ผ่านการตรวจสอบในแฟ้มประวัติ
- **การตัดแยกพลังงานและล็อกแขวนป้าย (LOTO)**: การตรวจสอบว่าแหล่งพลังงานอันตรายทางไฟฟ้า ชลศาสตร์ ลม และเคมี ได้รับการล็อก แขวนป้าย และตรวจสอบยืนยันสภาวะพลังงานเป็นศูนย์จริง (ทดสอบก่อนสัมผัส)

```
+-------------------------------------------------------------------------+
| เกณฑ์การตรวจสอบ PTW & LOTO |
| |
| [GATE 1] แนบ MOP ที่อนุมัติพร้อมขั้นตอนการย้อนกลับที่สมบูรณ์ |
| [GATE 2] ตรวจสอบคุณสมบัติบุคคลเทียบกับเกณฑ์ความสามารถของไซต์ |
| [GATE 3] ตรวจสอบพลังงานเป็นศูนย์: วัดมิเตอร์ไฟฟ้า & ระบายแรงดันตกค้าง |
| [GATE 4] คล้องกุญแจ LOTO, แม่กุญแจสีแดง, และป้ายเตือนอันตราย |
| [GATE 5] ตรวจสอบความซ้ำซ้อน: ยืนยันว่าระบบสำรองรับโหลดได้ตามปกติ |
+-------------------------------------------------------------------------+
```

## การตรวจสอบอะไหล่สำคัญ

ห้ามเริ่มขั้นตอนการบำรุงรักษาใดๆ จนกว่าอะไหล่สำคัญที่จะใช้เปลี่ยนจะมาวางอยู่ ณ สถานที่ปฏิบัติงานจริง

"อะไหล่สำคัญ" ไม่ใช่แค่อะไหล่ชิ้นใดก็ได้ที่บังเอิญวางอยู่ในคลังสินค้า อะไหล่สำคัญคือชิ้นส่วนที่หากเสียหายหรือไม่มีอยู่ จะทำให้ไม่สามารถดำเนินการตามแผนการย้อนกลับของ MOP ได้ สำหรับการเปลี่ยนปั๊ม CDU ทุติยภูมิ อะไหล่สำคัญประกอบด้วย:
- ชุดแมคคานิคอลซีลตัวใหม่ที่ใช้อีลาสโตเมอร์ EPDM ที่ตรงตามสเปก
- ปะเก็นประกบหน้าแปลนตามสเปกโรงงานสำหรับท่อดูดและท่อจ่าย
- สารละลายโพรพิลีนไกลคอล 25% ผสมเสร็จล่วงหน้าปริมาณ 50 ลิตร
- ประแจทอร์กที่ได้รับการสอบเทียบและมีใบรับรองการสอบเทียบที่ยังไม่หมดอายุ

หากช่างเทคนิคเปิดฝาตู้ CDU ออกแล้วพบว่าไม่มีปะเก็นหน้าแปลนตัวใหม่อยู่ในกรงเก็บอะไหล่ งานจะต้องไม่เริ่มขึ้น การหวังว่าปะเก็นเก่าจะสามารถขูดออกแล้วนำกลับมาใช้ใหม่ได้โดยไม่รั่วซึม คือสาเหตุที่ทำให้ลูปหล่อเย็นทุติยภูมิพ่นไกลคอลกระจายไปทั่วบัสเวย์ 400V

## การตัดสินใจที่ต้องบันทึก

- SOP ที่ใช้งานอยู่ทั้งหมดได้รับการยืนยันว่ามีเอกสารจริงที่อ่านได้วางอยู่ ณ จุดติดตั้งอุปกรณ์
- MOP ทั้งหมดที่ได้รับอนุมัติสำหรับกะวันนี้ พร้อมบันทึกระดับผลกระทบต่อบริการ
- หมายเลขทะเบียน LOTO และหมายเลขป้ายกุญแจคล้องที่ติดตั้งบนอุปกรณ์
- เวลาหมดอายุที่แน่นอนของใบอนุญาตทำงาน (PTW) ที่เปิดอยู่ทั้งหมด
- การยืนยันว่าได้ตรวจสอบอะไหล่สำคัญด้วยสายตาและมีอยู่จริง ณ หน้างานก่อนออกใบอนุญาต
