# 0. この本の使い方

この本は、データセンターの一日を管理する人のための現場手引である。その一日とは、シフトであり、実行が許された作業であり、発生した不具合であり、そして一日の終わりに胸を張って言明できる唯一の文である。

設備運用の講習テキストではない。講習の受講に代わるものでもない。Certified Data Centre Facilities Operations Manager (CDFOM) や Certified Data Centre Facilities Operations Specialist (CDCS) は講習のコース名である。この本はそれらの講習スライド、選択式演習、試験問題を復唱しない。顧客のベンダー要件マトリクスにそれらの資格証明が必要なら、その資格を保有する正規の認証機関から講習を受講せよ。

サービスマネジメントのフレームワーク、セキュリティ規格、設計基準、安全法規の写しでもない。ITIL、ISO/IEC 20000、ISO 22301、ISO 55001、NFPA 70E、OSHA 1910 にはそれぞれ固有の規格名と改訂版がある。それらを引用せよ。そのまま貼り付けるな。60ページもの企業の紋切り型文書をシフトフォルダにコピー＆ペーストした管理者は、設備を運用したのではない。冷凍機がトリップしたときに逃げ込むための紙の壁を築いただけである。

本シリーズのこれまでの巻は、特定の機械、ファイル、試験、モデルで完結していた：
- 第1巻：液冷負荷装置を製作し、マニホールドに計装を施す。
- 第2巻：熱的・水力的な速報レポートを読み解く。
- 第3巻：コミッショニング検証の7枚のシートを実行する。
- 第4巻：数値流体力学（CFD）モデルを物理的な実測値と突き合わせて監査する。

この本は、コミッショニング技術者がペリカンケースを詰め終え、仮設負荷装置がトラックの荷台に載せられ、ITサーバーに通電され、データホールが停電したときに誰かが責任を問われる現場から始まる。

各シフトを終えるとき、1枚の「一日管理シート（当日シート）」を引き渡さなければならない。そこには、誰が当直に就いているか、どの作業が許可されたか、何が変更されたか、どこを実際に歩いて点検したか、何が故障したか、そして何を約束しないかを明確に記録する。第10章および `sheets/day.md` にその雛形がある。明日朝の着任管理者であるなら、そこから着手せよ。

## 写してよいもの

シートの見出し項目は、現場の運用日誌や施設管理ソフトウェアにそのまま複製してよい。しかし、この本の文章を顧客とのサービス品質保証契約（SLA）に貼り付け、それを自社の運用規則と呼んではならない。各施設には固有の運転許可、契約上の事前通知ウィンドウ、緊急時エスカレーション経路が存在する。この本は、それらの文書が何を強制しなければならないかを規定するものである。それらの文書に代わるものではない。

## 記録する決定

- その日一日が支えることを許された、単一の拘束力ある言明。
- 文面を丸写しせず、規格名と版数によって引用する標準規格、法規、または契約条項。
- 次のシフトへ無線機を手渡す前に、自らの手で物理的に署名する一日管理シート。
