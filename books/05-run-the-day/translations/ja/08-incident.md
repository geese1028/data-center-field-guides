# 8. 障害が発生したとき

インシデントとは、重要インフラが契約上のサービス水準を維持できなくなった事象、人命が危険に晒された事象、あるいはそのいずれかを直ちに引き起こす不安定な状態に施設が突入した事象を指す。

| **インシデント・エスカレーション時間軸** |
| :--- |
| [T = 00:00] 事象検知（テレメトリトリップ、警報ブザー、目視） |
| ↓ |
| [T + 02:00] 停止と状況把握：ブザー停止、不具合サブシステムの特定 |
| ↓ |
| [T + 05:00] EOP発動：直近の安全状態の確立、ハザードの隔離 |
| ↓ |
| [T + 10:00] 対策本部立ち上げ：障害記録の開始、役割分担 |
| ↓ |
| [T + 15:00] 顧客SLA第1報通知：確認された事実のみ送信（推測・仮説の厳禁） |
| ↓ |
| [T + 60:00] 技術的封じ込め：MOPに基づく復旧作業、定時アップデート |
| ↓ |
| [事象収束後] 根本原因分析 (RCA)：なぜなぜ分析、単一の担当・期限付き是正措置 |

サービス提供や人命安全を脅かさない単なる騒々しい警報は、煩わしいノイズに過ぎない。それを非常事態に祭り上げてはならない。逆に、機器室が静かで平穏に見えるからといって、進行中のサービス劣化を軽視することも絶対に許されない。インシデントを測る唯一の尺度は、サービス提供の成否と人員の安全である。

## インシデント重大度分類

すべての異常事象は、検知から2分以内に以下の3つの厳格な重大度ティアのいずれかに分類されなければならない：

**インシデント重大度分類表**

| ティア 分類 | 運用の影響度 顧客通知要件 |  |  |
| :--- | :--- | :--- | :--- |
| P1 クリティ | カル IT負荷に対する電力 | または冷却の <= 15分以内通知 |  |
| 全喪失；人命安 | 全に関わる事態 毎時アップ | デート |  |

## 最初の1時間：インシデント時計

有事の現場において、人間の記憶はアドレナリンによって急速に劣化する。技術員は行動の順序を取り違え、管理者は20分間の逡巡を「5分で下した果断な決断」として美化して記憶する。

当直管理者は、事象が発生したまさにその分から、改ざん不能なタイムスタンプ付きの**「障害クロノロジー日誌」**を開始しなければならない：

| **障害クロノロジー日誌** |
| :--- |
| [09:14:22] EPMS：B系統受電遮断器 B-SWG-02 瞬時過電流トリップを受報 |
| [09:16:00] 当直管理者：EOP-E-04（2N B系統喪失対応）の発動を指示 |
| [09:18:45] 技術員 陳：A系統が全負荷の82%を正常給電中であることを確認 |
| [09:21:10] 安全状態1確立：IT負荷は片系受電にて安定 |
| [09:24:00] 顧客SLA第1報を管理ポータルより送信（T+10分） |
| [09:32:00] A系統受電盤の赤外線走査実施、表面温度58°C、安定を確認 |
| [09:45:00] 受配電盤メーカー緊急窓口へ連絡、受付番号 #84920 発行 |

すべての事象を正確なタイムスタンプとともに記録せよ：
- 監視コンソールで警報が検知された正確な分。
- 物理計器で何が観察されたか（誰かの推測ではなく目視事実）。
- 実行された正確なEOP番号、達成された安全状態、およびその状態が確認された分。
- 障害対応チームに招集された全員の氏名。
- 顧客通知が送信された分と、送信された正確な文面。
- 残余の健全系統を保護するために、意図的に「実施を拒絶した」または「延期した」操作。

## 反射的な安全状態の確立 vs. 英雄的トラブルシューティング

警報が鳴り響き機器がトリップしたとき、訓練されていない技術員が反射的に起こす行動は、遮断器のリセットボタンを押したり、バイパス弁を慌てて開けたりして、落ちた系統を何とか復旧させようとする「英雄的トラブルシューティング」である。

この衝動的な英雄気取りこそが、軽微な単一故障を全系ブラックアウトへと拡大させる元凶である：
- 瞬時過電流でトリップした遮断器は、下流の致命的な相間短絡事故を遮断した可能性がある。原因調査なしにその遮断器を再投入すれば、爆発的なアークフラッシュを引き起こし、配電盤列全体を破壊することになる。
- 低吸込圧力でトリップした二次CDUポンプは、膨張タンクの枯渇や配管の破断を示している可能性がある。原因を確認せずに待機ポンプを強制起動すれば、メカニカルシールがドライ回転で焼き付き、モーターが全損する。

インシデント時における絶対的な運用鉄則は以下の通りである：
1. **緊急対応手順書（EOP）を実行**し、事前に設計された直近の「安全状態（Safe State）」を確立する。
2. **手を止めよ（Stop）**。操作盤から手を離せ。
3. 生き残った冗長系統が安定して負荷を担っていることを確認する。
4. 承認されたMOPのもとで、体系的な原因調査を開始する。

サイレンが鳴り響く中で通電中の機器を直そうとするヒーローはアクション映画の登場人物であり、産業データセンターには不要である。産業データセンターで称賛されるのは、設備を直ちに安全状態へ落ち着かせ、一歩下がって手順に従う規律ある技術者である。

## 最初の顧客通知から「仮説」を排除せよ

顧客に対するインシデント第1報を起草する際は、以下の鉄則を死守せよ：**「確認された物理的事実のみを報告せよ。仮説や推測は一切書くな。」**

| **顧客通知の規律** |
| :--- |
| [許可される事実通知の例] |
| 「UTC 09:14、電気B系統フィーダーにおいて自動トリップが発生しました。 |
| すべての重要ITサーバーホールは、冗長構成のA系統を通じて給電を継続 |
| しています。設備は現在N-1状態で安全に稼働中です。 |
| 現在、運用チームがB系統トリップの原因調査を実施しています。 |
| 次回の公式状況報告は UTC 10:15 に提供いたします。」 |
| [禁止される推測的通知の例] |
| 「工事業者がB系統の継電器に誤って触れたか、あるいは近くで落雷が |
| あったのではないかと考えています。現在遮断器のリセットを試みており、 |
| 10分以内に復旧する見込みです。」 |

第1報で推測を伝達し、その後の詳細調査でそれが誤りであったと判明した場合：
- 運用能力に対する顧客の信頼は完全に失墜する。
- 顧客の法務チームに「重大な過失」を主張する武器を与えることになる。
- 技術チームは技術的復旧作業に集中すべき貴重な時間を、初期報告の弁明と説明修正に奪われることになる。

症状、発生時刻、影響範囲、現在の安全状態、次回報告予定時刻のみを告げよ。それ以上の余計なことは一切口にするな。

## 単一の担当・期限付き是正措置（RCA）

機器が再通電され、警報が解除されたからといって、インシデントが完了したわけではない。正式な根本原因分析（RCA）が実施され、**「具体的で担当者と期限が明記された単一の是正措置」**として結実したときにのみ、インシデントはクローズする。

関係者が集まって恐怖を語り合い、「今後はもっと慎重に作業しよう」と結論づけるような事後検討会は完全な時間の浪費である。「慎重になること」はエンジニアリングの管理手法ではない。

真正な是正措置とは、以下のいずれかを物理的に変えるものである：
- エンジニアリング設計（例：共通要因トリップを排除するためのインターポーザー隔離リレーの追設）。
- 保守手順（例：480V端子台のダブルトルクチェックを義務付けるMOP改訂）。
- 巡回点検項目（例：CDU点検リストへの日次屈折計サンプリングの追加）。
- 工具や予備品（例：配管への空気混入を防ぐ真空充填装置の配備）。

是正措置には単一の責任者名と確固たる完了期日が設定されなければならない。検討会が5つもの曖昧な提言を並べた場合、そのどれ一つとして実行されない。最も効果的な構造的対策を1つだけ選定し、担当者を割り当て、日々の引き継ぎ日誌で完了まで進捗を追跡せよ。

## 記録する決定

- インシデント重大度分類（P1 / P2 / P3）および正確な検知時刻。
- すべての操作、到達した安全状態、対応人員を記録したクロノロジー日誌。
- 推測的仮説が完全に排除されていることが確認された顧客第1報通知の写し。
- 定常実負荷条件下で署名された技術的復旧確認。
- 根本原因分析から導出された、担当者と期日が明記された単一の是正措置。

## 物理的責任分界（デマーケション）と定量的シフト監査プロトコル

シフト運用管理者は、設備の物理的境界（Ring 1: 受電・外構、Ring 2: 中央熱源・特高変電、Ring 3: ホール配電・二次CDU、Ring 4: 顧客ラック内部）における責任分界点（`DEMARC`）を厳格に維持し、以下の定量的監査基準を当日シート（Day Sheet）に記録しなければならない。

| シフト監査領域 | 監視・計測パラメータ | 正常運用エンベロープ | 即時介入・作業中止（Stop Work）閾値 |
| :--- | :--- | :--- | :--- |
| **2N受配電系統の負荷率上限** | バスA / バスB 定常負荷率 ($P_{\text{bus}} / P_{\text{rated}}$) | $\le 45.0\%$（片系喪失時 $\le 90.0\%$） | $> 45.0\%$ での新規ラック通電要求の即時拒絶 |
| **二次冷却ループ（CDU）水理・化学** | 供給圧力 $P_{\text{sup}}$、アプローチ温度 $\Delta T_{\text{PHE}}$、PG濃度 | $0.15\sim 0.90\,\text{MPa}$, $\Delta T_{\text{PHE}} \le 8.0\,\text{K}$, PG $25.0\% \pm 1.0\%$ | 差圧 $> 1.0\,\text{bar}$、導電率 $> 10\,\mu\text{S/cm}$、またはカプラー液滴 |
| **作業許可（PTW）とゼロエネルギー検証** | LOTO施錠、残留電荷放電、バイパス弁閉止確認 | 100% 現場ホスト同行・失効時刻前の完全復旧 | 承認MOPからの逸脱、または「ついで作業」の即時中止 |
| **インシデント時計とSLA通知** | 事象検知（$T_0$）、EOP安全状態確立、顧客第1報 | P1: $T_0 + 15\,\text{min}$ 以内に事実のみ通知 | 未確認の推測（仮説）の通知文への混入禁止 |
