# 7. ベンダーと外部工事業者

データセンター内で作業する外部ベンダーや設備メーカーのサービス技術員は、あなたの法的な作業許可のもとで動く「一対の手」である。彼らは、電気室に単独で放置してよい自律的な存在ではない。

```
+-----------------------------------------------------------------------------+
| ベンダー統制ゲートウェイ |
| |
| [GATE 1] 入構前作業範囲定義：具体的対象、承認済MOP、工具持込登録 |
| | |
| [GATE 2] セキュリティ＆安全ブリーフィング：入構証、LOTO検証、PPE確認 |
| | |
| [GATE 3] 専任エスコート：有資格社内技術員の常時同行、単独行動の厳禁 |
| | |
| [GATE 4] 作業境界の維持：MOP手順を逸脱した瞬間の作業停止（SWA） |
| | |
| [GATE 5] 技術的完了確認：物理点検、撤去部品回収、現場清掃の監査 |
| | |
| [GATE 6] 商務との分離：現場技術完了確認 != 請求書の検収受入 |
+-----------------------------------------------------------------------------+
```

入構証にサインし、蓄電池室を指差して自分のオフィスに戻る管理者は、施設の管理を放棄している。そのベンダーがラチェットレンチを480V母線に落としたり、誤った弁を開けてしまった場合、その障害の責任はベンダーではなく管理者に帰属する。

## 来所前の明確な作業範囲定義

ベンダーがセキュリティゲートを通過する前に、作業範囲が書面で厳格に定められていなければならない：
- 触れることが許可された正確な機器番号（例：「ターボ冷凍機 CH-02 のコンプレッサーオイルフィルター交換のみ」）。
- 触れることが固く禁じられた機器（例：「冷却水隔離バルブおよび隣接する冷凍機 CH-01 の制御盤には一切触れてはならない」）。
- 「作業完了」の定義：機器が修復されたと見なすために検証すべき具体的な物理試験項目、圧力値、または運転マイルストーン。
- 退構前に提出すべき成果物：メーカー工場サービス報告書、校正済み測定器の試験ログ、取り付けられた全交換部品のシリアル番号、および原因究明用として引き渡される全不具合部品の現物。

「UPSシステムの年次定期点検」などと書かれた曖昧な作業指示書は、事故への招待状である。境界も、試験限界も、運用上の制約も定義されていない。作業の72時間前までに項目ごとの詳細なMOPが提出されない場合、来所予定を取り消せ。

## 専任サイトホスト（社内立会者）

重要受配電室、熱源機械室、またはサーバーホール内で作業するすべてのベンダーには、当直シフトチームから専任の有資格社内技術員（サイトホスト）を同行させなければならない。

サイトホストはベンダーの肉体労働を手伝うのではない。ホストの任務は以下の通りである：
1. **作業境界の監視と強制**：ベンダーの行動を常時監視する。技術員が隣接する盤に手を伸ばしたり、MOPに記載のないバルブを回そうとした場合、ホストは即座に作業停止（Stop Work）を命じる。
2. **緊急時初期対応**：アークフラッシュ、薬品飛散、機器トリップが発生した場合、ホストは現場の緊急対応手順（EOP）を発動し、救護を要請し、安全隔離を指揮する。
3. **エスコート統制**：ベンダーを承認された物理的作業エリア内に留め、本番サーバルーム内を監督なしで徘徊させない。

### 気軽な作業拡大（「ついでに見ておきましょうか」）の撲滅

データセンター運用において最も危険な言葉は、ベンダー技術員が口にする以下のセリフである：
> *「盤のカバーを開けましたので、ついでにこの地絡継電器の感度設定も調整しておきましょうか？」*

この申し出に対する答えは、例外なく断固たる**「ノー」**である。

機器を開けた状態で見つかった都合の良い追加作業は、親切な好意ではない。事前審査も許可もない勝手なエンジニアリング変更である：
- 承認されたMOPが存在しない。
- 変更諮問委員会（CAB）のリスク審査を受けていない。
- 計算された切り戻し計画がない。
- 中央監視室に異常運転状態として登録されていない。

作業中に予期せぬ不具合や推奨調整事項が発見された場合、現場の不具合台帳にそれを記録せよ。その項目は将来の正規の保守ウィンドウにおいて、個別の許可証のもとで計画・審査・実行される。本番設備において自発的な作業拡大を許してはならない。

## 技術的検収と商用支払承認の分離

ベンダーの請求締め日の都合によって、技術的検収の基準を妥協させてはならない。

技術的検収とは、機器が完全な運用能力を取り戻したことを証明する厳密なエンジニアリング検証である：
- 実負荷条件下で運転され、異常振動、温度異常、流体漏れがないこと。
- 機器と中央BMS/EPMS間のデジタル通信（Modbus, BACnet, SNMP）が復旧・検証されていること。
- 作業エリアが清掃され、ゴミ、切断されたインシュロック、電線くずが全数回収され、すべての保護カバー、デッドフロントシールド、安全インターロックが元通り復旧されていること。
- 交換された古い不具合部品（焼損したコンタクタ、摩耗したメカニカルシール、劣化したコンデンサ）にタグが付けられ、箱詰めされ、調査用として隔離保管庫に搬入されていること。

ベンダーの退構時に署名する書類は、あくまで「実施された作業の現場確認書」に過ぎない。

これは請求書の商用的な受入検収を意味するものではなく、後日潜在的な欠陥が判明した場合に施設所有者が保証請求を行う権利を放棄するものでもない。実負荷運転が完了する前に商用の無条件検収書への署名を迫られた場合、シートにこう付記せよ：*「目視による作業実施を確認。機能的な技術検収は24時間の実負荷連続運転後に判定。」*

## 記録する決定

- 事前承認されたベンダーの作業範囲および添付MOPの管理番号。
- ベンダーに割り当てられた専任の当直社内ホスト氏名。
- 作業境界の遵守確認：書面MOPからの逸脱ゼロ、または作業停止命令の記録。
- 現場物理点検および実負荷運転検証の後にのみ署名された技術検収。
- 取り付けられた部品のシリアル番号および回収された不具合部品の隔離保管場所。
