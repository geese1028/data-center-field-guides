# 4. 許された作業

検証され承認された手順書を持たずに本番データセンター内で作業を行うことは、エンジニアリングではない。顧客の事業をチップにした単なるギャンブルである。

```
+-----------------------------------------------------------------------------+
| 現場運用文書ピラミッド |
| |
| /\ |
| / \ |
| / PTW\ 作業許可証 (PTW) |
| /------\ 誰が、どこで、いつ、どの工具で |
| / \ |
| / MOP \ 個別作業手順書 (MOP) |
| /------------\ 手順、安全隔離、切り戻し計画 |
| / \ |
| / SOP \ 標準作業手順書 (SOP) |
| /------------------\ 定常巡回点検、日常バルブ操作 |
| / \ |
| / EOP \ 緊急時対応手順書 (EOP) |
| /------------------------\ 身体が反射で動く安全状態の確立 |
+-----------------------------------------------------------------------------+
```

![Procedural Governance Pyramid](../figures/fig-02-sop-mop-eop-governance-pyramid.png)

構内で行われるすべての物理的操作は、4つの異なる運用文書によって統制される。それらの役割を決して混同してはならない。

## 標準作業手順書（SOP）

SOPは、システム構成が正常運転限界内に維持される反復的・定常的な日常作業を規定する：
- 毎日の物理巡回点検の実施。
- 冷却水サンプリングおよびグリコール屈折計測定。
- 軟水装置手動バイパス弁の定期操作。
- エアフィルター差圧の確認と清掃。

すべてのSOPは、作業現場（CDU筐体内や水処理室の壁面など）にラミネート加工された印刷物として物理的に備え付けられていなければならない。社内イントラネットの奥深くに保存されたPDFとしてしか存在しないSOPは、現場でサンプル瓶を手にする技術員にとって存在しないのと同じである。

## 個別作業手順書（MOP）

MOPは、重要インフラに触れ、設備の冗長性を変化させ、電力や冷却の供給にリスクをもたらす予定された非定常作業を規定する：
- 480V気中遮断器（ACB）の引出（ラックアウト）および挿入（ラックイン）。
- 洗浄保守のための一次プレート式熱交換器の隔離。
- 75kW二次循環ポンプのメカニカルシール交換。
- 中央監視システム（BMS）コントローラーのファームウェア更新。

すべてのMOPには、以下の6つの必須セクションが含まれていなければならない：
1. **作業範囲と機器識別**：機器固有タグ、棟、室名、グリッド座標を明記。
2. **前提条件の確認**：予備系統（N+1または2N）が100%健全に稼働し、警報が存在しないことの事前検証。
3. **必要保護具（PPE）および専用工具**：アークフラッシュ防護服、校正済みトルクレンチ、絶縁工具、圧力計、漏液回収キット。
4. **ステップ・バイ・ステップの実行順序**：全手順に連番が付され、各工程に実施者と確認者のサイン欄・チェックボックスを設置。
5. **詳細な切り戻し計画（Back-Out Plan）**：作業を中止し、プラントを100%安定した健全冗長状態へ安全に戻すための事前定義された手順。
6. **復旧検証と技術的検収**：実負荷下での健全性確認、仮設短絡線（ジャンパー）やLOTO南京錠の全数撤去の確認。

開いた電気盤の前に立ち、クリップボードの上で即興で書かれたり修正されたMOPは、事故報告書の下書きに他ならない。手順通りの作業が不可能な事態に直面した場合、技術員は直ちに作業を停止し、直前の安全な状態まで切り戻し、正式な設計再承認を求めなければならない。

## 緊急時対応手順書（EOP）

EOPは、機器の故障や破局的事象が発生した際、極度のストレス下で反射的に実行される即時対応を規定する：
- 二次冷却ループの制御不能な大規模漏水（> 50 LPM）。
- 商用系統電源の全喪失（ブラックアウト）。
- 自動切替開閉器（ATS）の致命的故障。
- 冷凍機電気室の火災に伴う緊急電源遮断（EPO）。

EOPは反射的な身体記憶のために設計されている。決して**2ページ**を超えてはならない。20ページにも及ぶ講釈が並んだEOPは教科書であり、非常手順書ではない。

優れたEOPが規定するのは以下の3項目のみである：
1. **停止（The Stop）**：被害拡大を食い止める即時手動操作（緊急遮断弁ボタン `EIV-101` の押下、蓄電池遮断器の開放など）。
2. **呼出（The Call）**：緊急招集先または電話番号（当直管理者無線チャンネル1、公設消防など）。
3. **最初の安全状態（The First Safe State）**：インシデント対策本部が立ち上がるまで保持すべき検証済みの安定モード（IT負荷を健全なB系統に維持、緊急グリコール補給ポンプの投入など）。

最初の安全状態が確立された時点で、EOPはその役割を終える。その後の調査、復旧、修理作業は、すべて承認済みMOPによる計画作業へと直ちに移行する。

## 作業許可証（PTW）

作業許可証（Permit to Work）は、手続きピラミッドの頂点に位置する。これは、指名された作業員が承認済みMOPに基づき、特定の場所で、指定された時間枠内に作業を行うことを当直管理者が法的に承認する文書である。

有効な作業許可証は、以下の4つの制約を厳格に強制する：
- **作業場所**：特定の部屋、アイル、盤番号。境界外での作業は重大な安全違反である。
- **作業時間枠**：明確な開始刻限と終了刻限。失効した許可証は即座の作業停止命令を意味する。
- **作業人員**：現場に資格記録が保管されている指名作業員。
- **施錠・標識（LOTO）**：危険な電気、流体、空気圧、化学エネルギーが物理的に施錠され、タグが付けられ、触れる前の無電圧・無圧確認（検電・脱圧）が行われたことの検証。

```
+-------------------------------------------------------------------------+
| PTWおよびLOTO監査ゲート |
| |
| [GATE 1] 完全な切り戻し手順を含む承認済みMOPの添付 |
| [GATE 2] 現場作業資格マトリクスに照らした作業員の資格照合 |
| [GATE 3] エネルギーゼロ検証：テスター検電および圧力ブリード開放 |
| [GATE 4] 物理的なLOTOハスプ、赤色南京錠、危険札の取付け |
| [GATE 5] 冗長系統確認：予備系統が健全に負荷を担っていることの確認 |
+-------------------------------------------------------------------------+
```

## 重要予備品の現品確認

必要な重要交換部品が作業現場に物理的に届いていない限り、いかなる保守作業も開始してはならない。

「重要予備品」とは、倉庫に適当に転がっている予備品のことではない。その部品が手元になければ、MOPに記載された切り戻し手順を実行できなくなるまさにその部品を指す。二次CDUポンプの交換作業であれば、以下の部品が現認されなければならない：
- EPDMエラストマーが適合した交換用メカニカルシール一式。
- 吸込・吐出フランジ接続用の純正仕様ガスケット一式。
- 事前混合済みの25%プロピレングリコール水溶液 50リットル。
- 有効な校正証明書を備えたトルクレンチ。

技術員がCDUの筐体を開けた後で、交換用フランジガスケットが部品棚にないことに気づくようでは作業資格がない。「古いガスケットを削り落として再利用しても漏れないだろう」という希望的観測こそが、二次冷却ループのグリコールを400V母線ダクトに噴き出させる原因である。

## 記録する決定

- 機器に物理的かつ可読な状態で備え付けられていることが確認された、すべての現行SOP。
- 本日のシフトで承認されたすべてのMOPと、そのサービス影響レベル。
- 機器に適用されたLOTO登録台帳番号と物理南京錠のタグID。
- 有効なすべての作業許可証（PTW）の正確な失効時刻。
- 作業着手前に、すべての重要予備品が現場で目視確認されたことの検証記録。
