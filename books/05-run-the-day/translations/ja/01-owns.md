# 1. 今日の管理者が保有するもの

設計、顧客のアプリケーションソフトウェア、ベンダーの工場保証のすべてを同時に抱え込もうとする管理者は、そのどれ一つとして管理できていない。今日あなたが保有するのは、設備の運転状態、設備に触れることを許された人員、そして何が実行されたかの改ざん不能な記録である。

顧客の分散データベースがクラスタ間でデータを正しくシャーディングしているかどうかは、あなたの責任範囲ではない。あなたが保有するのは、顧客に販売した二重化電源供給、冷却ループの流量、物理セキュリティの防壁が、契約上署名されたパラメータ範囲内で厳格に維持されているかどうかである。契約書に規定のない事項について、日々の運用ログで勝手な約束を捏造してはならない。電話会議で怒鳴り散らす顧客の技術責任者は、契約の新しい条項ではない。

プラントの再設計もあなたの保有物ではない。受配電設備や二次冷却ループの故障モードを変えてしまうような変更は、専門家による査読、保護継電器の協調検討、経営幹部の承認を必要とする設備投資プロジェクト（CAPEX）である。日々の運用部門がそれを提案することはあっても、定期保守ウィンドウに紛れ込ませて「日常的な運用の微調整」と呼ぶことは断じて許されない。電気単線結線図（SLD）や配管計装図（P&ID）の描き直しを伴う作業であるなら、それは今日の保守ではない。直ちに工具を止めよ。

受付の壁に掲げられた額入りの認定証も、あなたが保有するものではない。ISO 9001 の盾、Uptime Institute Tier IV 設計認証、企業のサステナビリティ表彰は、今日のシフトが適正に運用されたことの証拠にはならない。証拠とは「当日シート」そのものである。現場にいる資格保有オペレーターの氏名、有効な作業許可証、記録された物理巡回点検、そして隠蔽を拒絶したインシデントの記録である。

## 最初の30分間

監視ダッシュボードを開き、メールをチェックし、コーヒーを口にする前に、まず以下の4項目を精査せよ：

1. **前シフトから引き継がれた異常縮退（Impairments）**：自動起動から除外されロックアウトされた非常用発電機、VESDA盤で無効化された防排煙ゾーン、ポンプ1台バイパス運転中の二次冷却分配ユニット（CDU）、静止形バイパス運転中の無停電電源装置（UPS）など。
2. **現在もオープン状態の作業許可証と、それぞれの正確な失効時刻**：作業許可証（Permit to Work: PTW）とはリスクの一時的な貸出である。許可が06:00に失効しているにもかかわらず、特別高圧受電室にベンダーがまだ残っているなら、設備は不正な無許可状態で稼働している。
3. **未解決のインシデントと、各チケットの主担当者**：夜間にインシデントが発生した場合、誰が技術リードを持ち、どのような安全状態（Safe State）が確立されたかを確認せよ。
4. **本日実行ウィンドウを迎える変更作業と、リスクを正式に受諾した責任者**：予定されているすべての変更作業に対し、明確な切り戻し手順（バックアウトプラン）を備えた承認済み手順書（MOP）が存在することを確認せよ。

```
+-------------------------------------------------------------------------+
| 引き継ぎ前の4大必須確認項目 |
| |
| [1] 稼働中の異常縮退 --> 消火停止、バイパス弁、UPS N-1運転 |
| [2] オープン許可証 --> 作業場所、作業範囲、正確な失効刻限 |
| [3] 未解決障害 --> 重大度、安全隔離状態、指名された主担当者 |
| [4] 本日の変更作業 --> 承認済MOP、リスク受諾者、切り戻し手順 |
+-------------------------------------------------------------------------+
```

引き継ぎログにこれら4項目のいずれか一つでも欠けているなら、引き継ぎは成立していない。無線機を受け取ってはならない。ログに署名してはならない。不完全な引き継ぎに署名する施設管理者は、過去12時間の間に生じたすべての潜在的不具合、無効化された安全インターロック、記録されていない機器トリップの責任をすべて引き受けることになる。

4項目を確認したら、ベンダーや工事業者がセキュリティゲートに到着する前に、本日の作業が物理的に行われる現場を歩け。対象の配電盤、隔離バルブ、サービス通路を自らの目で点検せよ。現場の物理的状況により、書面の手順通りに機器を安全隔離することが不可能であるなら、その手順書は間違っている。作業を中止せよ。機器のカバーを開けてしまってから、手動隔離弁が固着していることや、バイパス遮断器が南京錠で施錠されていることに気づくような事態は絶対に避けなければならない。

朝の慌ただしさが始まる前に、その日一日を拘束する単一の言明を書き下ろせ。プロフェッショナルな現場において、その一文は意図的に退屈で堅実なものである：
> *「重要電源および冷却インフラは契約SLAの許容範囲を完全に維持した。すべての承認済み保守作業は承認手順書（MOP）に基づき無停止で完了した。構内に記録のない異常縮退は存在しない。」*

シフト終了時にこの文に偽りなく署名できないなら、たとえ経営陣向けの監視ダッシュボードがすべて緑色に点灯していようとも、その日の運用は失敗であったということである。

## 委譲してはならないもの

バルブのハンドルを回すこと、480V遮断器を引き出す（ラックアウトする）こと、バグフィルター前後の差圧を測定することは委譲してよい。しかし、以下の3点を委譲することは絶対に許されない：
- 施設が契約SLAの範囲内で稼働し続けているという判断。
- 本番系に影響を及ぼす可能性のある変更ウィンドウの開始承認。
- 顧客への公式なインシデント通知を発信するという決定。

これら3つの責任は、当直の有資格運用管理者、あるいはシフト名簿に書面で正式に指定された代理者のみに帰属する。社内チャットグループは指定代理者ではない。

## 記録する決定

- 契約書の正確な題名と箇条番号によって引用された、当日の運用サービス基準。
- 本日顧客に対して明示的に「約束しない」と定めた境界。
- 引き継ぎ時の4大確認項目：現認済みか、不備として指摘されたか。
- シフト終了時に自ら署名する拘束力ある締めの言明。
