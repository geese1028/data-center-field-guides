# 2. シフトに就く人々

データセンターはソフトウェアのテレメトリだけで動いているのではない。プラントの床を歩く技術者の能力、公的資格、そして物理的な規律によって動いている。マスターキーを持つ人員の正確な保有資格を把握していないなら、あなたはその設備を管理できていない。

```
+-----------------------------------------------------------------------------+
| シフト資格要件および作業制限マトリクス |
| |
| 役割 必要資格 承認される作業範囲 |
| ------------------ ---------------------------- ----------------------- |
| 当直管理者 CDFOM / 統括運用責任者資格 全体SLA管理、作業許可発効|
| 電気主任技術者 特高・高圧・低圧電気取扱資格 開閉器、変圧器、配電設備 |
| 冷却専門技術者 冷凍空調技士 / 冷媒取扱資格 冷凍機、CDU、グリコール |
| シフト技術員 データセンター設備運用技術資格 巡回点検、計測、ログ記入 |
| 安全専任員/案内者 安全衛生教育受講 / 救急救命 ベンダー監督、LOTO立会 |
+-----------------------------------------------------------------------------+
```

## 法的資格要件

メガワット級の液冷設備と数十メガボルトアンペアの特高受電設備を擁する超高密度AIデータセンターにおいて、資格を持たない無専門の技術員は致命的なリスク要因である。現場作業には法定資格が不可欠である：
- **電気設備作業**：特別高圧（10kV/35kV等）または低圧（400V/480V）開閉器の切替、引出、活線近接試験は、有効な公的電気資格を保持する有資格電気技術者のみが実施しなければならない。
- **冷却・化学作業**：ターボ冷凍機、冷却塔、一次・二次ポンプステーションの操作は、高圧ガス・冷媒取扱および産業水処理の認証を受けた冷凍空調技術者が担当しなければならない。

OpenViking運用指針（`ALZJ-YW-2.6XZ10`）に基づき、二次冷却分配装置（CDU）、一次施設水系統（FWS）、ラックマニホールドに関わる液冷作業には、化学殺菌剤、グリコール濃度測定、漏液封じ込めプロトコルに関する正式な技能訓練の受講証明が義務付けられている。

高圧開閉作業の法的資格を持たない技術員の名前を、電気切替作業票に記載してはならない。資格のない工事業者が分電盤の扉を開けているのを発見した場合、直ちに作業を停止させよ。

## ツーマンルール（Two-Person Rule）

基幹系統の電気切替、高圧機器の引出（ラックイン／ラックアウト）、一次冷却ループのバルブ隔離作業を、単独（ワンマン）で実施することは固く禁じられている。

ツーマンルールには以下の2名が必須である：
1. **作業実施者（Performer）**：承認された個別手順書（MOP）を保持し、操作スイッチ、遮断器ハンドル、隔離弁に物理的に触れる有資格技術者。
2. **作業確認者（Checker）**：実施者の直背後に立ち、印刷された手順書を保持し、各手順を声に出して読み上げ、盤の機器銘板番号（例：操作前に遮断器の銘板 `SWG-01-4A` が作業票と完全一致すること）を指差し確認し、非常停止の即応体制を維持する同等資格の技術者。

確認者の単一の任務は「検証と安全確保」である。実施者が誤った遮断器ハンドルに手を伸ばしたり、順序の違うバルブを回そうとした場合、確認者は即座に作業を静止させる絶対的な権限を持つ。

```
+-------------------------------------------------------------------------+
| ツーマンルール |
| |
| +------------------+ +------------------+ |
| | 作 業 確 認 者 | | 作 業 実 施 者 | |
| | MOP手順書を保持 | | スイッチに触れる | |
| | 手順を声出し復唱 | ----------> | 銘板を指差し確認 | |
| | 機器タグを照合 | | 動作を実行 | |
| | 即時停止権限保持 | | 完了状態を報告 | |
| +------------------+ +------------------+ |
+-------------------------------------------------------------------------+
```

## 作業停止権限（Stop Work Authority: SWA）

上級運用ディレクターから見習いの通線工に至るまで、構内に立ち入るすべての個人は、無条件の「作業停止権限（SWA）」を保有している。

以下の事態が生じた場合、例外なく作業停止権限を発動しなければならない：
- 現場の物理的状況が、承認手順書（MOP）に記された前提条件と乖離している場合。
- 中央監視盤（BMS）や電力監視システム（EPMS）で予期せぬ警報が発報した場合。
- 電気設備の近傍で水滴、液溜まり、異臭（オゾン臭や焦げ臭）が検知された場合。
- 規定の安全防護柵、個人用保護具（PPE）、施錠・標識（LOTO）の南京錠に欠落や破損がある場合。
- 作業員が次の手順に対して少しでも迷いや疑問を抱いた場合。

作業停止権限が発動された場合：
1. 設備を直ちに、手順書に定義された直近の安定した安全状態に置く。
2. 工具を置き、それ以上の弁やスイッチを一切操作しない。
3. 当直管理者を直ちに現場に呼び出す。
4. 曖昧さが完全に解消され、作業許可証に書面で記録された後にのみ作業を再開する。

正当な理由で作業停止を発動した技術者や工事業者を叱責したり、処罰したり、問い詰めたりすることは固く禁じられている。工程の遅れを恐れて技術者が作業停止の発動をためらう現場は、メガワット規模の全系停電を待っている現場に他ならない。

## 30分間の合同ウォークスルー

中央監視室のデスクに座り、コーヒーを飲みながらシフト引き継ぎを済ませてはならない。現場を見ない引き継ぎは職務放棄である。

着任管理者と離任管理者は、当日シートに署名する前に、施設内の6つの重要ゾーンを30分間かけて二人で物理的に歩いて点検しなければならない：
1. **特別高圧・高圧受電室**：35kV/10kV開閉器、遮断器のスプリング蓄勢表示器、SF6ガス圧計、制御用直流電源の蓄電池充電器の状態を確認する。
2. **変圧器室**：モールド変圧器や油入変圧器の巻線温度（T < 90°C であること）、強制冷却ファンの動作、異常な電磁音・高調波うなりがないかを確認する。
3. **UPSおよび蓄電池室**：直流母線の浮動充電電圧、個々の蓄電池ブロック温度（T < 25°C）、端子の腐食や電槽の膨れ、水素排気ファンの通風を確認する。
4. **熱源プラント（中央冷凍機・ポンプ室）**：凝縮器アプローチ温度（ΔT_approach ≤ 1.5 K）、油圧、インバータ（VFD）周波数、異常振動を確認する。
5. **CDU液冷ステーション**：一次・二次側の圧力（$0.15 \sim 0.90 \text{MPa}$）、ポンプ差圧（ΔP < 1.0 bar）、膨張タンク液面、ドレン受皿内の漏液の有無を確認する。
6. **AIホワイトスペース（サーバルーム）**：ホットアイル・コールドアイルを歩き、PDUの熱的ホットスポット、床下差圧（ΔP ≥ 5 Pa）、クイックディスコネクト継手（FD83/UQD）のにじみを確認する。

両管理者は必ず肩を並べて全ルートを歩く。離任管理者が現場の歩行点検を拒否した場合、着任管理者はすべての機器が未検証状態にあると見なし、引き継ぎログに拒絶の事実を記録せよ。

## 記録する決定

- 当直員全員の氏名、公的資格番号、および有効期限。
- 高圧電気および重要流体作業においてツーマンルールが遵守されたことの確認。
- シフト中に作業停止権限（SWA）が発動された場合の、その原因と解決記録。
- 着任・離任の両管理者が署名した30分間合同ウォークスルーの完了記録。
