# 6. シフト巡回点検

テレメトリのダッシュボードは嘘をつく。中央監視システム（BMS）の圧力トランスデューサーは校正ドリフトを起こす。光電式煙感知器は埃を吸い込んで正常信号を出し続ける。測温抵抗体（RTD）は上限に振り切れたままソフトウェアのバグで値が固定されることがある。

## 五感による点検規律

本番データセンターのあらゆるエリアは、4つの感覚チャンネルを通じて監査されなければならない：
1. **視覚**：水滴、染み、変色、錆、ボルトの緩み、コンデンサの膨らみ、過熱を示す塗装の焦げや水疱を目視し、アナログ計器の指針とデジタルテレメトリの数値を照合する。
2. **聴覚**：ポンプケーシング内のキャビテーション音（砂利を汲み上げているような音）、変圧器の鉄心緩みによるうなり音、ファンモーターのベアリング鳴き、アイルキャッピング扉の隙間風の笛吹き音を聴き分ける。
3. **熱感覚（赤外線）**：校正済みの携帯型赤外線サーモグラフィを用い、母線接続部、遮断器端子、ケーブル圧着端子、軸受部を走査する。表面温度が 70°C を超える箇所、または相間温度差 ΔT > 10 K を示す箇所は、直ちにカテゴリー1の重大欠陥として扱う。
4. **嗅覚**：過熱した電気絶縁材の刺激臭（オゾンやフェノール樹脂の焦げ臭）、微小漏洩したプロピレングリコール水溶液の甘い匂い、劣化鉛蓄電池から漂う硫黄臭（腐卵臭）に鼻を研ぎ澄ます。

### ステーション1：特別高圧・高圧受電室および開閉設備
- 35kVおよび10kV遮断器のスプリング蓄勢表示器が「蓄勢完了」を示していることを確認。
- ガス絶縁開閉装置（GIS）のSF6ガス圧力計が緑色の正常ゾーンにあることを確認。
- 直流制御母線の蓄電池充電電圧（125 VDC ± 2%）を確認し、非接地DC制御系に地絡警報が出ていないことを確認。

### ステーション2：変圧器室
- モールド変圧器のデジタル巻線温度計を確認（正常範囲：$60°\text{C} \sim 85°\text{C}$、警報閾値：110°C、自動遮断：130°C）。
- 強制空冷ファンの吸気障害がないか、ベアリングに振動がないかを確認。
- 油入変圧器の油面計、シリカゲル呼吸器の色（吸湿のない鮮やかな青色であること。ピンク色は湿気飽和を示し即時交換が必要）、タンク溶接部からの油にじみを確認。

### ステーション3：UPSおよび蓄電池室
- すべての静止形UPSモジュールの直流浮動充電電圧および充電電流を記録。
- 蓄電池室の環境温度を確認（$20°\text{C} \sim 25°\text{C}$ を厳格に維持。鉛蓄電池は 25°C から 8 K 上昇するごとに設計寿命が半減する）。
- 制御弁式鉛蓄電池（VRLA）の電槽膨れ、端子の腐食、電解液の漏れを目視確認。リチウムイオン蓄電池の場合は、BMSのセル間電圧不平衡（> 50 mV）がないことを確認。
- 水素排気ファンのガラリに手をかざし、正常な排気気流を確認。

### ステーション4：熱源プラント（中央冷凍機・ポンプ室）
- 冷凍機運転ログを確認：凝縮器アプローチ温度が ≤ 1.5 K であることを確認（ΔT_approach = T_cond, leaving - T_tower, entering）。2.5 K を超えるアプローチ温度は、伝熱管のスケーリングや汚れを示し、薬品洗浄が必要である。
- コンプレッサーの油面、油圧、油戻り温度を確認。
- 冷水ポンプの差圧（ΔP）を確認し、インバータ（VFD）がハンチングを起こさずにスムーズに追従していることを確認。

### ステーション5：二次冷却分配装置（CDU）
OpenViking `ALZJ-YW-2.6XZ10` に基づき、CDUはAI高密度クラスタの心臓部である：
- **圧力範囲**：一次施設水（FWS）供給圧力および二次技術冷却水（TCS）供給圧力が $0.15 \text{MPa} \sim 0.90 \text{MPa}$ の範囲にあることを確認。ポンプ差圧が < 1.0 bar であることを確認。
- **熱交換性能**：プレート熱交換器のアプローチ温度（ΔT_approach = T_TCS, supply - T_FWS, supply）が 8.0 K を超えていないことを確認。8.0 K 超過はプレート面の目詰まりや生物付着を示す。
- **流体化学性状**：校正済み光学屈折計を用いて二次冷却水をサンプリングする。プロピレングリコール濃度が**重量比25.0%**（± 1.0%）であることを確認（凍結防止 -11.5°C、破裂防止 -22.0°C）。導電率 < 10 μ S/ cm、pHは7.5〜9.0の範囲内。
- **物理的完全性**：CDU内部のドレンパンおよびベースフレームの乾燥状態を確認。連続線状漏水検知センサーが正しく敷設され乾燥していることを確認。膨張タンクの窒素封入圧力を確認（P_0 = P_fill - 0.2 bar）。

### ステーション6：AIホワイトスペースおよびNVL72ラック
OpenViking `ALZJ-YW-2.6XZ02` に基づく：
- **電力供給**：リモートパワーパネル（RPP）およびPDUを点検。赤外線サーモグラフィで遮断器端子部を走査し、緩みによる過熱を検知。
- **気流制御**：コールドアイルまたはホットアイルのキャッピングを点検。フリーアクセスフロア床下またはキャッピング境界の差圧が ≥ 5.0 Pa であることを確認。空きスロットにブランキングパネルが抜かりなく装着されていることを確認（1Uの欠落で毎秒25リットルの冷気がバイパスし、局所過熱を生む）。
- **液冷マニホールドおよび継手**：ラック内の垂直ヘッダーマニホールドを点検。計算トレイおよびNVLinkスイッチトレイに接続されるすべてのクイックディスコネクト継手（Danfoss FD83またはUQD）を点検する。液のにじみ、結晶化、液滴の形成は、直ちにトレイ隔離を要する作業停止条件である。マニホールド下のドレン受皿が清潔かつ乾燥していることを確認。

## 部屋を出る前の即時登録ルール

巡回中に欠陥や異常を発見した場合、**その部屋を退室する前に**設備管理台帳（CMMS）または物理的な不具合登録簿に記入しなければならない。

個人のスマートフォンで写真を撮り、「シフト終了時にまとめて記録しよう」とすることは厳禁である：
- 台帳に登録された欠陥には、正確なタイムスタンプ、資産番号、優先順位、および割り当てられた主担当者が付与される。
- スマートフォンの写真は、30分後に別の警報が鳴った瞬間に忘れ去られる個人の非公式メモに過ぎない。

発見した欠陥が機器の冗長性を損なっていたり、パラメータがSLA閾値を逸脱している場合、巡回点検を即座に中断し、無線で当直管理者に報告し、その場でインシデントチケットを発行せよ。昼食の席で「そういえばCDUポンプから水が漏れていた」と口にするような運用者は失格である。

## 記録する決定

- 巡回点検ルートの走破記録（開始・完了タイムスタンプ、巡回技術員の署名）。
- 6大点検ステーションすべてで記録された具体的な実測運転パラメータ。
- 二次冷却ループの現場屈折計濃度、導電率、pHの測定記録。
- 各室を退室する前に正式登録された不具合一覧、または「欠陥ゼロ」の明示的確認。

## 物理的責任分界（デマーケション）と定量的シフト監査プロトコル

シフト運用管理者は、設備の物理的境界（Ring 1: 受電・外構、Ring 2: 中央熱源・特高変電、Ring 3: ホール配電・二次CDU、Ring 4: 顧客ラック内部）における責任分界点（`DEMARC`）を厳格に維持し、以下の定量的監査基準を当日シート（Day Sheet）に記録しなければならない。

| シフト監査領域 | 監視・計測パラメータ | 正常運用エンベロープ | 即時介入・作業中止（Stop Work）閾値 |
| :--- | :--- | :--- | :--- |
| **2N受配電系統の負荷率上限** | バスA / バスB 定常負荷率 ($P_{\text{bus}} / P_{\text{rated}}$) | $\le 45.0\%$（片系喪失時 $\le 90.0\%$） | $> 45.0\%$ での新規ラック通電要求の即時拒絶 |
| **二次冷却ループ（CDU）水理・化学** | 供給圧力 $P_{\text{sup}}$、アプローチ温度 $\Delta T_{\text{PHE}}$、PG濃度 | $0.15\sim 0.90\,\text{MPa}$, $\Delta T_{\text{PHE}} \le 8.0\,\text{K}$, PG $25.0\% \pm 1.0\%$ | 差圧 $> 1.0\,\text{bar}$、導電率 $> 10\,\mu\text{S/cm}$、またはカプラー液滴 |
| **作業許可（PTW）とゼロエネルギー検証** | LOTO施錠、残留電荷放電、バイパス弁閉止確認 | 100% 現場ホスト同行・失効時刻前の完全復旧 | 承認MOPからの逸脱、または「ついで作業」の即時中止 |
| **インシデント時計とSLA通知** | 事象検知（$T_0$）、EOP安全状態確立、顧客第1報 | P1: $T_0 + 15\,\text{min}$ 以内に事実のみ通知 | 未確認の推測（仮説）の通知文への混入禁止 |
