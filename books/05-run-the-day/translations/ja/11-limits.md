# 11. この本が保有しないもの

データセンターのエンジニアリングと法的主権のすべてを抱え込んでいるかのように装う現場手引は、読者にとって極めて危険な存在である。運用の明晰さを保つためには、この本が保有するものと、他の正当な権威に属するものとの間に厳格な境界線を引かなければならない。

## 認証講習そのものは保有しない

この本は、あなたにいかなる資格証明も授与しない。
Certified Data Centre Facilities Operations Manager (CDFOM)、Certified Data Centre Facilities Operations Specialist (CDCS)、Certified Data Centre Sustainability Professional (CDCSP) は、専門の認定機関（EPI や Uptime Institute など）が所有する登録商標および独占的講習名である。

この本に含まれる内容は、それらの教育プログラムの公式カリキュラムでも、公認トレーニングマニュアルでも、試験対策集でもない。顧客の基本契約が施設管理者に対して特定の公的資格の保持を義務付けているなら、正式な講習を受講し、厳格な監督下の試験に合格し、発行元機関にライセンス料を支払え。あなたのデスクの上にある読み古されたペーパーバックの現場手引は、ISOの監査員や顧客の調達委員会を納得させる証拠にはならない。

## 規格、法規、ライブラリそのものは保有しない

この本は、国際規格、安全法規、サービスマネジメントフレームワークを、その規格番号、表題、発行年によって引用する。それらの著作権で保護された条文、付属書、計算表をそのまま転載することは意図的に行わない：
- **NFPA 70E（職場における電気安全規格）**：アークフラッシュ境界、保護具（PPE）カテゴリー、活線近接作業許可を法的に支配する。
- **OSHA 29 CFR 1910.147**：施錠・標識（LOTO）による物理的危険エネルギー隔離の法的義務を支配する。
- **ASHRAE TC 9.9**：データ処理環境の熱的許容エンベロープ（空冷機器のクラスA1〜A4、液冷機器のクラスW1〜W5 / W27〜W45）を規定する。ASHRAEは、その技術出版物の内容が著作権法により厳格に保護されており、書面による正式な許可なくAIの派生著作物として要約・学習・変換されることを認めていない旨を明示している。
- **ISO/IEC 20000 および ITIL**：サービスマネジメント、変更管理、構成管理データベースを支配する。

これらの規格の正規ライセンス版を、発行元（ANSI、NFPA、ASHRAE、ISO）から正式に購入せよ。現場のエンジニアリング書架に配備せよ。自社のMOPや障害報告書には、それらの条項番号を正確に引用せよ。著作権で保護された規格の文面を社内文書に貼り付け、それを現場固有の独自作成ルールであるかのように偽ってはならない。

## 顧客のビジネスそのものは保有しない

この本は以下を保有しない：
- 顧客のアプリケーションアーキテクチャ、災害復旧（DR）自動フェイルオーバー、または社内サーバーのテレメトリ。
- 施設の建築実施設計図、構造床荷重計算書、または自治体の開発許認可。
- キロワットあたりの契約リース料、電力会社との電気料金体系、または電力購入契約（PPA）。

それらの文書は、顧客、設計エンジニアリング会社、不動産事業者に排他的に帰属する。秘密保持契約（NDA）によって保護された安全な施設アーカイブに保管される。運用部門がそれらに触れるのは、物理的な接続境界と契約上のSLA提供限界を検証するときのみである。

## 物理試験や数値計算モデルそのものは保有しない

本シリーズのこれまでの巻が、物理的な試験器、データストリーム、コミッショニング試験、気流数値モデルを保有している：
- NVL72検証用の高密度液冷負荷装置を製作・校正する必要があるなら、**第1巻**を開け。
- 過渡的な温度スパイク、流量、速報レポートを解析する必要があるなら、**第2巻**を開け。
- レベル1からレベル5までの7枚のコミッショニング検証シートを実行する必要があるなら、**第3巻**を開け。
- 物理的な多点風速計の実測値とCFD報告書を突き合わせて監査する必要があるなら、**第4巻**を開け。

この本は、物理的なコミッショニングが完了し、本番の商用運用が開始された地点から始まる。運用部門は将来の構成変更に備えて負荷試験を計画したりCFD監査を依頼することはあっても、日常の根拠なき当て推量や未検証の感覚を、校正された物理測定値の代わりに用いることは断じて許されない。
