# 10. ورقة اليوم الرئيسية (Master Day Sheet)

ورقة اليوم الرئيسية هي السجل القانوني والفني والتشغيلي الملزم لوردية مركز البيانات.

```
+-----------------------------------------------------------------------------+
| هيكل ورقة اليوم الرئيسية |
| |
| [القسم 1] تدقيق تسليم ما قبل الوردية (التعطيلات، التصاريح، الحوادث، MOP) |
| | |
| [القسم 2] سجل الأعمال المصرح بها وتصاريح PTW (النطاق، LOTO، انتهاء الوقت) |
| | |
| [القسم 3] سجل جولة التفتيش المادي للوردية (6 محطات، القياسات متعددة الحواس) |
| | |
| [القسم 4] السجل الزمني للحوادث والتصعيد (التصنيف، إخطار SLA خلال 15 دقيقة) |
| | |
| [القسم 5] تدقيق السعة والتكرارية (قاعدة طاقة 45%، هيدروليكا CDU) |
| | |
| [القسم 6] الجملة الختامية النهائية (التوقيع الفردي الحاسم غير القابل للتعديل)|
+-----------------------------------------------------------------------------+
```

![Manager Shift Closeout Sheet](../figures/fig-07-manager-shift-closeout-sheet.png)

انسخ العناوين الواردة أدناه إلى برنامج تشغيل منشأتك أو سجل التسليم المطبوع. يمثل السطر الفارغ في ورقة اليوم جزءًا من المنشأة لم تقم بفحصه، وخطرًا لم تقم بإدارته، وانقطاعًا ستتحمل مسؤوليته وحدك.
