ترجمة بمساعدة الذكاء الاصطناعي من الطبعة الإنجليزية.

# 2. أفراد الوردية

لا يعمل مركز البيانات بالقياسات البرمجية عن بُعد فحسب، بل يعمل بكفاءة الفنيين الذين يجوبون أرضيات المنشأة، وتراخيصهم القانونية، وانضباطهم المادي. إذا كنت لا تعرف المؤهلات الدقيقة للأشخاص الذين يحملون المفاتيح الرئيسية، فأنت لا تسيطر على المنشأة.

```
+-----------------------------------------------------------------------------+
| مصفوفة مؤهلات الوردية ونطاق الصلاحيات |
| |
| الدور الشهادات والتراخيص المطلوبة نطاق العمل المصرح به |
| ------------------ ---------------------------- ----------------------- |
| مدير الوردية CDFOM / ترخيص إدارة العمليات اتفاقيات SLA والتصاريح |
| كبير الكهربائيين ترخيص الجهد العالي/المنخفض لوحات التوزيع، المحولات |
| أخصائي التبريد ترخيص التبريد وتكييف الهواء المبردات، وحدات CDU |
| فني الوردية شهادة تشغيل مرافق مراكز البيانات الجولات، القياسات، السجل|
| مسؤول السلامة OSHA 30 / إسعافات أولية / إنعاش إشراف الموردين، LOTO |
+-----------------------------------------------------------------------------+
```

## التراخيص والمتطلبات القانونية

في مراكز بيانات الذكاء الاصطناعي عالية الكثافة التي تحتوي على أنظمة تبريد سائل بقدرات ميغاواتية ومحطات فرعية كهربائية بقدرات تصل إلى عشرات الميغافولت أمبير، يُعد فنيو المرافق العامة غير المتخصصين خطرًا وجوديًا. تتطلب المهام التشغيلية شهادات معتمدة قانونيًا:
- **العمليات الكهربائية**: أي مناورة تبديل، أو سحب/إدخال للقواطع، أو اختبار تحت الجهد على لوحات الجهد المتوسط (10kV/35kV) أو الجهد المنخفض (400V/480V) يجب أن يتم حصريًا بواسطة كهربائيين معتمدين يحملون تراخيص حكومية سارية.
- **عمليات التبريد والمواد الكيميائية**: يتطلب تشغيل مبردات الطرد المركزي، وأبراج التبريد الصناعية، ومحطات الضخ الابتدائية/الثانوية فنيي تبريد مرخصين ومعتمدين في التعامل مع وسائط التبريد المضغوطة ومعالجة المياه الصناعية.

وفقًا لإرشادات تشغيل OpenViking (`ALZJ-YW-2.6XZ10`)، فإن عمليات التبريد السائل التي تتضمن وحدات التوزيع الثانوية (CDU)، وأنظمة مياه المنشأة الابتدائية (FWS)، وموزعات التبريد على مستوى الكبائن تتطلب تدريبًا تقنيًا موثقًا على المبيدات الحيوية الكيميائية، وقياس تركيز الغليكول، وبروتوكولات احتواء التسرب.

إذا كان أحد الفنيين في الوردية يفتقر إلى الترخيص القانوني للتبديل على الجهد العالي، فلا يجوز أن يظهر اسمه في بطاقة مناورة كهربائية. وإذا وُجد مقاول غير مرخص يفتح باب لوحة كهربائية، يتوقف العمل فورًا.

## قاعدة الشخصين (The Two-Person Rule)

لا يجوز إطلاقًا إجراء أي عملية تبديل حرجة، أو سحب قاطع جهد عالٍ، أو عزل صمام في حلقة تبريد ابتدائية بواسطة فني يعمل بمفرده.

تتطلب قاعدة الشخصين وجود:
1. **المنفذ (The Performer)**: الفني المعتمد الذي يحمل إجراء العمل المعتمد (MOP) ويلمس ماديًا مفتاح التحكم، أو مقبض القاطع، أو صمام العزل.
2. **المراجع (The Checker)**: فني مؤهل بنفس الدرجة يقف خلف المنفذ مباشرة، ويحمل الإجراء المطبوع، ويقرأ كل خطوة بصوت عالٍ، ويتحقق من ملصقات المعدات (مثل التأكد من أن تسمية القاطع `SWG-01-4A` تطابق بطاقة العمل قبل سحبه)، ويحافظ على الاستعداد للإيقاف في حالات الطوارئ.

الواجب الوحيد للمراجع أثناء العملية هو التحقق والسلامة. إذا بدأ المنفذ في الوصول إلى مقبض القاطع الخطأ أو أدار صمامًا بتسلسل خاطئ، فإن المراجع يمتلك السلطة المطلقة لإيقاف العملية على الفور.

```
+-------------------------------------------------------------------------+
| قاعدة الشخصين |
| |
| +------------------+ +------------------+ |
| | المـراجـع | | المـنـفـذ | |
| | يحمل ورقة MOP | | يلمس المفتاح | |
| | يقرأ الخطوة جهراً| ---------> | يشير للرمز التعريفي |
| | يطابق رمز المعدة| | ينفذ الإجراء | |
| | يملك سلطة الإيقاف| | يبلغ بالحالة | |
| +------------------+ +------------------+ |
+-------------------------------------------------------------------------+
```

## سلطة إيقاف العمل (Stop Work Authority: SWA)

يمتلك كل فرد يدخل المنشأة—من مدير العمليات التنفيذي إلى متدرب تمديد الكابلات—سلطة كاملة وغير مشروطة لإيقاف العمل (SWA).

يتم تفعيل سلطة إيقاف العمل متى ما:
- تباعدت الظروف المادية في الغرفة عن الافتراضات المكتوبة في إجراء MOP.
- انطلق إنذار غير متوقع في نظام إدارة المبنى (BMS) أو نظام مراقبة الطاقة الكهربائية (EPMS).
- تم اكتشاف قطرات ماء، أو برك سوائل، أو روائح كيميائية غير طبيعية بالقرب من المعدات الكهربائية.
- فُقدت أو تضررت حواجز السلامة المطلوبة، أو معدات الحماية الشخصية (PPE)، أو أقفال العزل (LOTO).
- شعر المشغل بالارتبาก أو عدم اليقين بشأن الخطوة الإجرائية التالية.

عند تفعيل سلطة إيقاف العمل:
1. توضع المعدات فورًا في أقرب حالة آمنة ومستقرة ومحددة في الإجراء.
2. توضع الأدوات أرضًا؛ ولا يتم تحريك أي صمامات أو مفاتيح إضافية.
3. يُستدعى مدير الوردية إلى موقع العمل.
4. لا يُستأنف العمل إلا بعد حل الغموض وتوثيقه كتابيًا على تصريح العمل.

لا يجوز أبدًا تأنيب أو معاقبة أو استجواب أي فني أو مقاول لاستخدامه سلطة إيقاف العمل بحسن نية. إن ثقافة المنشأة التي يتردد فيها الفنيون في إيقاف العمل بسبب ضغط الجدول الزمني هي منشأة تنتظر انقطاعًا كارثيًا للتيار الكهربائي بملايين الواطات.

## الجولة الميدانية المشتركة لمدة 30 دقيقة

إياك أن تنفذ تسليم وتسلم الوردية وأنت جالس خلف المكاتب في غرفة التحكم. إن التسليم الذي يتم على فنجان قهوة هو تخلٍ صريح عن الواجب.

يجب على مدير الوردية القادم ومدير الوردية المغادر إكمال جولة تفتيش ميدانية مادية مشتركة وإلزامية مدتها 30 دقيقة للمناطق الحرجة الست في المنشأة قبل توقيع ورقة اليوم:
1. **محطة التحويل والمفاتيح ذات الجهد المتوسط**: فحص قواطع 35kV/10kV، ومؤشرات شحن زنبرك القواطع، ومقاييس ضغط غاز SF6، وحالة شاحن بطاريات التحكم DC.
2. **غرف المحولات**: فحص درجات حرارة ملفات المحولات الجافة/الزيتية (التأكد من أن T < 90°C)، وتشغيل مراوح التبريد، والاستماع إلى التوافقيات الصوتية غير الطبيعية.
3. **غرف أجهزة UPS والبطاريات**: التحقق من جهد الشحن العائم لقضبان التوزيع DC، ودرجات حرارة مجموعات البطاريات (T < 25°C)، وفحص تآكل أقطاب البطاريات أو انتفاخها، والتحقق من تدفق هواء مراوح عادم الهيدروجين.
4. **محطة التبريد المركزية والمضخات**: التحقق من درجة حرارة اقتراب مكثف المبرد (ΔT_approach ≤ 1.5 K)، وضغوط زيت الضاغط، وترددات مغيرات السرعة (VFD)، والاهتزازات الصوتية.
5. **محطات التبريد السائل (CDU)**: التحقق من الضغوط الابتدائية والثانوية (0.15 - 0.90 MPa)، والضغط التفاضلي للمضخات (ΔP < 1.0 bar)، ومستويات سائل خزان التمدد، وتفتيش أحواض التجميع بحثًا عن أي رطوبة.
6. **قاعات خوادم الذكاء الاصطناعي**: السير في الممرات الباردة والساخنة، وفحص وحدات توزيع الطاقة (PDUs) بحثًا عن النقاط الساخنة، والتحقق من الضغط التفاضلي للأرضية المرتفعة (ΔP ≥ 5 Pa)، وفحص قارنات الفصل السريع (FD83/UQD) بحثًا عن أي ترشيح.

يجب على كلا المديرين السير في المسار بأكمله جنبًا إلى جنب. إذا رفض المدير المغادر السير في الموقع، يفترض المدير القادم أن جميع معدات المنشأة في حالة غير محققة ويسجل هذا الرفض في سجل التسليم.

## القرارات الواجب تسجيلها

- أسماء جميع أفراد الوردية، وأرقام تراخيصهم التي تم التحقق منها، وتواريخ انتهائها.
- تأكيد التزام العمليات ذات الجهد العالي والعمليات الهيدروليكية الحرجة بقاعدة الشخصين.
- أي تفعيل لسلطة إيقاف العمل (SWA) خلال الوردية، مع تفصيل السبب والحل.
- توقيع كلا المديرين القادم والمغادر على إتمام الجولة الميدانية المشتركة لمدة 30 دقيقة.
