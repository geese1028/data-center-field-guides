ترجمة بمساعدة الذكاء الاصطناعي من الطبعة الإنجليزية.

# 5. التغيير

معظم انقطاعات مراكز البيانات الكارثية لا تنجم عن ضربات الصواعق، أو الزلازل، أو عيوب التصنيع في المكونات. إن معظم الانقطاعات الكارثية هي تغييرات صُنفت باستهتار على أنها "صيانة روتينية".

```
+-----------------------------------------------------------------------------+
| دورة حياة تنفيذ التغيير |
| |
| [T - 72h] مراجعة هندسية: تقييم المخاطر، وتدقيق نقاط الفشل الفردية (SPOF) |
| | |
| [T - 24h] موافقة مجلس مراجعة التغيير (CAB): قبول المخاطر كتابيًا |
| | |
| [T - 02h] التحقق قبل النافذة: سلامة الأنظمة التكرارية 100% ودون إنذارات |
| | |
| [T = 00h] فتح نافذة الصيانة: نشر الحالة غير الطبيعية على لوحة التحكم |
| | |
| [T + التنفيذ] تنفيذ MOP خطوة بخطوة تحت مظلة قاعدة الشخصين |
| | |
| [T + التحقق] التحقق الوظيفي تحت الحمل: تأكيد استقرار الخدمة بالقياسات |
| | |
| [T + الإغلاق] اعتماد ما بعد التغيير: مسح الحالة غير الطبيعية وتحديث السجل |
+-----------------------------------------------------------------------------+
```

## ما الذي يشكل تغييرًا

التغيير هو أي إجراء مادي أو كهربائي أو ميكانيكي أو منطقي يؤدي إلى تعديل:
- كيفية تعطل البنية التحتية الحيوية في ظل الظروف العابرة.
- كيفية تشغيل المنشأة أو مراقبتها أو التحكم فيها من قِبل الفنيين.
- مستوى التكرارية أو السعة أو مسارات التغذية المسلمة للعميل.

إن استبدال مؤشر LED تالف بمكون مطابق من نفس المصنع هو صيانة، شريطة ألا يتطلب العمل عزلاً كهربائيًا وألا يقدم مخاطر حدوث ماس كهربائي في مسارات التحكم. أما استبدال قاطع دائرة بآخر له منحنى فصل مختلف، أو تعديل معدل تسارع محول التردد (VFD)، أو تعديل معاملات ضبط حلقة PID في نظام إدارة المبنى، أو تعديل نقطة ضبط حرارة الحلقة الثانوية لوحدة CDU بمقدار 0.5 K، فهو تغيير كامل الأركان.

إن نقل حمل الخوادم الحيوية من المسار الكهربائي A إلى المسار B—حتى لمدة عشرين دقيقة—هو تغيير حرج. إذا حدث اضطراب عابر غير متوقع على المسار B أثناء عزل المسار A، فستسقط المنشأة بأكملها. إذا أثار أي إجراء تشغيلي نقاشًا حول ما إذا كان يُعد صيانة أم تغييرًا، فاعتبره تلقائيًا تغييرًا دون تردد.

## مجلس مراجعة التغيير وقبول المخاطر

يتطلب كل تغيير موافقة رسمية من مجلس مراجعة التغيير (Change Advisory Board: CAB) قبل التنفيذ.

يجب أن توثق وثائق التقديم لمجلس CAB ما يلي:
1. **المبرر التشغيلي**: لماذا يجب إجراء التغيير. إن القول بأن "فني المورد كان موجودًا بالفعل في الموقع لمهمة أخرى" ليس مبررًا مقبولاً على الإطلاق. المبررات المقبولة هي معالجة خلل مسجل، أو استيعاب توسعة سعة متعاقد عليها، أو تخفيف ثغرة أمنية أو سلامة محددة.
2. **مستوى المخاطر التشغيلية**: مصنفًا وفقًا للتأثير المحتمل على العميل:
 - **المستوى 1 (حرج)**: أعمال تقتحم التوزيع الكهربائي الحي أو حلقات التبريد الابتدائية التي تخدم أحمال خوادم الإنتاج الفعلية. تتطلب توقيع مدير العمليات التنفيذي وإخطارًا إلزاميًا للعميل.
 - **المستوى 2 (رئيسي)**: العمل على الأنظمة التكرارية الاحتياطية (N+1) حيث قد يؤدي تعطل النظام الحي المتبقي أثناء النافذة إلى تأثير مباشر على العميل.
 - **المستوى 3 (ثانوي)**: عمل غير مقتحم على الأنظمة المساعدة أو المساندة حيث يضمن الفصل المادي والكهربائي عدم وجود مخاطر على الخدمة.
3. **قابل المخاطر (The Risk Acceptor)**: قائد أول يحمل السلطة التعاقدية والمالية لتحمل مخاطر التغيير. الفني الميداني الذي يحمل مفتاح عزم الدوران ليس هو قابل المخاطر. إذا تعذر الوصول إلى قابل المخاطر المحدد بالاسم، فلا تُفتح نافذة الصيانة.

## لوحة الحالة التشغيلية غير الطبيعية

أثناء نافذة الصيانة، تدخل المنشأة في **حالة تشغيلية غير طبيعية (Abnormal Operating State)** مؤقتة ومعلنة.

يجب أن تكون الطبيعة الدقيقة لهذه الحالة غير الطبيعية:
- مكتوبة بشكل بارز على السبورة البيضاء في غرفة التحكم المركزية.
- معروضة كشريط تحذيري رقمي عبر نظام إدارة المبنى (BMS) على جميع شاشات المشغلين.
- مسجلة بوضوح في سجل تسليم الوردية.

```
+-------------------------------------------------------------------------+
| لوحة الحالة غير الطبيعية في غرفة التحكم |
| |
| [العارض النشط] عزل المبرد CH-03 لإجراء عمرة صيانة شاملة للمكثف |
| [التكرارية المتبقية] 3 من أصل 4 مبردات تعمل؛ التكرارية = N+0 |
| [المخاطر] فقدان CH-01 أو CH-02 يطلق تفريغ الأحمال التلقائي |
| [النافذة] 2026-10-14 من 10:00 إلى 14:00 UTC | قابل المخاطرة: J. Vance |
| [الموعد الحاسم للتراجع] 13:00 UTC (إن لم تكتمل إعادة التجميع، تراجع) |
+-------------------------------------------------------------------------+
```

إن الحالة غير الطبيعية التي تنتهي بالمعنى المادي (كأن يشد الفني الميكانيكي البرغي الأخير) ولكن لم يتم إلغاؤها رسميًا على لوحة غرفة التحكم وسجل التسليم تظل خطرًا تشغيليًا قائمًا. إذا انطلق إنذار غير متوقع بعد ساعتين، فسيقوم أفراد الوردية القادمة باستكشاف الأخطاء بناءً على افتراض أن المنشأة في وضعها الطبيعي، مما يؤدي إلى قرارات تبديل خاطئة وفصل متسلسل للمعدات.

## التحقق قبل النافذة وتنفيذ خطة التراجع

إياك أن تبدأ نافذة تغيير بناءً على افتراض أن الأنظمة التكرارية تعمل بشكل سليم. قبل ساعتين من فتح النافذة (T-2 h)، يجب على فريق الوردية إجراء تدقيق شامل:
- التحقق من أن جميع الوحدات التكرارية المتبقية (مسارات التغذية الكهربائية 2N، ومبردات N+1، والمولدات الاحتياطية) تعمل بثبات ودون أي إنذارات نشطة أو كامنة.
- التأكد من عدم وجود توقعات لطقس قاسي (عواصف رعدية، عدم استقرار في الشبكة الكهربائية، موجات حر شديدة) خلال نافذة التنفيذ.
- التأكد من أن دعم خدمات الطوارئ الخارجية (مشغلو الشبكة العامة، وموردو الوقود، ومقاولو الصيانة المتخصصة) في وضع الاستعداد.

يجب أن تتضمن كل وثيقة MOP **موعدًا نهائيًا قاطعًا للتراجع (Back-Out Deadline)**. الموعد النهائي للتراجع هو النقطة الزمنية المطلقة أثناء نافذة الصيانة والتي يجب عندها التوقف عن مواصلة العمل وإعادة المنشأة إلى حالتها المرجعية، بغض النظر عن مدى التقدم المحرز. إذا كانت نافذة الصيانة مدتها ست ساعات وتتطلب خطة التراجع ساعتين، فإن الموعد النهائي للتراجع يحين بدقة بعد أربع ساعات من بدء النافذة (T+4 h). إذا لم يتم اختبار المكون الجديد بنجاح بحلول تلك الدقيقة، يجب على الفني البدء في إجراءات التراجع فورًا. لا تسمح أبدًا للمقاول بالتفاوض للحصول على "ثلاثين دقيقة إضافية فقط" بينما تنفد نافذة الصيانة.

## التحقق الفني مقابل الإتمام التجاري

لا يُغلق التغيير عندما يحزم المورد صناديق أدواته، ويسلم الفاتورة، ويغادر بوابة الأمن. يُغلق التغيير فقط عندما يكمل مدير المنشأة تحققًا هندسيًا صارمًا مقابل معايير SLA الأساسية:
- تم تشغيل المعدات المعدلة تحت الحمل الحراري والكهربائي الحي لفترة استقرار محددة (عادة من 30 إلى 60 دقيقة).
- تؤكد قياسات المراقبة عن بُعد أن درجات حرارة التشغيل، والضغوط، والاهتزازات، وتوازن مراحل التيار الكهربائي تطابق مواصفات ما قبل التغيير.
- أعيد تفعيل جميع الإنذارات التي تم تعطيلها أو كتمها أثناء الإجراء واختُبرت وظيفيًا بنجاح.
- يؤكد مسجل تسلسل الأحداث (SOE) عدم حدوث أي طفرات عابرة غير مسجلة أو أخطاء أرضية أثناء عمليات التبديل.

إذا تعذر إكمال التحقق الفني بشكل مرضٍ، يُصنف التغيير رسميًا على أنه **مُعلق مع وجود خلل نشط**، ويتم إصدار تذكرة حادث، ويوضع النظام تحت المراقبة المستمرة مع مهندس مخصص.

## القرارات الواجب تسجيلها

- السجل الكامل للتغييرات المنفذة اليوم، موضحًا قيم المعايير القديمة والجديدة.
- اسم ومسمى الشخص الرسمي القابل للمخاطر لكل تذكرة تغيير.
- طوابع وقت البدء والإغلاق الدقيقة لكل نافذة صيانة.
- الحالات غير الطبيعية المسجلة والمعلنة على لوحة غرفة التحكم وسجل التسليم.
- الاعتماد الفني الرسمي الموقع تحت ظروف الحمل الحي.
