# 丛书 brief：液冷假负载三部曲

**状态：** 第 1 本已交 KDP 审。第 2、第 3 本按 2026-10-11 的目标在写。  
**语言：** 英文原稿。  
**形态：** 每本 1.5–2.5 万词现场手册。  
**检索：** `ov find "问题" -u viking://resources/book-summaries`

不写客户名、现场编号、图纸和参数表。NVIDIA、CDU 规范只按公开接口讲方法，不贴原文。

## 系列

英文名暂定 *Liquid Load Bank Field Guides*。

阅读顺序：设计制造 → 读数据 → 做一次 NVL72 测试。后一本假设读者做过前一本。

## 1. Design and Build an NVIDIA-Aligned Load Bank

**读者：** 要做液冷假负载的测试工程师和设备负责人。  
**承诺：** 能列出一台可对接 NVL72 机柜液冷接口的假负载该有什么、怎么验收样机，而不是交出制造图纸。

**大纲**
1. 假负载在液冷测试里代替什么
2. 热负荷、流量、压差、温度测点要覆盖哪些量
3. 和机柜、CDU、管路的接口边界
4. 样机验收：功能、安全、仪表、文件
5. 不该做的事：拿现场图纸和厂商规范原文当设计包

**材料够用：** 假负载需求、样机验收方案、采集控制说明、NVL72 液冷流速资料、CDU 自认证资料（只作边界，不进正文）。  
**缺：** 可公开引用的 NVIDIA 接口要求。写前要你确认哪些数字可以写，哪些只能写“按厂商当时规范核对”。

## 2. Read and Use Load Bank Data

**读者：** 拿到测试曲线、还不会判断的人。  
**承诺：** 能从流量、进出水温度、压力和功率里判断这次测试是否有效。

**大纲**
1. 一条有效记录至少要有哪些通道
2. 如何对时、去坏点、看稳态
3. 用温差和流量核对热负荷，而不是只看功率设定
4. 什么样的曲线说明仪表、阀门或气流/液路有问题
5. 报告里写结论，不贴原始表

**材料够用：** 采集控制说明、验收记录类文件。方法够写。原始客户数据不进书。

## 3. Run an NVL72 Test Project

**读者：** 第一次把假负载用进机柜级液冷测试的项目负责人。  
**承诺：** 能排一次从方案、安全、执行到收口的测试，而不是一份某个现场的施工计划。

**大纲**
1. 测试要证明什么，不证明什么
2. 人、窗口、隔离、应急
3. 假负载、CDU、机柜、仪表怎么串成一次试验
4. 执行顺序和停机条件
5. 收口：数据是否够用，缺陷怎么记

**材料够用：** 液冷测试实施规程、测试方案、验证服务说明。现场名、考勤、报价、单线图不进书。
